# Work Journey Board 티저 사이트

Work Journey Board 소개를 위한 정적 사이트입니다.

## 파일 구성

- `index.html`: 사이트 메인 페이지
- `style.css`: 화면 스타일과 반응형 디자인
- `motion.js`: 화면 등장·업무 기록의 모션 효과
- `icon.svg`, `wordmark.svg`: 앱에서 사용하는 아이콘과 워드마크
- `gowun-dodum.woff2`: 사이트에서 사용하는 고운돋움 서체
- `font-license.txt`: 고운돋움의 SIL Open Font License 1.1 전문

## 다른 프로젝트에 배포하기

1. 압축을 풀어 모든 파일을 같은 폴더에 둡니다.
2. 해당 폴더의 내용물을 다른 프로젝트의 정적 파일 디렉터리 또는 정적 호스팅 서비스의 배포 폴더에 복사합니다. 파일 사이의 상대 경로를 유지합니다.
3. 웹 서버가 `index.html`을 기본 페이지로 제공하도록 설정합니다. 이 사이트에는 별도의 빌드 과정이나 서버 프로그램이 필요하지 않습니다.
4. 배포 후 메인 화면의 다운로드 버튼이 `https://github.com/chs2147/work-journey-board/releases`로 이동하는지 확인합니다.

프로젝트가 다른 기본 페이지를 이미 사용 중이라면, 기존 파일을 덮어쓰기 전에 별도의 하위 폴더나 독립된 배포 경로에 복사하세요.

## 참고

- 다운로드 링크는 GitHub 릴리즈 목록으로 직접 연결됩니다.
- 소개 화면의 업무 기록은 설명을 위한 가상 예시입니다.
- 사이트는 로컬 서체 파일을 사용하며 Google Fonts 등 외부 글꼴 호출이 필요하지 않습니다.
- 앱 아이콘과 워드마크는 Work Journey Board 저장소의 원본 파일입니다.
- 폰트를 함께 배포할 때 `font-license.txt`를 유지하세요.
- 이 압축 파일은 정적 사이트 파일이며, 이전 사이트의 호스팅 설정과 접근 권한은 포함하지 않습니다.
