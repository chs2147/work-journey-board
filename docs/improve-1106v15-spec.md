# 개선 v15 — Feature List 운영 문서와 시그니처 구분선

사용자 요청: 별도 브랜치 없이 main에서 작성·배포. 대상 앱 1.18.1, DB 구조 v14 유지.

## Feature List 문서 체계

[정본 운영 규칙](features/README.md). 현재 앱 기능을 고정 ID로 식별하고 최초 제공·RC·개선·제거 버전과 출시 근거를 남긴다. 현재 제공과 제거/대체·계획을 분리한다. 제품 ID와 독립 앱 버전, 배포 프로필(Windows 기본/macOS/Windows 오프라인), DB·문서 스키마를 구분한다.

현재 카탈로그는 활성 229개, 제거/대체3개, 계획3개다. 기능 분해 단위에 따라 센 값이며 변경 건수·UI 버튼 수와 다르다. 초기 도입은 README 출시 이력을 근거로 하며 Universe의 RC 선행 검증도 별도로 기록한다. 1.18.0 기준선은 출시 후 소급 정리했음을 표시한다.

JSON 정본 → 현재 Markdown·제품별 버전 스냅샷·검토용 Excel을 생성한다. CI에서 ID·버전·근거 경로·프로필 상속·현재 스냅샷·Excel 셀을 검사한다. 독립 파생 제품은 상위 고정 스냅샷과 자체 버전·차이표를 등록하는 계약을 문서화했고 예시는 현재 제공 제품으로 집계하지 않는다. 앱 런타임에는 기능 목록 UI/토글을 추가하지 않는다.

Excel은 안내/기능/버전/파생판/변경/버전목록/근거/미제공/운영/검토의10개 시트, 필터·고정 머리·출처 링크·줄바꿈·검토 상태 드롭다운을 제공한다. 검토 사본과 정본 재생성을 구분해 의견 손실을 막는다.

목록 정리 중 가이드06의 전용 AI 지시문 버튼 설명이 현행 요약 패널과 맞지 않아, 최종본 복사 후 외부 AI를 사용하고 수정본에 보관하는 실제 동작으로 정리한다. AI API 요약은 미제공 계획으로 기록한다.

## 시그니처 구분선

기존 `--line: #e9e1d5`와 업무 타임라인 배경 `#ede6dc`의 대비는 약1.05:1이다. 구분선 전용 `--timeline-divider`를 도입한다. 라이트·다크는 기존 선 토큰을 사용하고 시그니처만 `#947b62`로 지정한다.

년월 머리·접힌 월 머리·각 주 행의 아래쪽1px 직각 선에 적용한다. 기존 두께·여백·글자 위계·목록 순서·접기 동작은 유지한다. 시그니처 페이지와 약3.22:1, 현재 주 강조면과 약3.37:1 대비가 목표다. 실제 계산 스타일과 화면으로 확인한다.

## 배포와 검증

1.18.0의 사용자 기능은 그대로이며 문서 체계와 시각 대비 보정으로1.18.1 패치 배포한다. Excel 원본 일치·소스/버전 근거 검사, 세 테마 실제 화면·대비 확인, 기존 인사이트 E2E·타입·린트·포맷·웹 빌드·가이드를 확인한다. main에 커밋·푸시 후 CI·Windows 기본판·macOS 유니버설 빌드·정식 릴리스를 확인한다.
