## 1. 지금 구조(확인한 사실)
- 일지를 열 때 `openJournalAt`(session.ts): 연결 설정(`PRAGMA journal_mode=DELETE`) → `quick_check` → `migrate`. **새 구조 판정은 맨 마지막 `migrate`** 에서 `NewerSchemaError`를 던지고, 화면은 일반 "오류" 상태로 글 한 줄만 보여 준다(무엇을 해야 하는지·업데이트 단추 없음). 새 판 확인·설치(`updateStore`)는 **일지가 열린 상태에서만** 화면에 나온다.
- 공간 전환(`switchWorkspace`)·저장 위치 바꾸기도 같은 `openJournalAt`이라 실패 글만 알림으로 뜬다. Universe는 다른 공간을 열 때 구조가 다르면 이미 건너뛴다. 업데이트 전 백업(`preUpdateBackupClosed`)은 다른 공간 일지를 연결 설정까지 한 뒤 사본만 만든다.
- 칸반 섹션 순서: 사용자 섹션은 `kanban_section.sort_order`, ⋯ 메뉴 [왼쪽으로/오른쪽으로]만. TODO는 맨 앞, DONE은 맨 끝 고정. 열은 같은 폭으로 화면을 나눠 씀(가로 넘치면 스크롤).
- 칸반 상단: 상단 막대(제목·저장됨) 아래 **별도 도구 줄**(업무 거르기·기간 아이콘·[업무 항목 추가]·[섹션 추가]). 주간 보드는 상단 막대 한 줄에 주 이동·보기 아이콘 | 검색·태그·[업무 추가]·[주간 요약]·[내보내기]·저장됨.
- 카드 추가 창(`ItemDialog`): 업무 선택 상자가 다른 입력과 같은 바탕이라 눈에 띄지 않음. 시작 시각·마감일은 줄 오른쪽 ⏰⏳ 작은 아이콘(또는 `Alt+O`·`Alt+U`)으로만 — 있는지 알기 어려움. 단추 [취소]·[추가하고 계속]·[추가].
- 업무 타임라인: 이번 주는 강조 상자(안쪽 여백)라 **지난 주보다 오른쪽으로 12px 밀림**. 요일 칸은 36px에 `수` / `10/21` 두 줄로 좁음. 완료일 칩이 **항목 글 앞**(✓ 바로 뒤)이라 글 시작 위치가 줄마다 다름. 상단 [기간: 최근 12주] 드롭다운이 바탕색과 같아 묻힘.

## 2. A — 새 구조 일지는 열지 않고 "업데이트 필요" (시안 ①)
### 2-1. 판정 순서(쓰기 0)
1. 파일을 연 직후 **어떤 PRAGMA·쓰기보다 먼저** `app_meta.schema_version`만 읽는다(읽기 전용 SELECT).
2. 앱이 아는 최신(`LATEST_SCHEMA_VERSION`)보다 크면 → 연결을 **바로 닫고** `NewerSchemaError`. 연결 설정·무결성 검사·마이그레이션·자동 백업·설정 저장·Cabinet 복원 모두 하지 않는다.
3. 같거나 낮으면 지금처럼(연결 설정 → 검사 → 필요하면 직전 백업 후 올리기).
- 같은 검사를 쓰는 곳: 앱 시작, 공간 전환, 저장 위치 바꾸기/옮기기, 복원 화면 뒤 다시 열기, 업데이트 전 다른 공간 백업(새 구조면 그 공간은 건너뜀 — 백업도 연결 설정 전에 판정).
- **열려 있는 동안 다른 PC(동기화 폴더)에서 새 판이 올린 경우**: 창이 다시 활성화될 때·자동 백업 직전에 같은 값을 읽어(가벼운 SELECT 1회) 새 구조면 예약 저장을 버리지 않고 멈춘 뒤 같은 화면으로 바꾼다(쓰기 중단). — 결정 A2

### 2-2. "업데이트 필요" 화면
- 보드 자리 전체. 문구는 "일지 데이터와 앱 버전이 호환되지 않는다"는 뜻을 바로 전한다 — 외래어(앱·버전·데이터·DB·업데이트·워크스페이스)는 필요한 곳에 그대로 쓴다(2026-11-12 사용자 지시).
  - 제목: **"앱 업데이트가 필요합니다"**
  - 설명: "이 일지 데이터는 지금 설치된 앱 버전과 **호환되지 않습니다**. 더 최신 버전의 앱에서 저장된 데이터입니다. 데이터 손상을 막기 위해 일지를 열지 않았습니다 — 앱을 최신 버전으로 업데이트한 뒤 이용해 주세요. 일지 데이터는 변경되지 않았습니다."
- 정보: 워크스페이스 이름·폴더 경로·**데이터 버전**(`DB v21 (이 앱은 DB v20까지 지원)`)·**앱 버전**.
- 단추: **[업데이트 확인]**(주 단추 — 일지 없이도 최신 버전 확인·내려받기·SHA256 확인·설치. 설치 전 백업은 연결을 열지 않는 파일 복사 `_pre-update`) · [릴리스 페이지 열기](기본 브라우저) · [다른 워크스페이스 열기](둘 이상일 때) · [다른 일지 폴더 선택].
- 앱을 켤 때 자동 최신 버전 확인(지금 규칙 그대로 1번)은 이 화면에서도 돈다 — 최신 버전이 있으면 단추가 "1.31.0으로 업데이트"로 바뀜.
- 워크스페이스 전환으로 호환되지 않는 공간을 고르면: 지금 공간은 **그대로** 두고 확인 창 "이 워크스페이스의 데이터는 지금 앱 버전과 호환되지 않습니다 — [업데이트 확인] [닫기]".
- 다른 공간 읽기(Universe)·백업 복원은 지금처럼 새 구조를 거부(문구만 같은 표현으로).

### 2-3. 시험
- 단위: 새 구조 파일을 열 때 `PRAGMA`·쓰기 문장이 **하나도 실행되지 않음**(가짜 드라이버로 실행 문장 기록), 파일 바이트 변화 없음.
- e2e: `?schema=99` 같은 가상 일지로 시작 → 업데이트 필요 화면·단추, 공간 전환 거부 후 원래 공간 그대로(전환 무결성), 창 다시 활성화 때 구조가 올라간 경우 화면 전환.

## 3. K1 — 섹션 머리를 끌어 순서 바꾸기 (시안 ②)
- 열 머리(이름 줄) 전체가 끌기 손잡이 — 마우스를 올리면 커서 `grab`, 끄는 동안 열이 반투명 + 들어갈 자리에 **세로 표시선**. 놓으면 순서 저장, 알림 [되돌리기]. 키보드: 열 머리에 초점 후 `Alt+Shift+←/→`.
- 카드 끌기와 구분: 카드는 카드 몸통, 열 순서는 머리만. 머리의 ⋯·정렬 선택 상자는 끌기에서 제외.
- **범위(결정 K1-a)**: 추천 = **사용자 섹션끼리 자유, TODO는 맨 앞·DONE은 맨 끝 고정**(TODO = 새 카드가 들어오는 곳, DONE = 끝 — 의미가 순서와 묶임). 대안 = TODO·DONE도 아무 자리(Trello처럼 완전 자유 — 저장은 설정 `ui.kanbanOrder`).
- 저장: 사용자 섹션 `sort_order`(한 batch, 지금 `reorderSections` 재사용). 구조 변경 없음.

## 4. K2 — 배치 모드 2가지 (시안 ③)
| 모드 | 설명 |
|---|---|
| **균등 분할**(기본·지금) | 열이 화면 폭을 같은 비율로 나눔. 열이 많으면 최소 폭 260px에서 가로 스크롤 |
| **자유 배치** | 판 위에 섹션을 상자처럼 놓음 — 머리를 끌어 **위치**, 오른쪽 아래 모서리를 끌어 **크기**. 8px 격자에 붙음, 겹치면 앞쪽(마지막에 만진 것) 위. 판은 내용 크기만큼 스크롤 |
- 상단에 배치 모드 아이콘 단추 2개(⊞ 균등 / ▦ 자유) + 자유 모드에서만 [배치 초기화].
- 자유 배치에서 카드 끌어 놓기·섹션 머리 끌기는 그대로(머리 끌기 = 위치 이동, 순서는 왼쪽 위부터 읽는 순서로 자동).
- 저장: 일지 설정 `ui.kanbanLayout = { mode: "equal" | "free", rects: { [sectionKey]: {x, y, w, h} } }`(공간마다, 구조 변경 없음). 새 섹션은 맨 오른쪽 빈 자리, 지운 섹션 자리는 지움.
- 좁은 창(< 900px)에서는 자유 배치여도 균등 분할로 보이게(저장값은 유지) — 결정 K2-b.
- 대안(결정 K2-a): 자유 배치 대신 **열 폭 조절 모드**(각 열 경계를 끌어 폭만 바꾸기, 위치는 한 줄)도 가능 — 구현·사용이 더 단순. 요구가 "크기와 위치 자유"라 추천은 자유 배치.

## 6. K4 — 카드 추가 창 (시안 ⑤)
- 맨 위 **업무 고르기 띠**: 업무 색 점 + 이름을 크게(16px), 업무 색 왼쪽 띠(직각)·옅은 업무 색 바탕, 누르면 업무 목록(색 점 포함). 창을 열 때 초점은 내용 칸이지만 업무 띠가 가장 먼저 보이게. 업무를 고르지 않으면 [추가] 잠김.
- 날짜·섹션 줄 아래에 **두 행을 따로**(성격이 다르므로 — 2026-11-12 사용자 지시):
  - **시작 시간** 행: `⏰ 시작 시간 정하기` → 15분 단위 고르기(그날 일정의 시작). 정하면 `⏰ 09:30 ×` 칩.
  - **마감일** 행: `⏳ 마감일 정하기` + 빠른 단추 [이번 주 금]·[다음 주 금] → 날짜 고르기. 정하면 `⏳ 10/30(금) D-8 ×` 칩. 정하면 ★ 함께(지금 규칙) — 행 오른쪽에 안내.
  - 둘 다 지금 줄(초점이 있는 본 항목)에 적용. 줄마다 다르게 하려면 지금처럼 줄 ⏰⏳·`Alt+O`/`Alt+U`.
- 하단에는 단추만 — 단축키 안내 글은 두지 않음(2026-11-12 사용자 지시, U5).
- 단추: [닫기] · [추가하고 계속] · [추가] — "취소"를 **"닫기"** 로(쓴 내용이 있으면 닫기 전 "쓴 내용을 버릴까요?" 확인은 지금 규칙 그대로).

## 6-1. K7 — 업무 거르기: 전체 · 1개 · 여러 개 (시안 ⑧)
- 지금도 데이터(`ui.kanban.categories` 배열, 비면 전체)는 세 경우를 다 담지만, 화면은 "모두 체크된 상태에서 끄기"라 1개만 보기가 번거롭고 단추가 `업무: N개`로만 보인다.
- 단추 글자로 범위를 바로 보임: **`업무: 전체`** · 1개 = **업무 색 점 + 업무 이름** · 여러 개 = **`업무: N개 선택`**(마우스를 올리면 이름 목록). 거르는 중이면 단추를 강조색 옅은 바탕으로.
- 펼침 목록:
  - 맨 위 **(○) 전체 업무** — 누르면 전체로.
  - 업무 줄: 체크 상자 = 여러 개 고르기(전체 상태에서 하나를 체크하면 "그 하나"부터 시작), 줄 오른쪽 **[이것만]**(마우스를 올리면) = 그 업무 1개만. 체크를 모두 풀면 전체로.
  - 맨 아래 [종료된 업무도 보기].
  - 키보드: ↑↓ 이동 · Space 체크 · Enter 이것만 · Esc 닫기.
- 적용 범위: 모든 섹션·DONE·일괄 완료 대상. 공간마다 기억(지금과 같음, 구조 변경 없음).

## 7. K5 — 완료 축하 모션 (시안 ⑥)
- 카드가 DONE에 들어가는 순간(끌어 놓기·`Alt+Shift+→`·카드 ✓·중요 업무 목록 ✓로 칸반이 보일 때): 카드 위에 **초록 체크가 커졌다 작아지고**(0.25s), 카드 둘레에서 **작은 색종이 12~16개가 튀었다 떨어짐**(0.9s, 앱 강조색·초록·노랑, CSS만 — 외부 라이브러리 없음). 그 뒤 DONE 줄로 접힘.
- 일괄 완료는 모션 없이 알림만(수백 개일 수 있음). 한 번에 여러 장이면 첫 장만.
- OS "동작 줄이기"면 체크만 잠깐(색종이 없음). 설정 › 화면 **[완료 축하 모션]** 켜기/끄기(기본 켜짐, 이 PC 설정) — 결정 K5.

## 8. T — 업무 타임라인 정돈 (시안 ⑦)
- **가로 정렬**: 이번 주 강조 상자의 안쪽 여백을 모든 주에 같게(강조는 바탕색·왼쪽 띠만, 내용 시작 위치는 같음). 주 머리·요일·항목 글이 위아래 주와 같은 세로선에 맞음.
- **요일 칸**: 폭 36 → 76px, 한 줄 `수 10/21` — 요일은 굵게 14px·진한 글자, 날짜는 12px 보조색. 요일 칸과 항목 사이 16px. 묶음 사이 점선은 그대로.
- **완료일 열**: 줄을 `[요일] [✓·★·⏰] [항목 글 ……] [완료일] [메모]` 격자로. 완료일 칩은 **항목 글 뒤**, 모든 줄에서 같은 오른쪽 열(폭 고정 140px)에 맞춰 세로 정렬 — 칩이 없는 줄은 빈 칸. 세부 항목도 같은 열.
- **기간 드롭다운**(상단 [기간: 최근 12주 ▾]): 카드 바탕색(`--surface-card`)·테두리로 바탕과 구분(업무 거르기 단추와 같은 모양). — "주차 드롭리스트"를 이 드롭다운으로 이해함. 다른 곳(예: 달 머리 접기 줄)이면 알려 주세요.

## 9. 데이터·구조
