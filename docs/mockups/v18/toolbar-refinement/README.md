# C안 툴바 수정 시안 — 구현 전 검토

- 보기 도구(확대/축소·화면 맞춤·스크린샷·최대화/최소화)는 보드 상단 오른쪽으로 복귀.
- 팔레트는 생성(텍스트·이미지·링크·오브젝트 연결) / 클립보드 / 라이브 위젯의 논리 그룹을 유지하되 명칭과 객체 수를 화면에 표시하지 않음.
- 아이콘은 전부 1열. 그룹은 직선 구분선으로만 구분하고 이름/설명/실제 단축키는 hover/focus 툴팁에 표시.
- 접기/펼치기는 외곽선 없는 작은 꺾쇠+얇은 손잡이. 24×48px 입력 영역을 확보하고 접힌 상태에도 복귀 손잡이는 남김.
- 주간 보드에는 업무 전용 위젯 그룹을 제외. 기존 객체 단축키 Ctrl+Alt+C/V 유지.
- 이 폴더만 수정 시안이며 앱 소스에는 반영하지 않음. [조작 가능한 시안](index.html).
