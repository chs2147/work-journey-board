# v18 비교 시안

[index.html](index.html)을 브라우저로 열어 A/B/C 배치·아이콘 툴팁·표 메뉴·Universe 확대/정지 연출을 비교합니다. 시안은 가상 데이터이며 실제 앱 저장/에디터/3D 카메라 구현이 아닙니다. Ctrl+C/V는 아이콘의 시각적 비유이며 객체 명령의 실제 단축키는 Ctrl+Alt+C/V를 유지합니다.

사용자 선택: C안+접기/펼치기. [실제 펼침](implemented-open.png) · [실제 접힘](implemented-folded.png). 나머지 board-a/b/c 및 note/universe 이미지는 설계 시안이며 실제 구현 화면은 별도 링크와 최신 가이드 화면으로 구분합니다.
