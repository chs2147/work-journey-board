# Universe 개편 v2 — 검토용 시안

브랜치: `universe-renewal-v2` · 기준: v1.14.0 · 작성: 2026-11-05

`index.html`을 브라우저에서 열면 외부 의존성 없이 동작합니다. A/B/C 버튼으로 시각 스타일, 다이나믹 3D/정적 2D 버튼으로 표현을 비교합니다.

- 휠 확대: 현재 선택 노드(포인터 아래 노드 우선)로 가까이 가면 초점 진입. 충분히 축소하면 이전 은하로 복귀.
- 빈 곳 드래그: 회전. Shift+드래그 또는 오른쪽 드래그: 이동. 노드 클릭: 선택. 더블클릭: 초점.
- 키보드: 지도에 포커스 후 방향키 회전, Shift+방향키 이동, +/- 줌, Home 전체 보기, Esc 은하 복귀.
- 실제 레퍼런스 버튼: Obsidian 공식 화면과 3D Force Graph 공식 화면·라이브 데모 링크.
- 검색은 예시 제목을 선택합니다. 왼쪽 필터·시간 막대·원본 열기는 화면 배치 설명용입니다.

| 화면 | 파일 |
|---|---|
| A 차분한 우주·은하 | `a-galaxy.png` |
| A 초점 | `a-focus.png` |
| B JARVIS HUD | `b-hud.png` |
| C 미니멀 | `c-minimal.png` |
| 정적 2D | `static.png` |

Canvas 원근 투영으로 3D 모션을 시뮬레이션한 프로토타입입니다. 실제 제품의 WebGL 렌더러가 아니며, 성능·GPU 복구·대규모 그래프 검증 전입니다. 정적 화면에서도 지도는 어둡고 주변 앱 패널은 기존 테마를 유지합니다. 실제 서비스 레퍼런스는 `references/README.md`에 출처를 기록했습니다.

제품 소스·DB·의존성·버전·배포 설정은 변경하지 않았습니다. 상세설계 `../../universe-renewal-v2-spec.md`의 D1~D5를 검토한 후 구현합니다.

## 패널 개선 시안

기본은 필터·상세 모두 닫힌 넓은 지도입니다. 지도 상단 `☷ 필터` / `▤ 상세`로 열고, 같은 버튼·×·Esc로 닫습니다. 지도 카메라는 유지됩니다. 1050px 이하에서는 한 패널만 열립니다.

- `panels-both.png`: 넓은 창에서 양쪽 펼침
- `panel-filter.png`: 필터만 펼침
- `panel-detail.png`: 상세만 펼침
- `panel-narrow.png`: 좁은 창에서 상세 펼침
