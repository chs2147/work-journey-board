# v12 검토용 시안

브랜치 `improve-v12` · 기준 v1.15.1 · 제품 코드 미변경.

`index.html`을 브라우저에서 열어 다음을 비교합니다. 외부 라이브러리/네트워크 없이 가상 데이터만 사용합니다.

1. 완료·가져오기: 완료/취소 버튼으로 본문 취소선과 복사 후보 비교, 모두 완료 케이스·0건 안내.
2. 띠·별표 여백: 현행 문제를 단순화한 재현과 새 표시 영역. 제품 스크린샷이 아닌 제안입니다.
3. 글자색 A/B/C: 추천 A(A+직각 칩), B(A 타일), C(글자색+칩). 시안에서는 비교를 위해 메뉴를 펼쳐 표시합니다.

밝은/다크 배경을 비교할 수 있습니다. 제품 테마의 정확한 색상값 검증·실제 리치텍스트 편집기는 구현 승인 후 진행합니다. 전체 상세설계 `../../improve-1105v12-spec.md`의 D1~D5를 검토합니다.

## 실제 구현 화면

- `implemented-signature.png`, `implemented-light.png`, `implemented-dark.png`: 중요 업무에서 완료한 항목의 본문·아이콘 연동.
- `implemented-daily.png`: 같은 상태를 표시하는 데일리 뷰.
- `implemented-palette.png`: A+직각 칩 트리거와 직각 색상 팔레트.

시안과 별도로 실제 브라우저 앱에서 가상 샘플로 캡처했습니다.
