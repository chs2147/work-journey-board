# v19 구현 전 시안

[인터랙티브 시안·단일 파일](preview.html) / [분리 원본](index.html): A/B/C 전환, 은하/포커스, 자동 움직임 켜기/끄기, 3D/2D, 필터/상세 패널, 드래그·휠, 내보내기 메뉴를 비교한다. 모두 가상 데이터이며 앱 동작은 변경하지 않는다.

- A(추천): 미세 궤도. 좌우 ±2.5°, 상하 ±0.6°를 약 2분 주기로 왕복. 확대 비율·선택 노드 고정, 전시보다 읽기 우선.
- B: 회전 없이 ±5px 부유. 문서 탐색 시 가장 잔잔한 연출.
- C: 180초 한 바퀴 순환. 티저에 가까운 전시 효과, 읽는 위치 변화가 큼.

자동 움직임 버튼은 3D/2D 선택과 독립한다. 3D 자동 움직임을 끄더라도 드래그 회전·휠은 사용 가능하다. 실제 앱에서는 PC 설정에 저장한다(시안은 저장하지 않음). 모션 감소·비활성 탭·2D·목록·팝업 등에서는 자동 재생을 쉰다. 드래그/휠 후 3초 정지, 노드 탐색 중 정지. 시안의 Canvas는 앱 Three.js 카메라 효과의 시뮬레이션이다.

내보내기는 노트/보드 모두 버튼 아래 공통 팝오버 표현을 사용하되 실제 지원 형식만 표시한다. 실제 구현은 검토 후 진행한다.

## 최종 승인 및 적용 화면

A+C 모노그램 아이콘 전환과 독립 재생/정지 방식으로 구현했다. 위 B안은 초기 비교 자료다.
