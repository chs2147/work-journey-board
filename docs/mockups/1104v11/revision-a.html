기존 하단 ‘+ 업무 추가’ 행과 전용 여백을 제거합니다. 마지막 업무 행 아래에 메모 경계선이 바로 닿고, 높이 조절용 잡기 영역은 경계선 위에 유지합니다.

02 · 한 팝업에서 끝나는 짧은 입력 과정

① 업무 이름 → ② 태그 → 추가

  • 업무 이름에 자동 포커스, 이름은 필수
  • 기존 태그는 클릭해서 여러 개 선택
  • 새 태그는 같은 창에서 추가·선택
  • 태그는 선택 사항, 다음 단계 화면 없이 완료

반복 입력과 취소

  • ‘업무 추가’: 만들고 닫기
  • ‘추가하고 계속’: 이름만 비우고 태그 선택 유지
  • 취소·Esc: 업무와 신규 태그 모두 미저장
  • 입력 중 바깥 클릭은 닫지 않음

새 태그·업무는 실제 구현에서 한 번에 저장되도록 처리합니다. 기존 태그 필터가 있으면 처음에 선택해 두며 사용자가 바꿀 수 있습니다.

03 · Markdown URL은 기존 메모 링크로

# 참고 자료 [프로젝트 문서](https://example.com/docs) https://example.com/guide ![첨부](data:image/png;base64,…)
→
참고 자료

프로젝트 문서 ↗
https://example.com/guide ↗

글 내용은 순수 텍스트로 정리하고, URL 부분에만 기존 링크 속성을 붙입니다. 링크 제목은 제목으로, URL 단독 표기는 주소 그대로 표시합니다. Ctrl+클릭·↗로 여는 기존 동작을 사용하고 가져올 때 외부 접속은 하지 않습니다.
