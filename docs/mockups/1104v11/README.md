# v11 시안과 구현 화면

- `index.html`, `add-a/b/c.png`, `overview.png`: 최초 A/B/C 배치 비교 시안.
- `revision-a.html`, `revision-a-*.png`: 사용자 피드백을 반영해 승인받은 팝업·태그·아이콘·경계 시안. HTML 체험은 실제 앱 데이터를 저장하지 않음.
- `implemented-board.png`, `implemented-add.png`, `implemented-palette.png`: 구현된 앱을 가상 데이터로 실행해 촬영한 실제 화면.

설계·승인·검증 기록은 [개선 v11](../../improve-1104v11-spec.md)을 참고한다.
