시안의 검색·접기·선택·자료 카드 드롭·복제 피드백은 **검토용 데모**입니다. 데이터는 저장하지 않으며 새로고침하면 초기화됩니다. 실제 Tauri 창 간 드래그, 블록 편집기, 파일 가져오기/내보내기는 구현하지 않았습니다.

HTML을 로컬에서 열어 사용할 수 있습니다. 저장소 HTTP 서버를 사용하는 경우 예시 주소는 `http://127.0.0.1:1423/docs/mockups/cabinet-v2/index.html`입니다. 폰트는 저장소에 설치된 Pretendard를 사용하고, 없는 경우 시스템 글꼴로 표시합니다. 외부 통신은 없습니다.

## 검토 시 결정할 내용

1. 요소별 화면 선택: H / N / B / W / D 각각 A·B·C.
2. 업무 소유 단위: 기존 업무 분류(category), 날짜별 개별 항목 아님.
3. 누적 메모: 기본 원본 연결 / 직접 보드 간 드래그: 독립 사본.
4. 사본에는 출처를 남기되 날짜별 업무항목 연결은 자동 복사하지 않는 정책.
5. 노트는 하나의 업무에 소속, 다른 업무 보드에서도 참조 가능.

## 시안 확인 결과

- Chromium: 15개 화면 렌더링, 콘솔 오류/실패한 리소스 요청 없음.
- 보기 전환·검색·패널/목차 접기·노트 진입·자료 카드 드롭·메모 선택·복제 방식·복제 방향 등 데모 조작 10개 확인.
- 폭 1440px 전체 15화면, 1024/720px 추천 5화면에서 페이지 가로 넘침 없음. 캔버스 내부 배치는 실제 제품의 pan/zoom 구현 검증과 별개.
- 제품 소스·스키마·앱 버전 변경 없음. 제품 테스트/네이티브 빌드 결과로 해석하지 않음.
