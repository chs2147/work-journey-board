# v14 A안 검토용 시안

[index.html](index.html)을 브라우저로 열어 세 화면을 전환합니다. 모든 조작은 가상 화면 안에서만 적용됩니다.

- 메모: [3개 선택] 또는 빈 곳 사각 선택 → 어느 객체 본문이든 끌기 → 전체 이동/되돌리기. 단순 클릭 유지, 더블클릭 개별 편집, Esc 취소/해제.
- 업무 타임라인: 경과 지도 상시 표시·표 모노그램 토글, 년/월20px·주차16px·내역14px, 월 머리 아래와 주 사이 구분선. 10월 꺾쇠를 눌러 펼치면 주차 사이 선도 볼 수 있습니다.
- 활동: 창 폭을 늘리거나 [좁은 폭 비교]로 격자 확대/내부 스크롤 비교, 표 아이콘 전환.
- [다크 배경 비교]로 색상 비교. 실제 제품의 완전한 편집/관계선/저장 기능을 구현한 화면은 아닙니다.

상세 설계: [improve-1106v14-spec.md](../../improve-1106v14-spec.md).

- [업무 타임라인](timeline.png)

시안 검증 완료: Chromium에서 텍스트/이미지/링크 그룹 드래그, 클릭 선택 유지, 사각 선택, 실행 취소, Esc 원복, 더블클릭 편집, 월/표 토글을 확인했습니다. 1920px에서 격자 확장, 760px 카드와 700px 창에서 내부 스크롤 및 앱 전체 가로 넘침 없음도 확인했습니다. 이는 시안 검증이며 실제 앱 회귀 검증은 구현 승인 후 진행합니다.
