# 개선 v13 시안 A — 백업 버전·복원·정리

`index.html`을 브라우저로 열면 설정 / 백업 이력·복원 / 보관 정책을 전환할 수 있습니다.

- 이력의 [검사·상세]: 동일 구조·구형 구조·더 최신 구조·과거 백업·파일 정보 불일치 비교.
- 정책: 기간/개수 전환, 용량 목표 켜기/끄기, 추천값, 정리 미리보기.
- 가상 데이터와 정적 용량 예시입니다. 숫자를 편집해도 실제 파일 크기를 계산하지 않습니다. 버튼은 실제 파일/설정에 쓰지 않습니다.
- 앱 예시 버전 1.17.0은 검토용이며 제품 버전은 아직 1.16.0입니다.
- 모든 강조 띠·용량 표시선은 직각입니다. 일반 버튼·카드 외곽은 기존 스타일을 유지합니다.
