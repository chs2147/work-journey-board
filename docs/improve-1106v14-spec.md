## 2. 추천 A안 — 선택은 유지, 드래그는 묶음, 편집은 명시적으로

### 2-1. 기본 동작

| 조작 | 다중 선택 상태에서 결과 |
|---|---|
| 선택된 텍스트·이미지·링크 카드의 본문/여백/기존 이동 손잡이를 끌기 | 선택 전체가 같은 거리로 이동. 객체 간 간격·순서·크기·내용 유지 |
| 선택된 객체를 짧게 클릭 | 선택 전체 유지. 텍스트 커서/이미지 미리보기/링크 열기가 튀어나오지 않음 |
| 선택된 텍스트/링크 더블클릭 | 해당 객체만 편집, 나머지 선택 해제. 이미지 더블클릭은 해당 이미지 개별 보기 |
| 선택되지 않은 객체를 클릭/끌기 | 기존 그룹 해제 후 그 객체에 기존 단일 선택/이동 규칙 적용 |
| Shift+클릭 | 선택에 추가/제외, 이동하지 않음. 마지막1개는 단일 선택 상태로 정리 |
| 빈 곳을 클릭 | 그룹 해제만 수행, 이 클릭으로 빈 메모를 만들지 않음. 선택이 없는 다음 빈 곳 클릭은 기존 새 메모 동작 |
| 빈 곳 드래그 | 기존 사각 선택. 교차하는 상자 선택 규칙 유지 |
| Esc(이동 중)·pointercancel | 전체를 시작 위치로 복원하고 그룹 유지. 이동 확정 안 함 |
| Esc(이동 안 함) | 그룹 해제 |
| 방향키 / Shift+방향키 / Delete | 기존 다중 이동/삭제 규칙 유지. 삭제와 이동은 각각 되돌리기 한 번 |

단일 선택/편집 모드에서 기존 텍스트 입력·드래그 텍스트 선택·서식은 유지한다. 다중 선택 모드에서만 본문 드래그를 묶음 이동으로 해석한다.

### 2-2. 선택 상태의 가시성

- 각 객체 선택 테두리 + **그룹 전체의 직각 점선 외곽** + 상단 ‘3개 선택 · 함께 이동’ 작은 도구 막대.
- 외곽/객체 테두리는 선택 개수에 따라 항상 동기화. 선택 객체 위 커서는 `grab`, 이동 중 `grabbing`.
- 도구 막대의 이동 아이콘도 같은 그룹 이동을 시작하는 보조 진입점. 특정 손잡이만 찾아야 움직이는 방식으로 만들지 않는다.
- 선택 영역 가운데는 투명하고 포인터를 가로채지 않는다. 빈 간격을 누르면 선택 해제 가능. 조절점처럼 보이는 장식을 임의로 추가하지 않는다.
- ‘선택한 객체 어디든 끌면 함께 이동’ 안내는 메모 도크의 기존 좌우 기준선과 정렬한다. 떠 있는 도구 막대는 확대 배율과 무관하게 읽을 수 있는 화면 크기로, 화면 위쪽을 벗어나면 아래쪽으로 배치한다.

### 2-3. 우선순위와 충돌 방지

1. 버튼·메뉴·입력칸·서식 도구·관계선 연결점은 각 기능 우선. 다중 선택 중에는 개별 크기 조절/연결점 조작을 숨기거나 비활성화하고, 개별 편집으로 들어가야 활성화한다(그룹 크기 조절은 이번 범위 아님).
2. Ctrl/⌘+링크 열기는 명시적 외부 링크 조작으로 유지. Shift 선택 추가/제외도 이동보다 우선한다.
3. 그 외 선택 객체의 본문 pointerdown은 공통 그룹 이동으로 처리. 부모가 캡처 단계에서 먼저 판단해 하위 편집/단일 선택이 그룹을 지우지 못하게 한다.
4. 4px 안팎의 화면 이동 임계값을 넘어서야 이동 시작. 기준점을 넘은 드래그는 이후 click/dblclick/링크 열기를 실행하지 않는다.
5. Space/가운데 단추의 판 이동은 기존처럼 우선하되, 진행 중인 객체 이동과 판 이동을 섞지 않는다.

### 2-4. 좌표·저장·전환

- 드래그 시작 시 선택 ID/원본 x,y/배율/일지·메모 문서를 캡처하고, 문서 좌표 변화량으로 전체를 움직인다.
- 판의 위/왼쪽 경계에서는 **묶음 전체의 최소 좌표**로 변화량을 제한해 한 객체만 멈추거나 간격이 찌그러지지 않게 한다. 기존에 음수 좌표가 있을 경우를 포함해 실제 구현 전 범위를 확인한다.
- 그룹을 판 밖 보드 항목으로 끌었을 때 개별 메모 연결 모드로 바뀌지 않는다. 자동 일괄 연결은 추가하지 않음.
- 정상 놓기는 메모 실행 취소1단계·저장1묶음. Esc/취소는 저장/실행 취소 기록 추가 없음. 프레임마다 DB를 쓰지 않는다.
- 주/공간 전환·문서 교체·상자 삭제 시 진행 중 제스처를 먼저 정리한다. 이전 문서의 지연 pointerup이 새 문서에 쓰지 않게 저장소 identity를 검사한다. 기존 `beginGesture`/`moveBoxesLive`/`cancelGesture`를 재사용한다.

## 3. 인사이트 — 업무 타임라인 / 활동

### 3-1. 탭과 아이콘

- 표시 이름: **경과 타임라인 → 업무 타임라인**, **활동 개요 → 활동**.
- 각 탭 앞에16px 선형 SVG 모노그램: 시간축(점·선) / 활동(막대). 이름은 아이콘과 함께 계속 표시한다.
- 관련 진입 안내·활동에서 타임라인 이동 툴팁·가이드 문구도 같은 용어로 통일한다.
- 내부 탭 키 `timeline` / `overview`와 저장된 설정은 유지해 기존 사용자의 마지막 탭을 그대로 연다. 선택·포커스·좌우 방향키/Enter 동작도 유지한다.

### 3-2. 경과 지도

- 타임라인의 경과 지도는 데이터가 있으면 **항상 표시**한다. ‘경과 지도 접기/펼치기’ 버튼 제거.
- 과거 `insightMapOpen=false` 설정이 있어도 숨기지 않음. 기존 JSON 키는 호환을 위해 읽기만 무시하고, 사용자 DB 구조 변경은 하지 않는다.
- 데이터가 없으면 기존 빈 상태 안내. ‘접힌 것’처럼 보이는 빈 공간을 남기지 않는다.
- ‘표로 보기’는 표 모노그램 **아이콘 버튼**으로 전환. 누르면 표/지도 토글, 활성 테두리·`aria-pressed`·상태에 맞는 `aria-label`/툴팁. 표 보기 자체를 삭제하지 않는다.
- 활동 히트맵의 같은 ‘표로 보기’도 동일 아이콘 규칙을 적용한다.

### 3-3. 년/월 → 주차 → 상세

- A안은 **한 방향 세로 위계**: 년/월 머리 → 주차 제목줄 → 들여쓴 상세 내역. 왼쪽 업무 목록과 필터/경과 지도 위치는 유지한다.
- 년/월: 20px, 주차:16px, 상세:14px. 라이트/다크는 기존 굵기 토큰, 시그니처는 기존 고운돋움400 + 크기/간격으로 위계를 구분(가짜 굵기 금지).
- 년/월 머리 바로 아래 1px 구분선, 첫 주차 시작. 이후 주차 사이에도 동일 기준선의 1px 선. 현재 주차/다음에 표시되는 주차 사이도 예외 없이 구분한다. 월 경계에서 이중 선을 겹치지 않는다.
- 상세는 주 제목보다 한 단계 들여쓰고, 같은 주 안의 항목·세부 항목 들여쓰기를 보존한다. 모든 머리·선·안내는 기존 본문 좌우 여백에 맞춘다.
- ‘이번 주’는 텍스트 배지로 구분. 강조 배경과 표시선은 직각이며, 색만으로 날짜 위계를 전달하지 않는다.
- **월별 기록 접기와 무기록 묶음 접기는 유지**한다. 이번 요청으로 제거하는 것은 경과 지도 접기뿐이다.
- ‘눌러서 펼치기’ 글 버튼은 접힌 머리의 **오른쪽 꺾쇠 모노그램**으로 교체. 펼쳐졌을 때는 아래 꺾쇠. 년/월·주 범위·개수는 계속 표시하고, 전체 머리를 눌러 펼칠 수 있다. `aria-expanded`·‘2026년10월 펼치기’ 등 접근성 이름 유지.
- ISO 주차·과거→최근 정렬·검색/지도에서 해당 주로 이동·자동 접힘 정책은 변경하지 않는다. 월을 걸치는 주는 기존 주 시작일 기준 그룹에 한 번만 표시하고 날짜 범위는 양쪽 월을 명시한다. 없는 미래 주를 새로 만드는 기능은 추가하지 않는다.

## 4. 활동 콘텐츠의 창 너비 대응

- 활동 카드·헤더·날짜/주 격자를 가용 폭100%로 표시한다. 고정 `max-content` 폭 때문에 남는 여백을 제거한다.
- 업무 이름/합계 열은 가독성 있는 범위로 유지하고, 날짜 칸이 나머지 폭을 함께 채운다. 일 단위에서는 기존 주말/평일 폭 비율을 유지하며, 연간 주 단위는 동일 폭으로 늘린다.
- 현재 최소 칸 폭(일14/주말8/주20px 수준) 아래로 무리하게 줄이지 않는다. 좁은 창은 **카드 내부만 가로 스크롤**, 업무 이름 열 고정, 앱 전체 가로 넘침 없음.
- 월 라벨·주/날짜 라벨·모든 업무 합계·각 업무 행에 동일한 그리드 열 정의를 사용해 창을 늘려도 수직 기준선이 일치한다.
- 1280/1440/1920px와 좁은 창, 설정한 업무 이름 폭/기간·0개/많은 업무·연간52/53주·긴 업무 이름을 확인한다. 넓어져도 데이터 빈도나 색 단계는 바꾸지 않는다.
- 뷰 크기 변화만으로 날짜 범위/필터/선택/스크롤을 초기화하지 않는다. 히트맵 keyboard roving focus와 툴팁 위치도 실제 칸 경계를 기준으로 계산한다.

## 5. 시안의 검토 포인트

- **메모**: 사각 선택 또는 [3개 선택] 후 어느 메모의 본문이든 끌어 그룹이 함께 움직이는지, 선택 유지/더블클릭 편집/그룹 외곽과 도구 막대가 자연스러운지.
- **업무 타임라인**: 늘 표시되는 지도, 아이콘 표 전환, 년/월20→주16→본문14 위계와 구분선, 아이콘 펼치기.
- **활동**: 탭 아이콘·새 이름, 창 폭 변경에 따른 격자 확대, 좁을 때 카드 안 스크롤. 시안의 [좁은 폭 비교]로 비교 가능.
- 단일 추천안 A로 제시한다. 더 조밀한 보기가 필요하면 기존처럼 주차를 왼쪽 열에 두는 B도 가능하지만, 요청한 위계를 명확히 하는 A를 권장한다.

## 6. 승인 후 구현/검증 순서

1. 다중 선택 상태·포인터 진입점 통합, 텍스트/이미지/링크·업무 연결 메모·그룹 클릭/더블클릭·도구 예외·Esc/취소·배율/경계·실행 취소. 이 부분부터 기존 그룹 이동 E2E로 재현 후 수정.
2. 탭 명칭/아이콘·경과 지도 상시 표시·표/펼치기 아이콘과 접근성. 기존 `mapOpen=false` 설정으로 들어오는 경우 확인.
3. 타임라인 헤더/서체/구분선/들여쓰기와 검색 이동·접기 회귀 확인.
4. 활동 유동 폭/최소 크기/내부 스크롤. 월 라벨·합계와 날짜 행 정렬/방향키/툴팁 확인.
5. 단위/Chromium/WebKit E2E, 공간3회 이상 왕복 후 텍스트·이미지·위치/선택·실행 취소의 문서 분리. 테마3종·넓은/좁은 창, 브라우저 오류·CSP·타입/린트/빌드 검사.

## 8. 승인 후 구현 기록 — 2026-11-06

작업 브랜치 `improve-v14`, 앱 버전 1.17.1·일지 구조 v14 유지(main 반영 시 버전 확정).

- 캔버스 캡처 단계에서 선택된 객체의 본문/여백/손잡이를 공통 그룹 이동으로 연결했다. 하위 이미지/링크가 먼저 단일 선택으로 바꾸지 못한다. 클릭 선택 유지, 더블클릭 개별 편집/보기, Shift 추가/제외, 빈 곳 클릭의 선택 해제를 분리했다.
- 그룹 전체 직각 점선·선택 개수·보조 이동 버튼을 추가했다. 다중 선택 중 개별 크기 조절/관계선 연결점은 감춘다. 기존 명시적 링크/입력/메뉴 조작은 우선한다.
- 이동량을 그룹 단위로 스냅/경계 제한한다. 기존 좌표용 `snap()`은 음수를 0으로 제한하므로 변화량에는 별도 반올림을 사용해 왼쪽/위 이동도 허용한다.
- Esc/pointercancel/창 포커스 상실/메모 화면 종료·주/공간 전환은 임시 이동을 취소한다. 저장 타이머는 이동 도중 저장을 미루며, 명시적 저장/전환 전에 취소한다. 늦은 이벤트는 문서 세대로 차단한다. 확정한 이동은 실행 취소 한 번이다.
- 탭·진입 메뉴·관련 안내를 업무 타임라인/활동으로 통일하고 SVG 아이콘을 추가했다. 경과 지도 접기 UI는 제거했으며 과거 접힘 설정으로 화면을 숨기지 않는다. 표 버튼은 기존처럼 표를 표시/닫는 기능을 유지하면서 아이콘·툴팁·접근성 이름/상태를 제공한다.
- 년/월20px → 주차16px → 상세14px의 세로 위계, 월 아래·주 사이 구분선, 직각 현재 주 강조를 적용했다. 월별 기록 접기·검색·지도 이동·ISO 주차 계산은 유지했다.
- 활동 헤더/날짜/업무 행/합계에 동일한 유동 열 정의를 적용했다. 최소 폭과 주말 비율을 유지하며 좁으면 카드 내부만 스크롤한다.
- 이용 가이드 장면05·08 및 Universe의 타임라인 연결 문구, 명세·개요·소개 문구, 가이드 HTML/PDF·실제 이미지를 갱신했다. PDF는 이 환경의 `file://` 차단 때문에 동일 인쇄 옵션으로 로컬 HTTP에서 생성했다.
