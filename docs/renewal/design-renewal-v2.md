# 디자인 리뉴얼 v2 — 직선 색상 띠

2026-11-04 사용자 승인 A안. 작업 브랜치: `design-renewal-v2`.

기존 화면을 유지하면서 왼쪽 색상 띠의 휘어진 끝만 직선으로 정리한다.
색상·두께·길이·글꼴·간격·배치·동작은 유지하며 시그니처·라이트·다크에 같은 규칙을 적용한다.

## 적용 규칙

- 세로 색상 띠는 위아래 끝이 평평한 직사각형으로 표시한다.
- 카드/강조 면에 붙은 띠는 왼쪽 위·아래 모서리를 0으로 하고 오른쪽 곡률은 유지한다.
- 독립된 메뉴 선택 표시는 네 모서리를 모두 0으로 한다.
- 일반 버튼·입력칸·배지·색 점·차트·연결선의 곡률은 변경하지 않는다.

- 데일리 뷰·중요 표시·마감일·테마 및 CSP 관련 기존 E2E 25개 통과.
- 빌드(TypeScript 포함)·ESLint·Prettier·가이드 검사 통과.
