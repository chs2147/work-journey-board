# 디자인 리뉴얼 v1 — R0 시안 검토 (글꼴·모드)

> 작성: 2026-10-28 · 브랜치: `design-renewal-v1`(main에서 분기) · 상태: **R1 구현(시그니처 테마 토큰·글꼴·테마 선택지)** — 글꼴은 A안 확정(2026-10-28)
> 기준: [design-style-spec.md](design-style-spec.md)(정본) · [design-concept.md](design-concept.md)(원칙) · [reference-research.md](reference-research.md)
> 시안: 사용자 개인 미리보기(클로드 아티팩트 "디자인 리뉴얼 v1 — 글꼴·모드 비교 시안"). 시안 속 기록은 모두 가상 예시, 기준일 2026-10-28(수).

## 1. 방향 (2026-10-28 사용자 확정)

- **UX 구조는 그대로, 디자인만 바꾼다** — 화면 구성·기능·단축키·데이터는 손대지 않는다.
- **라이트·다크는 유지**하고, 스타일 명세(Warm Beige · 고운돋움)로 **시그니처 모드를 새로 추가**한다 → 설정 › 화면 › 테마 = 시스템 설정 / 라이트 / 다크 / **시그니처**.
- **로고·타이틀은 바꾸지 않는다**(2026-10-28 사용자 지시): 앱 아이콘·워드마크(`src/shared/brand/*.svg`)와 상단 타이틀 줄은 모든 모드에서 지금 그대로 — 워드마크 글자색만 지금처럼 모드를 따름(라이트·시그니처 = 라이트 색, 다크 = 다크 색). 스타일 명세의 구리색 로고·Georgia 영문 표현은 쓰지 않는다.
- 고민: **고운돋움을 모든 모드의 기본 글꼴로 바꿀지, 시그니처만 쓸지** → 아래 2절 시안으로 비교한 뒤 정한다.

## 2. 시안 구성

| 보드 | 내용 | 보는 점 |
|---|---|---|
| A1 | 주간 보드 · 시그니처 · 고운돋움 | 명세 그대로의 시그니처 |
| A2 | 주간 보드 · 시그니처 · Pretendard | 시그니처 색만 쓰고 글꼴은 그대로 두면 |
| B1 / B2 | 주간 보드 · 라이트 · Pretendard(지금) / 고운돋움 | 라이트에 글꼴만 바꾸면 |
| C1 / C2 | 주간 보드 · 다크 · Pretendard(지금) / 고운돋움 | 다크에 글꼴만 바꾸면 |
| D | 글자 비교 3모드 × 2글꼴 | 주차 제목·업무명(굵기)·본문 줄바꿈·세부 항목·편집 칸·숫자/영문·단추·11~12px |
| E1 | 시그니처 · 중요 업무 패널 열림 · 선택 열(목) ≠ 오늘(수) | 날짜 띠·완료 뱃지·선택/오늘 구분 |
| E2 | 시그니처 · 오늘 뷰 | 메모 + 업무 카드·직전 기록 |
| E3 | 시그니처 · 설정 › 화면 | 테마 4가지 카드 + 본문 글꼴 선택(안 C) |

모든 보드에 같은 상태를 넣었다: 오늘 열(수), 편집 중인 칸(포커스 링), 중요 ★, 처리 완료 ✓, 세부 항목, 매주 반복 "예정", 링크, 오후 반차 배지, 빈 칸의 [직전 기록 가져오기], 태그 칩, 연결 메모 상자, 저장됨 표시.

### 2-1. 시그니처에서 바뀌는 표현(명세 + 컨셉 원칙)
- 색: 바깥 `#EDE6DC` · 기록면 `#FCF9F3` · 조작 면 `#F7F1E7` · 본문 `#423C34` · 강조 브라운 `#856748` · 구리색 `#AC7754`(중요 표식만 — 로고에는 쓰지 않음).
- 선: 가로선 `#E9E1D5`, 세로선은 더 옅게 `#F1EBE1`. 단추는 테두리 없이 옅은 베이지 면.
- 오늘: 머리 전체 채움 대신 **작은 "오늘" 표식**(`#E8D9C3`/`#71583E`), 선택 열은 **옅은 샌드색 + 머리 밑줄 2px**.
- 중요: 노란 형광펜 대신 **옅은 베이지 + 구리색 왼쪽 선 2px + ★**.
- 저장됨·완료: 명세 성공색 `#526847`. 지난 날짜 띠: 오류색 `#A94F42`.
- 업무 색(c1~c8)은 유지.

## 3. 글꼴 적용 범위 — 선택지

| 안 | 내용 | 좋은 점 | 걸리는 점 |
|---|---|---|---|
| **A. 시그니처만 고운돋움** | 라이트·다크 = Pretendard 그대로, 시그니처 = 고운돋움 | 지금 쓰는 모드는 그대로(익숙함·정보 밀도 유지), 시그니처가 확실히 다른 분위기 | 모드를 바꾸면 글자 폭·줄 높이가 달라져 같은 칸의 줄바꿈이 바뀜. 글꼴 2개 번들(+약 0.45MB) |
| B. 모든 모드 고운돋움 | 세 모드 모두 고운돋움 | 앱 전체가 하나의 인상, 글꼴 1개 | 굵기가 하나뿐 → 라이트·다크의 업무명·제목·단추 굵은 글자가 모두 보통 굵기가 됨(B2·C2 시안). 줄 높이 1.75로 한 화면 기록량 감소 |
| C. 테마와 따로 고르기 | 테마 4가지 + 본문 글꼴 [테마에 맞춤 / Pretendard / 고운돋움] (E3 시안) | 사용자가 정함 — "테마에 맞춤"을 기본으로 하면 A와 같음 | 설정 1개 추가, 조합(다크+고운돋움 등)까지 확인할 화면이 늘어남 |

검토 포인트: B2·C2에서 업무명·주차 제목이 굵기 없이도 충분히 구분되는가 · D에서 본문 13.5px 고운돋움의 가독성(특히 다크) · A1과 A2 중 시그니처다운 쪽 · 1366×768에서 기록량.

## 4. 다음 단계
1. 사용자: 글꼴 안(A/B/C) 결정 + 시그니처 표현(2-1) 수정 의견.
2. R1: 토큰(`tokens.css`에 `:root[data-theme="signature"]`) · 고운돋움 번들(원본 woff2 + OFL, CLAUDE.md 4-1 갱신) · 테마 선택지에 시그니처 추가.
3. R2~R4: 공통 조작 요소 → 보드·메모·오늘 뷰 → 패널·인사이트·설정·대화상자·스플래시.
4. R5: 회사 PC 확인 → main 병합(판올림 `0.3.0` 후보).

### 7-1. 2차 — 나머지 화면 단추·주요 단추
- 테두리 단추 18곳(메모 도크 도구 막대·확대 묶음·미니맵, 오늘 뷰, 인사이트, 내보내기·업데이트·가져오기 대화상자, 연간 보기, 무기록 제안·완료 되돌리기·태그 필터 띠, 첫 실행)을 `--btn-bg`·`--btn-line`으로. 입력칸·선택 상자·메뉴·팝오버의 테두리는 그대로(입력 경계는 명세 6-2대로 유지).
- 주요 동작 단추 7곳(`.primary`)을 `--primary-bg/fg/line`(라이트·다크 = 강조색 채움 그대로, 시그니처 = 샌드색 `#e9ddcc` + 짙은 갈색 `#5f4b36`, 명세 6-1). 오늘 뷰의 [오늘] = `--today-chip-*`.
- **라이트·다크 회귀 확인**: main(리뉴얼 전)과 이 브랜치를 같은 가상 일지·같은 화면 8개(주간 보드·오늘 뷰·중요 업무 패널·인사이트·내보내기·연간 보기·설정 › 데이터·백업·가져오기 마법사) × 라이트·다크로 찍어 **픽셀 차이 0**.
