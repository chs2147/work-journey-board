## 1. 지금 구조(확인한 사실)
- 열 순서: `KanbanView`가 `[TODO, ...sections(sort_order), DONE]`로 고정. 섹션 머리 끌기(`placeSection`)는 사용자 섹션끼리만, TODO에 놓으면 맨 앞·DONE에 놓으면 맨 끝(improve-v22 K1-a).
- 자유 배치: `fillRects`가 자리 없는 열을 "놓인 상자들의 오른쪽 끝 + 16px"에 둔다 → 균등 모습을 그대로 옮긴 직후(상자들이 판 폭을 꽉 채움)에는 새 섹션이 항상 판 밖. 판은 가로 스크롤되지만 스크롤바만 생겨 사용자 눈에는 "안 생김"(브라우저 모드 재현: `x=1104px`, 판 `clientWidth 1124`).
- 중요 업무 목록: `listImportant()`가 `flagged = 1 AND kanban_section_id IS NULL` — 사용자 섹션 항목 제외(v21 D3).
- 축하 모션: 옮기기 전에 카드 요소 위치를 재고 저장이 끝난 뒤 보드 화면 안 `position: fixed` 층에 그림. Chromium·WebKit 브라우저 시험은 통과했으나 실앱에서 안 보인다는 보고 — 그리는 층이 보드 쪽 쌓임 맥락 안에 있고(실앱 창 구성·조상 요소의 transform/overflow에 따라 가려지거나 자리가 어긋날 수 있음), 실제 저장(IPC)이 느리면 끌기 중 흐려진 카드·스크롤 변화 뒤에 그려지는 점이 의심된다. 브라우저 모드로는 재현되지 않아 **표시 방식을 바꿔 원인 후보를 모두 없애고** 실기 확인표로 확인한다.
- 카드 추가 창: 시작 시간·마감일 줄 뒤 설명 글(`startHint`·`dueHint`), 아래쪽 [↻ 매주 반복 (Alt+R)] 체크.
- 카드 ⋯ 메뉴: 고치기·★·마감일·시작 시각·상태 이력·옮기기·지우기 — 매주 반복 없음(주간 보드에는 `toggleRepeat` 있음).
- 타임라인 요일 묶음: `.dayGroup + .dayGroup { border-top: 1px dashed var(--line) }` — 옅어서 구분이 잘 안 보임.

## 2. K1 — 모든 섹션 순서 자유 (시안 ①)
- 열 순서 = `ui.kanbanColumns.order: SectionKey[]`(TODO·DONE·섹션 id, 공간마다 일지 설정). 사용자 섹션끼리의 `kanban_section.sort_order`도 같은 순서로 맞춰 둔다(다른 화면·내보내기 호환).
- 목록에 없는 열(새 섹션·예전 일지)은 DONE 바로 앞(DONE이 없으면 끝)에 끼운다. 지운 섹션은 빠진다.
- 모든 머리(TODO·DONE 포함) 끌기 · 머리에 초점 + `Alt+Shift+←/→` · 알림 [되돌리기]. 섹션 ⋯의 [← 왼쪽으로]·[오른쪽으로 →]도 모든 열에(DONE에도 ⋯ 메뉴: 아이콘 바꾸기·옮기기).
- 자유 배치: 위치는 지금처럼 자유, 순서(카드 추가 창 섹션 단추·카드 메뉴 [→ …] 순서)는 왼쪽 위부터 읽는 순서 — TODO·DONE도 포함.
- 상태 의미는 그대로: TODO = 시작, DONE = 완료. 순서만 바뀐다.

## 3. K2 — 자유 배치 섹션 추가 (시안 ③)
- 새 열 자리 = 보드에 보이는 영역 안의 빈자리(폭 300 × 높이 360, 8px 격자, 왼쪽 위부터 첫 자리) → 없으면 가장 아래 상자 아래 왼쪽(x 16).
- 만든 뒤 그 상자가 보이게 스크롤하고 1.5초 강조(바깥 테두리). [섹션 추가] 창은 균등·자유 모두 같은 창.
- [배치 초기화]는 지금처럼 균등 모습으로(열이 많으면 최소 폭 220에서 두 줄로 접어 화면 안에).

## 4. K3 — 중요 업무 목록 (시안 ④)
- 조건을 `flagged = 1`(미완료)로 — TODO·모든 사용자 섹션. DONE(완료)은 지금처럼 "이 주 완료"로.
- 사용자 섹션 항목에는 작은 칩(아이콘 + 섹션 이름), 누르면 칸반 그 카드 강조. 레일 ★ 배지 수도 같은 기준.
- v21 D3(사용자 섹션 ★ 제외)를 사용자 요청으로 되돌린다 — 가이드 장면15 팁 문장도 고친다.

## 5. K4·K5 — 상단 정리 (시안 ①)
- 균등 분할 오른쪽 끝 세로 [＋ 섹션 추가] 없앰.

## 6. K6 — 완료 축하 모션 (시안 ⑥)
- 시작점: 끌어 놓기 = 놓은 마우스 위치, 카드 메뉴 [→ DONE]·`Alt+Shift+→`·중요 목록 ✓(칸반이 보일 때) = DONE 열 맨 위 첫 줄 자리.
- 그리는 층: `document.body`에 붙인 포털(z-index 최상, `pointer-events: none`) — 보드 화면의 쌓임·잘림과 무관.
- 시점: 놓는 순간 바로 시작(저장 결과를 기다리지 않음). 저장이 실패하면 알림만(모션은 이미 끝남).
- 그대로: 일괄 완료는 모션 없음, 동작 줄이기 = 체크만, 설정 › 화면 [완료 축하 모션].
- 시험: 실제 마우스 끌어 놓기(Chromium·WebKit)에서 축하 층이 **창 안 좌표**에 보이는지, 메뉴·키보드 경로도. 확인표에 실기 항목.

## 7. K7·K8·K9 — 카드 추가 창 (시안 ⑤⑥)
- 본 항목 줄 왼쪽에 "카드 1·2·3" 꼬리표, 세부 줄은 "세부"(점선). 줄이 1개면 꼬리표 숨김.
- 저장 단추: 줄 1개 = [추가], 2개 이상 = [카드 N장 추가]. 저장 알림 "카드 3장을 TODO에 추가했습니다".
- 시작 시간·마감일 뒤 설명 글 없앰(마감일 = ★ 함께 동작은 그대로).
- [↻ 매주 반복] 체크 없앰 → 카드 ⋯ [↻ 매주 반복 켜기/끄기](`Alt+R`, 주간 보드와 같은 `toggleRepeat`) · 고치기 창에도 두지 않음.
