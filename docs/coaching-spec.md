# 앱 안 코칭(기능 둘러보기) 상세 설계

2026-11-25 · 작업 브랜치 `coaching-feature` · 기준 `v1.52.1 Open Beta` (`8aec489`) · 시안 `docs/mockups/coaching/` · 상태 **확정 2026-11-25**(사용자 — 추천안 D1~D10 + 수정 2건: ① 코칭은 늘 가상 예시 화면 기준 ② 기존 사용자도 코칭을 안 봤으면 업데이트 뒤 1회 알림) · 구현 대기(C1부터)

> 앱 기능이 많아져 처음 쓰는 사람이 어디서 무엇을 하는지 알기 어렵다. 모바일 게임처럼 화면을 어둡게 가리고 알려 줄 곳만 밝혀 콕 집어 설명하는 **단계별 코칭**을 넣는다. 처음 설치한 사람에게는 짧게 한 번 보여 주고, 나머지는 언제든 다시 볼 수 있는 **코칭 메뉴**에서 고른다.

## 1. 지금 앱의 구조(코칭 대상)

- **왼쪽 레일**: 공간 단추 → 주간 보드(`Alt+1`) · 칸반(`Alt+6`) · 인사이트(`Alt+3`) · Universe(`Alt+5`) │ 중요 업무(`Alt+2`, 배지) · Cabi.NET(`Alt+4`) … 맨 아래 설정(`Ctrl+,`).
- **주간 보드 상단 줄**: ◀ 주차 ▶ · [오늘] · [연간 보기](`Alt+Y`) · [주간|데일리](`Alt+V`) · 검색 · 태그 · [업무 추가] · [주간 요약](`Alt+S`) · [내보내기](`Alt+E`) · 저장 알약.
- **주간 보드 본문**: 업무 행 × 요일 칸(개조식 기록, `Alt+I` 중요 · `Alt+U` 마감 · `Alt+O` 시작 시각 · `Alt+R` 매주 반복 · `Alt+D` 다른 날로), 아래 **주간 메모 도크**(`Alt+M`, 팔레트: 글·링크·이미지·복사·붙여넣기 / 보기 막대: 줌·맞춤·관계선·그림 저장·크게 보기).
- **처음 실행 흐름**: 환영 → 저장 폴더 → 업무 이름 → 주간 보드(빈 일지). 처음 사용자는 기록이 하나도 없다(칸반·인사이트·Universe가 빔) → 코칭은 내 일지가 아니라 **코칭 전용 예시 일지** 위에서 진행한다(4-5).
- 코칭이 가리킬 요소는 대부분 이미 `data-testid`가 있다(시안 `shots/boxes.json`에 위치 기록). 없는 곳(예: 오늘 칸)은 구현 때 `data-coach="…"` 표식을 더한다.
- **F1**은 지금 쓰는 단축키가 없다 → 코칭 메뉴 단축키 후보.

## 2. 목표와 원칙

1. **짧게 먼저, 깊게는 골라서** — 첫 실행 투어는 1분(약 10단계). 나머지는 화면을 처음 열 때 제안하거나 메뉴에서 고른다.
2. **기록을 건드리지 않는다** — 코칭은 일지에 쓰지 않는다. 진행 상태만 이 PC 설정(`config.json`)에 둔다. 코칭 중에는 마스크가 클릭을 막아 실수로 기록이 바뀌지 않는다(화면 이동처럼 데이터를 바꾸지 않는 "직접 눌러 보기"만 허용).
3. **언제든 멈추고 다시** — 모든 단계에 [건너뛰기]·`Esc`, 코칭 메뉴에서 처음부터·이어서.
4. **예시 화면 위의 진짜 앱** — 그림 설명서가 아니라 실제 앱 화면의 그 단추를 밝히되, 내용은 늘 **가상 예시 일지**(기록·메모·칸반 카드·Universe 별이 채워진 상태)로 보여 준다. 처음 사용자든 오래 쓴 사용자든 같은 예시로 배운다. 내 일지는 코칭 동안 닫혀 있어 바뀌지 않는다.
5. **하나의 원본** — 윈도우·맥 같은 투어, 문구는 `platformText` 변환(⌘·⌥·Finder), 라이트·다크·시그니처 테마.

## 3. 노출 정책(언제·어디까지)

### 3-1. 처음 설치한 사용자(확정)
| 시점 | 무엇을 | 방식 |
|---|---|---|
| 첫 실행 마지막 단계(업무 이름)를 마치고 주간 보드가 처음 뜬 직후(0.8초 뒤) | **환영 카드**: "1분 둘러보기를 시작할까요?" [둘러보기 시작] [나중에] | 화면 가운데 작은 카드, 자동 시작하지 않음 |
| [둘러보기 시작] | **T0 시작하기**(10단계, 약 1분) — 레일·주간 보드 핵심·주간 메모, 마지막 단계에서 코칭 메뉴(?) 위치 | 스포트라이트 투어 |
| T0 끝 | "다음에 볼 만한 것" 카드 — 주간 보드 기록 익히기(T2)·주간 메모 보드(T3) 바로가기 + [닫기] | 이어 볼지 고름 |
| 칸반·인사이트·Universe·Cabi.NET을 **처음 열 때** | **제안 칩**(화면 오른쪽 아래): "이 화면 30초 둘러보기 ▶ ✕" | 자동 시작하지 않음, ✕ 또는 한 번 보면 그 화면은 다시 안 띄움 |
| [나중에]·[건너뛰기] | 레일 **?** 단추가 3초 깜박이며 "여기서 언제든 다시 볼 수 있어요" 토스트 | 한 번만 |

- 첫 투어에 모든 화면을 넣지 않는 이유: 10단계를 넘으면 대부분 건너뛴다. 그 화면을 실제로 처음 열 때가 배우기 좋은 시점이다(투어 자체는 예시 화면으로 진행하므로 내 기록이 비어 있어도 된다).

### 3-2. 이미 쓰던 사용자(코칭이 들어간 판으로 업데이트) — 확정
- 판정: 코칭 판을 처음 켤 때 `config.json`에 이미 일지(`dataDir` 또는 `workspaces`)가 있고 `coaching` 항목이 없음 = **기존 사용자**. 이때 `coaching.existingUser = true`를 한 번 적는다.
- **안 본 사람에게 처음 1회 알림**: 기존 사용자이고 `coaching.introShown`이 없으며 아직 끝까지 본 투어가 없으면(`done` 비어 있음), 업데이트 뒤 처음 일지가 열린 직후(새 판 안내 띠·업데이트 안내가 있으면 그 뒤) **새 기능 카드**를 한 번 띄운다.
  - 카드: "새로 생긴 **기능 둘러보기** — 예시 화면으로 주요 기능을 1분 만에 다시 볼 수 있어요" [둘러보기 시작(T0)] [메뉴 보기] [다음에]
  - 생김새(2026-11-25 사용자 요청 "너무 사무적" → 눈길 끄는 시안 4가지, 시안 2-1절): V1 히어로 그림(코칭 장면 그림 + 화면 칩) · V2 카드 부채꼴(화면 미리보기 4장 + 9칸 진행 막대) · **V3 스포트라이트 소개**(화면을 가리고 새 ? 단추만 반짝, 말풍선 — 추천: 기존 사용자) · V4 선물 상자(색종이). 처음 사용자 환영 카드는 V1 추천. 움직임은 짧게 한 번 + 은은한 반복, "동작 줄이기"면 정지(D13).
  - 어느 단추를 누르거나 닫아도 `introShown`을 적어 **다시 띄우지 않는다**. [다음에]면 레일 ?가 3초 깜박이며 위치 안내.
  - 카드를 띄운 뒤에도 투어를 하나도 끝까지 안 봤으면 레일 ?에 점이 남는다(코칭 메뉴를 한 번 열면 사라짐).
- 자동 투어는 시작하지 않는다(카드에서 고를 때만). 화면별 제안 칩은 기존 사용자도 켬(그 화면을 코칭 판에서 처음 열 때 1회) — 끄려면 코칭 메뉴·설정에서.

### 3-3. 새 단계가 생길 때(신기능)
- 투어마다 콘텐츠 판(`v`)을 둔다. 이미 본 투어에 새 단계가 붙으면 코칭 메뉴의 그 투어에 **"새 단계 N"** 표시, 레일 ?에 점. 자동으로 띄우지는 않는다(8절 공통 규칙과 연결).

### 3-4. 플래그(이 PC `config.json` `coaching`) — 확정
| 키 | 뜻 | 언제 적나 |
|---|---|---|
| `existingUser` | 코칭 판 이전부터 쓰던 기기 | 코칭 판 첫 실행 때 일지가 이미 있으면 한 번 |
| `introShown` | 처음 1회 카드(새 사용자 = 환영 카드, 기존 사용자 = 새 기능 카드)를 띄운 판(콘텐츠 판) | 카드를 띄우고 사용자가 고르거나 닫은 순간 |
| `done` | 투어별 끝까지 본 콘텐츠 판 `{ T0: 1, T4: 1, … }` | 투어 [마치기] |
| `progress` | 보다가 멈춘 곳 `{ tour, step }` | 건너뛰기·창 닫기 |
| `seenScreens` | 제안 칩을 띄운 화면 `["kanban", …]` | 칩을 띄운 순간 |
| `suggest` | 화면별 제안 칩 켜기(기본 켬) | 메뉴·설정 스위치 |
| `menuOpened` | 코칭 메뉴를 연 적 있음(레일 ? 점 끄기) | 메뉴를 처음 연 순간 |
- 새 사용자: 첫 실행 마지막 단계에서 `existingUser = false`. 플래그는 공간·온라인 계정과 무관한 **기기 단위**(DEV 판은 설정 폴더가 달라 따로).
- 코칭 메뉴 [진행 기록 지우기] = `done`·`progress`·`seenScreens`·`introShown`을 지운다(다음 실행 때 카드가 다시 뜸).

## 4. 화면 방식(마스킹·말풍선)

### 4-1. 시안 3가지(`docs/mockups/coaching/index.html`)
| 안 | 모습 | 장점 | 단점 |
|---|---|---|---|
| **A 스포트라이트** | 화면 전체를 어둡게(약 70%) 가리고 대상만 둥근 사각형 구멍 + 강조 테두리(은은한 맥박), 옆에 말풍선(제목·설명·단계 `3 / 10`·[이전][다음]) · 오른쪽 위 [건너뛰기] | 차분하고 업무 앱에 어울림, 모든 테마에서 읽기 쉬움 | 게임 느낌은 약함 |
| **B 게임식 손가락** | A + 손가락 포인터가 대상을 톡톡 가리키는 움직임, 말풍선 왼쪽에 앱 아이콘 캐릭터, 단계 진행 막대 | 요청한 "모바일 게임" 느낌이 가장 강함, 시선 끌기 | 매일 쓰는 업무 앱에서 다시 볼 때 과할 수 있음 |
| **C 따라 하기** | 대상을 실제로 눌러야 다음으로(다른 곳은 막힘) | 몸으로 익혀 기억에 남음 | 기록이 생기는 동작은 막아야 하고(데이터 안전), 막히면 답답함 |

**추천: A를 기본 + B의 손가락은 "직접 눌러 보기" 단계에만 + C는 화면 이동처럼 데이터를 바꾸지 않는 단계에만.** 예) "칸반 아이콘을 눌러 보세요" → 손가락이 톡톡, 누르면 칸반으로 넘어가며 다음 단계. 기록을 쓰는 동작(칸에 글 쓰기·카드 옮기기)은 보여 주기만 한다.

### 4-2. 구성 요소
- **마스크**: 화면 전체 SVG 한 장, 대상 사각형만 뚫음(여백 6px, 모서리 8px). 대상이 움직이면(창 크기·스크롤·패널 열림) 다시 잰다. 마스크 클릭 = 아무 일 없음(실수 방지).
- **강조 테두리**: 대상 둘레 2px 강조색 + 맥박(1.6초). `prefers-reduced-motion`이면 맥박·손가락 없음.
- **말풍선**: 대상 쪽을 가리키는 꼬리, 대상 위·아래·좌·우 중 화면 안에 들어가는 자리를 자동으로. 내용 = 제목 1줄 + 설명 2~3줄 + 단축키 칩(`Alt+6`) + 단계 점/막대 + [이전] [다음](마지막은 [마치기]). 최대 폭 340px.
- **진행 막대**: 직각(띠 규칙 — 둥근 모서리 금지).
- **건너뛰기**: 오른쪽 위 고정 [건너뛰기 ✕]. 확인 창 없이 바로 끝(다시 보기 쉬움). 끝나면 3-1의 ? 안내.

### 4-3. 조작
| 동작 | 마우스 | 키보드 |
|---|---|---|
| 다음 / 이전 | [다음] / [이전] | `→`·`Enter` / `←` |
| 건너뛰기 | [건너뛰기 ✕] | `Esc` |
| 직접 눌러 보기 단계 | 밝힌 대상을 클릭 | `Enter`(대상 실행) |
| 코칭 메뉴 | 레일 ? | `F1` |
- 코칭 중에는 앱 단축키를 쉬게 하고(코칭 키만), 끝나면 원래 포커스로 돌아간다. 말풍선은 `role="dialog"`·`aria-live`로 화면 읽기 프로그램이 내용을 읽는다.

### 4-4. 화면 이동
- 단계에 `before` 동작을 둔다: 예) 칸반 투어 1단계 전 `openKanban()`, 메모보드 투어 전 메모 도크 펼치기, Universe 투어 전 Universe 열기. 기존 화면 전환 함수만 쓴다(새 길 없음). 투어가 끝나거나 건너뛰면 **시작 전 화면으로 돌아간다**(D9).

### 4-5. 코칭 예시 화면(가상 예시 일지) — 확정
> 처음 사용자는 일지가 비어 있다. 빈 화면에서는 "오늘 칸에 적기"·칸반 카드·Universe 별을 보여 줄 수 없다 → **모든 투어는 코칭 전용 예시 일지로 잠시 바꿔서** 진행하고, 끝나면 내 일지로 돌아온다.

**예시 일지**
- 내용: 앱에 들어 있는 가상 샘플(`fixtures/sample-showcase.json` — 업무 4개·5주 기록·주간 메모 보드·관계선·이미지·Cabi.NET 자료·마감·중요·완료). README·소개 사이트·DEV 판 "가상 샘플 일지"와 같은 데이터.
- 날짜 맞춤: 샘플은 2026-09~10월 기록이라, 만들 때 **이번 주로 주 단위 이동**(요일 유지 — `domain/coachingSample.ts` 순수 함수, 주차는 `domain/week.ts`). 오늘 칸 강조는 실제 오늘.
- 저장: **메모리 일지(sql.js)** — 파일·백업·설정을 만들지 않는다. 투어가 끝나면 버린다. (sql.js 실행 허용은 이미 CSP에 있음 — 온라인 공간 이 기기 사본용 `wasm-unsafe-eval`.)
- 읽기 전용: 예시 일지 저장소는 쓰기를 받지 않는다(마스크가 클릭을 막고, 그래도 들어온 쓰기는 무시). 혹시 써도 메모리라 사라지며, 내 일지는 그동안 닫혀 있다.

**바꾸는 길(4-7 일지 전환 무결성 그대로)**
1. 투어 시작 → 지금 화면 상태 기억(공간·화면·주·데일리 날짜·열린 패널·메모 도크 높이)
2. 내 일지 저장 마무리: `flushPending` → `finishNote` → (Cabi.NET 노트·보드 창이 열려 있으면 저장 확인 후 닫기) → `detachAll()` → 내 드라이버 닫기 — **종료 백업은 하지 않음**(곧 다시 엶)
3. 예시 일지 `activate`(코칭 표식: 공간 이름 "예시", 저장 알약 대신 **"예시 화면 — 내 기록은 그대로"** 띠). `config.json`의 `dataDir`·`lastWorkspace`·공간 목록은 **바꾸지 않는다**.
4. 투어 진행(화면 이동은 기존 함수로)
5. 끝·건너뛰기·`Esc`·오류 → `detachAll()` → 예시 드라이버 버림 → **내 일지 다시 열기**(같은 `switchWorkspace` 길) → 1에서 기억한 화면으로 복귀(D9)
- 온라인 공간을 보던 중이면: 2에서 이 기기 사본 저장·보내기 대기열 정리 후 닫고, 5에서 같은 온라인 공간으로 돌아간다(서버에 아무것도 보내지 않음).
- 코칭 중 앱을 닫으면: 예시 일지는 메모리라 버려지고, 다음 실행은 평소처럼 내 일지로 시작한다(설정을 안 바꿨으므로).
- 예시 화면에서 막는 것: 새 판 확인·자동/주기 백업·온라인 동기화·Cabi.NET 폴더 존재 확인·폴더 창·링크 열기·내보내기 저장(투어는 단추를 가리키기만 함).

**Cabi.NET(T8)**
- 실앱의 Cabi.NET은 별도 창이다. T8은 Cabi.NET 창 안에서도 같은 코칭 오버레이를 띄워 진행한다(창끼리 기존 메시지 길로 단계 동기화). 예시 일지의 자료 줄은 보여 주되, 폴더 존재 확인·폴더 창 열기는 하지 않는다.

**대상이 그래도 없을 때(좁은 창 등)**
- 정한 대체 대상(그 영역 전체)을 밝히고, 없으면 말풍선을 가운데에 띄워 작은 그림으로 설명한다(단계는 건너뛰지 않음).

## 6. 투어 목록과 단계(콘텐츠 초안)

> 모든 단계는 **예시 일지** 화면 위에서 진행한다(예시 업무: 차세대 정산 시스템 구축·협력사 보안 점검·사내 데이터 대시보드·신규 입사자 온보딩). 문구는 C1·C2에서 다듬어 `src/shared/coachingStrings.ts` 한 곳에 둔다. `[대상]` = 밝힐 요소, ✋ = 직접 눌러 보기 단계.

### T0 시작하기(첫 실행 자동 제안, 10단계)
1. (가운데 카드) **반가워요!** 요일 칸에 업무를 적어 두면 주간 요약·경과·엑셀이 저절로 만들어집니다. **예시 일지**로 1분만 둘러볼게요 — 끝나면 내 일지로 돌아옵니다.
2. `[왼쪽 메뉴]` **화면 이동** — 주간 보드·칸반·인사이트·Universe, 중요 업무·Cabi.NET을 여기서 오갑니다.
3. `[업무 행 머리]` **업무 = 한 줄** — 처음에 적은 업무가 한 줄씩. ⋯ 에서 이름·색·종료를 바꿉니다.
4. `[오늘 칸]` **오늘 칸에 적기** — 칸을 누르고 쓰면 끝. `Enter` 새 항목, `Tab` 세부 항목. 자동 저장됩니다.
5. `[업무 추가]` **업무 늘리기** — 새 업무를 행으로 더합니다.
6. `[주간|데일리]` **보기 바꾸기** — 한 주 전체 또는 하루만 크게(`Alt+V`).
7. `[연간 보기]` **한 해 훑기** — 기록이 있는 주를 달력으로 보고 바로 이동(`Alt+Y`).
8. `[주간 요약]` **보고서 초안** — 이번 주 기록이 업무별로 정리됩니다. 고쳐 쓰거나 AI 지시문과 함께 복사(`Alt+S`).
9. `[내보내기]` **엑셀로** — 여러 주를 엑셀 파일로(`Alt+E`).
10. `[레일 ?]` **언제든 다시** — 다른 화면 둘러보기는 여기(`F1`)에서. → 내 일지로 돌아온 뒤 "다음에 볼 만한 것" 카드.

### T1 화면 구성과 왼쪽 메뉴(9)
공간 단추(회사·개인 공간 전환, `Ctrl+Alt+1~9`) → 주간 보드 → 칸반 → 인사이트 → Universe → 중요 업무(배지 = 미완료 수, 빨간 점 = 마감 지남) → Cabi.NET → 설정 → ? 코칭 메뉴. 각 단계 단축키 칩.

### T2 주간 보드 — 기록하기·보기·요약·내보내기(9)
1. `[주차 ◀ ▶ · 오늘]` 주 넘기기(`Alt+←/→`, `Alt+T`)
2. `[오늘 칸]` 기록 — `Enter`·`Tab`·`Shift+Tab`, 끌어서 옮기기(⋮⋮)
3. `[항목 도구]` ★ 중요(`Alt+I`)·⏳ 마감(`Alt+U`)·⏰ 시작 시각(`Alt+O`)·↻ 매주 반복(`Alt+R`)·완료
4. `[직전 기록 가져오기]` 지난 기록 이어 쓰기(`Alt+P`)
5. `[주간|데일리]` 보기 바꾸기
6. `[연간 보기]`
7. `[업무 추가]`
8. `[주간 요약]`
9. `[내보내기]` — 범위·시트(주간 요약 시트 포함) 고르기

### T3 주간 메모 보드(8)
1. ✋ `[메모 도크]` 펼치기(`Alt+M`) 2. `[팔레트 — 글 상자]` 빈 곳 클릭으로도 3. `[링크·이미지]` 캡처 `Ctrl+V`·파일 끌어 놓기 4. `[복사·붙여넣기]` 객체 복사 `Ctrl+Alt+C/V` 5. `[상자 → 업무 항목]` 상자를 칸 항목에 끌면 연결(타이틀 띠) 6. `[연결점]` 관계선 잇기 7. `[보기 막대]` 줌·맞춤·관계선 보기 8. `[그림 저장·크게 보기]` PNG·Markdown

### T5 인사이트(7)

### T6 Universe — 개념과 보기 모드(10)

### T7 중요 업무(6)

- **대상 지정**: `data-testid` 우선, 없으면 구현 때 `data-coach="today-cell"` 등 표식 추가(화면 동작은 바꾸지 않음).
- **저장**: 이 PC `config.json`에 `coaching: { existingUser?, introShown?, done: Record<tourId, contentVersion>, progress?: { tour, step }, seenScreens: string[], suggest: boolean, menuOpened? }`(3-4). 공간·온라인과 무관(기기 단위, 동기화 안 함). DEV 판은 설정 폴더가 달라 따로. 일지 구조 변경 없음(v20 유지).
- **샘플 번들**: `fixtures/sample-showcase.json`(약 57KB)과 샘플 이미지는 코칭 시작 때만 불러온다(동적 import — 앱 시작 속도 영향 없음).
- **전환 무결성(4-7)**: 예시 일지 진입·복귀는 새 길을 만들지 않고 `appController`의 전환 순서를 그대로 쓴다. 코칭 저장소 자체는 일지 데이터를 들지 않아 `detachAll` 대상이 아니다. 예시 화면 중에는 공간 전환·로그인/로그아웃·설정의 저장 위치 바꾸기를 막는다(투어가 끝난 뒤 가능). 공간 전환·종료 안내(전체 화면)가 뜨면 투어를 끝내고 내 일지로 복귀한다.
- **외부 통신 없음**, 새 의존성 없음(직접 SVG·CSS).

## 8. 공통 규칙 — 신기능과 코칭(2026-11-25 사용자 지시)

## 11. 시험 계획(구현 때)
- 단위: 투어 정의 검사(단계 수·문구 길이·키 중복·판), 플래그 저장 왕복, 기존 사용자 판정·1회 카드 조건(새 사용자/기존·안 봄/기존·이미 봄/이미 띄움), 샘플 날짜 이동(주 경계·연도 경계·요일 유지).
- **예시 화면 무결성(4-7 형식)**: 내 일지에 가상 기록·메모 이미지 넣기 → 투어 시작·끝·건너뛰기를 3번 이상 → 내 일지 그대로(기록·이미지·저장소 개수 `__wjbApp`), 예시 일지 기록이 내 일지에 섞이지 않음, `config.json`의 `dataDir`·`lastWorkspace` 그대로. 온라인 공간에서 시작해 복귀하는 경우도.
- E2E(빈 일지로 시작한 새 사용자 + 기록이 있는 기존 사용자 두 경우): 모든 투어를 끝까지 넘기며 **각 단계의 대상이 보이거나 대체 표시가 뜨는지**, 건너뛰기·`Esc`·이어서, 투어 중 기록이 바뀌지 않는지(저장소 쓰기 0), 투어 후 원래 화면 복귀, 좁은 창(1024px)·맥 표기(`?os=mac`).
- 접근성: 말풍선 포커스·읽기, reduced-motion.
