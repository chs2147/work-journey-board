## 1. 행 개별 삭제 (#1)

### 1-1. 화면·조작 (시안 ①·② A)
- 보드 칸·오늘 뷰 카드의 항목에 **마우스를 올리면** 오른쪽에 단추 줄: 본 항목 `[메모] [↻] [삭제]`, 세부 항목 `[메모] [삭제]`(반복은 본 항목 묶음 단위라 세부 항목에는 없음 — 지금과 같음).
- 단추는 Tab 순서에서 뺀다(지금 ☆·↻와 같음) — 키보드 기록 흐름(2분, CLAUDE.md 4-6)을 바꾸지 않는다.
- 키보드: 칸 안 `Alt+Delete` = 지금 커서가 있는 항목 삭제(본 항목이면 묶음). 커서는 바로 위 항목 끝(없으면 아래 항목 앞, 칸이 비면 칸을 떠남).
- 기존 동작은 그대로: 빈 항목에서 `Backspace` = 그 항목만 삭제.

### 1-2. 되돌리기
- **확인 대화상자 없이** 지우고, 지금 칸 저장과 같은 경로(`saveCell`)로 저장 → 실행 취소 1단계. 토스트 `항목 3개를 지웠습니다(세부 2개 포함) [되돌리기]`(지금 "항목 N개 삭제" 토스트를 그대로 씀).

### 1-3. 다른 기능과의 관계
| 기능 | 처리 |
|---|---|
| ★ 중요 | 중요 업무 목록에서도 빠짐(되돌리면 돌아옴 — 표시는 항목에 실려 있다) |
| ↻ 반복으로 들어온 항목 | 이 주만 빠지고 규칙은 그대로(important-repeat-spec 3-3과 같음) |
| 연결된 메모(#4~#7) | 메모는 남고 타이틀 띠가 "연결된 항목이 삭제됨"(6-3) |
| 가져온 항목(M3-S0) | 지금 삭제와 같음 |

## 2. 하위 항목 함께 삭제 (#2)
- 본 항목의 [삭제]·`Alt+Delete` = 본 항목 + **바로 아래 이어지는 세부 항목 전부**(Alt+↑/↓의 묶음 규칙과 같은 범위).
- 세부 항목의 [삭제] = 그 세부 항목만.
- 삭제 단추에 마우스를 올리면 지워질 줄들이 옅은 빨강 + 취소선으로 미리 보인다(시안 ② B).

## 3. 행 끌어서 옮기기 (#3)

### 3-1. 조작 (시안 ② C·D)
- 항목에 마우스를 올리면 왼쪽 여백에 **⋮⋮**. 이것을 잡아 끈다(글자 위를 끌면 지금처럼 글자 선택).
- 끄는 동안: 원래 자리는 흐리게, 커서 옆에 항목 그림자, 놓을 자리에 **파란 가로선**, 다른 칸이면 그 칸 테두리 파랑. `Esc` = 취소.
- 본 항목 = 딸린 세부 항목과 함께, 세부 항목 = 혼자.
- 놓는 곳의 깊이: 본 항목 묶음은 본 항목 그대로. 세부 항목은 놓은 자리의 위 항목에 딸리고, 칸 맨 위에 놓으면 본 항목이 된다.
- 좁은 토·일 열 위로 가져가면 그 열이 넓어진다(포커스 열이 됨).

### 3-2. 범위 (추천)
- **보고 있는 주의 모든 칸**(다른 요일·다른 업무). 오늘 뷰는 그 날의 카드(업무)끼리.
- 다른 주로는 끌 수 없다(주 이동 중 끌기 없음).
- 메모 판에 놓으면 이동이 아니라 **연결된 메모 만들기**(4절).

### 3-3. 옮길 때 따라가는 것 (추천)
- 항목 id 그대로 날짜·업무만 바뀐다 → ★ 표시·처리 완료 기록·매주 반복 연결·연결된 메모·가져오기 묶음(import_id)이 그대로 따라간다.
- 반복 규칙과의 관계: 규칙은 "그 주에 이 규칙의 항목이 있는가"로 판단하므로 같은 주 안 이동은 다음 주 생성에 영향이 없다.
- 한 번의 `Ctrl+Z`로 두 칸 모두 되돌림.

### 3-4. 저장 (데이터 안전, CLAUDE.md 4-3)
- 새 저장소 메서드 `saveCells(cells[])` — 대상 칸을 **먼저**(같은 id의 upsert가 행의 날짜·업무를 바꿈), 그다음 원래 칸(목록에 없는 행만 삭제 — 옮겨 간 행은 이미 다른 칸이라 지워지지 않음)을 **한 batch**로. 기존 `saveCell` 규칙(빈 항목 제거·첫 항목 본 항목·seq 다시 매김)을 그대로 쓴다.
- 스키마 변경 없음.

### 3-5. 구현 메모
- 브라우저 표준 끌기(HTML5 DnD)는 textarea 안 글자 끌기와 섞이므로 **포인터 이벤트로 직접**(⋮⋮에서 시작, `setPointerCapture`, 놓을 칸·자리는 `elementFromPoint` + 행 경계 계산). 실앱은 `dragDropEnabled:false`가 이미 켜져 있어 화면 안 끌기가 동작.
- 끄는 중에는 자동 저장 타이머를 먼저 비우고(flushAll) 놓을 때 한 번 저장.

## 4. 업무항목 연계 메모 만들기 (#4)
- 행의 **[메모]** 단추: 메모 판의 가장 아래 상자 밑(지금 [텍스트 상자 추가]와 같은 자리)에 **연결된 글 상자**를 만들고 본문에 커서. 메모 도크가 접혀 있으면 펼친다, 오늘 뷰는 왼쪽 메모.
- 행을 **⋮⋮로 끌어 메모 판에 놓기**: 놓은 자리에 연결된 글 상자(메모 판 위에서 점선 자리 "여기에 놓으면 이 항목과 연결된 메모"). 행은 그대로 남는다.
- 본문은 **비어 있게**(추천) — 무엇에 관한 메모인지는 타이틀 띠가 보여 준다. 글자를 쳐야 상자가 남는 U1 규칙(빈 상자 안 만듦)은 연결 상자도 같다: 아무것도 안 치고 떠나면 사라진다.

## 5. 기존 메모를 항목에 연결 (#5)
- 메모 상자(글·이미지·링크 카드)의 **위 막대(이동 손잡이)를 잡고 보드의 항목 위**로 가져가면 그 행이 파란 테두리 + "여기에 연결". 놓으면 상자는 **원래 자리로 돌아가고** 타이틀 띠가 붙는다(메모 판 배치는 바뀌지 않음).
- 같은 주의 항목에만(메모는 주마다 하나). 오늘 뷰에서는 오른쪽 카드의 항목에.
- 한 상자는 한 항목에만, 한 항목에는 상자 여러 개. 이미 연결된 상자를 다른 항목에 놓으면 연결이 옮겨 간다(메모 기록 1단계).

## 6. 연계 오브젝트의 타이틀 (#6)

### 6-1. 모양 (시안 ③ C)
- 상자 맨 위 한 줄 띠(높이 26px, 옅은 회색 바탕): `● 업무명 · 10/22(목) · 항목 글…`(업무 색 점, 업무명 굵게, 넘치면 줄임). 오른쪽에 끊긴 사슬(연결 해제).
- 글·이미지·링크 카드 상자에 모두 같은 띠. 상자의 이동 손잡이·⋯ 메뉴는 띠 아래 본문 기준 그대로.
- 띠를 누르면 **그 항목으로 이동**(그 주·그 칸, 항목에 커서 + 잠깐 강조 — 중요 업무 목록의 이동과 같은 동작).

### 6-2. 보드 쪽 표시
- 연결된 메모가 있는 항목 끝에 작은 배지(메모 아이콘 + 수). 누르면 그 메모 상자로(여럿이면 첫 상자, 메모가 접혀 있으면 펼침).

### 6-3. 상태
| 상황 | 띠 |
|---|---|
| 항목 있음 | 업무명·날짜·항목 글(항목 글을 고치면 바로 따라 바뀜) |
| 항목을 다른 칸으로 옮김 | 새 업무명·날짜 |
| 항목을 지움 | 회색 `연결된 항목이 삭제됨` + [연결 해제]. 항목 삭제를 되돌리면 다시 정상 |
| 업무 이름·색을 바꿈 | 따라 바뀜 |

### 6-4. 저장
- 메모 문서(weekly-note-spec 5절) 상자에 **`ref: { "item": "<entry_item.id>" }` 한 칸만** 더한다. 타이틀 글은 저장하지 않고 화면에서 늘 지금 항목으로 만든다 — 항목이 바뀌어도 어긋나지 않게. 스키마 변경 없음(문서 JSON).
- `parseNoteDoc`은 `ref.item`이 문자열이 아니면 버린다.

## 7. 연계 해제 (#7)
- 타이틀 띠의 끊긴 사슬, 또는 상자 ⋯ → **[연결 해제]**. 띠만 사라지고 상자·본문·자리는 그대로.
- 메모 기록(`Ctrl+Z`)으로 되돌림.

## 8. 중요 업무 목록 — 업무명으로 묶기 (#8)

### 8-1. 모양 (시안 ④)
```
오늘 3
 ● 차세대 정산 시스템 구축 2
   ☐ 이관 대상 테이블 확정
   ☐ 배포 리허설 › 롤백 스크립트 점검
 ● 협력사 보안 점검 1
   ☐ 보고서 초안 검토 요청
이번 주 2
 ● 차세대 정산 시스템 구축 1
   ☐ 개발계 1차 배포 · 10/23 (금)
```
- 묶음(지난 날짜 / 오늘 / 이번 주 / 다음 주 이후)은 그대로, 그 안을 **업무명**으로 한 번 더 묶는다. 업무 순서 = 보드 순서, 업무 안 = 날짜 → 칸 안 순서.
- 업무 머리: 업무 색 점 + 이름 + 수(종료된 업무는 "종료됨"). 항목 줄에서는 업무명을 빼고, 날짜는 "오늘" 묶음이면 생략·그 밖은 한 칸.
- 세부 항목의 "본 항목 ›" 앞머리, "지남" 표시, 최근 완료(날짜순)는 그대로.

### 8-2. 키보드 (바뀌지 않음)
- `Alt+2`로 열면 첫 항목에 포커스, `↑/↓`는 **항목만** 지난다(업무 머리는 건너뜀), `Space` 처리 완료, `Enter` 그 항목으로, `Esc` 보드로.
- 구현: `domain/important.ts groupImportant`가 묶음마다 `categories: { id, name, color, ended, items }[]`를 돌려준다(순수 함수, 단위 테스트).

## 9·10. 주간 / 오늘 보기 아이콘 (#9·#10)
- 연간 보기 옆 `[주간|오늘]` 글자 묶음을 **아이콘 두 개**로(시안 ⑤). 크기 38×30, 눌린 쪽은 지금처럼 파란 바탕.
  - 주간 뷰: 달력 + 세로 칸 4개(요일 열을 뜻함).
  - 오늘 뷰: **한 장짜리 일력 + 날짜 숫자** — "하루 단위 뷰"로 읽히게. 숫자 = 오늘 뷰가 보여 주는 날(다른 날로 옮기면 그 날짜), 주간 뷰일 때는 오늘 날짜.
- 이름·단축키는 `aria-label`·툴팁(`주간 뷰 (Alt+V)`, `오늘 뷰 · 10/22(목) (Alt+V)`).
- 인라인 SVG(`src/ui/common/icons.tsx`), 숫자는 본문 글꼴 — 외부 아이콘 글꼴 없음(CLAUDE.md 4-1).

| 3 | 끌기 범위 | ✅ 보고 있는 주의 모든 칸(다른 요일·업무) + 오늘 뷰 카드끼리 | 같은 칸 안 순서만 |
| 4 | 옮길 때 표시 | ✅ ★·반복 연결·연결된 메모 모두 따라감 | 다른 칸으로 가면 반복 연결은 끊음 |
| 5 | 연계 메모 본문 | ✅ 비움(타이틀 띠가 항목을 보여 줌) | 항목 글을 첫 줄로 복사 |
| 6 | 연결 단위 | ✅ 상자 1개 = 항목 1개(같은 주), 항목 1개 = 상자 여러 개 | 한 상자를 여러 항목에 |
| 7 | 집계·엑셀의 연계 메모 | ✅ 메모 글 그대로(타이틀 안 넣음) | `[메모]`에서 연계 상자 앞에 `(업무명)` 앞머리 |
| 8 | 항목을 지우면 | ✅ 메모는 남고 "연결된 항목이 삭제됨" + [연결 해제] | 연결 자동 해제 / 메모도 함께 삭제 |
| 9 | 보드 쪽 배지 | ✅ 항목 끝 배지(메모 아이콘 + 수), 누르면 그 메모로 | 배지 없음 |
| 10 | 중요 목록 업무 머리 | ✅ 묶음 › 업무명 › 항목, 머리 접기 없음 | 업무 머리를 접고 펼 수 있게 |
| 11 | 오늘 아이콘 숫자 | ✅ 오늘 뷰가 보여 주는 날(주간 뷰에서는 오늘) | 늘 오늘 날짜 / 숫자 없는 일력 |
| 12 | 진행 순서 | ✅ V1(삭제·중요 목록·아이콘, 작고 매일 쓰는 것) → V2(끌어서 옮기기) → V3(업무연계 메모) | 업무연계 메모 먼저 |
