## 2. 현행 구조와 변경 경계

- `UniverseView.tsx`: `FocusMap`은 SVG, `GalaxyMap`은 2D Canvas. 별도 배치·`usePanZoom`으로 모드 전환 때 연속 카메라가 없다.
- `domain/universe.ts`: `layoutFocus` / `layoutGalaxy`는 2D 결정적 배치. `universeStore.ts`에 mode/view/seed/selected/filter/time 보관.
- `Universe.module.css` 지도까지 전역 테마 토큰 사용. 이번 사용자 요청은 기존 `universe-spec.md`의 지도 테마 3종 적용·의존성 0 원칙을 해당 영역에 한해 대체한다.
- 그래프 생성·노드 ID·원본 열기·직접 연결·지식 카드·근거 묶음·시간/공간 필터는 재사용한다. 원문·관계의 의미를 모션으로 변경하지 않는다.
- 승인 전 제품 `src/`·의존성·DB·빌드 워크플로를 변경하지 않는다. HTML 프로토타입은 합성 데이터로 움직임을 설명하며 실제 앱 연결은 없다.

## 3. 실제 레퍼런스와 채택 범위

공식 공개 화면을 **원본 그대로** 저장했다. 새 Universe 시안과 타사 화면을 분리한다. 온라인 데모는 사용자가 링크에서 직접 조작할 수 있다. 이 환경에서는 외부 데모 사이트의 직접 접속이 제한돼 공식 화면·공식 설명·예제 소스를 확인했으며, 서비스의 최신 실행 화면을 직접 조작했다고 주장하지 않는다.

| 자료 | 실제 화면 / 동작 | 가져올 것 / 가져오지 않을 것 |
|---|---|---|
| Obsidian Graph view | [공식 설명](https://help.obsidian.md/plugins/graph) · [공식 화면 원본](https://raw.githubusercontent.com/obsidianmd/obsidian-help/master/en/Attachments/obsidian-graph-view.png) · [설명 원문](https://github.com/obsidianmd/obsidian-help/blob/master/en/Plugins/Graph%20view.md) | 전체/Local Graph, 휠 확대·드래그 이동·주변 연결 강조. **3D나 휠 자동 모드 전환 사례는 아님** |
| 3D Force Graph | [실제 3D 대형 그래프 데모](https://vasturiano.github.io/3d-force-graph/example/large-graph/) · [선택 노드로 카메라 이동 데모](https://vasturiano.github.io/3d-force-graph/example/click-to-focus/) · [공식 화면](https://raw.githubusercontent.com/vasturiano/3d-force-graph/master/example/preview.png) | 실제 깊이·회전·노드 접근 카메라. **완성된 지식관리 서비스가 아니라 시각화 라이브러리 예제** |

3D 카메라 예제 소스의 `cameraPosition(..., 3000)`을 확인했다. 우리 전환 시간은 이보다 짧게 제안한다. 공식 이미지의 재배포 범위·고지는 구현/외부 공개 전 확인하며 레퍼런스는 리뷰 자료에만 둔다. 앱 번들에 포함하지 않는다. 출처·확보일·SHA256은 시안 `references/README.md`에 기록한다.

## 5. 조작과 의미적 확대 규칙

| 입력 | 다이나믹 3D | 정적 2D |
|---|---|---|
| 휠·트랙패드 핀치 | 카메라 거리, 지시한 노드/선택 노드 쪽 접근 | 현재와 같은 2D 줌, 자동 초점 전환 없음 |
| 빈 곳 왼쪽 드래그 | 중심 주위 회전(roll 금지, 수직 ±70°) | 2D 이동 |
| Shift+왼쪽 드래그 / 오른쪽 드래그 | 화면 평면 이동, 지도에서만 문맥 메뉴 억제 | 2D 이동 |
| 노드 클릭 | 선택·상세 열기. 카메라 강제 이동 없음 | 동일 |
| 노드 더블클릭 / [초점으로] | 해당 노드 초점 전환 | 즉시 현재 초점 2D 배치 |
| [+] / [-] | 휠과 동일 확대·축소 | 2D 확대·축소 |
| [은하] / [초점] | 카메라 전환의 명시적 대안 | 즉시 모드 전환 |
| [전체 보기] | 현재 필터 결과에 맞춤 | 2D 맞춤 |
| [이전 시점] / Esc | 초점 진입 직전 은하 위치·회전·선택 복원 | 지도 포커스일 때 초점에서 은하로, 편집기 Esc 우선 |

- 모드 `galaxy/focus`와 표현 `dynamic/static`은 독립 상태다. 정적은 기존처럼 **2D**를 유지하며, 다이나믹에서는 은하·초점이 모두 진짜 3D다.
- 진입 대상 우선순위: 포인터 아래 노드 → 현재 선택 노드. 빈 공간 + 미선택이면 확대만 하고 임의 노드를 고르지 않는다.
- 거리의 화면 반지름 정규화 값 q 사용: 전체 맞춤을 q=1.0으로 두고, 대상이 있는 확대에서 q ≤ 0.42에 초점 진입. 초점에서 q ≥ 0.65면 은하 복귀. 0.42~0.65 완충 구간·180ms 유지·전환 중 재진입 잠금으로 튐 방지. 수치는 시안 검토 후 실장비에서 조정.
- 휠 deltaMode(줄/페이지/픽셀)를 정규화하고 누적 속도를 제한한다. 지도 포커스/포인터가 지도 안일 때만 소비하며 상세 패널 스크롤은 가로채지 않는다. Ctrl+휠은 지도 안에서 핀치로 다루고 앱 전체 글자 확대는 별도 단축키와 충돌 검증.
- 초점은 같은 3D 좌표의 선택 주변 1단계(최대 표시 수는 성능 단계에서 조정)를 선명하게 하고 나머지를 희미하게 한다. 다른 레이아웃으로 순간 교체하지 않는다.
- 필터로 제외된 노드는 자동 복구하지 않는다. 선택 노드가 제외되면 선택 해제 안내·필터 결과 전체 맞춤. 멀리서 접힌 군집은 대표 개수+명시적 펼치기 제공, 개별 노드와 구별.

## 6. 모션·글자·테마

- 카메라 접근/복귀 650ms ease-in-out, 선택 강조 160ms, 멀어지는 노드 fade 240ms. roll·급격한 가속·무한 터널 연출 없음.
- 유휴 카메라 **자동 회전은 기본 꺼짐**. 선택 고리의 약한 호흡과 사용 후 160~240ms 관성으로 생동감 표현. 제목/클릭 표적은 떠다니지 않는다.
- 관계 흐름은 선택 노드와 직접 연결된 선만, 방향 의미가 있는 관계에서만 방향 표현. 소속/관련 관계에는 가짜 방향·인과를 부여하지 않는다.
- 조작 중 라벨·HUD 펄스는 억제. 선택/hover/직접 연결 제목 우선, 먼 노드는 거리별 생략·충돌 방지. 가까운 노드가 뒤의 노드를 가리면 목록/검색으로 접근 가능.
- 다이나믹↔정적 전환 시 필터·선택·시점 맥락 유지, 모드 값은 바꾸지 않음. 정적에서는 관성·유휴·전환 애니메이션 모두 끔. 지도는 두 표현 모두 어두움.
- `prefers-reduced-motion` 기본 준수: 첫 실행 정적 추천, OS 설정이 reduce로 바뀌면 모션 중단·안내. 사용자가 명시적으로 다이나믹 선택 가능하되 유휴 모션은 끔.
- 테마 격리: 지도 루트 `--u-space-*` 전용 토큰, canvas 배경/라벨/줌 버튼/툴팁 포함. 나머지 패널은 기존 앱 토큰. 다크 지도만 켰다고 전체 앱 테마를 바꾸지 않음.
- 키보드: Tab으로 지도 도구·대체 목록 접근, 방향키 회전(정적 이동), Shift+방향키 이동, +/- 줌, Home 전체 맞춤. 검색/편집기 안에서는 지도 단축키 무시.

## 7. 구현 설계 (승인 후)

추천: **Three.js + 공통 카메라 컨트롤러**, 그래프 의미/상태는 기존 코드 재사용. force-graph 예제를 그대로 붙이는 안보다 기존 결정적 배치·키보드·필터 동작을 통제하기 쉽다. 신규 의존성 추가는 이 설계 승인 후 고정 버전·전이 의존성·라이선스·지원 WebGL 버전을 검증한 뒤 진행한다.

- `domain/universeLayout3d.ts`: 노드 ID 기반 결정적 3D 배치·군집/중심·장면 경계. 그래프 조회·DB 쓰기 없음. 실행마다 무작위 재배치 금지. 데이터 변경 시 기존 노드 위치 보존.
- `ui/universe/scene/UniverseScene.tsx`: 하나의 WebGL 장면, instancing/배치 선·깊이·ray picking. 라벨은 제한된 DOM/SVG overlay. 외부 폰트/텍스처/CDN 없음.
- `cameraController.ts`: camera pose/목표/이전 시점·휠 정규화·전환 상태·취소·단축키. 현재 `focusOn`/`select`와 연결하되 렌더 루프에서 저장소 업데이트하지 않음.
- `StaticUniverseMap`: 기존 SVG/Canvas 2D 보존, 전용 다크 토큰만 적용. WebGL 미지원·context lost면 상태 유지 후 정적으로 전환·이유 안내, 복구는 명시적으로 제공.
- 표현 기본 다이나믹(성능 지원 시), OS reduce는 정적. 앱 설정에 표현/비주얼 프리셋만 저장(기존 Platform 설정 경로). 카메라·hover는 세션 상태로만, 일지에 저장하지 않음.
- 워크스페이스 전환·닫기: requestAnimationFrame/이벤트/pointer capture/worker 정리, 지연 결과는 repo+load generation 검사. `detachAll`과 연동해 이전 공간 결과 폐기.
- GPU dispose: geometry/material/renderer·context·resize observer 해제. 비활성·문서 숨김 시 루프 정지. 재진입 때 살아 있는 루프 1개만.

## 8. 성능·실패 처리와 검증 관문

- 목표(확정 보장 아님): 1천 노드/3천 선에서 회전 45fps 이상, hover 지연 p95 100ms 이하. 5천/1만5천 선은 군집/LOD로 화면 노드 제한, 30fps 목표. 표시 개수·생략 여부 명시, 데이터 자체를 버리지 않음.
- DPR 최대 1.5~2, bloom 전체화면 효과는 기본 끔. 2초 이상 프레임 저하 시 효과 축소 안내·정적 전환 제공(사용자 선택 존중).
- 대표 장비: Windows WebView2 회사 PC + 사용자 M4 Pro WKWebView. 최저 지원 GPU·macOS와 선택 Three.js 버전의 WebGL 지원은 첫 기술 검증에서 확인.
- 검증: 임계값 양방향/히스테리시스·빠른 반전·빈 곳 줌·포인터 캡처 취소·클릭/드래그 구분·고 DPI·트랙패드·키보드·포커스·3테마 지도 동일·정적/OS reduce·WebGL context lost.
- 회귀: 원본 열기·관계 편집·지식 카드·근거 묶음·전체 필터·시간 막대·다른 공간 읽기 전용. 3회 이상 공간 전환 후 일지/메모 무결성 + GPU 메모리/루프 누수 확인.
- 가상 노드 데이터만 사용. 타사 화면은 레퍼런스 탭 전용. 제품 번들·서비스 외부 통신 추가 없음.

| D1 시각 스타일 | A 차분한 우주 (B HUD / C 미니멀 비교 가능) |
| D2 정적 해석 | 현재 2D 조작·배치를 유지 + 지도 다크 배경 |
| D3 다이나믹 기본 | WebGL 지원 + OS reduce 아님 → 다이나믹, 그 외 정적 |
| D4 자동 초점 전환 | 대상 노드가 있는 확대만, 축소하면 직전 은하 시점 복원 |
| D5 모션 강도 | 자동 회전 꺼짐, 약한 강조/조작 관성만 |

시안은 Canvas 원근 투영으로 동작을 설명한다. 제품 WebGL 성능·피킹·GPU 복구를 검증한 결과가 아니며 임계값은 단순화되어 있다.

## 10. 추가 요구 — 필터·상세 패널 접기/펼치기 (2026-11-05)

사용자 피드백: 기본 패널이 지도를 많이 차지하므로 필요에 따라 표시한다. 기존 3열 고정 배치를 **지도 전체 폭 + 필요할 때 펼치는 보조 패널**로 대체한다. A/B/C와 다이나믹/정적 모두 공통 규칙이다.

- **첫 진입은 두 패널 모두 닫힘**. 빈 패널 자리·폭·구분선은 남기지 않는다. 지도 상단 왼쪽 `☷ 필터`, 오른쪽 `▤ 상세` 버튼은 항상 표시한다. 버튼에 텍스트·펼침 상태를 함께 제공한다.
- 펼침은 지도 위에 겹치는 비모달 패널: 필터 왼쪽 250px, 상세 오른쪽 290px(시안 기준). 지도를 다시 배치하거나 카메라를 자동으로 이동하지 않는다. 패널 밖 지도는 계속 회전/확대 가능하다.
- 넓은 창에서는 두 패널을 독립적으로 함께 열 수 있다. 1050px 이하에서는 한 패널만 열고, 다른 패널을 열면 앞 패널을 닫는다. 800px 이하에서는 도구 줄을 줄바꿈하고 패널은 지도 폭에서 좌우 18px 여백을 둔 최대 290px 폭으로 제한한다. 제품 구현 시 최소 창 폭에서 버튼 겹침을 검사한다.
- 노드 클릭은 선택·가벼운 제목/종류 미리보기만 갱신하며 **닫힌 상세 패널을 자동으로 열지 않는다**. 현재 선택을 유지한 채 [상세]로 펼친다. 상세가 열려 있으면 새 선택 내용으로 갱신한다. 노드 더블클릭은 기존 초점 전환을 유지한다.
- 패널의 × 또는 같은 토글 버튼으로 닫는다. 지도 클릭만으로는 닫지 않아 조작 중 뜻하지 않게 사라지지 않는다. Esc는 현재 열린 패널 중 마지막 사용 패널부터 닫고 토글로 포커스를 돌린다. 편집 대화상자가 있으면 해당 대화상자의 Esc 처리를 우선한다.
- 필터를 접어도 조건은 유지된다. 제품에서는 활성 필터 개수와 [초기화]를 접힌 상태의 도구 줄에서도 제공한다. 패널 열림 여부와 필터 조건을 분리한다. 조건 변화·선택·시간/공간 변경은 패널을 강제로 열지 않는다.
- 패널은 앱 테마, 지도와 지도 도구는 독립 다크. 검색/폼/목록 위 휠은 패널 스크롤이며 카메라 줌으로 전달하지 않는다. 드래그 캡처 시작점이 패널이면 지도 조작 금지.
- 접기/펼치기는 session UI 상태로만 보관(일지 DB 변경 없음). 다른 화면에서 Universe로 돌아올 때 같은 세션 열림 상태 복원, 앱 재시작 후 두 패널 닫힘. 목록 보기에도 같은 패널 토글 규칙 적용.
- `aria-expanded`·`aria-controls`·패널 이름·키보드 닫기·포커스 복원 제공. 열 때 첫 조작 가능한 컨트롤에 포커스, 비모달이므로 포커스 가두기 없음. 좁은 창에서 반대 패널을 닫을 때 숨겨진 곳에 포커스가 남지 않게 한다.
- 펼침 전환은 opacity/짧은 160ms slide만, 정적/OS reduce에서는 즉시 표시한다. 카메라·선택·필터는 접기 동작 전후 동일해야 한다.

**D6 추가 검토안: 기본 두 패널 접힘 + 지도 위 독립 펼침, 좁은 창에서는 한 번에 하나.**

시안 구현 범위: 기본 접힘·독립 토글·패널 ×·Esc·좁은 창 상호 배타·선택 내용 갱신. 실제 필터 적용 개수/초기화·세션 복원·목록 보기 연동은 제품 구현 단계이며 현재 프로토타입에 연결하지 않았다.


## 11. A안 구현 기록

- 설계·시안 커밋 `c50a735`를 신규 브랜치에 푸시한 뒤 사용자 승인 A안을 구현했다. 버전은 main 병합 전 `1.14.0`을 유지한다.
- Three.js `0.180.0`과 타입을 고정했다. 런타임은 로컬 WebGL 렌더링만 사용하며 URL 로더·CDN·외부 API를 사용하지 않는다. MIT 전문을 `public/licenses/Three-MIT.txt`에 포함하고 설정의 라이브러리 표에 표시한다.
- 노드 ID 기반 안정적인 3D 좌표·공통 카메라·회전/이동/줌·선택 강조·직접 연결 방향·초점 접근과 은하 복귀, 정적 2D 보존, WebGL 초기화 실패/context lost 시 정적 전환을 연결했다.
- 필터/상세는 기본 닫힘·독립 토글·좁은 창 한 패널·Esc 포커스 복원. 조건 유지/개수/초기화·선택과 패널 열림 분리. Universe에 진입할 때 기존 중요 업무 패널이 지도를 가리지 않도록 처리했다.
- 지도 색상은 전역 테마와 격리한다. 표현 취향은 기존 Platform config 경로에 `universeMotion`으로 저장하며 일지/스키마는 바꾸지 않는다. OS 모션 감소는 정적 모드로 전환한다.
- 실제 Chromium WebGL(소프트웨어 렌더링 포함) 화면과 모드 재진입을 확인했고 페이지 오류가 없었다. 구현 화면 `mockups/universe-renewal-v2/implemented-*.png`.
- 정적 지도·원본 열기·관계·카드·근거·다중 공간에 대한 기존 회귀 검사와 신규 패널 테스트를 실행했다. 전체 단위 검사 중 문서 생성 전 가이드 불일치 1건은 HTML/PDF 재생성 후 해당 스위트 재검사로 해결했다.
- 가이드 장면 14/대응표/화면/HTML/PDF 갱신. Windows 회사 PC·Mac WKWebView의 GPU/트랙패드 실기와 1천/5천 노드 성능 목표 수치는 Linux 검증 결과로 대체하지 않는다. 대규모 LOD·라벨 충돌 방지는 후속 성능 검증에서 보강할 항목이다.

### 최종 로컬 검증

- 전체 단위 테스트: 49개 파일, 465개 통과.
- Chromium E2E: 탐색/패널/다중 공간 무결성 17개 통과, 카드/근거 묶음 5개 통과.
- 실제 WebGL 카메라의 확대→초점/축소→은하 왕복 및 정적 모드 재진입: 통과, 페이지 실행 오류 없음.
- TypeScript·ESLint·Prettier·프로덕션 웹 빌드·릴리스 노트·가이드 검사 통과.
- Windows/macOS 설치 파일 생성·릴리스 게시·main 병합은 이 구현 커밋에 포함하지 않는다. 사용자 실기 검토를 위한 작업 브랜치다.

### 상단 전환 버튼 아이콘화 (2026-11-05)

사용자 요청에 따라 지도 표현(큐브/평면), 탐색 모드(조준점/궤도), 보기(지도/목록)의 여섯 버튼을 공통 16px 모노그램 SVG 아이콘으로 변경했다. 텍스트는 title/aria-label로 보존하고 aria-pressed·배경·아래 강조선으로 선택 상태를 표시한다. 기존 data-testid·전환 동작은 유지한다. 브라우저에서 여섯 버튼의 이름·툴팁·SVG와 세 그룹 전환을 확인했으며 TypeScript·ESLint·Prettier·가이드 검사를 통과했다. 실제 화면·가이드 HTML/PDF 동반 갱신.


### 패널 너비와 설정 메뉴 개선 (2026-11-05)

- 필터 오른쪽·상세 왼쪽 가장자리 드래그/←→ 10px·더블클릭 초기화·Home/End 최소/최대. 화면 안에서 220~640px 범위를 사용하며, 넓은 창에서는 양 패널이 겹치지 않도록 각각 지도 폭의 절반 미만으로 제한한다. 창이 좁아지면 보이는 폭만 줄이고 기존 선호 폭은 유지한다.
- 기존 Platform config에 `universePanelWidths`로 PC 취향을 저장한다. 드래그 중 DB/파일 쓰기 없이 놓을 때만 직렬화 저장하며, 비동기 설정 읽기와 사용자 조작 경합을 방지한다. 일지 형식 변경 없음.
- 설정 메뉴 영역은 최소 360px 및 내용 길이에 맞춰 확장한다. 설명은 줄바꿈·말줄임 없이 표시하고 좁은 화면의 가로 탭에서도 설명을 숨기지 않는다.
- Chromium E2E: 드래그·재열기·키보드·초기화, 1440px/1024px에서 모든 설명의 한 줄·잘림 없음·페이지 가로 넘침 없음 확인.
