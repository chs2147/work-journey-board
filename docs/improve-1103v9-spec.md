## N1. 항목 도구 — 시안 3개 (`item-tools-abc.png`)
지금은 마우스를 올리면 📝(메모 만들기)·↻(반복)·⋯(커서 있을 때)·🗑(삭제)가 글 오른쪽 위에 겹쳐 뜬다. 좁은 칸에서는 글을 가리고, 단추마다 보이는 때가 달라 헷갈린다(v8 확인).

| | A안 · ⋯ 하나로 모으기 | B안 · 떠 있는 도구 막대 | **C안 · 왼쪽 손잡이 메뉴(추천)** |
|---|---|---|---|
| 모양 | 오른쪽에 ⋯ 하나 → 메뉴(메모 만들기·반복·시각·옮기기·삭제) | 항목 **위쪽 바깥**에 작은 막대 [📝 ↻ ⏰ 📅 🗑] | 왼쪽 ⋮⋮ 손잡이: **끌면 옮기기, 누르면 메뉴**(A안과 같은 메뉴) |
| 글 가림 | ⋯ 하나만큼 | 없음(위 항목을 잠깐 덮음) | **없음** |
| 누르는 횟수 | 메뉴 → 1번 더 | 1번 | 메뉴 → 1번 더 |
| 새 단추 | ⋯ | 막대 | **없음**(이미 있는 ⋮⋮) |
| 공통 | 📝N·🗄 바로 누르기 유지 · ↻는 켜졌을 때만 상태로 표시(누르면 끄기) · 오른쪽 클릭 = 같은 메뉴 · 단축키(`Alt+R`·`Alt+O`·`Alt+D`·`Alt+Delete`) 그대로 · 윈도우·맥 같은 모양 |

## 9. 구현 기록 (`v1.7.1`, 2026-11-03)
- **N1 C안**: 글 오른쪽에 겹쳐 뜨던 [메모]·↻(마우스 올림)·⋯·🗑을 모두 뺐다. 항목 왼쪽 **⋮⋮ 손잡이 하나**가 끌면 옮기기(`rowDrag.ts` — 움직이지 않고 떼면 `onTap`), 누르면 **항목 메뉴**(`ItemActions.tsx` `ItemMenu`): 연결된 메모 만들기 · 매주 반복 켜기/끄기(본 항목만) · 시작 시각… · 다른 날로 옮기기… · ─ · 삭제(세부 항목이 있으면 "세부 항목 N개와 함께 삭제", 올리면 지워질 줄을 붉게 미리 보임). 메뉴는 손잡이 왼쪽 끝에 맞춰 열리고 첫 줄에 포커스, `↑`/`↓`·`Esc`. 오른쪽 클릭 = 같은 메뉴. 아이콘은 모두 같은 선 아이콘(`icons.tsx` `IconRepeat`·`IconClock`·`IconMoveDate`).
- **손잡이 크게(사용자 지시)**: 18×24px(예전 작은 글자 ⋮⋮ → 점 6개 SVG, 반지름 1.6), 마우스를 올린 항목에서 흰 바탕 + 테두리로 늘 또렷하게, 손잡이에 올리거나 메뉴가 열리면 강조색. 옆 칸 글을 덮지 않도록 칸 안 왼쪽 여백 18px(`.cellBody`).
