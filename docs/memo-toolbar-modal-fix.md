# 메모보드 보기 도구·링크 모달 수정

2026-11-07 · 사용자 요청에 따라 main 직접 수정 · 1.22.1 / DB18 유지

- 주간·데일리·확대 메모보드 및 업무 메모보드 공통 NoteDock의 관계선 보기/숨김을 생성 그룹에서 상단 오른쪽 보기 툴바로 옮긴다. 기존 관계선 표시 상태와 빈 보드 안내 동작을 유지한다.
- 링크 넣기 팝업은 body 포털의 native dialog.showModal()로 열어 top layer에서 표시한다. 창 전체 반투명·blur 배경과 브라우저의 inert 동작으로 배경 클릭·포커스 접근을 막는다. 업무 보드의 다른 독립 창은 막지 않는다.
- Tab/Shift+Tab은 모달 내부에 유지하고 Esc(한글 조합 중 제외)·취소·바깥 클릭으로 닫으며 기존 호출 버튼으로 포커스를 복원한다. React 포털의 키 이벤트가 메모 줌·업무 전역 단축키로 전파되지 않게 한다. 캡처 단계의 그룹 이동·키보드 연결 처리도 열린 모달에서 실행하지 않는다.
- 주소 검증·링크 카드 생성·저장 방식과 DB 구조는 변경하지 않는다.
- 회귀 검증: 주간·확대·데일리·업무 보드에서 보기 도구 위치, top layer/전체 크기, 포커스 차단·Tab·단축키, 배경 도구 좌표의 실제 클릭 차단, 취소/재열기/정상 추가. 기존 관계선·링크 편집 및 CSP 검사 포함.

실제 적용 화면: [전체 배경 차단 모달](mockups/memo-modal-v1.22.1.png).

검증: Chromium 기능/CSP 회귀 23개 통과. 추가 한글 조합 Esc 회귀 포함 모달 네 화면 검증, 타입·린트·포맷·웹 빌드 및 릴리스/가이드/Feature List 일치 검사. 기존 1.22.0 CI·설치판·릴리스·사이트 모두 성공 완료를 확인해 진행 중 실행을 중단하지 않는다.
