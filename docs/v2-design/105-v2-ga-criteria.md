## 3. 2.0.0 출시 때 할 일

1. 관문 A~F 결과를 이 문서 4절에 기록하고 사용자 승인.
2. 최신 `main`에서 `release-2.0.0` 작업 브랜치(CLAUDE.md 6절) → `package.json` `version` = `2.0.0`, `releaseLabel` 삭제(앱 판 표시·릴리스 제목에서 Open Beta가 빠짐).
3. 릴리스 노트 `v2.0.0`(Open Beta 동안 바뀐 것 요약)·README·VERSION_HISTORY·가이드 기준 판·Feature List.
4. 이전 main은 `release/v1.5x.y`로 보존 → `main` 반영 → 릴리스 `v2.0.0`(Latest) 확인 → 1.5x에서 업데이트 실기.
5. 운영 서버는 그대로(판 번호와 무관) — 출시 직후 끝 점검 12/12 한 번 더.
