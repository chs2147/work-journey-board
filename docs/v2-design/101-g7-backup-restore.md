# 101. G-7 백업·복구·장애 대응

2026-11-17 · 브랜치 `v2-g-stage` · 97문서 G-7 · 결정 G-D6(월 1회 관리자 내보내기 + 각 기기 이 기기 일지, 무료 플랜 안)

## 0. 원칙

- 무료 플랜은 자동 백업을 내려받을 수 없다 → **관리자 내보내기**가 서버 쪽 백업이다. 각 기기의 이 기기 일지(온라인 사본)와 이 PC 공간은 그대로 두 번째·세 번째 사본.
- 내보내기 형식 = **앱의 이 기기 사본과 같은 형식**(`header.json`·`records.json`·`<sha256>.bin`). 그래서 서버가 없어도 앱의 되살리기 코드(`restoreFromCache`)로 **로컬 일지(.db)** 로 되살릴 수 있다.
- 내보낸 자료에는 실제 기록이 들어 있다 → 저장소·증거 파일에 넣지 않는다(CLAUDE.md 4-2). 증거에는 개수만.

## 1. 관리자 내보내기(`poc/v2-ops/export.mjs`)

```bash
node poc/v2-ops/export.mjs --export-development <빈 출력 폴더>
```

- 필요 변수(값은 채팅·저장소에 두지 않음): `WJB_CLOUD_ENV=development`, `WJB_SUPABASE_DEV_PROJECT_REF`, `WJB_SUPABASE_DEV_MANAGEMENT_TOKEN`(읽기 전용 SQL), `WJB_SUPABASE_DEV_SERVICE_ROLE_KEY`(그림 내려받기 — 새 secret 키 또는 예전 키, 종류에 맞는 머리로).
- 게시된 공간마다: 동기화한 공간 = 지금 기록(지움 표시 뺌), 아니면 게시본 · 그림 = 기록이 참조하는 것만 · 내려받은 그림은 크기·SHA-256 확인 · `export-manifest.json`에 공간·행·그림 수와 파일 해시.
- 서버는 읽기만 한다(SQL은 `SET TRANSACTION READ ONLY`). 출력 폴더가 비어 있지 않으면 거절. 운영은 G-2 뒤 같은 도구에 운영 줄(`--export-production`)을 더한다.
- **주기**: 매월 1일 관리자가 자기 PC에서 실행하고, 결과 폴더를 개인 백업 위치(외장 디스크·개인 클라우드)에 둔다. 최근 3개월치 보관.

## 2. 복구 리허설(`tests/unit/onlineExportRestore.test.ts`)

```bash
WJB_EXPORT_DIR=<내보낸 폴더> WJB_RESTORE_OUT=<되살린 .db 둘 폴더> npx vitest run tests/unit/onlineExportRestore.test.ts
```

- 공간마다 내보낸 파일 → 앱 일지 바이트 → 앱처럼 열기(최신 구조로 마이그레이션, 무결성 확인) → 표별 행 수. 그림 해시가 다르면 되살리지 않는다.
- 가상 샘플 경우는 늘 돈다(CI): 업무·기록·주간 메모·그림이 원본과 같은지.
- **2026-11-17 개발 서버 실행**: 공간 3개 · 기록 93행 · 그림 2개 내보냄(해시 확인) → 3개 모두 되살려 열림(`evidence/g7-export-restore-dev.json`, 개수만).

## 3. 서버를 잃었을 때(복구 순서)

1. 내보낸 폴더로 로컬 일지를 되살린다(2절) → 각 사용자가 이 PC 공간으로 바로 쓸 수 있다(온라인 없이).
2. 새 프로젝트를 G-2 절차서대로 만든다(SQL 001~031, 버킷, 인증, gateway, 관리자).
3. 앱에서 [온라인 워크스페이스 만들기…] › 이 PC 기록으로 → 되살린 일지를 골라 다시 올린다.
4. 각 기기의 이 기기 사본에 보내지 못한 변경이 남아 있으면, 그 사본도 같은 방법으로 로컬 일지로 되살려 비교한다.

## 4. 모니터링·장애 대응

| 상황 | 알아채는 곳 | 대응 |
|---|---|---|
| 그림·DB가 무료 한도에 가까움 | 관리 카드 전체 그림·전체 DB **한도 임박(80%)**·**한도 초과** 배지 | 안 쓰는 그림 정리(매일 03:10 KST 자동) 확인 → 계정 한도 조정 → 큰 공간 소유자에게 정리 요청 |
| 프로젝트 일시 정지(무료 플랜 1주 미사용) | 앱 알약 "오프라인 · 이 기기에 저장됨" 지속 | KeepAlive(pg_cron 매일 12:00 KST) 확인 → 대시보드에서 다시 켜기. 그동안 기기 저장은 그대로, 켜지면 자동으로 보냄 |
| gateway 오류 | 알약 "동기화하지 못했습니다(…)" · `/v2/me` 503 | 대시보드 Edge Functions 로그 → 직전 판으로 다시 배포(`deploy.mjs`) |
| 서버 열쇠 유출 의심 | — | Settings › API Keys에서 `wjb_gateway` 비밀 키를 새로 만들고 예전 것 삭제(gateway는 이름으로 읽어 배포 없이 바뀜) |
| 계정 남용·이상 사용 | 관리 카드 계정 목록 | [정지](읽기만) → 필요하면 [계정 삭제…] |
| 데이터 손상 의심 | 사용자 보고 | 바로 내보내기(1절) → 리허설(2절)로 확인 → 3절 |
