# 12. V2 MVP 범위·설계 결정 통합안

2026-11-08 (KST) · `v2-design` · 검토용 기준안

## 12.1 확정과 추천의 구분

**사용자 확정:** 한국어/영어, 개인 여러 기기 우선, 퍼블릭 클라우드 가능 모델, 소규모 출발, 초기 아시아 리전 범위, 현재는 상세 설계만 진행.

**미확정 추천 묶음:** Desktop Windows/macOS부터, 관리형 PostgreSQL/Auth/Storage 기반(우선 Supabase 검증), 이메일 OTP, TLS+서버 저장 암호화, V1 복사 전환, 공간별 로컬/온라인 백업/증분 동기화, 기기별 즉시/주기/수동. 이 묶음은 사용자가 각각 선택한 사실로 기록하지 않는다.

V2라는 프로젝트명은 제품2.0.0 확정이 아니다. PoC 통과는 출시/운영 배포/실제 사용자 자료 업로드 승인과 다르다.

## 12.2 검증 PoC와 고객용 MVP를 구분

- **PoC:** 가상 계정/공간·명시한 데이터로 기술적 불확실성을 검증한다. 기능을 일부만 구현할 수 있으나 실제 고객 업무를 맡기지 않는다.
- **MVP:** 고객이 쓸 수 있는 최소 완결 제품이다. 아래 필수 경로와 운영/복원 관문을 모두 충족해야 한다. 온라인 백업만 제공한 버전은 ‘온라인 백업 지원’으로 안내하고 실시간 동기화 MVP라고 하지 않는다.
- 기존 desktop 기능은 원칙적으로 보존한다. 다국어 이전/저장 경계 분리 때문에 기존 기능을 임의 삭제하는 범위 승인이 아니다. 플랫폼별249개 검토 CSV는 지원 확정표가 아니다.

## 12.3 고객용 MVP 제안 범위

| 영역 | 필수 포함 제안 | 검토 기준 |
|---|---|---|
| 로컬 기능·저장 | 기존 업무/메모/노트/이미지/자료/Universe·백업 유지 | 로컬 저장 실패/공간 혼입 회귀 없음 |
| 언어 | ko/en 앱·오류·네이티브 안내·출력·사이트·현재 가이드 | 필수 키100%, 사용자 데이터/날짜 불변, 실제 PDF 렌더링 |
| 계정 | 이메일 OTP·기기 세션·로그아웃/회수·계정 복구 정책 | 계정/공간 격리, 메일/세션 회수 검증 |
| 공간 연결 | 새 온라인 공간·V1 사본 전환·새 기기 다운로드 | 원본 보존, staging 검증, 이름으로 자동 합치기 금지 |
| 동기화 | 로컬 우선 outbox/push/pull·즉시/주기/수동·오프라인 재개 | revision/멱등성/cursor/generation·참조 정합성 |
| 충돌 | 같은 노트/보드·삭제/수정 충돌 목록과 사본 보존 | 조용한 덮어쓰기/유실 없음, 관련 없는 수정은 계속 전달 |
| 자산 | 이미지 원본 업로드·검증·다운로드·보존 참조 GC | 깨진 이미지/원본 소실/무권한 접근 없음 |
| 복구 | 온라인 백업·새 로컬 공간 복원·온라인 전체 복원 영향 확인 | 실제 복원 훈련, 구 generation 쓰기 차단/재조정 |
| 운영 | 비공개 저장·한도/모니터링·백업·문의/삭제 정책 | 장애/계정 상실/용량 초과 시 사용자 자료 보존 |

위 표의 동기화 처리 방식은 로컬 저장이 서버 성공을 기다리지 않고 먼저 완료하는 구조다. 숫자 기본값(750ms·5초·5분/15분/30분·백업30일/수동10개)은 추천 초안이며 서비스 SLA·요금제 약속이 아니다.

## 12.4 1차에서 분리할 제안 범위

- 팀 초대/타 계정 공유/동일 문장 공동 편집·CRDT.
- Web/Mobile 정식 동등 기능 출시. 도메인/프로토콜 경계와 후속 지원 계획은 처음부터 유지한다.
- 여러 클라우드 제공자 선택 UI·다중 대륙 복제·고객 자체 호스팅.
- 두 개의 내용 있는 공간 자동 합치기, 로컬 디렉터리의 실제 파일 자동 업로드.
- 소셜 로그인/기업 SSO·편의 페어링 코드의 동시 출시.
- 모든 과거 기술 문서/48개 릴리스 기록의 완역. 현재 고객 경로와 과거 문서 연결 안내는 포함한다.

E2EE는 단순 후순위 기능으로 미루는 목록에 넣지 않는다. 채택 여부가 키·검색·복구 계약을 바꾸므로 구현 전 결정해야 한다.

## 12.5 단계별 Go/No-go

| 단계 | 결과물 | 다음 단계로 넘어가는 기준 |
|---|---|---|
| G0 설계 잠금 | 이 문서 범위 + 12.6 미확정 결정 | 사용자 범위 검토, 구현할 PoC와 자원/데이터 범위 확정 |
| G1 로컬 계약 검증 | 공통 명령·V1 사본·outbox 원자성 | 원본 보존·충돌/재시도·공간 전환 검증 통과 |
| G2 클라우드 검증 | 가상 계정/기기·Auth/DB/blob·복원 | 선택 리전/권한·세션 회수·이미지/PDF·실제 복원 증거 |
| G3 동기화 검증 | 주기/수동 증분 후 즉시 알림 | 중복/끊김/동시 수정/구세대 요청 처리 통과 |
| G4 고객 경로 통합 | ko/en·설치/출력/가이드·실기 | 필수 기능/언어/OS·운영·회수·복구 관문 완료 |
| G5 제한 출시 검토 | 운영 지표·비용·지원·복원 훈련 | 사용자 승인된 출시 범위/버전/정책과 일치 |

단계 실패 시 로그·고정 fixture·기대 결과를 남기고 계약을 수정한다. 한 기기에서 저장/다운로드가 되는 것만으로 G3를 통과하지 않는다.

## 12.6 구현 전에 결정할 핵심 항목

| 결정 | 권장 검토안 | 현재 상태 |
|---|---|---|
| 초기 플랫폼 | Desktop Win/macOS, Web/Mobile 단계 확장 | 추천, 미확정 |
| 백엔드 | Supabase 중심 PoC, 요구 미충족 시 AWS 재비교 | 추천, 사업자 미선정 |
| 실제 리전 | 아시아 내 단일 primary. DB/Auth/blob/백업/로그/메일 처리 위치 확인 | 아시아 범위만 확정 |
| 암호화 | MVP는 TLS+서버 저장 암호화, 보호 범위 명시 | E2EE 여부 미확정 |
| 기본 인증/계정 복구 | 이메일 OTP + 명시한 복구·기기 회수 정책 | 세부 복구 수단 미확정 |
| 보관/한도/장기 오프라인 | 기본값·요금·로그/tombstone 하한 연동 | 수치 미확정 |
| 첫 부하·예산 | 100명 모델을 비교 기준으로, 실제 사용자/자산/월 상한 확정 | 소규모 외 수치 미확정 |

가상 PoC는 위 가정을 문서로 고정해 시험할 수 있지만, 미정 항목을 운영 제품의 승인값으로 승격하지 않는다. 다음 문서의 검증 명세도 아직 실행되지 않았다.
