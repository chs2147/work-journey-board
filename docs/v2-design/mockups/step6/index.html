WORK JOURNEY BOARD / V2 DESIGN REVIEW / 06

익숙한 기록, 새로운 연결.

실행 격리·온라인 워크스페이스 만들기·상태와 복구를 비교하는 상세 UI 시안입니다. 모든 계정·수치·상태는 가상이며 실제 연결이나 저장은 하지 않습니다.

버튼으로 흐름 체험 · 창 닫기 Esc · 모든 아이콘은 선형 모노그램
01 · 원본은 그대로

기존 오프라인 전용 워크스페이스는 이름·ID·파일·기능을 유지합니다. 신규 온라인 워크스페이스에서 온라인 작업을 운영합니다.

02 · 저장과 전송을 구분

기기에 저장된 상태와 서버에 반영된 상태를 각각 표시합니다. 연결이 끊겨도 저장 여부를 오해하지 않게 합니다.

03 · 작업을 잃지 않는 복구

이관을 중단해도 원본과 진행 기록은 남습니다. 전송이 불확실한 작업은 확인 전까지 완료·삭제로 표시하지 않습니다.
