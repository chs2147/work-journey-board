# 6번 · 실행 격리와 온라인 연결 시안

**[한눈에 3안 비교](comparison.html)** · **[직접 조작하는 상세 시안](index.html)** · [상세 설계 정본](../../67-product-isolation-connection-ui.md)

이 자료는 UI 검토용이다. 실제 로그인·메일·파일 읽기·업로드·저장·클립보드 접근을 하지 않는다. 사용되는 계정·수치·경로는 가상값이며, 예시182MB/이미지28개는 현재 PoC의64KiB/8개 제한을 통과했다는 뜻이 아니다. 외부 통신 없이 같은 저장소의 폰트만 참조한다. 독립 파일을 복사할 경우 폰트는 OS 기본 글꼴로 표시될 수 있다.

## 검토 순서

1. [A 설정 확장](a-overview.png) / [B 공간 허브](b-overview.png) / [C 공간 메뉴](c-overview.png)를 비교한다. 추천은 기존 설정 구조를 유지하는A다.
2. 상세 HTML 상단에서A/B/C를 선택하고 ‘상세 화면 보기’를 누른다. 사본 검토의 동의는 기본 꺼짐이며 선택하면 다음 단계로 진행한다.
3. 로그인 → 원본 선택 → 검토 → 진행, ‘잠시 중단’/‘이어서 준비하기’, ‘이관 취소’/확인/정리 대기를 체험한다.
4. 창 하단 ‘시안 도구’로 전체20개 상태를 전환한다. 제품에 들어가는 버튼이 아니다. Esc로 닫으면 상단의 안/테마를 바꿀 수 있다.
5. 오프라인/충돌/기기 받기 화면은 후속 제품 동작의 설계다. 현재 변경분 동기화나 native 구현 완료를 뜻하지 않는다.

## 화면 목록

| 영역 | 세부 상태 | 검토할 내용 |
|---|---|---|
| 계정 | 이메일, 인증번호 | 계정 표시와 실제 연결 동의 분리 |
| 원본 | 폴더 선택, 사용 중 | 저장 후 닫기·원본 무변경 |
| 생성 | 검토, 진행, 중단, 완료 | 원본/새 공간·개수·용량·오프라인 이미지·동의 |
| 취소 | 확인, 정리 중, 완료 | 원본 유지·미정산 IO 대기·부재 확인 후 완료 |
| 복구 | 전송 결과 확인 중, 용량 부족 | 완료/삭제를 추정하지 않기 |
| 다른 기기 | 받기, 다운로드, 준비 완료 | 기존 cloud 공간 유지·이 기기에 캐시 생성 |

| 후속 동기화 | 오프라인 대기, 충돌, 로그아웃 | 로컬 저장/온라인 반영 분리·두 버전/대기열 보존 |

## 구현 전에 남은 선택

A/B/C 진입 배치와 Classic/별도Connected Preview 실행 방식, 원본 보존·새 사본 안내를 검토한다. 이메일 OTP 운영·제품용 cache/receipt·독립 업데이트 채널은 정본67문서의 관문을 따른다. 이 HTML을 제품 화면으로 복사해 활성화하지 않는다.

## 시안 검사 재현

저장소 루트에서 로컬 정적 서버를 띄운 뒤 검사한다. 제품/서비스를 실행하는 명령이 아니다.

```sh
python3 -m http.server 14620 --bind 127.0.0.1
# 별도 터미널에서, 이 환경의 설치 Chromium을 사용할 경우:
PW_CHROMIUM_PATH=/usr/bin/chromium node docs/v2-design/mockups/step6/verify.cjs
```

Chromium 경로를 지정하지 않으면 설치된 Playwright 브라우저를 사용한다. 실제 결과는 [검사 JSON](../../evidence/step6-ui-review-check.json)에 기록한다. C안430px/Tab focus/배경 차단/동의 기본값·중단·취소 확인을 포함한다.
