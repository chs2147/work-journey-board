# 95. 온라인 UX 통합 — 시안·결정(2026-11-16 승인)

2026-11-16 · `v2-design` · 로드맵(사용자 결정): E 실기 마무리 → E+ → 1.40.1 → **온라인 UX 통합** → G 운영 준비 → F 다국어(보류)

## 0. 무엇을 하는가

지금 Preview는 **기능 검증용 껍데기**다 — 로그인·복제·온라인 공간 목록을 시작 화면 카드로, 열린 공간 위에 띠를 얹었다. 이 단계는 그 기능들을 **제품 화면 안으로** 옮기는 설계다. 사용자 결정(67·68문서): **A안 = 기존 설정·워크스페이스 구조 확장**, 공간 **유형**(오프라인 전용 / 온라인)과 **상태**(동기화됨·전송 대기·연결 끊김…)를 따로 표시.

**반영한 지금까지의 실제 동작**

| 단계 | 화면에 들어가야 할 것 |
|---|---|
| B 로그인 | 이메일 인증번호, OS 보안 저장소 |
| 94 초대 전용 | 초대받지 않은 이메일 안내("초대받은 이메일만 가입할 수 있습니다…"), 같은 PC 여러 계정(계정별 기기 ID) — **계정이 바뀌면 목록·공간이 즉시 그 계정 것만**(실기 의견: 지금은 화면 전환이 있어야 빠짐) |
| C 복제 | 원본은 그대로, 새 온라인 공간, 미리 보기·올리기·잠시 멈추기·이어서·취소, 폴더 경로는 올리지 않음 |
| D 열기 | 다른 기기의 온라인 공간 = 이 기기에 받아서 열기(캐시), 오프라인일 때 받아 둔 내용 |
| E·E+ 동기화 | 이 기기 저장 / 서버 동기화 구분, 대기 N건, 연결 끊김, 충돌(이 기기·서버·둘 다), 그림, 받은 변경은 화면만 새로 고침 |
| 닫기 | "저장하고 종료하는 중…" 즉시 덮개(1.40.1 정식판 포함) |

3. 지금 Preview 시작 화면(카드)·위 띠는 제품 화면으로 대체. 온라인 공간 열기·닫기·전환은 `appController`의 한 길(CLAUDE.md 4-7) — 오프라인 전용 ↔ 온라인 전환도 공간 전환과 같은 길.
4. 시험: E2E(브라우저 모드 가짜 서버) — 공간 메뉴 전환·상태 알약·충돌 화면·계정 전환 즉시 반영·만들기 4단계, 전환 무결성(`workspace-integrity`), 실기.

### UX-3 실기 수정(2026-11-16)

- 증상: 온라인 공간을 연 채 설정 › 워크스페이스 [+ 새 워크스페이스…]를 쓰면 온라인 플랫폼의 가짜 폴더(메모리)에 일반 일지가 생기고 그리로 바뀌어, 동기화가 `no such table: wjb_sync_meta`, 레일은 이전 공간 구름 아이콘으로 남음(다시 켜면 그 일지는 사라짐).
- 수정: ① 온라인 공간을 연 동안 설정 › 워크스페이스 = 이 계정의 온라인 공간 목록(끼움 자리 `WorkspaceSettings`) — 지금 공간 [이름·색·아이콘](일지 설정 → 동기화 → 서버 목록, 레일·메뉴에 바로), 다른 공간 [열기](한 길 전환), 이 PC 새 공간·기존 폴더 추가·목록에서 빼기 없음. 공간 메뉴 [워크스페이스 관리…]도 이 화면으로 ② 온라인 플랫폼은 그 공간 폴더 밖에 폴더·일지·사본을 만들지 않음(`ONLINE_SPACE_ONLY`) ③ 동기화 엔진은 지금 일지가 그 공간의 이 기기 일지일 때만 읽고 쓴다.
- 시험: 단위(폴더 밖 거절), E2E(설정 목록·새 공간 단추 없음·이름 바꾸기·다른 공간 열기 후 동기화 오류 없음).
