## 1. 서버 계약 013

- 생성기 `build-workspace-sql.py` → `013-workspace-upload-paging.sql`(적용) · `014-…-verify.sql`(점검) · `015-…-rollback.sql`(정확히 010 함수로 되돌림, 013만 허용하는 업로드가 있으면 거절). **001~012는 바이트 그대로.**
- 바뀌는 것은 공개 명령 `wjb_v2_migration_command` 하나(표·한도·`command_core`·그림 모듈 그대로).
- `upload_begin`: `기록 ≤ 페이지×1000` 그리고 `기록 ≥ 페이지`(예전: 페이지 = 올림(기록/1000)). `upload_page`는 그대로 1~1,000행.
- 오래된 업로드 정리는 사용자 잠금 안에서 `created_at < 지금 − 24시간`인 업로드만 지운다(시작된 업로드는 이미 작업으로 옮겨져 없음).
- gateway `server-rpc.mjs`의 같은 검사를 맞춰 완화 → 재배포(v9).
- 적용 도구 `development/paging-apply.mjs`(검토 manifest `upload-paging-review-manifest.json` 해시 고정, 명시 실행·운영 거절·비밀값 없으면 요청 전 중단 — 시험 3개 추가).

## 2. 화면

| 단계 | 내용 |
|---|---|
| 로그인 전 | "로그인한 뒤 사용할 수 있습니다." |
| 시작 | [로컬 일지 폴더 고르기…], 끝나지 않은 작업 목록(이어서·취소) |
| 읽기·변환 | "일지를 읽는 중…" → "온라인 형식으로 바꾸는 중…" (움직이는 막대) |
| 미리 보기 | 원본 폴더·일지 구조·업무·업무 기록·그림(개수·용량)·전체 행·보낼 묶음·이 기기에만 두는 항목 → [올리기 시작] [그만두기] |
| 올리는 중 | 단계 글(기록 n/N · 그림 n/N · 용량 · 서버 확인 · 게시) + 진행 막대(직각) + [멈추기](게시 중에는 잠김) |
| 멈춤·끊김 | 이유 + [이어서 올리기] [작업 취소] |
| 완료 | 온라인 공간 ID·업무 기록·그림 수, 사본 파일은 지움 |
| 취소 | 서버에 올린 자료를 지웠다는 안내 |

오류는 코드별 한국어 문구(`STR.previewCopy.errors`) — 쓰는 중·구조 다름·칸반 저장 중·한도(기록 2만·그림 2,000개·10MB·200MB) 등.

화면 기록: [`mockups/c4/`](mockups/c4/) — 1 시작 · 2 미리 보기 · 3 올리는 중 · 4 멈춤 · 5 완료 · 6 완료(다크) · 7 좁은 창(720px). 가상 1년치 일지(그림 104개 21.6MB, 브라우저 모드 `?sample=year-img`).

## 3. 고친 것

- 실행기: 첫 통신 전에 이어하기 기록을 먼저 저장(바로 멈춰도 목록에 남음). 서버와 통신 전 멈춘 작업 취소 = 이 기기 사본만 지움.
- 가상 1년치 샘플 생성기의 그림 크기 계산(base64 `=` 채움 글자) 오류 → 엔진이 `ASSET_ENCODING`으로 거절해서 발견. 실앱은 `blob.size`를 저장하므로 실제 일지와는 무관.
