# 98. G-1 로컬·온라인 통합 앱(A안) — 설계·구현

2026-11-17 · 브랜치 **`v2-g-stage`**(사용자 지시: G단계부터 새 브랜치, `v2-design`에서 갈라짐) · 97문서 G-D1 = **A안**(사용자 결정)

## 0. 결정

- **A안 — 정식판 하나에 온라인을 선택 기능으로.** 로그인하지 않으면 지금 정식판과 완전히 같다(로컬 일지만, 로그인 권유 없음 — 로컬 영구 유지). 로그인하면 공간 메뉴에 온라인 공간이 더해지고 오프라인 공간과 같은 방식으로 오간다. 앱을 켜면 **마지막으로 쓴 공간**(로컬이든 온라인이든)으로 시작.
- **DEV 판에서 먼저 만들고 검증**한다. 정식판(`main`)에 넣는 것은 실기 뒤 다시 확인(정식판 동작·업데이트 경로를 바꾸는 정책 변경 — CLAUDE.md 4절·4-8 사용자 승인).
- Connected Preview는 지금처럼 검증판으로 남는다(온라인만). 통합 동작은 DEV 판.
- 로컬 일지 파일·백업·설정 구조는 바꾸지 않는다. 온라인 공간은 지금처럼 앱 설정 폴더 안 별도 위치(이 기기 사본·캐시).

## 1. 동작

| 상황 | 동작 |
|---|---|
| 로그인 안 함 | 지금 그대로. 설정에 **계정** 분류가 생기고(로그인 전 = 이메일 → 인증번호), 공간 메뉴 아래 [온라인 로그인…] |
| 로그인 함 | 공간 메뉴 = **이 PC**(오프라인 전용) 묶음 + **온라인 · 이메일** 묶음(구름 표시). 설정 › 워크스페이스도 두 목록 |
| 공간 바꾸기 | 로컬↔로컬(지금), 로컬→온라인, 온라인→로컬, 온라인→온라인 모두 **한 길**: 저장 → 지금 일지 닫기(closeCurrent) → 다음 공간 플랫폼으로 열기(openAt). 온라인으로 갈 때는 "서버와 맞추는 중…" 첫 동기화(10초 상한) |
| 앱 시작 | 마지막 공간이 로컬 = 지금 그대로. 온라인 = 로그인 확인 → 첫 동기화 후 열기(오프라인이면 이 기기 사본, 열 수 없으면 로컬 마지막 공간으로) |
| 온라인 공간을 연 동안 | 상단 동기화 알약·패널, 충돌 화면, 사용량·관리 카드(95·96 그대로) |
| 로그아웃 | 열린 온라인 공간은 보내고 저장 후 닫고 **로컬 마지막 공간으로**(첫 화면 아님) |

## 2. 구현 단계

| 단계 | 내용 |
|---|---|
| G-1a | Rust: 온라인 모듈을 `online` 기능으로 묶고 DEV(`dev-channel`)·Preview가 함께 켬. DEV 명령 목록 = 로컬 명령 + 온라인 명령(Preview의 닫기 주도 `preview_close`는 제외 — DEV는 지금 닫기 흐름 + 열린 온라인 일지 닫기). 정식판 명령 목록은 그대로(appProfile·profile 시험이 고정). 브랜치 설치 파일 빌드 대상에 `v2-g-stage` |
| G-1b | 화면: 실행 프로필에 "온라인 가능"(DEV·Preview) — 설정 › 계정, 공간 메뉴 온라인 묶음·[온라인 로그인…], 설정 › 워크스페이스 두 목록 |
| G-1c | 전환·시작: appController에 로컬↔온라인 전환(한 길), 이 PC 설정 `config.json`에 마지막 공간(`lastWorkspace` — 로컬 폴더 또는 온라인 공간 ID·계정), 시작 흐름, 로그아웃 → 로컬로 |
| G-1d | 시험: E2E(브라우저 DEV 모드에서 로컬·온라인 오가기 3번 + 행 수 그대로 — 4-7 전환 무결성), 정식판 무변경(appProfile·정식판 E2E), 실기표 |
