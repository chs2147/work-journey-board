# 11. Desktop·Web·Mobile 지원 기능표 초안

2026-11-08 (KST). **첫 출시 플랫폼은 Windows·macOS로 사용자 확정**됐다. Web/Mobile은 후속 확장이며 아래 개별 기능표는 설계 검토안이다. 출시 일정·플랫폼별 세부 기능 제공은 아직 확정하지 않았다.

## 11.1 1차 플랫폼 확정과 후속 범위

**개인 다기기 동기화는 Windows+macOS부터 검증·출시**하고 Web, Mobile은 단계적으로 확장한다. Web/Mobile을 desktop과 함께 출시하는 것을1차 MVP 관문으로 두지 않는다. 공통 도메인·프로토콜과 플랫폼 어댑터 경계는 처음부터 유지한다.

| 기능 | V2 Desktop | Web 첫 버전 추천 | Mobile 첫 버전 추천 |
|---|---|---|---|
| 한국어/영어·기본 설정 | 전체 경로 | 동일 계약 | 동일 계약·작은 화면 재배치 |
| 개인 계정·공간·동기화 | 로컬 우선·기기별 전송 | 브라우저 캐시+증분 | 로컬 저장+재개 시 증분 |
| 주간/데일리 업무·중요/완료·태그 | 기존 기능 유지 | 읽기/편집 | 데일리 중심 읽기/간단 편집, 주간 전체 격자 조정 |
| 업무 노트 | 기존 블록 편집 | 읽기/블록 편집 | 읽기/텍스트·체크 중심, 복잡한 표/블록 드래그는 후속 |
| 주간/업무 메모보드 | 자유 편집·연결·이미지 | 포인터/터치 성능 PoC 후 편집 | 보기·확대·객체 탐색 우선, 자유 편집은 후속 |
| Universe | 3D/2D·패널 | WebGL/성능 fallback | 목록/2D 중심, 자동 3D 연출은 후속 검증 |
| 인사이트 | 기존 기능 유지 | 반응형 보기 | 요약/단일 차트 중심, 큰 표·전체 timeline 편집 제외 |
| 자료함 폴더·OS 바로가기 | 기기별 경로 binding | 원본 로컬 경로 열기 불가. 자료 메타데이터·일반 URL 제공 | 동일. 앱/OS 공유로 연결할 자료 유형 별도 설계 |
| 이미지 추가 | 붙여넣기/파일/DnD | 파일/클립보드 권한별 지원 | 파일 선택·OS 공유, 카메라는 권한/품질 PoC 후 |
| PDF/Markdown/Excel 내보내기 | 기존 기능·폰트 유지 | 다운로드·메모리/폰트 검증 후 | 표준 공유/내보내기 PoC, 대형 Excel/PDF는 후속 후보 |
| 백업·복원 | 로컬/온라인·안전 사본 | 온라인 공간/새 캐시에 복원, PC 경로 지정 불가 | 온라인 복원·로컬 보존 제약 대응 |
| 설치·업데이트 | NSIS/DMG·오프라인 설치 | 웹 배포·캐시 갱신 | 앱스토어/배포 방식 미정 |
| 백그라운드 동기화 | 실행 중 제공 | 탭/브라우저 제한, 재개 시 확인 | OS가 정지하면 실시간 보장 불가, 재개 시 확인 |

폴더 카드가 보인다고 웹/모바일에서 PC 폴더의 파일을 서버로 자동 복제하지 않는다. 미지원 액션은 사용 가능처럼 보이는 버튼 대신 플랫폼 안내와 가능한 대체 동작을 제공한다.

## 11.2 코드 공유 경계

- 공유: 업무/날짜/문서 규칙, 명령/오류·동기화 protocol, i18n 키·formatter·검증, 공통 디자인 토큰.
- 어댑터: SQLite/브라우저 저장소, 파일/클립보드/공유, 자격증명 보관, 네트워크 transport·백그라운드, 창/OS 메뉴.
- UI는 의미와 컴포넌트를 공유하되 마우스 자유 보드를 작은 모바일 화면에 그대로 축소하지 않는다.
- Mobile 스택은 Tauri mobile/PWA/React Native를 비교한다. Tiptap/DOM 기반 편집기·기존 CSS·파일/보안 저장 요구를 함께 검증하고,100% 소스 재사용을 약속하지 않는다.

## 11.3 현재 Feature ID별 검토 자료

[현재 활성 기능249개 검토 CSV](platform-feature-review.csv)는 `docs/features/catalog.json`의 기준1.23.0 활성 기능 ID를 그대로 사용한다. 각 항목의 기존 platform 정보와 V2의 **영역 기반 1차 검토 후보**를 담았다. 화면별 전수 설계가 완료된 구현 계약이 아니다.

`candidate-review`는 지원 확정이 아니라 검토 대상, `native-only-review`는 네이티브 종속 기능이어서 대체/미지원 여부를 분해해야 함, `staged-review`는 단계적 축소/확장이 필요한 영역이다. 신규 Auth/Sync는 기존249개에 포함되지 않으며 아래 별도로 둔다. 공식 제품 Feature List와 배포 프로필은 이 초안 때문에 바꾸지 않는다.

## 11.4 V2 신규 기능의 검토 단위

| 임시 설계 ID | 내용 | 플랫폼 제약 |
|---|---|---|
| V2-AUTH | OTP·세션·기기 관리/회수 | 네이티브 보안 저장 vs Web cookie/CSRF |
| V2-SYNC | outbox·cursor·충돌·generation | 브라우저 eviction/여러 탭, 모바일 정지/재개 |
| V2-MIGRATE | V1 복사 전환·staging 검증 | desktop 우선. Web/Mobile은 서버에서 새 사본 내려받기 |
| V2-RESTORE | 원격 보존본·영향 확인·복원 | 경로/로컬 사본 유지 방식이 플랫폼마다 다름 |
| V2-I18N | ko/en·locale별 출력·가이드 | OS 메뉴·설치기·폰트·배포 경로 |

위 ID는 설계 표의 별칭이며 공식 Feature ID로 발급하지 않았다. 플랫폼별 도입 버전·검증 완료는 실제 구현/출시 때 기록한다.

## 11.5 PoC 검토 관문

- Desktop 두 기기의 끊김/종료·중복/충돌·공간/계정 전환·기기 회수와 복원.
- 후속 Web 관문: 탭2개·캐시 eviction·사이트 데이터 삭제·미전송 outbox 보존/경고·오프라인 재개. IndexedDB/OPFS 선택은 이 검증 후 결정.
- 후속 Mobile 관문: 실제 iOS/Android의 한글/영문 입력·긴 노트·기본 이미지·스크롤·메모리·OS 정지/재개. 기기/OS 지원 하한은 미정.
- 공통: 한국어/영어, 날짜/타임존 불변, 접근성, 미지원 기능의 명확한 표시, 원문/자산 유실0.

플랫폼 선택은 확정됐으며, 다음에는 계약/정책의 남은 항목과24문서의 첫 로컬 PoC 구현 범위를 검토한다. 플랫폼 선택만으로 앱·백엔드 구현 착수 승인으로 바꾸지 않는다.
