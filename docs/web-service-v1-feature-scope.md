# 반응형 웹 v1 기능 범위 검토안

데스크탑 **1.55.1 Open Beta**의 Windows 기본판과 macOS 유니버설 기능을 기준으로 작성했습니다. 기준은 GitHub `main`의 `0f46476`와 해당 버전의 고정 기능 목록입니다. 아래 범위는 웹 v1 시안을 만들기 위한 검토안입니다. [기준 기능 목록](features/releases/work-journey-board/v1.55.1.json) · [현재 웹 설계](web-service-v1-spec.md)

## 기본 원칙

- 반응형 설계와 구현은 웹에서 진행합니다. 데스크탑 앱의 화면, 조작, 동기화 방식, 로컬 일지와 백업을 그대로 유지합니다. 웹은 기존 서버 계약 안에서 읽고 쓰며, 호환되는 계약으로 지원할 수 없는 동작은 후속 검토 대상으로 둡니다.
- 초대받은 로그인 계정에 허용된 온라인 공간만 표시합니다. 같은 환경의 같은 온라인 공간에서 만든 기록과 변경은 데스크탑과 웹이 공유합니다. 색·아이콘과 업무 상태처럼 공간에 속한 값은 공유하고, 탐색 상태·테마·개인 표시 순서는 브라우저에서 관리합니다.
- 웹은 스마트폰과 접힌 폴드에서 터치 중심의 한 화면을 제공합니다. 펼친 폴드에서는 가용 폭에 따라 목록과 상세를 나란히 배치하고, 넓은 브라우저에서는 주간 격자를 사용할 수 있게 합니다. 브랜드·글꼴·업무 팔레트와 4px 직선 업무 띠는 기존 데스크탑 기준을 사용합니다.
- 읽기 범위의 자료도 원본·연결·첨부·서식 정보를 보존합니다. 웹에서 저장하는 항목은 해당 조작에 필요한 필드만 기존 규칙에 따라 변경합니다.
- 기능이 확정되면 온라인 공간 선택, 기록 입력, 칸반 이동에 짧은 웹 도움말을 두는 안을 시안에서 확인합니다.

## 웹 v1 범위

| 판단 | 항목 수 | 의미 |
| --- | ---: | --- |
| 제공 | 49 | 같은 온라인 데이터와 동작 제공 |
| 웹 방식 | 76 | 사용자 목적을 터치·브라우저 다운로드 등 웹에 맞는 방식으로 제공 |
| 읽기 | 35 | 조회와 원본 이동 제공. 편집 범위는 항목별로 검토 |
| 후속 검토 | 70 | 웹 v1 범위에서 보류. 추후 구현 가능성을 검토 |
| 제공 제외 | 58 | 로컬·운영체제 전용 동작 또는 데스크탑 전용 표현을 웹 범위에서 제외 |

현재 카탈로그의 기능·배포 항목 **288개** 중 **160개**를 웹 v1 제공 범위로, **128개**를 후속 검토 또는 제공 제외로 제안합니다. 항목에 여러 동작이 묶여 있으면 아래 표에서 웹 제공 범위를 명시했습니다. 예를 들어 Cabi.NET의 폴더는 이름을 볼 수 있고, 경로 지정과 탐색기 열기는 데스크탑에서 수행합니다.

| 영역 | 웹 v1에서 제공 | 데스크탑에서 이용하거나 후속 검토 |

검토가 필요한 정책은 **새 빈 온라인 공간과 사용자 본인의 계정·공간 삭제를 v1에 포함**, **메모·업무노트·Universe는 읽기 우선**, **반복·인사이트·대량 가져오기는 후속 검토**입니다.

현재 공개 웹(`a2bff01`)의 확인 범위는 로그인, 온라인 공간 선택, 오늘·주간·칸반·검색·요약, 기록 본문 편집·칸반 이동, 주간 요약 Markdown, 주간 메모·Cabi.NET 읽기입니다. 첨부 이미지 스트리밍은 작업 브랜치의 로컬 구현입니다. 표의 **제공**은 검토안의 범위를 나타냅니다. 데스크탑 정식판은 운영 온라인 환경을 사용하며 현재 공개 웹은 DEV 온라인 환경에 연결돼 있습니다. [웹 구현 현황](../web/README.md) · [현재 배포 구성](../web/production.md)

## 기능 목록 외 확인 사항

- **운영자 전용 기능**은 별도 고정 ID가 없어 출시 기록으로 보완했습니다. 데스크탑의 관리자 메뉴에서 사용자 등록·정지·계정 삭제와 사용자별 한도·사용량을 관리합니다. 웹 v1은 사용자 본인의 계정·사용량과 공간 관리만 제공합니다. [1.51.0 출시 기록](release-notes/v1.51.0.md) · [계정·관리자 이용 안내](guide/16-online.md)
- **Universe의 동명 본 항목**은 같은 공간·업무 안에서 묶고, 기록 날짜와 세부 항목을 펼쳐 원본으로 이동하는 동작을 웹 읽기에 포함합니다. [1.51.0 출시 기록](release-notes/v1.51.0.md)
- **Excel·Markdown 다운로드**는 웹에서 브라우저 저장으로 설계합니다. 데스크탑 전체 기능 목록을 기준으로 삼되, 현재 데스크탑 온라인 어댑터의 저장 동작은 웹 개편 범위 밖입니다. [데스크탑 온라인 어댑터](../src/platform/onlinePlatform.ts)
- **설치·개발 운영 항목** 12개는 전체 검토에 포함했습니다. 표에서 웹 사용자 기능과 배포 운영을 구분했습니다. 웹과 설치판의 릴리스 단위는 별도 출시 검증에서 다룹니다.
