## 1. ⭐ 업무별 경과 타임라인 (정성적 관리의 핵심 화면)

### 1-1. 목적
한 업무의 기록을 처음부터 끝까지 한 화면에서 읽으며 "이 일이 어떻게 흘러왔는지"를 파악. 보고·인수인계·회고 때 쓰는 화면.

### 1-2. 데이터
```sql
SELECT date, seq, depth, text FROM entry_item
WHERE category_id = :id AND date BETWEEN :from AND :to
ORDER BY date, seq;
```
+ 그 업무의 `category_period`(시작·종료·재활성 표시용). 주차 묶음은 앱의 `week.ts`로.

### 1-3. 화면 구성
```
┌ 업무 목록 ───────┐┌ 차세대 정산 시스템 구축 · 2026-09-14 시작 · 진행 중 ──── [🔍 검색] ┐
│● 차세대 정산 …  ││ ▸ 2026년 7월 (4주 · 항목 23)                           ← 접힌 달 │
│● 협력사 보안 …  ││ ─ 2026년 10월 ─────────────────────────────────────────── │
│● 사내 데이터 …  ││ W42 10/12~18                                              │
│● 신규 입사자 …  ││   (월) 정산 배치 현행 분석 자료 정리                         │
│ ─ 종료된 업무 ─ ││   (화) 정산 배치 요구사항 1차 리뷰                            │
│○ 레거시 이관    ││         · 재계산 대상 범위 이견 2건 확인                     │
│                 ││ · · · 2주 기록 없음 (W40~W41) · · ·                       │
│                 ││ W43 10/19~25                                     ← 이번 주 │
│                 ││   (월) 정산 배치 요구사항 2차 리뷰 …                          │
└─────────────────┘└───────────────────────────────────────────────────────────┘
```
- **업무 선택**: 왼쪽 목록(보드 순서, 색 점 + 이름 + 마지막 기록일). 종료된 업무는 아래 "종료된 업무" 묶음(필터 "종료 업무 포함"이 켜졌을 때).
- **세로 시간축**: 위=과거 → 아래=최근(읽는 방향 = 흐름 방향). 처음 열 때 **맨 아래(이번 주)로 스크롤**.
- **주 행**: 왼쪽 고정폭 열에 `W43 10/19~25`, 오른쪽에 그 주 항목을 `(요일) 내용` / 세부 `·` 들여쓰기로(자동 집계와 같은 표기).
- **무기록 주**: 연속 구간을 한 줄 `· · · N주 기록 없음 (W40~W41) · · ·`로 접음(공백 자체가 정보).
- **긴 기간 접기**: 최근 3개월은 펼침, 그 이전은 월 머리줄 `▸ 2026년 7월 (4주 · 항목 23)`로 접힘. 클릭 시 펼침.
- **구간 표시**: 종료 지점에 `■ 종료 (10/23)`, 재활성 지점에 `▶ 재개 (11/02)` 구분선.
- **검색**: 입력 시 일치 항목 강조, 일치 없는 주는 흐리게(숨기지 않음 — 흐름 유지).
- **이동**: 항목 클릭 → 보드의 그 주·그 요일 칸으로 이동(편집 커서 위치).
- **복사**: [이 업무 경과 복사] → 화면에 보이는 범위를 자동 집계와 같은 평문으로 복사(인수인계·보고용).

### 1-4. 빈 상태
- 업무 미선택: "왼쪽에서 업무를 고르면 기록이 시간순으로 펼쳐집니다."
- 기록 0건: "아직 이 업무의 기록이 없습니다. 보드에서 기록하면 여기에 쌓입니다."

## 2. 활동 히트맵

### 2-1. 목적
업무별 몰입 기간·공백 기간을 한눈에. "요즘 어떤 일에 붙어 있었나".

### 2-2. 두 모드
| 모드 | 열 | 칸 값 | 열 수 |
|---|---|---|---|
| **최근 12주**(기본) | 날짜(월~일, 토·일 열은 폭 절반) | 그날 그 업무 **본 항목(depth 0) 수** | 84 |
| **연간**(ISO 연도) | 주차 W01~W52/53 | 그 주에 그 업무를 **기록한 날 수**(0~7) | 52~53 |

- 연간을 일 단위로 그리면 업무당 365칸 → 행이 너무 길어져 주 단위로 바꾼다.
- 세부 항목(depth 1)은 세지 않는다: 같은 일을 잘게 쪼개 적는 습관이 밀도를 부풀리지 않게.

### 2-3. 색 (순차, 단일 파랑 계열 — 업무 색을 쓰지 않음)
| 단계 | 12주 모드(항목 수) | 연간 모드(기록 일수) | 라이트 | 다크 |
|---|---|---|---|---|
| 0 | 0 | 0 | 표면색보다 한 단계 짙은 회색 `#efeee9` | `#262624` |
| 1 | 1 | 1 | `#cde2fb` | `#184f95` |
| 2 | 2~3 | 2 | `#86b6ef` | `#256abf` |
| 3 | 4~5 | 3~4 | `#3987e5` | `#3987e5` |
| 4 | 6+ | 5+ | `#1c5cab` | `#86b6ef` |
- 업무 구분은 행 머리의 **업무 색 점 + 이름**이 맡는다(색만으로 구분하지 않음).
- 범례: 차트 아래 `적음 □□■■■ 많음` + 단계별 숫자 범위.

### 2-4. 인터랙션
- 칸 호버 → 툴팁: `차세대 정산 시스템 구축 · 10/21(수) · 항목 3개` + 첫 항목 텍스트 1줄.
- 칸 클릭 → 보드 그 주로 이동. 행 머리 클릭 → 경과 타임라인 탭에서 그 업무 열기.
- 히트 영역은 칸보다 크게(칸 사이 2px 간격 포함 전체).
- 오늘 열은 위쪽에 작은 삼각 표시.

## 3. 업무 기간 막대 (간트)

### 3-1. 목적
업무가 언제 시작해 언제 끝났는지, 그 기간 중 실제로 손댄 구간이 어디인지.

### 3-2. 데이터 → 표시
| 요소 | 원천 | 표시 |
|---|---|---|
| 활성 구간 | `category_period` 각 행 `[start_date, end_date ?? 오늘]` | 옅은 막대(업무 색 20% 농도), 둥근 끝 4px |
| 기록 구간 | 그 업무의 기록이 있는 주 | 막대 위 **진한 눈금**(업무 색, 주 폭) — 연속 주는 이어져 진한 띠가 됨 |
| 진행 중 | 열린 구간 | 오늘 위치에서 끝 + 오른쪽 열린 화살촉 `▸` |
| 재활성 | 구간 2개 이상 | 같은 행에 막대 여러 개, 사이 공백 그대로 |
| 오늘 | — | 세로 점선 + `오늘` 라벨 |

- x축: 시간(월 눈금). 기간이 짧으면 막대의 의미가 약하므로 **기본 "올해(ISO 연도)" 고정**, 기간 필터가 "전체" 또는 1년을 넘는 직접 지정일 때만 그 범위를 따른다. y축: 업무(보드 순서, 종료 업무는 필터 켜면 아래쪽).
- 툴팁: `차세대 정산 시스템 구축 · 2026-09-14 ~ 진행 중 · 기록한 주 6/7`.
- 클릭 → 경과 타임라인.

## 4. 주별 업무 비중

### 4-1. 목적
주마다 어떤 업무에 손이 많이 갔는지의 분포 변화. **시간 투입 비율이 아니라 "기록한 날 수"** 임을 차트 제목에 명시: `주별 업무 비중 (기록한 날 수 기준 · 시간 투입 아님)`.

### 4-2. 데이터
- 주 W, 업무 X의 값 = W 안에서 X의 항목이 1개 이상인 **날의 수**(0~7).
- 기본 표시 = **100% 누적 막대**(그 주 값 합계 대비 비율). [일수 보기] 전환 시 절대 일수 누적(같은 날 여러 업무를 쓰므로 합계가 5를 넘을 수 있음 — 축 제목 `업무별 기록 일수 합계`).
- 기간: 최근 12주(기본) / 올해.
- 업무가 8개를 넘으면 그 기간 합계 상위 7개 + **"기타"**(회색) 1개로 접는다(9번째 색을 만들지 않음).

### 4-3. 표시
- 막대 순서 = 보드 순서(아래부터 쌓음). 색 = 업무 색(6절). 막대·조각 사이 2px 표면색 간격.
- 범례는 항상 표시(차트 위 한 줄, 업무 색 점 + 이름). 막대에 숫자를 일일이 쓰지 않음.
- 툴팁(막대 조각): `W43 · 차세대 정산 시스템 구축 · 6일 (43%)`.
- 기록이 하나도 없는 주는 빈 자리 + 아래 `—`.

## 5. 공통 — 화면 배치·필터

### 5-1. 인사이트 화면 (상단 바 [인사이트])
```
[보드] [인사이트]                                         ← 상단 바 보기 전환
┌ 필터 ─ 기간 [최근 12주 ▾]  업무 [전체 4 ▾]  [ ] 종료 업무 포함 ───────────────┐
│  탭: (경과 타임라인) (활동 개요)                                              │
├────────────────────────────────────────────────────────────────────────────┤
│ 활동 개요:                                                                   │
│  ┌ 활동 히트맵 ─────────────────────────────── [12주|연간] ┐                 │
│  └──────────────────────────────────────────────────────────┘                 │
│  ┌ 업무 기간 막대 ───────────────┐ ┌ 주별 업무 비중 ─────── [비율|일수] ┐       │
│  └───────────────────────────────┘ └────────────────────────────────────┘       │
└────────────────────────────────────────────────────────────────────────────┘
```
- **탭 2개인 이유**: 타임라인은 길게 읽는 텍스트 화면이라 대시보드 칸에 넣으면 잘린다. 나머지 셋은 "패턴 보기"로 한 화면에 함께 둘 때 서로 비교된다.
- 개요 탭에서 업무를 클릭하면(히트맵 행 머리·간트 막대·비중 조각) **타임라인 탭이 그 업무로** 열린다 = 개요에서 발견 → 타임라인에서 읽기.

### 5-2. 필터 (한 줄, 두 탭 공통 상태)
| 필터 | 값 | 기본 |
|---|---|---|
| 기간 | 최근 4주 / 최근 12주 / 올해 / 전체 / 직접 지정(주 선택기) | 최근 12주 |
| 업무 | 다중 선택(보드 순서), 전체 선택 | 전체(진행 중) |
| 종료 업무 포함 | 토글 | 끔 |
- 히트맵의 [12주|연간]·비중의 [비율|일수]는 차트 자체 전환(필터와 별개). 히트맵 연간 모드는 기간 필터와 무관하게 "올해".
- 필터 상태는 앱 실행 중 유지, 재시작 시 기본값.

### 5-3. 빈·적은 데이터
- 기록 4주 미만: 개요 탭 상단에 `기록이 4주 이상 쌓이면 흐름이 잘 보입니다` 안내(차트는 그대로 그림).
- 차트마다 [표로 보기] 링크 → 같은 데이터를 표로(접근성·확인용).

## 6. 업무 색 팔레트 (카테고리 색 8개, 순서 고정)

보드 행 머리·간트·비중 차트가 같은 색을 쓴다. 색약 대비가 검증된 범주형 8색을 **이 순서로** 새 업무에 차례로 배정(사용자가 바꿀 수 있음). 9번째 업무부터는 다시 1번부터 배정하되, 비중 차트는 4-2절의 "기타" 접기로 같은 색이 한 차트에 겹치지 않게 한다.

| 키 | 색 | 라이트 | 다크 |
|---|---|---|---|
| c1 | 파랑 | `#2a78d6` | `#3987e5` |
| c2 | 주황 | `#eb6834` | `#d95926` |
| c3 | 청록 | `#1baf7a` | `#199e70` |
| c4 | 노랑 | `#eda100` | `#c98500` |
| c5 | 분홍 | `#e87ba4` | `#d55181` |
| c6 | 초록 | `#008300` | `#008300` |
| c7 | 보라 | `#6250d6` | `#9085e9` |
| c8 | 빨강 | `#e34948` | `#e66767` |

- 이웃한 색끼리(누적 막대에서 맞닿는 순서) 색약 시뮬레이션 대비가 확보된 순서 — **순서를 바꾸지 않는다**.
- 글자는 업무 색으로 칠하지 않는다(가독성). 색은 점·막대·테두리에만, 이름 글자는 본문 색.
- 노랑·분홍·청록은 밝은 배경에서 대비가 낮음 → 이 색들은 항상 이름 라벨과 함께 쓴다(색만으로 정보 전달 금지).

## 7. 차트 구현 방식 (구현 단계 메모)
| 후보 | 판단 |
|---|---|
| **직접 SVG + d3-scale/d3-array** | ✅ 채택. 4개 모두 단순 도형(사각형·막대). 번들 작고, 오프라인·외부 통신 0과 무관하게 안전, 스타일을 디자인 토큰으로 완전 제어 |
| ECharts | 히트맵·간트 지원하나 ~1 MB, 테마 맞추기 비용. 불필요 |
| Recharts | 누적 막대는 쉽지만 히트맵·간트 미지원 → 결국 직접 그려야 함 |
- 차트 컴포넌트는 `(data, size) → SVG` 순수 함수형으로 작성 → 클라우드(리눅스) Playwright 스크린샷으로 확인 가능.
- 데이터 계산(주차 묶음·일수 집계·접기)은 UI와 분리된 `src/domain/insights.ts`에서 단위 테스트.
