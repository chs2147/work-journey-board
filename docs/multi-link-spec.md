## 1. 여러 줄 타이틀 띠 (시안 ①)
- 줄 하나 = 지금 띠 한 줄과 같은 모양: 업무 색 점 · **업무명(굵게)** · 날짜(`10/22 (목)`) · 항목 글(넘치면 …). 줄 높이 24px(지금 26px 한 줄 띠를 조금 줄여 여러 줄이어도 덜 차지하게), 줄 사이 옅은 구분선.
- 연결이 하나면 지금과 똑같이 보인다(줄 하나).
- 줄을 누르면 **그 항목으로**(보드 그 주·그 칸, 항목에 커서 + 잠깐 강조 — 지금과 같음).
- 줄에 마우스를 올리면 그 줄 옅은 파랑 + 보드의 그 항목도 파란 테두리(어느 항목인지 바로 보이게).
- 줄 끝 **✂**(끊긴 사슬 아이콘) = 그 연결만 해제(4절).
- 글·이미지·링크 카드 상자 모두 같은 띠. 이동 막대·⋯ 메뉴·폭 손잡이·관계선 연결점은 그대로.
- 줄 순서: 보드 순서 — 업무 순서 → 날짜 → 칸 안 순서(문서에 저장한 순서와 상관없이, 항목을 옮기면 줄도 따라 자리를 바꿈). 지워진 항목 줄은 맨 아래.

## 2. 연결 더하기 (시안 ②)
### 2-1. 상자를 항목에 끌어 놓기 — 옮기기 → 더하기 (②A)
- 상자 위 막대를 잡고 보드의 항목 위로: 그 행 파란 테두리 + **"+ 여기에 연결 추가"**. 놓으면 연결이 **더해지고**(줄 하나 늘어남) 상자는 원래 자리로.
- 이미 연결된 항목 위에서는 회색 **"연결됨"**, 놓아도 그대로.
- 지금(v0.2.11~)의 "다른 항목에 놓으면 연결이 옮겨 감"은 없어진다 — 옮기려면 새 항목에 놓고 옛 줄을 ✂(8절 #3).

### 2-2. 보드 행을 기존 상자 위에 놓기 (②B, 새)
- 행의 ⋮⋮를 끌어 메모 판으로: **빈 곳**에 놓으면 지금처럼 그 항목과 연결된 새 글 상자, **상자 위**에 놓으면 그 상자에 연결 추가(상자 파란 테두리 + 띠 맨 아래에 미리보기 줄 `+ 업무명 · 날짜 · 항목 글 — 놓으면 연결 추가`).
- 이미 연결된 상자 위면 "연결됨". 행은 보드에 그대로 남는다(지금과 같음).

### 2-3. 상자 ⋯ → [업무 항목 연결…] (②C, 새)
- 작은 고르기 목록: 맨 위 찾기 칸, 그 아래 이번 주 보드의 항목(글 있는 본·세부 항목)을 **업무별 묶음**으로, 날짜·칸 순서대로. 체크 = 연결됨.
- 체크/해제 = 바로 연결/해제(메모 실행 취소 1단계씩). 아래에 `연결 N개`.
- 키: 찾기 칸에서 `↓`로 목록, `↑↓` 이동, `Space`/`Enter` 켜기·끄기, `Esc` 닫기(상자로 포커스).
- 끌기가 어려운 경우(토·일 접힌 열, 오늘 뷰에 안 보이는 날, 키보드만 쓸 때)를 위한 길.
- 행의 **[메모]** 단추는 지금처럼 **새 상자**를 만든다(기존 상자에 더하는 것은 2-1~2-3).

## 3. 연결 수
| 경우 | 규칙 |
|---|---|
| 한 상자의 연결 | 최대 **20개**. 넘으면 토스트 `한 메모에 연결은 20개까지입니다`. 같은 항목은 한 번만 |
| 한 항목의 상자 | 제한 없음(지금과 같음) — 보드 배지 = 그 항목에 연결된 상자 수 |
| 같은 업무의 여러 항목 | 항목마다 한 줄(업무명이 되풀이됨) — 날짜·항목 글로 구분 |
| 다른 주 항목 | 지금처럼 같은 주만(메모는 주마다 하나) |

## 4. 해제 (시안 ③A)
- **줄의 ✂**: 그 연결만. ✂에 마우스를 올리면 그 줄이 옅은 빨강 + 취소선(지워질 줄 미리보기). 토스트 `연결을 해제했습니다 [되돌리기]`·`Ctrl+Z`.
- **상자 ⋯ [연결 모두 해제 (N)]**: 연결이 2개 이상일 때만. 한 번의 되돌리기로 모두 복구.
- **[업무 항목 연결…] 목록에서 체크 해제**.
- 마지막 줄을 해제하면 띠가 사라진다(상자·본문·자리는 그대로).
- 지워진 항목 줄: 회색 `연결된 항목이 삭제됨` + ✂(지금과 같음). 항목 삭제를 되돌리면 다시 정상.

## 5. 많을 때 (시안 ③B)
- 연결 **5개 이상**이면 처음 4줄 + `▾ 연결 N개 더 보기`. 누르면 모두 펼침, 다시 `▴ 접기`. 펼친 상태는 기억하지 않는다(주를 옮기면 다시 접힘).
- 띠는 본문을 아래로 밀어낸다(본문을 덮지 않음).
- 요청 문구("연결 수만큼 여러 줄")를 늘 그대로 지키려면 접기 없이 모두 표시(8절 #5 대안).

## 6. 다른 기능과의 관계
| 기능 | 처리 |
|---|---|
| 보드 배지 | 항목마다 연결된 상자 수 — 같은 상자가 여러 항목의 배지에 함께 셈된다. 누르면 그 상자로(여럿이면 첫 상자) |
| 경과 타임라인(m3-s1-spec 4-4) | 같은 메모가 연결된 **각 항목 아래** `메모 N`으로 나온다(업무마다 그 업무의 항목 아래) |
| 경과 복사 | 각 항목 아래 `[메모]` 줄로 — 같은 글이 여러 업무의 경과에 들어갈 수 있음 |
| 항목을 다른 칸으로 옮김 | 그 줄만 새 업무명·날짜, 줄 순서도 다시 맞춤 |
| 상자 복제 | 연결도 함께 복제(지금과 같음) |
| 관계선(note-relation-spec) | 별개 — 관계선은 상자끼리, 연결은 상자 ↔ 항목 |
| 주간 요약·엑셀 | 바뀌지 않음(메모 글만) |
| 행 삭제(v2 #1) | 그 항목 줄만 "삭제됨" |

## 7. 데이터 · 코드 배치
### 7-1. 메모 문서 JSON (week_note.doc — 스키마 변경 없음)
```json
{ "id": "…", "kind": "text", "refs": [ { "item": "<entry_item.id>" }, { "item": "<entry_item.id>" } ] }
```
- 상자의 `ref`(한 칸) → **`refs`**(배열). 읽을 때(`parseNoteDoc`) 예전 `ref`는 `refs` 한 개로 바꿔 읽고, 저장은 `refs`로만(연결이 없으면 필드 없음).
- 정리: 빈 id·64자 넘는 id·같은 항목 중복은 버리고, 20개를 넘는 것은 버린다. 순서는 의미 없음(화면은 늘 보드 순서).
- **이전 판과의 관계**: `0.2.14` 이하로 되돌려 설치하면 `refs`를 읽지 못해 연결이 보이지 않고, 그 상태로 저장하면 연결이 지워진다 — 릴리스 노트에 적는다.

### 7-2. 코드
| 영역 | 파일 | 바뀌는 것 |
|---|---|---|
| 도메인 | `src/domain/note.ts` | `BoxRef` 배열 `refs`, `parseRefs`(예전 `ref` 받기), `linkCounts`·`linkedBoxes`가 `refs` 기준, `addRef`/`removeRef` 규칙(중복·상한) |
| 도메인 | `src/domain/insights.ts` | `memoFor`가 `refs`에 그 항목이 든 상자 |
| 상태 | `src/ui/note/noteStore.ts` | `linkBox` = 더하기(옮기기 아님), `unlinkBox(id, itemId?)`(하나/모두), `toggleLink` |
| 화면 | `LinkStrip.tsx` | 여러 줄·줄마다 ✂·접기·줄 hover → 보드 항목 강조 |
| 화면 | `rowDrag.ts`·`boxShared.ts` | 행을 상자 위에 놓기(상자 찾기·미리보기 줄), "연결됨"/"+ 여기에 연결 추가" |
| 화면 | `LinkPicker.tsx`(새) | ⋯ [업무 항목 연결…] 고르기 목록 |
| 화면 | `CellEditor.tsx` | 배지·끌기 대상 판정이 `refs` 기준 |

### 7-3. 테스트
- 단위: `parseNoteDoc`(예전 `ref` → `refs`, 중복·상한·빈 id), `linkCounts`(한 상자가 여러 항목에 셈), 줄 순서(보드 순서), 타임라인 `memoFor`(여러 항목 아래).
- E2E: 끌어 놓기로 2번째·3번째 연결 → 띠 3줄 · 이미 연결된 항목 "연결됨" · 행을 상자에 놓기 · ⋯ 고르기 목록(찾기·Space) · 줄 ✂ → 되돌리기 · [연결 모두 해제] · 5개 이상 접기/펼치기 · 줄 누르면 보드 항목 · 보드 배지 수 · 예전 `ref` 문서가 그대로 보임 · CSP.
