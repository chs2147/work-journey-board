# 메모 보드로 맥락 남기기

**언제 쓰나요** — 항목 한 줄로는 부족한 배경·결정·그림을 그 주에 함께 남길 때.

1. 보드 아래 **이번 주 메모**의 빈 곳을 누르면 글 상자가 생깁니다. 서식·체크 목록·링크를 쓸 수 있습니다.
2. 항목에 마우스를 올려 **[메모]**를 누르면 그 항목과 **연결된 메모**가 생기고, 항목 옆에 메모 수 배지가 붙습니다(항목을 상자에 끌어 놓아도 연결).
3. 그림은 붙여 넣기·끌어 놓기로 **이미지 상자**, 주소는 **링크 카드**로.
4. 상자 가장자리의 연결점을 끌어 다른 상자에 놓으면 **관계선** — 이름표·화살표·점선을 고릅니다.
