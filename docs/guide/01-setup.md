# 처음 설치와 저장 폴더

**언제 쓰나요** — 회사 PC에 처음 설치할 때, 또는 PC를 바꿔 일지를 옮길 때.

1. [최신 판 내려받기](https://github.com/chs2147/work-journey-board/releases/latest)에서 `WorkJourneyBoard_<판>_setup.exe`를 받아 실행합니다. 관리자 권한 없이 내 계정에만 설치됩니다.
2. 처음 켜면 **저장 폴더**를 고릅니다. 추천 위치는 `C:\Users\<사용자>\WorkJourney`입니다 — OneDrive 동기화 폴더는 안내가 뜹니다.
3. 기존 일지가 있으면 **기존 일지 열기**로 그 폴더를 고릅니다(`work-journey.db` 파일 하나가 일지 전체).
4. 보드가 뜨면 `+ 업무 추가`에 지금 하고 있는 업무 이름을 적고 `Enter`.

![첫 실행 — 저장 폴더 고르기](shots/01-setup.png)
