# 기능 둘러보기(코칭)

**언제 쓰나요** — 처음 설치했을 때, 업데이트로 새 기능이 생겼을 때, 또는 "이 단추는 뭐였지?" 싶을 때. 화면을 어둡게 가리고 설명할 곳만 밝힌 뒤 말풍선으로 하나씩 짚어 줍니다.

1. 왼쪽 레일 **?** 단추(⚙ 바로 위) 또는 `F1` — **기능 둘러보기** 메뉴가 열립니다. 시작 · 주간 보드 · 칸반·인사이트·Universe · 중요 업무·Cabi.NET 묶음으로 투어가 나뉘고, 칸반·인사이트·Universe·Cabi.NET을 보는 중이면 **이 화면** 투어가 맨 위에 보입니다.
2. 투어를 고르면 **예시 화면**(가상 예시 일지 — 이번 주 날짜로 맞춤)으로 바뀝니다. 상단 주황 띠 "예시 화면 — 내 기록은 그대로"가 보이는 동안은 내 일지를 건드리지 않고, 끝나거나 건너뛰면 **내 일지·시작 전 화면**으로 돌아옵니다. 일지가 비어 있어도 같은 예시로 봅니다.
3. 말풍선 **[다음]**·`→`·`Enter` 다음, **[이전]**·`←` 이전, 오른쪽 위 **[건너뛰기]**·`Esc` 그만. 손가락 표시가 있는 단계는 밝힌 곳을 직접 눌러 보면 다음으로 넘어갑니다.
4. 메뉴의 오른쪽 표시 — 걸리는 시간(안 봄) · `3 / 9`(보다 그만둔 단계, 누르면 거기부터) · **✓ 완료** · **새 단계 N**(본 뒤에 새 기능 단계가 생김). ↺ = 처음부터.

**처음 한 번 뜨는 안내**
- 새로 설치하면 첫 보드가 뜬 뒤 환영 카드 — [1분 둘러보기 시작 ▶]·[골라서 보기]·[다음에].
- 쓰던 일지로 기능 둘러보기가 들어간 판에 업데이트하면, 아직 투어를 본 적이 없을 때 한 번 **?** 단추를 밝혀 소개합니다.
- 어느 쪽이든 [다음에]를 누르면 다시 띄우지 않습니다 — 언제든 **?**·`F1`로 엽니다.

**팁**
- 칸반·인사이트·Universe·Cabi.NET을 처음 열면 오른쪽 아래에 그 화면 둘러보기 제안이 한 번 뜹니다. 메뉴 아래 또는 설정 › 업데이트·정보 › **기능 둘러보기**에서 **[화면별 둘러보기 제안]**을 끕니다.
- 설정 › 업데이트·정보 › 기능 둘러보기 — **[열기]**(메뉴) · **[다시 보기]**(처음 설치처럼 진행 기록을 지우고 환영 카드부터) · 제안 켜기/끄기. 진행 기록은 이 PC 설정에만 남습니다(일지에는 쓰지 않음).
- 투어 중에는 앱 단축키가 쉬고, 예시 화면에서는 저장·백업·공간 바꾸기를 하지 않습니다.
