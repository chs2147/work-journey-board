# 금요일 주간 보고 만들기

**언제 쓰나요** — 한 주 기록을 보고용 글로 정리할 때.

1. 위쪽 **[주간 요약]** — 이번 주 기록이 업무별 개조식으로 자동 정리됩니다(요일·세부 항목·휴가 표시 포함).
2. 그대로 [복사]해 메일·메신저에 붙이거나, 패널에서 고쳐 쓴 글을 저장합니다(기록이 바뀌면 안내).
3. AI로 다듬으려면 [AI 지시문 복사] → 쓰는 AI에 붙여 넣고, 받은 글을 다시 붙여 넣어 보관합니다(앱은 AI에 직접 접속하지 않음).

**팁**
- 업무가 많으면 태그 필터(위쪽 [태그: 전체 ▾])로 보고 대상만 골라 볼 수 있습니다.
