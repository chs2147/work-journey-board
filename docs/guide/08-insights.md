# 지난 일 돌아보기(인사이트)

**언제 쓰나요** — 한 업무가 어떻게 흘러왔는지, 언제 바빴는지 볼 때.

1. 레일 인사이트 아이콘 또는 `Alt+3`(칸에 커서가 있으면 그 업무) — **경과 지도**와 **업무 타임라인**이 열립니다.
2. **년/월 → 주차 → 상세 업무** 순으로 읽습니다. 월 제목 아래와 주차 사이 구분선으로 경계를 구분합니다. 오른쪽 꺾쇠 아이콘으로 월 기록을 펼치거나 접습니다.
3. 타임라인에서 주마다 항목·★·↻·연결 메모를 따라가고, `Enter` = 보드의 그 칸으로. `Ctrl+F` 찾기, `Ctrl+Shift+C` 경과 복사.
4. **활동** 탭: 12주(일)·연간(주) 히트맵으로 업무별 기록 밀도를 봅니다.

![인사이트 — 업무 타임라인](shots/08-insights.png)

**팁**
- 업무 머리 ⋯ › [업무 타임라인 보기]로도 들어갑니다. `Alt+1` = 보드로.

- 경과 지도는 항상 표시됩니다. **표 아이콘**으로 표를 표시/닫으며, 버튼 위에 마우스를 올리면 이름을 확인할 수 있습니다.
- **업무 타임라인 / 활동** 탭 앞에 각 기능의 모노그램 아이콘이 표시됩니다. 활동 격자는 창 너비에 맞춰 늘어나고, 좁으면 카드 안에서 가로 스크롤합니다. 업무 이름은 고정돼 날짜를 넘겨도 읽을 수 있습니다.

- 시그니처 테마의 월 아래·주차 사이 선은 배경보다 진한 갈색으로 표시됩니다.
