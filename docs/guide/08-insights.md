# 지난 일 돌아보기(인사이트)

**언제 쓰나요** — 한 업무가 어떻게 흘러왔는지, 언제 바빴는지 볼 때.

1. 레일 인사이트 아이콘 또는 `Alt+3`(칸에 커서가 있으면 그 업무) — **경과 지도**와 **업무 타임라인**이 열립니다.
2. **년/월 → 주차 → 상세 업무** 순으로 읽습니다. 월 제목 아래와 주차 사이 구분선으로 경계를 구분합니다. 오른쪽 꺾쇠 아이콘으로 월 기록을 펼치거나 접습니다.
3. 타임라인에서 주마다 **요일별 묶음**(날짜마다 `수 10/21`처럼 요일·날짜를 한 줄로 한 번, 그날 항목을 그 오른쪽에)으로 항목·★·↻·연결 메모를 따라가고, `Enter` = 보드의 그 칸으로. `Ctrl+F` 찾기, `Ctrl+Shift+C` 경과 복사.
4. **활동** 탭: 12주(일)·연간(주) 히트맵으로 업무별 기록 밀도를 봅니다.

![인사이트 — 업무 타임라인](shots/08-insights.png)

**팁**
- 업무 머리 ⋯ › [업무 타임라인 보기]로도 들어갑니다. `Alt+1` = 보드로.
- 기록한 날이 아닌 날에 끝낸 항목은 항목 글 뒤 **완료일 열**에 **완료 2026-10-27 (화)**처럼 실제 완료일이 붙습니다 — 모든 줄이 같은 세로선에 맞습니다(같은 날 끝냈으면 ✓만).
- 이번 주는 바탕색과 왼쪽 띠로만 강조되고, 요일·항목 글은 지난 주와 같은 세로선에서 시작합니다. 위쪽 [기간] 드롭다운은 카드 바탕으로 구분됩니다.
- 경과 복사 글도 요일별 묶음 — `(월) 10/12` 줄 아래 `- 항목`.

- 경과 지도는 항상 표시됩니다. **표 아이콘**으로 표를 표시/닫으며, 버튼 위에 마우스를 올리면 이름을 확인할 수 있습니다.
- **업무 타임라인 / 활동** 탭 앞에 각 기능의 모노그램 아이콘이 표시됩니다. 활동 격자는 창 너비에 맞춰 늘고 줄어 가로 스크롤 없이 표시됩니다.

- 시그니처 테마의 월 아래·주차 사이 선은 배경보다 진한 갈색으로 표시됩니다.

- 업무 타임라인 목록 오른쪽 경계, 활동의 업무 이름 열 오른쪽 경계를 끌어 너비를 조절합니다. 활동은 모든 행·헤더가 함께 바뀌고 이름 열이 넓어지면 날짜 칸이 줄어듭니다. 두 설정은 공간별로 따로 기억합니다.
- 경계에 포커스 후 ←/→는 16px, Shift+←/→는 32px, Home·더블클릭은 기본 폭으로 복원합니다. 창이 좁아지면 적용 가능한 폭만 일시 제한합니다.
- 활동 히트맵에는 **기록 일수 제목·표시 열을 두지 않습니다.** 업무 이름 열을 제외한 남은 폭을 날짜 격자가 사용합니다.
