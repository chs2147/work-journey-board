# 매일 2분 기록(키보드)

**언제 쓰나요** — 하루를 마치며(또는 틈틈이) 오늘 한 일을 업무별로 적을 때.

1. 앱을 켜면 오늘 칸에 커서가 있습니다. 바로 적고 `Enter` = 다음 항목, `Tab` = 세부 항목, `Shift+Tab` = 본 항목.
2. 칸의 첫·끝 줄에서 `↑`/`↓` = 위·아래 업무 칸, `Esc` = 편집 끝. 입력을 멈추면 0.5초 뒤 자동 저장(위쪽 `저장됨 ✓`).
3. 지난 요일·다른 주는 `Alt+←`/`Alt+→`(주 이동), [오늘]로 돌아오기. 하루만 크게 보려면 `Alt+V` = **데일리 뷰**.
4. 붙여 넣으면 줄마다 항목으로 나뉘고, 들여 쓴 줄은 세부 항목이 됩니다.

![주간 보드 — 오늘 칸에 바로 기록](shots/02-daily.png)

**팁**
- 새 업무는 상단의 아이콘이 붙은 **업무 추가**에서 만듭니다. 팝업에 업무 이름을 입력하고 기존 태그를 고르거나 새 태그를 추가합니다(태그는 선택). **업무 추가**는 만들고 닫기, **추가하고 계속**은 태그를 유지하며 연속 입력입니다. 취소하면 새 태그도 저장하지 않습니다.
- 주간 업무의 마지막 행 아래에 메모 경계가 바로 닿습니다. 경계를 끌어 높이를 조절하거나, 경계에 포커스한 뒤 `↑`/`↓`로 조절하고 `Home`으로 자동 높이로 돌아갑니다.
- 데일리 뷰의 업무 카드는 왼쪽의 직선 색상 띠로 구분합니다. 업무별 색상은 주간 보드와 같습니다.
- 실수는 `Ctrl+Z`/`Ctrl+Y`(50단계), 항목 지우기는 `Alt+Delete` 또는 항목 메뉴 [삭제](토스트 [되돌리기]).
- 그날까지 끝내야 하는 일은 `Alt+U`(항목 메뉴 **⏳ 마감일…**) → 빠른 단추·달력·숫자(`1026`)로 **마감일**을 정합니다. 항목 오른쪽 아래에 `⏳ 10/26(월) D-4`가 붙고(지나면 빨강 `2일 지남`, 당일은 `오늘 마감`), ★ 중요 표시도 함께 켜집니다. 꼬리표를 누르면 바꾸거나 지웁니다.
- 회의처럼 **시작 시각**이 있는 항목은 `Alt+O`(또는 항목 메뉴 — 아래 ⋮⋮ 참고) → 시·분(15분 단위) 고르기. 항목 앞에 `⏰ 10:00`이 붙고, 누르면 바꾸거나 지웁니다.
- 할 일을 **다른 날로 옮기려면** `Alt+D` — 다음 주·이전 주 같은 요일·내일·달력에서 고른 날로, 세부 항목까지 함께 갑니다(알림의 [그 날로 가기]·[되돌리기]).
- 항목에 마우스를 올리면 왼쪽에 **⋮⋮ 손잡이**가 나옵니다 — **끌면** 순서를 바꾸거나 다른 요일·업무 칸으로 옮기고(`Alt+↑`/`Alt+↓`도 같음), **누르면 항목 메뉴**: 연결된 메모 만들기·매주 반복·시작 시각·다른 날로 옮기기·삭제. 항목을 오른쪽 클릭해도 같은 메뉴입니다.
- 업무·요일 열 폭은 열 머리 오른쪽 끝을 끌어 바꿉니다(두 번 누르면 자동 폭, 주를 넘겨도 유지).
- 주소(`https://…`)는 링크가 되고 `Ctrl+클릭`으로 기본 브라우저에서 열립니다.
- 업무 이름 옆 🗄(숫자)는 그 업무에 연결된 Cabi.NET 폴더·링크입니다 — 누르면 바로 엽니다. → [11. Cabi.NET](#s11)

- 항목마다 **체크 사각형 아이콘**으로 완료, **되돌림 화살표 아이콘**으로 완료 취소합니다. 완료 본문에만 취소선이 표시되고 글 내용은 그대로 남습니다. 완료 취소는 완료 전 별표 상태를 복원합니다. 중요 업무 패널에서 완료한 항목도 같은 상태로 표시됩니다.
- 강조 띠·별표·완료 아이콘의 공간을 기본으로 비워 두어 별표를 켜도 본문 시작점이 움직이지 않습니다. 모든 강조 띠는 직각입니다.

- 완료/취소 조작 아이콘은 해당 행에 마우스를 올리거나 키보드로 접근하면 표시됩니다. 완료 상태 배지와 취소선은 항상 보입니다. 작은 창에서 업무 내용이 길면 보드만 스크롤하고 메모는 최소 높이를 유지합니다.

**날짜로 복제** — 항목 손잡이 ⋯/우클릭 › [날짜로 복제…]에서 날짜와 범위를 확인하고 [복제]를 누릅니다. 본 항목은 딸린 하위도 함께, 하위 하나는 독립 본 항목으로 추가됩니다. 같은 날도 가능하며 원본은 유지됩니다. 새 항목은 미완료·일회성이며 시작 시각과 원래 마감일을 유지합니다. 알림에서 그 날로 가거나 되돌릴 수 있습니다.
