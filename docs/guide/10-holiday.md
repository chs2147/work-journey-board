# 휴일·휴가

**언제 쓰나요** — 연차·반차, 공휴일, 회사 휴일·공가 같은 쉬는 날을 표시할 때.

1. 요일 머리 ⋯(데일리 뷰는 [근무 ▾]) → 연차·오전/오후 반차·**공휴일(이름)**·**기타 휴가(사유)**. 사유는 칩(공가·야유회·경조사·교육·대체휴무)이나 직접 입력.
2. 대한민국 공휴일(설·추석 연휴, 대체공휴일, 선거일)은 앱 안 표로 자동 표시됩니다(인터넷 접속 없음).
3. 설정 › **달력·휴일**: 자동 표시 켜기/끄기, 날짜별 끄기, 회사 휴일(매년·그 해만), 기타 휴가 사유 목록.

**팁**
- 공휴일인 날 근무했다면 그 날을 [근무]로 돌리세요 — 그 날 표시만 꺼집니다.
- 쉬는 날은 주간 요약 끝 줄·엑셀 날짜 머리에 이름이 들어가고, 3주 무기록 판정에서 빠집니다.
