# Cabinet — 자주 쓰는 폴더·링크

**언제 쓰나요** — 업무마다 여는 작업 폴더·위키·대시보드를 한곳에 모아 두고 바로 열 때.

1. 레일 🗄 또는 `Alt+4` → Cabinet 창. 탐색기의 폴더나 브라우저의 링크·주소를 끌어 놓으면 지금 고른 업무에 등록됩니다([+ 폴더…] [+ 링크…]도 됨).
2. 링크는 **링크 등록** 창에서 제목(브라우저가 함께 준 페이지 제목)을 확인·고치고 `Enter`.
3. [전체 · 📁 폴더 · 🔗 링크]로 나눠 보고, 폴더는 두 번 누르면 **폴더 창**(별도 창, 여러 개 동시) — 파일 두 번 누르기 = 기본 앱으로 열기. 링크는 누르면 기본 브라우저.
4. ⋯ 메뉴: 제목 고치기(`F2`)·업무·항목 연결·경로 복사·탐색기에서 열기·등록 해제.

![Cabinet 창과 폴더 창](shots/11-cabinet.png)

**팁**
- Cabinet은 폴더를 읽고 열기만 합니다 — 파일을 지우거나 옮기지 않습니다.
- 항목에 연결해 두면 보드 그 항목 옆에 🗄 표시가 붙어 바로 열 수 있습니다. 열어 둔 창은 다음에 켤 때 다시 열립니다.
