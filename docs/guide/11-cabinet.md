# Cabi.NET — 자주 쓰는 폴더·링크

**언제 쓰나요** — 업무마다 여는 작업 폴더·위키·대시보드를 한곳에 모아 두고 바로 열 때.

1. 레일 🗄 또는 `Alt+4` → Cabi.NET **별도 창**이 열립니다(앱 밖 어디로든 옮기고, 크기·위치는 다음에도 그대로). 왼쪽 맨 위 **전체** = 모든 폴더·링크, 그 아래 진행 중인 업무가 모두 보입니다(연결이 없으면 0).
2. 탐색기의 폴더나 브라우저의 링크·주소(크롬·엣지 주소창 아이콘 포함)를 끌어 놓으면 지금 고른 업무에 등록됩니다([+ 폴더…] [+ 링크…]도 됨). 링크는 **링크 등록** 창에서 제목을 확인·고치고 `Enter`.
3. [전체 · 📁 폴더 · 🔗 링크]로 나눠 보고, 폴더는 두 번 누르면 **폴더 창**(별도 창, 여러 개 동시) — 파일 두 번 누르기 = 기본 앱으로 열기. 링크는 누르면 기본 브라우저.
4. 줄을 **끌어서** 순서를 바꾸고, 왼쪽 업무에 놓으면 **그 업무에도 연결**됩니다(기존 연결은 그대로).
5. 폴더 줄의 탐색기 단추 또는 ⋯ 메뉴: 제목 고치기(`F2`)·업무·항목 연결·경로 복사·**탐색기에서 열기**(그 폴더 안으로)·**경로 다시 지정**·등록 해제.
6. [폴더 확인]으로 등록 폴더가 아직 있는지 검사합니다(열 때도 자동) — 이름이 바뀌거나 옮겨진 폴더는 ⚠ 찾을 수 없음. 폴더 창은 [새로 고침](`F5`) 외에 열려 있는 동안 자동으로 바뀐 내용을 반영합니다.

![Cabi.NET 창과 폴더 창](shots/11-cabinet.png)

**팁**
- Cabi.NET은 폴더를 읽고 열기만 합니다 — 파일을 지우거나 옮기지 않습니다.
- 바탕 화면의 폴더 **바로 가기**를 끌어 놓아도 가리키는 폴더로 등록됩니다. 왼쪽 업무 목록 폭은 사이 구분선을 끌어 바꿉니다.
- 보드의 업무 이름·항목 옆 🗄를 누르면 연결된 것을 바로 엽니다(여럿이면 Cabi.NET에서 보여 줌). 열어 둔 창은 다음에 켤 때 다시 열립니다.

업무 항목을 날짜로 복제하거나 이전 내역을 가져오면 원본 Cabi.NET 폴더/링크에 새 항목 연결만 추가됩니다. 업무 전체 연결은 그대로 공유하며 폴더·링크 객체 자체를 중복 등록하지 않습니다.


**업무 노트 — 날짜와 관계없이 기록하기**

왼쪽에서 업무를 선택하거나 상단 업무 선택을 고른 뒤 **새 노트**를 누릅니다. 한 업무에 여러 노트를 만들 수 있으며 각각 별도 창에서 열립니다. 노트 제목과 본문은 자동 저장합니다. 원래 업무 화면을 함께 사용할 수 있습니다.

본문은 블록 편집기입니다. **블록 종류** 또는 `/`로 제목·목록·체크·인용·코드·구분선·표를 선택합니다. 블록 왼쪽 손잡이로 순서를 바꾸고 상단 아이콘으로 위/아래 이동·복제·삭제합니다. 글자색과 링크도 지정할 수 있습니다.

![Cabi.NET 업무 노트](shots/11-cabi-note.png)

**가져오기 / 내보내기**

Markdown 파일을 선택하거나 본문에 놓으면 구조와 제외 항목을 미리 확인하고 새 노트로 만들거나 현재 위치에 삽입할 수 있습니다. 상대 경로 이미지는 해당 이미지 파일들을 Markdown과 함께 선택해 가져옵니다. base64·실행 콘텐츠·자동 다운로드가 필요한 이미지는 제외하거나 대체 텍스트로 남깁니다.

내보내기는 **Markdown**과 **PDF**를 제공합니다. Markdown은 이미지가 있으면 옆 `_images` 폴더에 함께 저장하며 글자색은 보존되지 않습니다. PDF는 한글 글꼴을 포함하고 텍스트를 선택할 수 있는 문서로 저장합니다.

**업무 메모보드 — 업무당 하나의 자유 보드**

**업무 보드 만들기/열기**로 별도 창을 엽니다. 같은 업무의 보드는 하나이며 다시 열면 기존 창으로 이동합니다. 날짜를 바꾸거나 업무를 종료해도 남습니다. 기존 주간 메모와 같은 편집·이미지·관계선·다중 선택·줌·실행 취소를 사용합니다.

**자료함**에서 폴더·링크·노트의 복제 아이콘을 보드로 끌면 **원본 연결 카드**가 생깁니다. 카드끼리 관계선으로 연결할 수 있고 원본 열기 버튼으로 해당 자료를 엽니다. 카드를 지워도 원본 자료는 지워지지 않습니다.

![Cabi.NET 업무 보드와 주간 메모 연동](shots/11-cabi-board.png)

**주간 메모** 패널에는 해당 업무의 업무항목에 연결된 누적 메모가 전체 기간에 걸쳐 표시됩니다. 같은 메모는 한 번만 나타나며 여러 개를 선택해 **원본 연결** 또는 **사본 만들기**로 추가합니다. 원본 연결은 최신 내용을 보여 주고 편집은 원본에서 합니다. 사본은 독립적으로 수정합니다.

선택 객체 위의 **복제 아이콘**을 다른 보드 창으로 끌거나, 객체 복사(`Ctrl+Alt+C`) 후 다른 창에서 객체 붙여넣기(`Ctrl+Alt+V`)를 사용할 수 있습니다. 주간↔업무 보드 모두 지원하며 원본은 그대로 남습니다. 그룹 내부 관계선과 이미지도 복제하지만 날짜별 업무항목 연결은 자동 복사하지 않습니다. 폴더·링크·노트 카드는 계속 같은 자료 원본을 가리킵니다.

자료함·주간 메모 패널은 필요할 때 열고 경계선을 끌어 폭을 바꿀 수 있습니다. 저장 실패가 표시되면 내용을 내보내거나 재시도한 후 닫습니다.


**Live Widget — 업무의 현재 상태**

업무 보드 상단 **Live Widget**에서 **업무 경과일**, **업무 타임라인**, **중요 업무**를 추가합니다. 위젯 제목을 끌어 배치하고 오른쪽 아래/하단 손잡이로 너비와 높이를 조절합니다. `⋯`에서 설정·복제·배치 삭제를 사용합니다. 배치 삭제는 원본 업무 기록에 영향을 주지 않습니다.

- **업무 경과일**: 시작일 또는 마지막 기록일 기준입니다. 기기의 오늘 날짜를 사용하며 자정·창 복귀 시 갱신합니다.
- **업무 타임라인**: 기록 목록형, 가로 마일스톤형, 가로 주차 요약형을 선택합니다. 마일스톤은 **마일스톤 관리**에서 원본 기록을 직접 고릅니다. 원본 날짜순으로 균등 배치하며 실제 경과 시간에 비례한 간격은 아닙니다. 주차 요약형은 기록을 자동 집계합니다.
- **중요 업무**: 해당 업무의 미완료 중요 항목만 표시합니다. 완료 버튼은 원본과 메인 중요 업무에 함께 반영하며 메인의 되돌리기를 공유합니다.

![업무 보드 Live Widget](shots/11-cabi-live.png)

보드의 **내보내기**에서 Markdown 또는 PNG를 고릅니다. 위젯은 내보낸 시점의 기준일이 포함된 정적 사본이 됩니다. 주간 보드로 복제할 때도 일반 텍스트 사본으로 변환합니다. 다른 업무 보드에 복제하면 확인 후 대상 업무를 표시하며 마일스톤은 다시 선택합니다.

**블록 이끌이와 선택 서식**

노트의 각 블록 가까이에 마우스를 올리면 이끌이 `⠿`가 나타납니다. 끌어서 이동하거나 눌러 블록 종류·위/아래 이동·복제·삭제 메뉴를 엽니다. 키보드는 블록 안에서 `Shift+F10`을 사용합니다. 목록 항목의 하위 내용은 함께 이동하고 표·코드는 한 블록으로 이동합니다.

텍스트를 선택하면 가까이에 서식 도구가 나타납니다. 굵게·기울임·취소선·코드·링크와 주간 메모와 같은 글자색을 적용합니다. Markdown은 글자색을 보존하지 않습니다. 노트와 보드는 메인과 같은 **저장됨** 표시를 사용합니다.

보드 전체 삭제는 **업무 보드 삭제**를 누르고 영향 범위를 확인한 뒤 `삭제`를 입력해야 실행됩니다. 노트를 삭제하면 열린 해당 노트 창도 저장 확인 후 닫힙니다.

업무 보드에서도 접이식 세로 팔레트와 Live Widget 그룹을 사용합니다. 노트 상단의 **이미지**는 그림 추가, **가져오기**는 Markdown 문서 가져오기입니다. 표의 셀을 선택하면 행 왼쪽/열 위쪽 이끌이에서 행·열 추가/삭제를 사용합니다. 순서 목록 안의 Tab/Shift+Tab은 단계 내리기/올리기이며 1. → 1-1. → 1-1-1.로 번호가 이어집니다. 표 안의 Tab은 기존 셀 이동을 유지합니다.

팔레트에서는 카테고리명과 상자 개수를 표시하지 않으며 각 그룹의 아이콘을 1열로 정렬합니다. 기능명·설명은 아이콘에 마우스를 올려 확인합니다. 작은 꺾쇠 손잡이로 접고 펼치며, 보기 비율·화면 맞춤·스크린샷·최대화/최소화는 접힘과 관계없이 상단에 유지됩니다.

관계선 보기/숨김은 주간 메모와 동일하게 상단 오른쪽 보기 툴바에 있습니다. 링크 넣기 팝업은 업무 보드 창 전체를 흐리게 하고 배경 조작과 포커스 이동을 차단합니다. 다른 독립 창은 그대로 사용할 수 있습니다.
