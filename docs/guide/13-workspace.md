# 여러 워크스페이스(회사·개인…)

**언제 쓰나요** — 회사 업무와 개인 생활·공부처럼 기록을 **완전히 따로** 두고 싶을 때. 공간마다 폴더와 일지 파일이 따로라 서로 섞이지 않습니다.

1. 왼쪽 레일 맨 위 **공간 단추**(색 사각형 + 아이콘)를 누르면 워크스페이스 목록이 열립니다. 고르면 그 공간으로 바뀝니다 — `Ctrl+Alt+1`~`9` = n번째 공간, `Ctrl+Alt+0` = 목록.
2. 목록의 **[+ 새 워크스페이스…]** → 4단계: 이름·색·아이콘·용도 → 저장 위치(추천: 지금 공간 폴더 옆) → 첫 업무(용도별 추천, 고쳐도 됨) → 지금 공간에서 가져올 설정(휴일·태그·무기록 알림).
3. 지금 어느 공간인지는 공간 단추 아이콘·레일 왼쪽 색 띠·상단 이름·창 제목(`Work Journey Board — 개인`)으로 보입니다.

![워크스페이스 목록](shots/13-workspace.png)

**팁**
- 설정 › **워크스페이스**: 이름·색·아이콘(생산성 도구 모노그램 28개) 바꾸기, ▲▼ 순서(= 단축키 순서), 폴더 열기, 기존 폴더를 워크스페이스로 추가.
- [목록에서 빼기]는 이 PC 목록에서만 빠지고 **폴더·파일은 그대로** 남습니다. 지금 연 공간은 뺄 수 없습니다.
- 백업은 공간마다 그 폴더의 `backups`에, 보조 백업 위치는 공간별 하위 폴더에 남습니다. 업데이트 직전에는 등록된 모든 공간을 한 부씩 백업합니다.
- 검색·주간 요약·엑셀·인사이트는 지금 연 공간만 다룹니다. 공간이 둘 이상이면 내보낸 파일 이름에 공간 이름이 붙습니다.
- 회사 PC에서 개인 공간을 만들 때는 회사 OneDrive 밖 폴더를 권합니다.
