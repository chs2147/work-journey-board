# 업무일지 내보내기(엑셀·마크다운)

**언제 쓰나요** — 월간·분기 보고, 다른 사람과 기록을 나눌 때.

1. [내보내기] 또는 `Alt+E` → **업무일지 내보내기** 창. 제목 오른쪽에서 **엑셀**·**마크다운** 형식을 고릅니다(마지막 형식을 기억).
2. **범위**: 이번 주·최근 4주·기간 지정·**연도**(그 해의 첫 기록 주부터 이번 주까지)·전체. 아래 **업무** 단추로 전체·1개·여러 개를 고릅니다(체크 = 여러 개, [이것만] = 1개, 다음에 열면 다시 전체).
3. **포함**: 엑셀은 주간보고·원장·주간 요약·메모 보드 스냅샷 시트, 마크다운은 업무 기록·주간 요약·주간 메모(글만). 요약은 해당 주의 수정본, AI본, 자동 집계 순으로 가져오고, 업무를 골랐으면 고른 업무만으로 자동 집계합니다.
4. **미리 계산**에서 주·업무·항목 수를 보고 [저장 위치 선택…]. 저장이 끝나면 토스트의 [폴더 열기]·[파일 열기].
5. 메모 보드만 마크다운으로: 메모 머리 카메라 메뉴 › [마크다운으로 내보내기…] → `.md`(+ 이미지 폴더)로 저장하거나 복사합니다.

![업무일지 내보내기](shots/07-export.png)

**팁**
- 마크다운 업무일지는 주(오래된 주부터) → 업무 → 날짜 → 항목 순이고, 처리 완료 항목 끝에 ✓, 연차·휴일은 날짜 옆에 붙습니다. 그림은 넣지 않습니다.
- 파일 이름에 연도(`업무일지_2026년_W38~W43`)·고른 업무(1개면 이름, 여러 개면 `업무 N개`)가 들어갑니다.
- 내보낸 마크다운을 다시 메모 보드에 끌어 놓을 수 있습니다. 글과 링크만 새 텍스트 메모로 가져오며 이미지 폴더·첨부 데이터는 자동으로 읽지 않습니다. → [5. 메모 보드](#s5)
- 저장은 고른 경로에만 하고, 일지 파일·`backups` 폴더에는 쓰지 않습니다.

다른 주와 공유하는 메모의 연결 항목도 원본 날짜·업무·본문을 찾아 Markdown·PNG·엑셀 스냅샷에 표시합니다. 메모 객체와 이미지는 원본 소유 주차에 한 번만 보관합니다.
