# 백업과 복원

**언제 쓰나요** — 기록을 안전하게 지키고, 문제가 생겼을 때 되돌릴 때.

1. 앱이 자동으로 **일일 백업**(켤 때·2시간마다·닫을 때)과 **월간 백업**을 `저장 폴더\backups`에 만듭니다. 업데이트·구조 변경·가져오기 직전에도 따로 남깁니다.
2. 설정 › **데이터·백업**: 지금 백업, 백업 폴더 열기, 보관 개수, 보조 백업 위치(다른 폴더에 하나 더).
3. **복원**: 설정 › 데이터·백업 › [백업에서 복원…] → 사본 고르기. 지금 일지는 `…_before-restore.db`로 보존된 뒤 바뀝니다.

![설정 › 데이터·백업](shots/12-backup.png)

**팁**
- 일지 파일이 깨졌다고 나오면 시작 화면에서 바로 최근 백업으로 복원할 수 있습니다.
- 다른 PC로 옮길 때는 저장 폴더째(`work-journey.db` + `backups`) 복사하면 됩니다.
