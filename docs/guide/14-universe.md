# Universe — 기록과 지식의 연결 지도

**언제 쓰나요** — 예전에 비슷한 일을 어떻게 했는지, 이 기록이 어떤 메모·폴더·업무와 이어져 있는지 한눈에 보고 원래 자리로 돌아갈 때.

1. 왼쪽 레일 **Universe**(연결망 아이콘) 또는 `Alt+5` — 보드에서 커서가 있던 항목이 가운데(**초점** 보기)에 놓이고, 그 업무·같은 업무의 가까운 기록·연결된 메모 상자·Cabinet 폴더가 둘레에 보입니다.
2. 별을 선택하고 상단 **[상세]**를 펼치면 **원문과 "왜 이어졌나"**(소속·메모에서 연결·Cabinet에서 연결·메모 관계선)가 나옵니다. 두 번 누르면 그 별이 가운데로.
3. **[원본 열기]** — 항목은 보드의 그 칸, 메모 상자는 그 주 메모, Cabinet은 그 줄, 업무는 경과 타임라인으로 갑니다. 다시 `Alt+5`로 돌아오면 보던 자리 그대로.
4. **[연결하기]** — 주를 넘어 다른 기록·메모·업무와 직접 잇습니다. 대상을 찾아(같은 업무·최근 기록이 먼저, 두 글자 이상 치면 검색) 고르고 종류를 정하면 끝 — **관련**(방향 없음) · **후속**(이 별 다음에 대상) · **근거** · **반대 근거** · **대체**(원문은 그대로). 설명은 한 줄(200자)까지 선택.

5. **[지식 카드로 정리]** — 여러 기록에서 얻은 해결법·의사결정·배운 점·업무 길잡이를 카드로 남깁니다. 고른 별이 첫 출처가 되고, [출처 더하기]로 기록·메모·Cabinet을 더 붙입니다(1~50개). 제목·요약·적용 조건·본문을 쓰고 [저장]. 원문은 본문에 복사하지 않고 출처마다 "당시 발췌"로 남습니다.
6. **[근거에 담기]** — 사내 AI에 물어볼 원문을 모읍니다(Universe 상세·보드 항목 메뉴). 위쪽 [근거 묶음 n]으로 서랍을 열고 질문을 적으면, 미리보기가 실제로 복사할 글(지시문 + 원문 + 근거 번호 S1·K1 + 주의)이 됩니다. [사내 AI용 복사] 또는 [Markdown으로 저장…].

**팁**
- 위쪽 [초점 | **은하**]: 은하 = 모든 기록을 한 화면에(업무가 별자리 중심, 태그가 업무를 잇는 허브). 다이나믹 3D에서는 드래그로 회전·Shift+드래그로 이동합니다. 선택한 별을 향해 휠로 충분히 확대하면 초점으로, 축소하면 은하로 돌아갑니다.
- [지도 | **목록**]: 같은 자료를 표로 — `↑`/`↓`로 고르고 `Enter` = 원본 열기.
- 바닥 **시간 막대**: 년 → 월 → 주 → 일로 눌러 들어가면 그 기간만 밝게, [전체 기간]으로 되돌림.
- 상단 **[필터]**를 펼쳐: 검색(두 글자 이상) · 업무 · 태그 · 종류 · 연결 출처. 워크스페이스가 둘 이상이면 다른 공간도 **읽기 전용**으로 함께 볼 수 있고, 그 공간 별의 [원본 열기]는 그 공간으로 바꾼 뒤 그 자리로 갑니다.
- 직접 연결은 지도에 **굵은 선·화살표**로, 상세의 "왜 이어졌나" 맨 위에 "A 다음에 B가 이어짐" 같은 문구로 보입니다. [고치기]로 종류·방향·설명을, [끊기]로 연결만 지웁니다. Universe 안에서 `Ctrl+Z` = 직접 연결 작업 되돌리기, `Ctrl+Y` = 다시 하기.
- 직접 연결은 지금 공간 안에서만 만듭니다(다른 공간 별은 읽기 전용).
- 원문 고치기는 보드·메모에서 — Universe가 고치는 것은 직접 연결·지식 카드뿐입니다.
- 지식 카드 상태: **초안 → 검토함 → 보관**. "검토함"은 적용 조건·출처를 확인했다는 표시입니다(사실 보증이 아님). 원문이 바뀌면 카드를 저절로 고치지 않고 출처 옆에 **내용 변경**·**위치 변경**·**원문 없음**을 표시합니다 — [비교]로 당시 발췌와 지금 원문을 나란히 보고 [다시 확인].
- 카드 출처인 보드 항목에는 오른쪽 끝에 **◆** — 누르면 그 카드로. 통합 검색(`Ctrl+Shift+F`) 결과에도 카드가 나옵니다.
- 근거 묶음은 원문 12,000자·원본 20개까지 — 넘치면 원본을 통째로 빼고 무엇을 뺐는지 보여 줍니다. Cabinet 경로·링크 주소는 기본으로 빼고, 그림은 설명 글만 담습니다. 복사 직전에 원문을 다시 읽어 바뀌었으면 미리보기를 새로 만들고 다시 확인받습니다. 앱은 사내 AI에 보내지 않습니다(복사·파일까지).
- 공간을 바꾸면 근거 묶음은 비워집니다 — 카드·묶음은 지금 공간 원문만.

- 필터·상세 패널은 기본 접힘입니다. 각 버튼·×·Esc로 닫고, 접어도 선택과 필터는 유지됩니다. 좁은 창에서는 한 패널씩 표시합니다.
- **[다이나믹 3D / 정적 2D]**: 정적은 기존 평면 탐색입니다. 지도는 앱 테마와 별개로 항상 어두운 배경을 사용합니다. OS 모션 감소 설정 또는 3D 미지원 시 정적 모드가 제공됩니다.
- 3D 지도에 포커스한 뒤 방향키로 회전, Shift+방향키로 이동, +/-로 확대·축소, Home으로 전체 보기를 할 수 있습니다.

- 상단 전환은 모노그램 아이콘 버튼입니다. **큐브 / 평면** = 다이나믹 3D / 정적 2D, **조준점 / 궤도** = 초점 / 은하, **지도 / 목록** = 보기 방식입니다. 마우스를 올리면 이름이 표시되고, 선택 상태는 배경과 아래 강조선으로 구별합니다.
