# 부록 — 단축키·자주 묻는 질문

> 단축키는 Windows 표기 옆 괄호에 **macOS 표기**를 함께 적었습니다 — 예: `Ctrl+Shift+F` = 맥 `⇧⌘F`(`⌘` Command · `⌥` Option · `⇧` Shift · `⌦` fn+delete · `↩` return). 앱 화면의 안내 글은 맥에서 맥 표기로 보입니다.

**화면 이동**

| 키 | 동작 |
|---|---|
| `Alt+1` / `Alt+2` / `Alt+3` / `Alt+4` | 보드 / 중요 업무 패널 / 인사이트 / Cabinet(별도 창 열기·닫기) |
| `Ctrl+Alt+1`~`9` · `Ctrl+Alt+0` | n번째 워크스페이스로 · 워크스페이스 목록 |
| `Alt+5` | Universe 열기(커서가 있는 항목이 가운데) / 보드로 |
| `Ctrl+,` | 설정 |
| `Alt+←` / `Alt+→` · `Alt+V` | 앞·뒤 주(데일리 뷰는 하루) · 주간 ↔ 데일리 뷰 |
| `Ctrl+Shift+F` · `F3` | 검색 · 다음 결과 |
| `Alt+E` | 엑셀 내보내기 |

**칸 입력**

| 키 | 동작 |
|---|---|
| `Enter` / `Shift+Enter` | 새 항목 / 항목 안 줄바꿈 |
| `Tab` / `Shift+Tab` | 세부 ↔ 본 항목 |
| `Alt+↑` / `Alt+↓` | 항목 순서 |
| `Alt+I` · `Alt+R` | 중요 표시 · 매주 반복 |
| `Alt+O` · `Alt+D` | 시작 시각 · 다른 날로 옮기기(항목 ⋮⋮ · 오른쪽 클릭 메뉴에도) |
| `Alt+P` · `Alt+Shift+P` | 직전 기록 가져오기(이 칸 · 모든 업무) |
| `Alt+Delete` · `Ctrl+Z` | 항목 지우기 · 되돌리기 |

**자주 묻는 질문**
- **인터넷이 없어도 되나요?** — 네. 새 판 확인(켤 때 1번)만 GitHub에 묻고, 기록·메모는 어디에도 보내지 않습니다.
- **기록은 어디에 있나요?** — 처음 고른 저장 폴더의 `work-journey.db` 한 파일입니다.
- **윈도우에서 쓰던 일지를 맥으로 옮길 수 있나요?** — 네. `work-journey.db` 파일을 맥으로 복사하고 처음 켤 때 **기존 일지 열기**로 그 폴더를 고릅니다(파일 형식이 같습니다). Cabinet에 등록한 윈도우 폴더 경로는 맥에 없으니 "폴더 없음" 표시에서 **경로 다시 지정**을 씁니다.
- **새 판은 어떻게 받나요?** — 켤 때 새 판이 있으면 위쪽 띠가 알려 줍니다. 설정 › 업데이트·정보에서도 확인·설치합니다(설치 전 자동 백업).
