# 검색

**언제 쓰나요** — "그거 언제 했더라?" 싶을 때.

1. 위쪽 검색 칸 또는 `Ctrl+Shift+F` → 낱말 입력(띄어 쓰면 모두 들어간 것) → `Enter`.
2. 오른쪽 결과 목록: 업무 기록·메모 보드(글·이미지 설명·링크 카드·관계선)·Cabi.NET 폴더/링크가 꼬리표와 함께. 누르면 그 칸·메모 상자로.
3. `F3`/`Shift+F3` = 다음/이전 결과, 보드 위 노란 띠의 [검색 초기화]로 끝냅니다.

![검색 결과 패널](shots/09-search.png)

**팁**
- 기간(전체·올해·최근 12주)과 거르기(업무 기록·메모 보드)로 좁힙니다.


전역 검색에는 Cabi.NET 노트 제목·본문과 업무 보드의 내용도 표시합니다. 결과를 누르면 해당 노트 또는 업무 보드를 별도 창에서 엽니다.
