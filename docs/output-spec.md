## 2. 주간 자동 집계 포맷

### 2-1. 규칙
1. 머리줄: `[주간 업무 요약] {보드 제목}` (보드 제목 규칙은 data-spec 1-2절).
2. 업무 순서 = 보드 행 순서(`sort_order`). 그 주에 보이는 업무 중 **항목이 1개 이상인 업무만** 본문에.
3. 업무 안에서는 날짜순 → `seq`순.
4. 본 항목(depth 0): `- (요일) 내용`. 세부 항목(depth 1): `  · 내용`(요일 태그 없음, 바로 위 본 항목에 속함).
5. 항목 안 줄바꿈은 다음 줄을 들여 이어 씀 — 본 항목은 공백 2칸, 세부 항목은 공백 4칸(2026-10-24 확정: 메신저·메일 글꼴마다 한글 폭이 달라 `(요일)` 머리 너비에 맞추지 않고 고정 칸 수).
6. 업무 블록 사이 빈 줄 1개.
7. 메모 포함 시 본문 뒤 `[메모]` 블록 — 주간 메모의 글을 읽는 순서(위→아래, 높이가 비슷하면 왼쪽→오른쪽)로: 제목·문단은 한 줄씩 그대로, 글머리 `- `, 번호 `1. `, 체크 목록 `- `(완료는 `- (완료) `), 안쪽 목록은 공백 2칸 더 들여쓰기, 이미지 상자는 설명이 있으면 `- (이미지) 설명`(없으면 빠짐), 상자 사이 빈 줄 1개. 글이 없으면 블록을 넣지 않는다(weekly-note-spec 6절). 예전 요일 메모는 `- (요일) 내용` 글머리 목록으로 옮겨져 같은 모양이 나온다.
8. 맨 끝 `※` 줄(빈 줄 1개 뒤, 사이에 빈 줄 없이):
   - 연차·반차 표시가 있으면 `※ 연차: 화(10/27), 수(10/28) · 오전 반차: 목(10/29) · 오후 반차: 금(10/30)` — 종류 순서 연차 → 오전 → 오후, 날짜순(v0.2.5, improve-1026-spec 1-3). 표시가 없으면 줄이 없어 2-2 샘플과 글자 하나 다르지 않다.
   - 항목 0개인 업무가 있으면 `※ 이번 주 기록 없음: 업무1, 업무2`.
9. 기호는 `■`·`-`·`·`만 사용(사내 메신저·메일·한글 문서에 붙여도 깨지지 않는 문자).

### 2-3. 세 가지 본(本)의 관계
| 본 | 생성 | 저장 | 화면 |
|---|---|---|---|
| 자동 집계본 | 항상 계산(기록 변경 즉시 반영) | 안 함 | 주간 요약 패널 기본 탭 |
| AI본 | 클립보드 다리 결과를 붙여넣어 저장 | `weekly_summary.ai_text` | AI본 탭 |
| 수정본 | 자동 집계본 또는 AI본을 "편집해서 수정본 만들기" | `weekly_summary.edited_text` | 수정본 탭 |

- AI본·수정본 저장 시 그 시점 자동 집계본의 SHA-256을 `*_basis_hash`에 저장 → 이후 기록이 바뀌어 해시가 달라지면 해당 탭에 "작성 후 기록이 변경되었습니다 · [자동 집계본과 비교]" 안내(덮어쓰지 않음).
- 패널의 "최종본" 표시 = 수정본 > AI본 > 자동 집계본 중 존재하는 가장 앞의 것. [최종본 복사] 버튼 하나로 보고서에 붙여넣기.

## 3. 엑셀 양식

라이브러리: ExcelJS(서식·병합·필터·고정 지원). 글꼴 **맑은 고딕**(본문 10pt), 파일은 앱 안에서 생성 → 사용자가 고른 위치에 저장(외부 전송 없음).

### 3-1. ① 주간보고 시트 (`주간보고`, 사람이 읽는 용)

**열 구성(시트 공통 너비)**
| 열 | 내용 | 너비(문자) |
|---|---|---|
| A | 업무 | 22 |
| B~F | 월~금 | 각 34 |
| G | 토 | 26 (범위 안 어느 주라도 토 기록이 있을 때만 존재) |
| H | 일 | 26 (같은 조건, 일요일) |

**주차 블록(위 → 아래, 오래된 주부터)**
| 행 | 내용 | 서식 |
|---|---|---|
| 제목행 | `2026-W43 (10/19~10/25)` — A~블록 마지막 열 병합 | 12pt 굵게, 배경 `#E8E8E4`, 높이 22 |
| 머리행 | `업무 | 월 10/19 | 화 10/20 | … | (토 10/24)` — 연차·반차 날은 끝에 ` (연차)`·` (오전 반차)`·` (오후 반차)`(v0.2.5) | 굵게, 가운데, 배경 `#F4F4F1` |
| 업무 행 | A=업무명(굵게, **왼쪽 테두리 굵게 = 업무 색**) / 요일 칸=그날 항목 | 줄바꿈, 위·왼쪽 정렬 |
| 메모 행 | A=`메모` / **B~마지막 열 병합** 한 칸 = 주간 메모 글(2-1절 규칙 7과 같은 글, 메모에 글이 있는 주만). 높이는 병합 너비 합계로 계산 | 회색 글자 `#5F5E5A` |
| 요약 행 | A=`주간 요약` / B~마지막 열 병합 = 수정본 > AI본, 없으면 `—`. 첫 줄에 `[수정본]`/`[AI본]` 표시 | 배경 `#FAFAF7` |
| 간격 | 빈 행 1개 | — |

- **셀 안 개조식**: 본 항목 `- 내용`, 세부 항목 `   · 내용`, 항목 사이 줄바꿈(`\n`) + `wrapText`.
- **블록에 넣는 업무** = 그 주에 보이는 업무 중 **항목이 있는 업무만**(자동 집계와 같은 규칙, 보드 순서). 항목 0개인 업무는 출력 안 함.
- **토·일**: 블록별로 그 요일에 업무 항목이 있을 때만 머리행·칸 생성(주간 메모는 요일이 없어 세지 않는다). 없는 블록에서는 그 열을 비워두고 테두리 없음, 요약 행 병합은 그 블록의 마지막 열까지.
- **테두리**: 블록 안 전체 얇은 선 `#BFBFBF`.
- **행 높이**: ExcelJS는 자동 맞춤이 없으므로 직접 계산 — `줄 수 = Σ(각 줄 ceil(표시폭 / 열 너비))`, 표시폭은 한글·전각 2, 그 외 1. 행 높이 = `max(15, 줄 수 × 13.5 + 3)` pt(행 안 칸들 중 최댓값). 병합된 요약 행은 병합 너비 합계로 계산.
- **인쇄**: A4 가로, 너비 1페이지에 맞춤, 바닥글 `Work Journey Board · 내보낸 날짜 YYYY-MM-DD · &P/&N`. 블록이 페이지 경계에서 잘리지 않도록 각 블록 제목행 앞에 수동 페이지 나누기 넣지 않음(주당 높이가 작아 불필요, 인쇄 미리보기에서 확인).
