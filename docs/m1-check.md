> 작성: 2026-10-24 · 관련: [i-m1-plan.md](i-m1-plan.md) S5, [project-plan.md](project-plan.md) ◆G2, [m0-install-check.md](m0-install-check.md)(M0 절차)
> 목적: 클라우드(리눅스·브라우저 모드)에서 확인할 수 없는 **윈도우 실기 항목**을 회사 PC에서 한 번에 확인하고 ◆G2(2주 실사용)를 시작한다.

## 0. 준비
- 다운로드: GitHub 저장소 → Releases → **`Work Journey Board v0.1.0`**
  `https://github.com/chs2147/work-journey-board/releases`
- 받을 파일: `WorkJourneyBoard_0.1.0_setup.exe`
- (선택) 변조 확인: `certutil -hashfile WorkJourneyBoard_0.1.0_setup.exe SHA256` → 릴리스의 `SHA256SUMS.txt`와 같으면 정상.
- 이미 쓰는 일지가 있으면, 확인 전에 **설정 → 백업 → [지금 백업]** 을 한 번 눌러 둡니다.

이미 일지를 쓰고 있으면 3-1·3-2는 **처음 설치할 때 확인했는지** 기억으로 적고 넘어가도 됩니다(일부러 설정을 지우지 않습니다).

| # | 확인 | 결과 |
|---|---|---|
| 3-1 | 첫 실행 → [새로 시작하기] → [찾아보기]에서 **윈도우 폴더 선택 창**이 뜬다 | |
| 3-2 | OneDrive 동기화 폴더(예: 문서)를 고르면 **경고**가 뜨고 [다음]이 막힌다 | |
| 3-3 | (D 드라이브가 있으면) 설정 → 저장 위치 → [저장 위치 변경…] → `D:\WorkJourney`(빈 폴더) → 옮기기. 보드가 그대로 열리고, **원래 폴더의 일지 파일도 남아 있다**. 확인 뒤 원하면 원래 위치로 다시 옮긴다 | |
| 3-4 | 설정 → [폴더 열기]·[백업 폴더 열기]가 탐색기로 그 폴더를 연다 | |

## 4. 매일 기록(◆G2 기준 ①)
| # | 확인 | 결과 |
|---|---|---|
| 4-1 | **2분 측정**: 앱을 열고 → 키보드만으로 오늘 칸에 **업무 3개 × 항목 2개 + 메모 1줄** → 걸린 시간 ___분 ___초 (`Enter` 다음 항목, `↓` 아래 업무 칸, 마지막 업무 아래 `↓`는 메모) | |
| 4-2 | **한글 입력기**: 글자를 조합하는 중에 `Enter`·`Tab`을 눌러도 글자가 깨지거나 항목이 두 번 생기지 않는다 | |
| 4-3 | 한글 입력 상태에서 단축키가 동작한다: `Alt+←/→`(주 이동) · `Alt+T`(오늘) · `Alt+I`(중요) · `Alt+R`(반복) · `Ctrl+Z`(실행 취소) | |
| 4-4 | 업무 행 머리를 **끌어서** 순서를 바꿀 수 있다(놓을 자리 표시가 보인다) | |
| 4-5 | 상단 저장 표시가 입력을 멈추면 `저장됨 ✓`으로 바뀐다 | |

## 5. 중요 표시·매주 반복
| # | 확인 | 결과 |
|---|---|---|
| 5-1 | 항목 앞 점에 마우스를 올리면 ☆ → 누르면 형광펜 + ★, 왼쪽 레일 ★에 개수 배지 | |
| 5-2 | 레일 ★(또는 `Alt+2`) → 중요 업무 패널에서 체크하면 처리 완료(강조 해제), [되돌리기] 동작 | |
| 5-3 | 항목에서 `Alt+R`(또는 ↻) → 다음 주(`Alt+→`)에 흐린 "예정" 항목이 보인다 | |
| 5-4 | **주가 바뀐 뒤**(다음 주 월요일 이후) 앱을 처음 열면 반복 항목이 들어오고 "↻ 반복 항목 n개가 이번 주에 들어왔습니다" 토스트가 뜬다 | |
| 5-5 | (v0.1.1~) 상단 [주간 요약](또는 `Alt+S`) → 오른쪽 패널에 이번 주 자동 집계. [최종본 복사] 후 메일·메신저에 붙여 넣어 기호(`■`·`-`·`·`)가 깨지지 않는다 | |
| 5-6 | (v0.1.1~) 주간 요약 패널을 **연 채로 앱을 끄고 다시 실행** → 패널은 열려 있고, 커서는 보드 오늘 칸에 있어 바로 타이핑된다 | |

## 7-2. 주간 요약·엑셀 내보내기 (I-M2 `v0.2.0`)
> 확인용 가상 데이터 파일도 함께 씁니다: 세션에서 받은 `sample-export_2026-W38~W43.xlsx`(가상 업무 6주)를 엑셀로 열어 서식을 먼저 볼 수 있습니다.

| # | 확인 | 결과 |
|---|---|---|
| M2-1 | `Alt+E`(또는 상단 [내보내기]) → [저장 위치 선택…]에서 **윈도우 저장 대화상자**가 뜨고, 기본 위치가 `저장 폴더\exports`, 파일명이 `업무일지_<주차>.xlsx`다 | |
| M2-2 | 같은 이름으로 한 번 더 저장 → 윈도우가 **덮어쓰기 확인**을 묻는다(취소하면 저장되지 않음) | |
| M2-3 | OneDrive 동기화 폴더(예: 문서)를 고르면 저장 전에 **경고**가 뜬다 | |
| M2-4 | 저장 후 토스트 [파일 열기] → **엑셀**이 그 파일을 연다, [폴더 열기] → 탐색기가 그 폴더를 연다 | |
| M2-5 | 엑셀에서: 글꼴 **맑은 고딕**, 칸 안 글이 **잘리지 않는다**(행 높이), 업무 이름 왼쪽에 업무 색 굵은 선, 주간 요약 행이 표 아래 가로로 병합 | |
| M2-6 | 엑셀 **인쇄 미리보기**: A4 가로, 너비가 한 페이지에 맞고, 바닥글 `Work Journey Board · 내보낸 날짜 … · 쪽/전체` | |
| M2-7 | 원장 시트: 첫 행 고정·자동 필터가 동작하고, 날짜 열이 날짜로 정렬·필터된다. 중요 표시한 항목의 `중요` 열에 ★ | |
| M2-8 | 엑셀이 그 파일을 연 채로 같은 이름으로 다시 저장 → "엑셀에서 열려 있으면 닫고 다시 시도" 안내가 뜨고 앱은 멈추지 않는다 | |
| M2-9 | 주간 요약 [최종본 복사] → 메일·메신저·한글 문서에 붙여 넣어 기호(`■`·`-`·`·`)와 들여쓰기가 깨지지 않는다(5-5와 같음) | |

- **I-M2 완료 기준**(project-plan): ◆G2 동안 실제 기록이 **4주 이상** 쌓이면, 회사 PC에서 그 기간을 내보내 M2-5~M2-7을 한 번 더 봅니다. 실제 기록으로 만든 파일은 저장소·세션에 올리지 않고, 문제는 증상만 알려 주세요.
