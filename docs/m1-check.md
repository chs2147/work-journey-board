## 7-4. 기존 일지 가져오기 (`v0.2.4`, i-m3-plan M3-S0)
> 회사 PC에서 **실제 OneNote 주간 페이지 2~4주**로 시험합니다. 캡처·엑셀·화면은 세션에 보내지 않고, 결과와 "AI가 틀린 곳의 유형"(예: 요일 밀림, 업무 섞임, 요약 칸을 옮김)만 알려 주세요 — 지시문을 고칩니다.

| # | 확인 | 결과 |
|---|---|---|
| I-1 | 설정 → [기존 일지 가져오기…] → [양식 엑셀 받기] → **윈도우 저장 대화상자**, 엑셀로 열면 `안내`·`업무`·`기록` 시트, `업무` 시트에 이번 주 진행 중 업무가 들어 있다 | |
