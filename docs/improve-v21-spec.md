## 1. 지금 구조(확인한 사실)

- 항목 = `entry_item`(id 고정 — 저장은 upsert라 id가 유지됨), 날짜·업무·순서·깊이(0/1)·글 + ★(`flagged`)·완료 시각(`flag_done_at`)·완료 전 ★ 여부(`completion_was_flagged`)·반복·시작 시각·마감일.
- 상태는 둘뿐: **미완료**(`flag_done_at IS NULL`) / **완료**(`flagged = 0 AND flag_done_at` 있음). 완료는 항목마다 따로(본 항목을 완료해도 세부 항목은 그대로).
- 완료 시각은 하나만 남고(되살리면 지워짐) **이력이 없다**.
- 중요 업무 패널 = ★ 항목(처리 전) + 보고 있는 주에 완료한 ★ 항목.
- 타임라인(`Timeline.tsx`)은 본 항목마다 `(요일)`을 앞에 붙인다 → 같은 날 본 항목이 여럿이면 요일이 반복. 완료는 ✓ 아이콘(툴팁에만 완료일).

## 2. 칸반 보드 — 화면

### 2-1. 들어가기 (시안 ①)
- **레일**: [주간 보드] 바로 아래, [인사이트] 위에 [칸반 보드] 단추. 단축키 **`Alt+6`**(기존 Alt+1~5는 그대로 — 번호를 밀면 손에 익은 키가 바뀌므로 새 번호).
- 인사이트처럼 **보드 자리를 덮는 화면**(주간 보드는 숨긴 채 그대로 — 보던 주·커서 유지). `Alt+1` = 주간 보드로.
- **왼쪽 중요 업무 패널**은 주간 보드와 **같은 패널 그대로**(Alt+2, 폭 기억). 칸반에 "중요" 섹션을 따로 두지 않는다.
  - 패널에서 체크 = 완료 → 카드가 DONE으로. 패널 항목을 누르면 칸반에서는 **그 카드로 스크롤·강조**(주간 보드로 넘어가지 않음).
- 상단 줄: `칸반 보드` 제목 · 업무 필터 · 기간 필터 · 검색 · **[＋ 업무 항목 추가]** · [섹션 추가] · 저장 표시.

### 2-2. 섹션(열)
- 순서: **TODO** → 사용자 섹션들 → **DONE**. TODO·DONE은 기본(`기본` 표시, 지우기·순서 바꾸기 없음).
- 열은 가로로 나란히, 각 열은 세로 스크롤. 열이 많아 좁아지면(열 최소 폭 280px) 가로 스크롤.
- 열 머리: 이름 · 카드 수 · (TODO) 정렬 · ⋯ 메뉴.
- 맨 오른쪽 좁은 점선 열 = [＋ 섹션 추가](상단 단추와 같음).

### 2-3. 카드 = 본 항목 1개
- 왼쪽 **업무 색 띠(직각)** · 업무 이름 · 기록일 · ★(중요일 때).
- 본문 = 본 항목 글(첫 줄), 그 아래 **세부 항목 목록**(완료한 세부는 취소선, 4개 이상이면 3개 + "외 n개").
- 꼬리표: ⏳ 마감(D-n·지남 색은 주간 보드와 같음) · ⏰ 시작 시각 · ↻ 반복 · `세부 1/3` · ▤ 연결 메모 수 · 🗄 Cabi.NET 연결 수 · (사용자 섹션) `10/14부터 이 섹션`.
- **카드 전체가 끌기 대상** — 이끌이 아이콘 없음. 마우스를 올리면 오른쪽 위 ⋯.
- 누르기 = 선택(테두리), **두 번 누르기·Enter = 편집 창**, 오른쪽 클릭·⋯ = 카드 메뉴.
- 본 항목 없이 칸 맨 위에 세부 항목만 있는 경우(드묾)는 그 세부 항목을 카드 1장으로 본다.

### 2-4. DONE (접힌 카드)
- 한 줄 카드: 색 띠 · ✓ · 글(취소선) · 완료 시각(오늘이면 시:분, 아니면 월/일).
- **완료 시각 최신순**으로 쌓이고 `오늘 / 이번 주 / 지난주 / 월별` 구분 머리.
- 누르면 그 자리에서 펼쳐(세부 항목·꼬리표·기록일·업무 이름) 보이고 다시 누르면 접힘.
- 많을 수 있으므로 **처음 50개 + [이전 완료 n개 더 보기]**.

### 2-5. 필터
- **업무**: 전체 / 선택(여러 개) — 인사이트의 업무 고르기(`CategoryPicker`) 재사용, [종료 업무 포함] 토글.
- **기간**(2026-11-12 사용자 확정): 오늘 · **이번 주(기본)** · 최근 2주 · 최근 4주 · 최근 12주 · 전체 · 지정일(시작~끝 날짜).
  - 기준 날짜: **TODO·사용자 섹션 = 기록일**, **DONE = 완료일**(→ "이번 주에 끝낸 일"이 보임). — 결정 D5
- 필터 상태는 일지 설정에 기억(`ui.kanban`). 필터에 가려진 수는 열 머리 툴팁에.
- 정렬(TODO·사용자 섹션): 최신순(기본) · 오래된 순 · 마감 임박순. 손으로 순서를 바꾸는 기능은 이번 범위 밖(D8).

## 3. 상태와 규칙

### 3-1. 상태 판정(단일 출처 `domain/kanban.ts`)
| 조건 | 섹션 |
|---|---|
| 본 항목이 완료(`flag_done_at` 있음, ★ 아님) | DONE |
| 완료 아님 + `kanban_section_id` 있음 | 그 사용자 섹션 |
| 그 밖 | TODO |

### 3-2. 이동 규칙
| 이동 | 처리 |
|---|---|
| TODO/사용자 섹션 → **DONE** | 본 항목 완료(지금 시각) + **아직 미완료인 세부 항목도 같은 시각으로 완료** · 사용자 섹션 표시 지움 · ★였으면 기존 완료 규칙대로(★ 꺼짐, 되살릴 때 복원) |
| **DONE** → TODO/사용자 섹션 | 본 항목 되살림(★ 복원) + **그 본 항목과 같은 시각에 함께 완료됐던 세부 항목만** 되살림(따로 먼저 끝낸 세부는 완료 유지) |
| TODO ↔ 사용자 섹션, 사용자 ↔ 사용자 | `kanban_section_id`만 바꿈(완료·★·세부 항목 변화 없음) |
- 놓으면 알림 `"… → DONE"` + **[되돌리기]**(이전 섹션·세부 항목 상태까지 복원). 실행 취소 대상.
- 끌기: 끄는 동안 원래 자리 흐리게, 놓을 열에 점선 자리 표시(+ DONE이면 "세부 항목 n개도 함께 완료"), `Esc` 취소. 같은 열 안에서 놓으면 변화 없음.
- 키보드: 카드 메뉴 "섹션 이동", `Alt+Shift+←/→` = 옆 섹션으로.

### 3-3. 중요 업무·주간 보드와의 관계
- **TODO/DONE ↔ 중요 업무 패널·주간 보드는 양방향 동기화**(같은 데이터): 주간 보드에서 완료 = DONE, 패널에서 체크 = DONE, 칸반에서 DONE = 주간 보드 완료 표시.
- **사용자 섹션은 칸반에서만**:
  - 주간 보드에는 그 항목이 **보통의 미완료 항목으로 그대로 보인다**(기록이므로 숨기지 않음). 섹션 이름·표시는 나타내지 않는다.
  - 사용자 섹션에 있는 동안 ★ 항목은 **중요 업무 패널·레일 배지에서 빠진다**(★ 자체는 유지 — TODO로 돌아오면 다시 나옴). — 결정 D3
  - 주간 보드에서 그 항목을 완료하면 DONE(섹션 표시 지움).
- **세부 항목 자동 완료**는 칸반에서 DONE으로 옮길 때 적용. 주간 보드·패널에서 본 항목을 완료할 때도 같은 규칙으로 맞출지 — 결정 D4(추천: 맞춤 — 어디서 끝내든 결과가 같아야 함).

### 3-4. 사용자 섹션 관리 (시안 ⑤)
- [섹션 추가]: 이름(1~20자, 중복 불가). 색은 고르지 않음 — **무채색 두 가지 고정**(TODO·사용자 섹션 = 같은 회색, DONE = 진한 회색 — 2026-11-12 사용자 지시, D10 변경). TODO와 DONE 사이 맨 뒤에 생김. **최대 8개**.
- 열 ⋯: 이름 바꾸기 · 왼쪽/오른쪽으로 · 이 섹션 카드 모두 TODO로 · **섹션 삭제**.
- 삭제: 확인 창(카드 수 표시, 처음 초점 [취소]) → 카드는 지우지 않고 **TODO로** 돌려보냄(이력에 기록).

## 4. 상태 변경 이력 (시안 ②)
- 상태(섹션)가 바뀔 때마다 한 줄: **일시(UTC 저장·내 PC 시각 표시) · 이전 섹션 · 이후 섹션 · 바꾼 곳**(칸반 / 주간 보드 / 중요 업무 / 일괄 처리 / 섹션 삭제 / 가져오기).
- 섹션 이름은 **그때 이름을 함께 저장**(나중에 섹션을 지우거나 이름을 바꿔도 이력이 읽힘).
- 보는 곳: 카드 메뉴 [상태 이력 보기] 팝오버, 카드 꼬리표 `10/14부터 이 섹션`, DONE 카드의 완료 시각.
- 구조 v20으로 올릴 때 **이미 완료된 항목은 `TODO → DONE` 이력 한 줄을 완료 시각으로 채워 넣는다**(이전 기록과 이어지게).
- 항목을 지우면 그 이력도 함께 지워진다(항목 삭제 되돌리기 때 함께 복원).
- 범위: 본 항목 기준. 세부 항목의 개별 완료는 기존 완료 시각만(이력 줄 없음) — 단, 본 항목과 함께 자동 완료된 것은 본 항목 이력에 "세부 n개 포함"으로 남김.

## 5. 업무 항목 추가·편집 (시안 ③)
- **[＋ 업무 항목 추가]**(상단) · 열 맨 위 [＋ 카드 추가](그 섹션이 미리 선택됨) · 단축키 `N`(칸반에서 카드·입력에 초점이 없을 때).
- 레이어 창(모달 `<dialog>` — 1.24.2의 최상위 레이어 방식):
  - **업무**(필수, 진행 중 업무 목록 — 업무 필터가 하나면 그 업무가 기본)
  - **날짜**(기본 **오늘**, 달력·[오늘][내일][다음 주 월])
  - **섹션**(TODO 기본 / 사용자 섹션 — DONE은 고를 수 없음)
  - **내용** = 주간 보드와 **같은 입력기**: Enter 다음 항목 · Tab 세부 · Shift+Tab 본 항목, ★(Alt+I) · ⏳ 마감일(Alt+U) · ⏰ 시작 시각(Alt+O) · ↻ 매주 반복(Alt+R) · ⋯ 메뉴(연결된 메모 만들기·태그 등). 본 항목을 여러 개 쓰면 카드도 여러 장.
  - [추가] · [추가하고 계속](업무·날짜 유지) · [취소]/Esc(쓴 내용이 있으면 확인).
- 저장 = 그 날·그 업무 칸의 **맨 끝에 덧붙임**(주간 보드에 바로 보임). 구현은 `CellEditor`를 임시 칸에 연결해 재사용 — 주간 보드와 동작이 갈라지지 않게 한다.
- **편집**: 카드 두 번 누르기 → 같은 창(업무·날짜는 [다른 날로 옮기기]로만 바꿈), 글·세부 항목·표시를 고침.
- 카드 메뉴(시안 ②): 편집 · 주간 보드에서 보기 · ★ · ⏳ · ⏰ · ↻ · 다른 날로 옮기기 · 날짜로 복제 · 섹션 이동 · 상태 이력 · 삭제(되돌리기).

## 7. Cabi.NET 요소와 끌어 놓기
주간 보드의 항목 행이 받는/보내는 끌기와 **같은 형식·같은 처리**를 카드에 붙인다(새 규칙 없음).
| 방향 | 동작 |
|---|---|
| Cabi.NET의 폴더·링크·노트 줄 → 카드 | 그 항목에 연결(주간 보드 행에 놓는 것과 같음), 꼬리표 🗄 수 갱신 |
| 카드 → 업무 메모보드·주간 메모 보드(상자/빈 곳) | 연결된 메모 만들기/연결 더하기(행을 끄는 것과 같음) |
| 카드 → Cabi.NET 창(업무 연결) | 주간 보드 행과 같은 처리 |
- 카드 끌기 하나가 "섹션 이동"과 "다른 창에 놓기"를 겸한다 — 칸반 열에 놓으면 상태 변경, 메모·Cabi 창에 놓으면 연결.
- 구현 때 주간 보드 행 끌기 코드(`rowDrag.ts`·`CabiDrag`)의 형식을 그대로 쓰고, 지원 항목은 확인표에 주간 보드와 1:1로 대조한다.
- **`1.25.0-rc.1` 구현 범위: 첫 줄(Cabi.NET 줄 → 카드)만** — 카드 → 메모 보드·Cabi.NET 창은 넣지 않음(이유·후속안 14절).

## 8. 설정
- 설정 › 화면에 **시작 화면**: `주간 보드`(기본) / `칸반 보드`. 주간 보드 = 마지막에 본 주간/데일리 뷰 그대로.
- 일지 설정 `ui.startView: "board" | "kanban"`, `ui.kanban: { categories, includeEnded, period, from, to, sort }`.

## 9. 타임라인 개선 (시안 ⑥)
- **T1 요일별 묶음**: 주 안에서 날짜마다 왼쪽에 `요일 + 월/일`을 **한 번만** 쓰고 그날의 본 항목·세부 항목을 그 아래 묶는다. 묶음 사이 옅은 점선. 기록 없는 요일은 나오지 않음(지금과 같음). 검색 강조·키보드 이동(↑↓)·경과 복사 글은 그대로(복사 글의 요일 표기도 묶음 형식으로).

  - 일괄 완료를 "기록일에 끝낸 것으로" 처리한 항목은 같은 날이므로 칩이 없다.
