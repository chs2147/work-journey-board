## 1. P2-1 시그니처 모드를 처음 설치 기본값으로

| 경우 | 지금 | 바꾼 뒤 |
|---|---|---|
| 처음 설치(설정 파일 없음, 화면 사본 `wjb.theme` 없음) | 시스템 설정 | **시그니처** — 첫 실행 화면부터 시그니처, 첫 일지를 만들 때 `config.json` `theme: "signature"`로 저장 |
| 이미 쓰던 사용자(직접 고른 적 없음) | 시스템 설정 | **그대로 시스템 설정**(업데이트로 화면이 갑자기 바뀌지 않게) — 저장된 사본 `wjb.theme`가 있으므로 구분된다 |
| 이미 쓰던 사용자(직접 고름) | 고른 값 | 그대로 |

- 구현: `public/theme-early.js`·`src/shared/theme.ts` `readStoredTheme()`의 "사본 없음" 기본값을 `signature`로(두 곳 같은 규칙, `theme.test.ts`가 대조). 시작 창(`splash.html`)도 같은 스크립트라 처음부터 시그니처.
- `adoptTheme(config?.theme ?? readStoredTheme())`는 그대로 — 기존 사용자는 사본이 `system`이라 바뀌지 않는다.
- 브라우저 모드·E2E: 테스트는 대부분 `wjb.theme` 없이 시작하므로 기본이 시그니처가 된다 → 라이트를 전제로 한 화면 비교 E2E는 `?theme=light` 또는 사본 지정으로 고정(영향 테스트 목록은 구현 때 정리).

## 4. P2-4 정식 판 배포(1.0.0)와 오프라인판

- **정식 판 표시**: `1.0.0` 이상이고 `-rc` 같은 꼬리표가 없는 판은 GitHub 릴리스를 **사전 릴리스가 아닌 정식("Latest")** 으로 올린다(`build-windows.yml` `prerelease:` 조건). 새 판 확인(update.rs)은 사전·정식을 모두 보므로 동작 변화 없음.
- **오프라인판 함께 배포**: 정식 판(위 조건) main 빌드는 기본판 + **오프라인판(WebView2 포함, +약 130MB)** 을 함께 만들어 같은 릴리스에 올리고, `SHA256SUMS.txt`에 둘 다 적는다. 사전 판(0.x·rc)은 지금처럼 기본판만, 오프라인판은 수동 실행.
  - CLAUDE.md 6절 "오프라인판은 빌드할 때마다 먼저 확인" 규칙은 **정식 판만 자동 포함**으로 바꾼다(이번 요청이 그 승인 — 확정 시 문서 갱신).
  - 새 판 확인·설치(update.rs)는 계속 기본판을 받는다(오프라인판은 인터넷이 막힌 PC용 수동 설치).
- 릴리스 본문 설치 파일 표: 기본판/오프라인판 용도·크기 안내(이미 틀 있음).
- 회사 PC 확인: 오프라인판을 WebView2가 있는 PC에 덮어 설치해도 정상인지 1회.
