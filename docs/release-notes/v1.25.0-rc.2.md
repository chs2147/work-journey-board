# 칸반 보드 다듬기 — 기간 아이콘·단추 통일·섹션 무채색 (검증용)

## 고친 점
- **기간 필터 = 아이콘**: 글자 단추 7개를 달력 아이콘으로 바꿨습니다 — ■ 오늘 · ━ 이번 주(기본) · 2·4·12 최근 n주 · ∞ 전체 · [ ] 지정일. 마우스를 올리면 이름과 실제 날짜 범위가 보이고, 짧은 기간 | 긴 기간 | 전체·지정일 사이에 구분선이 있습니다.
- **오른쪽 위 단추**: [업무 항목 추가]·[섹션 추가]를 주간 보드 상단 단추와 같은 아이콘 + 글자 단추로 맞췄습니다(채움 색 강조 없음).
- **섹션 색 = 무채색 두 가지**: 업무 색과 헷갈리지 않게 TODO·사용자 섹션은 모두 같은 회색, DONE만 진한 회색으로 고정합니다(라이트·다크·시그니처 테마마다 맞춤). 섹션 색 고르기는 없앴습니다 — 이미 만든 섹션도 같은 회색으로 보입니다.

## 주의
- 데이터 형식: **구조 v20 유지**(1.25.0-rc.1에서 올린 일지 그대로 열림). 1.24 이하에서 처음 올리는 일지는 rc.1과 같이 `_pre-migration-v20` 백업 뒤 v19 → v20.
- 외부 통신·새 의존성 변화 없음. 검증용 판입니다. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.
