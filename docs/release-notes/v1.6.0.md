# macOS 판 — 윈도우와 같은 판·같은 기능

## 새 기능
- **macOS 앱**: 같은 판 번호로 윈도우와 함께 나옵니다. `WorkJourneyBoard_1.6.0_mac.dmg`(macOS 13 이상, 인텔·애플 실리콘 공용)를 열어 앱을 응용 프로그램 폴더로 끌어 놓으면 설치됩니다.
- 맥에서는 한국어 메뉴 막대(설정 `⌘,` · 보기 · 도움말 › 빠른 이용 가이드), 화면 안내의 단축키·낱말이 맥 표기(`⌘`·`⌥`·`⇧`, Finder, macOS 설정)로 보입니다. 키 동작은 윈도우와 같습니다(`Ctrl` 자리에 `⌘`, `Alt` 자리에 `⌥`).
- Cabinet: Finder 폴더·가상본을 끌어 놓아 등록, [Finder에서 보기], Finder 숨긴 파일은 감춤.
- 맥에서도 앱 안에서 새 판을 받아 설치합니다(SHA256 확인 → 일지 자동 백업 → 앱 교체 → 다시 열기).
- OneDrive 말고도 iCloud Drive·Google Drive·Dropbox 같은 동기화 폴더를 저장 위치로 고르면 안내합니다(맥).
- 진단 정보에 OS 줄.

## 고친 점
- 메모 보드 [그림으로 복사]를 누른 즉시 클립보드 항목을 만들도록 — 맥(WebKit)에서 거부되던 것을 막고, 윈도우도 같게 동작합니다.

## 주의
- 데이터 형식: 변경 없음 — 윈도우에서 쓰던 `work-journey.db`를 맥에서 그대로 열 수 있습니다(Cabinet의 윈도우 폴더 경로는 맥에서 ⚠ 표시 → 경로 다시 지정).
- 외부 통신: 변화 없음(새 판 확인·내려받기만 GitHub, 맥도 같은 주소)
- 맥 첫 실행: 애플 개발자 서명이 없는 앱이라 처음 열 때 "확인되지 않은 개발자" 안내가 나옵니다 — 시스템 설정 › 개인정보 보호 및 보안 › **그래도 열기**를 한 번 누르세요(앱 안에서 받은 새 판은 다시 묻지 않음).
- 맥에서 Dock 메뉴나 로그아웃으로 끝내면 종료 백업이 생략될 수 있습니다(기록은 입력 즉시 저장, 다음 실행 때 일일 백업). `⌘Q`·메뉴 › 종료는 종료 백업까지 합니다.
- 윈도우 판: 화면·동작 변화 없음.
