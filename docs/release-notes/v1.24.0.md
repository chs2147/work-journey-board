# 업무노트 삭제 잠금·복제·표 편집 개선 · 새 판 확인 403 대응

## 새 기능
- **업무노트 삭제 잠금**: 편집 화면 저장 표시 옆 자물쇠 단추. 잠그면 편집 화면 메뉴의 [노트 삭제]가 흐려지고, 목록에서는 🗑 대신 🔒가 보입니다. 잠금은 삭제만 막고 편집·내보내기·업무 옮기기는 그대로이며, 푸는 곳은 편집 화면 한 곳입니다.
- **업무노트 삭제 최종 확인 창**: 노트 제목·업무·마지막 저장 시각·이미지 수·이 노트를 가리키는 연결 수를 보여 줍니다. 처음 초점은 [취소](Enter를 눌러도 지워지지 않음).
- **업무노트 복제**: 목록 줄의 ⧉(편집 화면 메뉴에도). 같은 업무에 "(사본)" 노트가 생기고 이미지는 새로 복사됩니다. 원본의 연결·삭제 잠금은 옮기지 않습니다.

## 고친 점
- **끌기 손잡이 아이콘 통일**: 복사 모양과 헷갈리던 끌기 손잡이를 점 6개(⠿)로 — Cabi.NET 목록(노트·폴더·링크)·업무 보드 자료 서랍·노트 블록. 보드 객체를 다른 보드로 끌어 복제하는 손잡이는 ⠿+. 복사 모양(⧉)은 복제 단추에만 씁니다.
- **노트 표**:
  - 표 손잡이(⠿, 표 바깥 왼쪽 위)·행 이끌이(⋮, 왼쪽 테두리)·열 이끌이(⋯, 위 테두리)를 나눠 겹치지 않게 — 표 손잡이로 **표 전체를 다른 줄로** 끌어 옮깁니다(끄는 동안 원래 표는 반투명).
  - 행/열을 끄는 동안 옮기는 행/열을 연하게 칠하고 **들어갈 경계에 선**을 그립니다. 칸의 위/아래(왼/오른) 절반으로 앞/뒤를 정해 선과 결과가 같고, `Esc`로 취소, 놓은 뒤 잠깐 강조합니다.
  - 열 경계 위에서 커서가 글자 커서가 아니라 **↔(열 너비 조절)** 로 바뀝니다.
- **새 판 확인 403**: 판 목록을 ETag로 물어 바뀐 게 없으면 GitHub 확인 한도를 쓰지 않습니다. 실패하면 "한도 초과 — 약 N분 뒤"와 "회사망 차단"을 구분해 안내하고 [릴리스 페이지 열기](기본 브라우저)를 둡니다. 한도 초과일 때는 `github.com/…/releases/latest` 한 주소에서 최신 정식 판 번호만 읽어 새 판을 알려 줍니다(설치는 지금처럼 SHA256 확인을 통과해야 함).
