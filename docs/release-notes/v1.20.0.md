# Cabi.NET 업무 노트·메모보드 개편

## 새 기능
- Cabinet 표시명을 Cabi.NET으로 변경하고 업무별 자료·노트·보드 허브를 제공한다. 기존 폴더·링크와 업무/업무항목 연결은 유지한다.
- 업무 하나에 여러 노트를 작성하고 별도 모달리스 창에서 블록 단위로 편집한다. 제목·목록·체크·표·코드·이미지·링크·글자색, 자동 저장·충돌 감지를 제공한다.
- Markdown 파일의 블록 구조를 가져오고 Markdown/이미지 묶음과 한글 PDF로 내보낸다. 함께 선택한 상대 경로 이미지는 노트 자산으로 가져오며 base64 콘텐츠와 실행 HTML·외부 이미지 자동 다운로드는 제외한다.
- 업무당 하나의 자유 메모보드를 별도 창에서 제공한다. 기존 보드 엔진의 메모·이미지·링크·관계선·다중 선택·Undo·줌·스냅샷을 재사용하고, 폴더/링크/노트 원본 참조 카드를 배치한다.
- 해당 업무항목에 연결된 누적 주간 메모를 전체 기간에서 찾아 원본 연결 또는 독립 사본으로 추가한다.
- 선택 객체의 복제 아이콘을 다른 보드 창으로 끌어 놓거나 객체 복사/붙여넣기로 주간↔업무 보드에 복제한다. 원본은 유지하고 이미지 자산과 내부 관계선은 사본에 보존한다.
- 노트·보드를 전역 검색에 추가하고 워크스페이스 전환/종료 전 별도 창의 저장을 확인한다. 업무 보드의 업무항목 연결도 날짜 복제·삭제 취소에 보존한다.

## 주의
- Windows 기본 설치판과 macOS 유니버설 DMG를 함께 제공한다. 기존 1.19.0 소스는 `release/v1.19.0` 브랜치에 보존한다. 네이티브 빌드·Rust 검사 통과와 실제 OS 환경의 설치·창 간 드래그 실기 확인은 구분한다.
- 데이터 구조: DB v15 → **v16**. 직전 자동 백업 후 전진 마이그레이션한다. 예전 앱은 새 구조를 열 수 없으므로 원복은 마이그레이션 전 백업을 사용한다.
- '업무'는 기존 업무 분류이며 날짜별 업무항목이 아니다. 업무가 종료되어도 노트·보드를 보존한다.
- 원본 연결 카드는 원본을 가리키며, 보드 간 복제는 독립 사본이다. 날짜별 업무항목 연결은 사본에 자동 추가하지 않는다. 관계선은 함께 선택한 객체 사이의 것만 복제한다.
- 노트의 글자색은 일반 Markdown 형식에 포함되지 않는다. 가져오지 못한 이미지는 대체 텍스트로 남긴다.
