# Universe 3D 탐색과 조절 가능한 패널

## 새 기능
- 다이나믹 3D 지도: 드래그 회전, Shift+드래그 이동, 휠 확대·축소와 은하↔초점 카메라 전환.
- 지도는 앱 테마와 별개의 어두운 배경이며 정적 2D도 선택할 수 있습니다. 3D 미지원 또는 모션 감소 설정 시 정적 모드를 제공합니다.
- 필터·상세 패널은 기본 접힘, 필요할 때 독립적으로 펼칩니다. 좁은 창에서는 한 번에 하나씩 표시합니다.

## 고친 점
- 필터·상세 패널은 가장자리 드래그·방향키로 너비 조절, 더블클릭 기본 너비 복원을 지원하며 이 PC 설정에 저장합니다.
- 설정 서브메뉴 영역을 넓혀 부연 설명을 한 줄로 표시합니다. 좁은 창에서는 설명이 있는 가로 탭을 제공합니다.
- 3D/2D·초점/은하·지도/목록 전환을 모노그램 아이콘으로 통일했습니다. 이름은 툴팁과 접근성 이름으로 제공합니다.
- Universe에서 중요 업무 패널이 지도를 가리지 않도록 정리했습니다.

## 주의
- 사용자 RC 빌드 설치·확인 완료 후 정식 반영했습니다. 대규모 그래프 성능 목표는 기기별 추가 확인 대상입니다.
- 데이터 구조 v13 유지. 일지 형식 변경은 없습니다. 표현 취향만 기존 앱 설정 파일에 저장합니다.
- 외부 통신 범위 변경 없음. Three.js는 로컬 WebGL 렌더링에만 사용하며 CDN·원격 로더를 사용하지 않습니다.
- Windows 기본 설치판과 macOS 유니버설 DMG를 함께 빌드합니다. Windows 오프라인판은 포함하지 않습니다.
