# 표 행·열 이동 실행 취소 경계 수정

## 수정
- 표 생성·열 너비 조절 직후 빠르게 행/열을 옮기면 실행 취소 시 표 전체가 사라질 수 있던 오류를 수정한다.
- 이동을 한 단계로 실행 취소/다시 실행하고, 다음 입력도 별도 이력으로 처리한다. 시간 간격을 강제한 단위 회귀 검사를 추가한다.

## 주의
- main CI 42585959844의 Chromium 실패/WebKit 재시도 로그를 바탕으로 수정했다. 검사 대기시간을 늘리거나 검사를 비활성화하지 않았다.
- DB18·외부 통신·기존 저장 데이터/화면 배치 변경 없음. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드한다.

## 가이드
- 장면11: 표 행열 이동의 실행 취소 안내 갱신. 시각적 UI 변경이 없어 기존 스크린샷 유지.
