# 메모 다중 이동·인사이트 개선 검증판

## 개선
- 사각 선택한 텍스트·이미지·링크 카드의 본문 어디든 드래그하면 선택 전체가 함께 이동합니다. 직각 점선 외곽과 선택 개수·보조 이동 버튼을 제공합니다.
- 선택 객체 클릭은 그룹을 유지하고 더블클릭은 개별 편집/보기로 전환합니다. Esc·취소·주/공간 전환 시 임시 이동을 원복하며 확정한 이동은 한 번에 되돌립니다.
- 인사이트 탭을 아이콘이 붙은 **업무 타임라인 / 활동**으로 통일했습니다. 경과 지도를 항상 표시하고 표 보기·기록 펼치기를 모노그램 아이콘으로 제공합니다.
- 타임라인을 **년/월 → 주차 → 상세 업무** 위계로 정리하고 월 아래·주차 사이 구분선을 추가했습니다.
- 활동 격자는 창의 가용 폭을 채우고 좁은 창에서는 카드 내부에서만 가로 스크롤합니다.

## 주의
- RC 검증판입니다. Windows 기본 설치판과 macOS 유니버설 DMG를 함께 제공합니다.
- 일지 DB 구조는 v14로 유지하며 추가 마이그레이션은 없습니다.
- 다중 선택에서는 더블클릭으로 개별 편집에 들어갑니다. 개별 크기 조절·관계선 연결점은 다중 선택 해제 후 사용합니다.
