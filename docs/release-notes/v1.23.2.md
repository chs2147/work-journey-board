# Cabi.NET 목록 정렬·업무 노트 표 편집 개선

## 개선
- 목록의 노트 아이콘/본문 시작선과 폴더·링크 정렬을 통일한다.
- 표 열 경계 드래그로 너비를 조절하고 행/열 손잡이를 드래그해 순서를 바꾼다. 변경은 자동 저장되며 편집기의 실행 취소를 사용한다.
- 표 손잡이 메뉴 바깥 클릭 시 닫기와 블록 메뉴 내부 스크롤 유지 동작을 제공한다.

## 주의
- 사용자 요청으로 main에 직접 반영. DB18 유지, 외부 통신/저장 형식 변경 없음.
- V2 설계/PoC는 v2-design에 보존하며 이번 패치에는 포함하지 않는다.
- Windows 기본판·macOS 유니버설 DMG를 함께 빌드한다. 실제 설치/릴리스 결과는 Actions에서 별도 확인한다.

- 로컬 검증: 단위525개·표/메뉴/정렬 및 기존 캐비넷 회귀11개 통과. 타입·lint·형식·프로덕션 빌드 확인.

## 가이드
- 장면11: 표 열 너비·행열 손잡이 이동·메뉴 동작과 노트 목록 정렬 안내 갱신.
