# Universe 초기 탐색 모드 유지

## 고친 점
- 3D 카메라 초기화·복원 중 넓은 시야를 자동 축소로 해석해 은하로 바뀔 수 있던 문제를 수정했습니다. 자동 모드 전환은 실제 휠·줌 버튼 입력이 있을 때만 수행합니다.
- Universe 회귀 검사는 화면 열림을 기다린 뒤 정적 모드를 선택하도록 정리하고, 라이선스 표의 Three.js 고지를 확인합니다.

## 주의
- 데이터 구조·외부 통신 범위 변경 없음. Windows 기본판과 macOS DMG를 함께 제공합니다.

## 가이드
- 기능·조작법 변경 없음. 기준 판·HTML·PDF를 1.15.1로 갱신했습니다.
