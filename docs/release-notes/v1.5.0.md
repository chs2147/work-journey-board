# 열 폭 조절·Cabinet 다듬기 2·메모 여러 상자 함께 옮기기

## 새 기능
- **주간 뷰 열 폭 조절**: 업무 열·요일 열 머리 오른쪽 끝을 끌어 폭을 바꿉니다. 요일마다 따로 기억하고 주를 넘겨도 그대로, 두 번 누르면 자동 폭으로 돌아갑니다.
- **메모 보드 여러 상자 함께**: 빈 곳을 끌면 선택 사각형 — 걸친 상자를 함께 골라 한꺼번에 옮깁니다(방향키·`Delete`도 함께, `Ctrl+Z` 한 번에 되돌리기, `Esc` 해제, `Shift`+상자 머리로 더하기/빼기).
- **Cabinet 폴더 확인**: [폴더 확인](Cabinet을 열 때도 자동)으로 이름이 바뀌거나 옮겨진 등록 폴더를 ⚠ 찾을 수 없음으로 알려 주고, ⋯ › 경로 다시 지정으로 연결은 그대로 경로만 바꿉니다.
- **Cabinet 폴더 창 새로 고침**: [새로 고침]·`F5`, 열려 있는 동안에는 탐색기에서 바꾼 내용이 몇 초 안에 저절로 반영됩니다.
- **Cabinet 목록 다듬기**: 폴더 줄에 [탐색기에서 열기] 단추, 업무 목록과 폴더·링크 목록 사이 구분선을 끌어 폭 조절.

## 고친 점
- 일부 폴더가 Cabinet에 끌어 놓아도 들어가지 않던 것 — 폴더 **바로 가기(.lnk)**는 가리키는 폴더로 등록하고, 긴 경로 표기도 받으며, 안 되는 경우에는 무엇이 왜 안 되는지(압축 파일·파일·찾을 수 없는 경로) 이름과 함께 알려 줍니다.
- 업무 항목 끌기 손잡이(⋮⋮)를 크고 또렷하게.
