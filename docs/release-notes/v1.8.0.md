# 워크스페이스 — 회사·개인 기록을 따로

## 새 기능
- **워크스페이스**: 회사 업무와 개인 생활·공부처럼 기록을 완전히 따로 두는 공간을 여러 개 만들 수 있습니다. 공간마다 폴더와 일지 파일이 따로라 서로 섞이지 않습니다.
- 왼쪽 레일 맨 위 **공간 단추**(색 사각형 + 모노그램 아이콘)로 목록을 열어 전환 — `Ctrl+Alt+1`~`9`(맥 `⌘⌥1`~`9`) = n번째 공간, `Ctrl+Alt+0` = 목록.
- **새 워크스페이스 4단계**: 이름·색·아이콘·용도 → 저장 위치(지금 공간 폴더 옆 추천) → 첫 업무(용도별 추천) → 지금 공간에서 휴일·태그·무기록 알림 설정 가져오기. 새 워크스페이스는 **늘 새 일지 파일**로 만들고(이미 일지가 있는 폴더를 고르면 그 안에 새 폴더), 만들 파일 경로를 미리 보여 줍니다.
- 아이콘은 생산성 도구 이모지 28개를 한 색 선 그림(모노그램)으로 — 색과 따로 바꿀 수 있습니다.
- 설정 › **워크스페이스**: 이름·색·아이콘, 순서(= 단축키 순서), 폴더 열기, 기존 폴더 추가, 목록에서 빼기(폴더·파일은 그대로).
- 지금 공간 표시: 레일 왼쪽 색 띠 · 상단 공간 이름 · 창 제목 `Work Journey Board — 개인`(공간이 둘 이상일 때).

## 바뀐 점
- 업데이트 직전 백업을 이 PC에 등록된 모든 공간에 한 부씩 남깁니다.
- 공간이 둘 이상이면 내보낸 엑셀·마크다운·메모 그림 파일 이름에 공간 이름이 붙습니다(`업무일지_개인_2026-W45.xlsx`).
- 보조 백업 위치는 새로 만든 공간마다 그 아래 하위 폴더에 남습니다.
- 이 PC 설정을 하나씩 차례로 저장합니다(동시에 저장해도 값이 지워지지 않게).
