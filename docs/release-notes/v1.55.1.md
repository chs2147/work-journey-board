# Open Beta — 메모 글 상자 크기 조절점·관계선 끝점 보완, 내보내기 진행 막대·취소

## 수정
- **글 상자 크기 조절점 되살림**: 1.55.0에서 빠졌던 위·아래·모서리 손잡이가 돌아왔습니다(여덟 개). 옆면 손잡이(◀▶)는 너비만 바꾸고 높이는 글에 맞추며, 위·아래·모서리 손잡이로 정한 높이만 그대로 둡니다(넘치면 상자 안 스크롤). 정한 높이는 상자 ⋯ › **[높이를 글에 맞춤]**으로 풉니다. 예전 판에서 너비만 바꿀 때 고정된 높이는 계속 쓰지 않아 아래 빈칸은 다시 생기지 않습니다.
- **관계선과 상자 사이가 뜨던 문제**: 예전에 높이가 고정됐던 글 상자에 관계선을 이으면 선이 상자 아래보다 밑에서 시작했습니다. 이제 글 상자의 실제 높이를 다시 재어 선이 늘 상자 끝에 붙습니다.

## 개선
- **내보내기 진행 막대**: [저장 위치 선택…] 뒤 진행 막대와 단계(기록 읽는 중 · 메모 그림 만드는 중 · 파일 만드는 중 · 저장하는 중)·%가 보입니다.
- **진행 중 잠금**: 내보내는 동안 창 안 다른 조작과 앱 단축키가 막힙니다.
- **취소**: [취소] 또는 `Esc`로 멈추면 파일을 만들지 않고 창은 그대로 남습니다(파일을 쓰기 시작한 뒤에는 끝까지 씁니다).

## 주의
- **1.55.1도 Open Beta입니다.** 일지 구조 **v20 유지**(노트 문서에 선택 값 `heightSet` 추가 — 예전 판은 이 값을 무시하고 읽음), 새 의존성 없음, 외부 통신 · 운영 서버 변경 없음.
- 이전 main 1.55.0은 `release/v1.55.0` 브랜치에 보존했습니다. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 설치 후 확인
- 글 상자를 골라 손잡이 여덟 개가 보이는지, 옆면으로 넓혀도 아래가 비지 않는지, 아래 손잡이로 늘린 높이가 남고 ⋯ [높이를 글에 맞춤]으로 풀리는지.
- 예전에 아래가 비었던 글 상자에 관계선을 이을 때 선이 상자 끝에 붙는지.
- 메모 그림이 많은 범위로 엑셀을 내보낼 때 진행 막대가 움직이고, [취소]로 멈추면 파일이 생기지 않는지.
