# 메모 보드 스냅샷

## 새 기능
- 메모 머리에 [스냅샷](카메라) 단추가 생겼습니다. [PNG 그림으로 저장…]을 누르면 메모 보드 전체(화면 밖 상자 포함)를 그림 한 장으로 저장합니다. 늘 밝은 테마, 선명한 2배 해상도입니다.
- [그림으로 복사]를 누르면 같은 그림이 클립보드에 들어가 메일·문서에 바로 붙여 넣을 수 있습니다.
- 그림에는 글 서식·목록·체크·이미지·링크 카드·업무 연결 띠·관계선이 들어가고, 손잡이·메뉴·미니맵은 빠집니다.
- 엑셀 내보내기의 [포함]에 "메모 보드 스냅샷"이 생겼습니다. 켜면 "메모 보드" 시트에 메모가 있는 주마다 제목과 그림이 들어갑니다(기본 꺼짐, 마지막 선택을 기억).

## 고친 점
- 메모 연결 띠에서 지워진 항목 줄이 맨 위로 가던 문제(이제 맨 아래)

## 주의
- 데이터 형식: 변경 없음
- 되돌려 설치: 안전(0.2.16으로 되돌리면 스냅샷 단추·엑셀 선택만 사라짐)
- 외부 통신: 없음(그림은 앱 안에서 만들고, 고른 위치에만 저장)
- 그림이 들어간 엑셀은 파일이 커질 수 있습니다(주당 약 0.2~1MB).

## 설치 후 확인
- 회사 PC 확인표 7-17 (5항목, 약 5분)
