# 직선 색상 띠와 업무·메모 입력 개선

## 새 기능
- 상단 **업무 추가** 버튼에서 업무명과 기존/신규 태그를 함께 입력하는 팝업을 제공합니다. 취소하면 업무·태그가 남지 않습니다.
- 메모 텍스트의 글자색을 팔레트에서 선택하고 기본색으로 복원할 수 있습니다.
- Markdown 파일을 메모보드에 놓으면 순수 텍스트 메모를 만듭니다. URL은 클릭 가능한 링크로 유지하고 이미지·base64 등 첨부 콘텐츠는 제외합니다.

## 고친 점
- 데일리 업무 카드·중요 업무·메뉴 선택 표시 등 앱 전체 세로 색상 띠의 휘어진 끝을 직선으로 통일했습니다.
- 마감일 묶음의 개수를 없애고 D-day를 임박도별 컬러칩으로 표시합니다. 날짜·정렬·업무 이동은 유지합니다.
- 업무 추가·주간 요약·내보내기를 아이콘과 함께 상단에 배치하고, 주간 업무와 메모보드 사이의 불필요한 빈 줄을 제거했습니다.
- 첫 업무 생성 후 입력 포커스가 이탈하던 문제와 미니맵 조작 후 Space 패닝이 막히던 문제를 수정했습니다.

## 주의
- 데이터 형식: 구조 v13 유지. 기존 일지 마이그레이션은 없습니다.
- Markdown 원본 파일은 변경하지 않습니다. 텍스트와 링크만 가져오며 이미지·첨부는 새 메모에 포함하지 않습니다.
- 외부 통신: 범위 변경 없음. 새 Markdown 파서는 앱 안에서 텍스트만 분석합니다.
- Windows/macOS 설치 앱의 실제 파일 드롭·입력은 각 운영체제에서 확인이 필요합니다(확인표 7-42).
