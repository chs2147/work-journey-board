# 칸반 섹션 순서·아이콘 · 중요 목록 · 카드 추가 창 · 타임라인 구분선 (검증용)

## 새 기능
- **섹션 순서 자유**: TODO·DONE을 포함해 모든 섹션 머리를 끌어 원하는 자리에 놓습니다(세로 표시선·알림 [되돌리기]). 섹션 ⋯ [왼쪽으로]/[오른쪽으로], 머리에 초점을 두고 `Alt+Shift+←`/`→`도 같습니다. 공간마다 기억합니다.
- **섹션 아이콘**: 섹션 머리마다 색 아이콘. 섹션 이름("검토 중"·"보류"·"배포"…)에 맞춰 먼저 골라지고, 아이콘을 누르거나 ⋯ [아이콘 바꾸기]로 36가지 중에서 바꿉니다(TODO·DONE도, [기본 아이콘]으로 되돌리기).
- **카드 ⋯ [↻ 매주 반복 켜기/끄기]**: 카드에서 바로 매주 반복을 켜고 끕니다. 카드에서 `Alt+R`도 같습니다.

## 고친 점
- 사용자 섹션(예: 검토 중)으로 옮긴 ★ 항목이 중요 업무 목록에서 사라지던 문제 — DONE이 아니면 모두 보이고, 줄에 섹션 이름 칩이 붙습니다.
- 자유 배치에서 [섹션 추가]한 상자가 화면 밖에 놓여 보이지 않던 문제 — 지금 보이는 빈자리(없으면 맨 아래)에 놓고 그 자리로 움직여 잠깐 강조합니다.
- 카드를 끌어 DONE에 놓아도 축하 모션이 보이지 않던 문제 — 놓은 자리에서 바로, 모든 창·패널 위 레이어에 그립니다. 메뉴·키보드·중요 목록 ✓로 완료하면 DONE 머리에서.
- 상단 순서를 배치 모드 → [업무 추가] → [섹션 추가]로, 균등 배치 오른쪽 끝의 섹션 추가 단추는 없앴습니다.
- 카드 추가 창: 본 항목이 두 줄 이상이면 줄마다 "카드 1"·"카드 2"(들여쓴 줄은 "세부"), 단추 [카드 N장 추가]. 시작 시간·마감일 옆 설명 글과 매주 반복 체크는 없앴습니다(매주 반복은 카드 ⋯로).
- 섹션 추가 창 아래 아이콘 설명 글 없이 아이콘 칸만.
- 업무 타임라인: 요일 묶음 위아래에 가는 구분선.

## 주의
- 데이터 형식 변경 없음(구조 v20 유지). 섹션 순서·아이콘은 일지 설정(`ui.kanbanColumns`)에 저장합니다.
- 섹션 아이콘 그림은 Microsoft Fluent Emoji Flat(MIT) — 개발용 의존성 `@iconify-json/fluent-emoji-flat`(버전 고정)에서 생성 도구로 앱 안에 넣었습니다. 실행 중 외부 통신 없음, 런타임 의존성 변화 없음. 라이선스는 정보 › 오픈소스 라이선스.
- 검증용 판입니다(정식 릴리스 전 실기 확인). Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.
