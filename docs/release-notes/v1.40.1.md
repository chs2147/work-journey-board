# 앱 닫기 안내·안전장치

## 수정
- **앱을 닫을 때 바로 "저장하고 종료하는 중…"**: X(맥은 ⌘Q·윈도우 닫기)를 누르면 화면 전체에 안내가 뜨고, 저장이 끝날 때까지 클릭·입력이 뒤 화면에 닿지 않습니다. 큰 일지는 종료 백업으로 몇 초 걸릴 수 있는데, 그동안 앱이 멈춘 것처럼 보이던 문제를 없앴습니다.
  - 10초가 넘으면 "종료가 늦어지고 있습니다 — 잠시만 기다려 주세요…"로 바뀝니다.
  - 45초가 넘으면 저장을 더 기다리지 않고 창을 닫습니다. 일지는 저장 방식상 안전하며(끝나지 않은 묶음은 다음에 열 때 되돌려짐), 그날 종료 백업만 생략될 수 있습니다(다음 실행 때 일일 백업).
  - 화면이 아예 멈춘 경우에도 닫기를 누르고 60초가 지나면 앱이 스스로 끝납니다.
  - 노트·메모보드 창 저장에 실패하면 지금처럼 안내를 걷고 오류 창을 띄운 채 창을 남깁니다. 이때는 60초 안전장치도 풀려 고친 내용이 강제로 사라지지 않습니다.

## 주의
- 사용자 요청 main 직접 패치(V2 개발 브랜치에서 실기 확인한 닫기 안내·안전장치만 반영, 온라인 기능은 포함하지 않음). 데이터 형식 **구조 v20 유지**, 외부 통신·새 의존성 변화 없음.
- Rust 명령 1개 추가(`exit_guard_cancel` — 저장 실패 때 안전장치 풀기).
- Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 가이드
- 변경 없음(장면 글·스크린샷은 앱 닫기 안내를 다루지 않음). 대응표 기준 판만 1.40.1로 갱신.

## 설치 후 확인
- 일지를 연 채 X(맥 ⌘Q) → 바로 "저장하고 종료하는 중…"이 보이고 곧 종료, 작업 관리자에 남지 않는지.
- 다시 열면 닫기 직전 입력한 글이 그대로인지.
