# 좁은 칸의 완료 조작·메모 영역 회귀 수정

## 고친 점
- 완료/취소 아이콘의 추가 고정 공간으로 좁은 주간 칸의 본문이 과도하게 줄바꿈되던 문제를 수정했습니다.
- 띠·별표·본문 기본 여백은 유지하고, 완료/취소 조작 아이콘은 행에 마우스를 올리거나 키보드로 접근할 때 표시합니다. 아이콘 표시 전후 행 크기는 동일합니다.
- 완료 상태 배지와 본문 취소선은 항상 표시하며, 중요 업무와의 상태 동기화·가져오기 제외 규칙은 그대로입니다.
- 행 순서 드래그·메모 연결점과 작은 창의 보드 스크롤·메모 최소 높이를 함께 검사했습니다.

## 주의
- RC 검증판이며 구조 v14를 사용합니다. 적용 전 자동 백업, 이전 v13 앱으로 되돌릴 때는 마이그레이션 전 백업 사본을 사용합니다.
- rc.1에서 추가된 완료 전 중요 여부 보존·기존 완료 기록은 유지됩니다. rc.1 대비 추가 구조 변경 없음.
- 외부 통신 범위 변경 없음. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 가이드
- 장면 02의 완료 아이콘 표시 조건과 대응표·화면·HTML·PDF를 갱신했습니다.
