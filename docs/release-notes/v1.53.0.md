# Open Beta — 기능 둘러보기(앱 안 코칭)

## 새 기능
- **기능 둘러보기**: 화면을 어둡게 가리고 설명할 곳만 밝힌 뒤 말풍선으로 하나씩 짚어 주는 단계별 안내입니다.
  - 왼쪽 레일 **?** 단추(⚙ 바로 위) 또는 `F1`로 메뉴를 엽니다. 설정 › 업데이트·정보 › **기능 둘러보기**에서도 열 수 있습니다.
  - 투어 11가지: 시작하기(1분) · 화면 구성과 왼쪽 메뉴 · 주간 보드(기록·보기·요약·내보내기) · 주간 메모 보드 · 칸반 · 인사이트 · Universe · 중요 업무 · Cabi.NET · **업무노트** · **업무 메모보드**.
  - 늘 **가상 예시 화면** 위에서 보여 줍니다. 일지가 비어 있어도 같은 예시로 보고, 끝나거나 건너뛰면 내 일지와 보던 화면으로 돌아옵니다. 내 기록·설정에는 아무것도 쓰지 않습니다.
  - 업무노트·업무 메모보드 둘러보기는 예시 노트·보드가 별도 창으로 열리고 그 창 안에서 진행됩니다.
  - `→`·`Enter` 다음, `←` 이전, `Esc`·[건너뛰기] 그만. 손가락 표시가 있는 단계는 밝힌 곳을 직접 눌러 넘어갑니다. 보다 그만둔 투어는 메뉴에서 그 단계부터 이어 봅니다.
- **처음 한 번 안내**
  - 새로 설치하면 첫 보드가 뜬 뒤 환영 카드가 한 번 뜹니다([1분 둘러보기 시작 ▶]·[골라서 보기]·[다음에]).
  - 쓰던 일지로 이 판에 업데이트하면, 아직 둘러보기를 본 적이 없을 때 새 **?** 단추를 밝혀 한 번 소개합니다.
  - 칸반·인사이트·Universe·Cabi.NET을 처음 열면 그 화면 둘러보기 제안이 한 번 뜹니다(메뉴·설정에서 끌 수 있음).

## 주의
- **1.53.0도 Open Beta입니다**(2.0.0에서 정식). 일지 구조 **v20 유지**, 새 의존성 없음, 운영 서버 변경 없음, 외부 통신 추가 없음.
- 둘러보기 진행 기록은 이 PC 설정(`config.json`의 `coaching`)에만 남습니다(기기마다 따로, 동기화 안 함).
- 예시 화면 중에는 공간 바꾸기·설정·백업을 하지 않습니다. 둘러보기를 마치면 평소대로 동작합니다.
- 이전 main 1.52.1은 `release/v1.52.1` 브랜치에 보존했습니다. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 가이드
- 장면17 신규 "기능 둘러보기"(메뉴·예시 화면·처음 한 번 안내·업무노트/업무 메모보드 창 안 둘러보기·설정), 부록 단축키 `F1`. 레일에 ? 단추가 생겨 모든 장면 스크린샷을 다시 찍었습니다.

## 코칭
- 신규 — T0 시작하기(10) · T1 화면 구성과 왼쪽 메뉴(9) · T2 주간 보드(9) · T3 주간 메모 보드(6) · T4 칸반(7) · T5 인사이트(7) · T6 Universe(10) · T7 중요 업무(6) · T8 Cabi.NET(7) · T9 업무노트(10) · T10 업무 메모보드(9), 모두 콘텐츠 판 1.

## 설치 후 확인
- 쓰던 일지로 업데이트한 뒤 ? 단추 소개가 한 번 뜨고, [다음에] 뒤에는 다시 안 뜨는지.
- `F1` → 시작하기를 끝까지 보고 내 일지·보던 주로 돌아오는지, 내 기록이 그대로인지.
- 다크 테마에서 말풍선이 잘 보이는지, 업무노트 둘러보기에서 예시 노트 창이 열리고 끝나면 닫히는지(Windows·macOS).
