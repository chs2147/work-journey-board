# Open Beta — 업무일지 내보내기(엑셀·마크다운·연도·업무), 메모 글 상자 아래 여백 정리

## 새 기능
- **업무일지 내보내기**: 주간 보드 [내보내기](`Alt+E`) 창 이름이 "업무일지 내보내기"로 바뀌었습니다. 제목 오른쪽에서 **엑셀**·**마크다운** 형식을 고르고(마지막 형식 기억), 범위 · 포함 · 미리 계산 구역이 구분선으로 나뉩니다.
- **연도 범위**: 범위에 "연도 [2026년 ▾]"가 생겼습니다. 그 해의 첫 기록 주부터 이번 주까지 내보냅니다(지난해는 그 해 마지막 주까지).
- **업무 고르기**: 범위 아래 [업무] 단추로 전체 · 1개 · 여러 개를 고릅니다(체크 = 여러 개, [이것만] = 1개). 주간보고 · 원장 · 마크다운 · 미리 계산이 고른 업무만 담고, 주간 요약은 고른 업무만으로 자동 집계합니다(수정본 · AI본은 전체 업무 기준이라 제외). 다음에 열면 다시 전체입니다.
- **마크다운 업무일지**: 주(오래된 주부터) → 업무 → 날짜 → 항목 순 `.md` 하나. 처리 완료 항목 끝에 ✓, 연차 · 휴일은 날짜 옆. 포함 = 업무 기록 · 주간 요약 · 주간 메모(글만, 그림 제외).
- 파일 이름에 연도(`업무일지_2026년_W38~W43`)와 고른 업무(1개면 이름, 여러 개면 `업무 N개`)가 들어갑니다.

## 개선
- **메모보드 글 상자 아래 여백**: 상자 옆면 손잡이로 너비만 바꿔도 높이가 고정돼(최소 80px) 글 아래가 비던 문제를 고쳤습니다. 글 상자는 이제 옆면 손잡이로 너비만 바꾸고, 높이는 늘 글에 맞춥니다. 예전에 고정된 높이도 화면 · PNG 스냅샷에서 쓰지 않아 기존 상자의 빈칸도 사라집니다(주간 메모보드 · 업무 메모보드 공통). 이미지 · 링크 상자와 Live Widget은 그대로입니다.

## 주의
- **1.55.0도 Open Beta입니다.** 일지 구조 **v20 유지**, 새 의존성 없음, 외부 통신 · 운영 서버 변경 없음. 마크다운 저장은 기존 내보내기 경로(고른 `.md` 하나, 일지 파일 · `backups` 거부)를 그대로 씁니다.
- 글 상자의 위 · 아래 · 모서리 크기 손잡이가 없어졌습니다(너비만). 길게 쓴 글은 상자 안 스크롤 대신 상자가 길어집니다.
- 이전 main 1.54.1은 `release/v1.54.1` 브랜치에 보존했습니다. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.
