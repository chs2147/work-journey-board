# Universe 자동 움직임·Cabi.NET 내보내기 개선

## 새 기능
- 다이나믹 3D 은하·포커스에 자동 움직임을 기본 제공한다. 미세 궤도(A)·느린 순환(C)을 모노그램 아이콘으로 전환하고 재생/일시정지를 따로 선택한다.
- 유형과 켜짐 여부를 PC 설정에 저장한다. 직접 조작 후 3초 뒤 재개하며 노드 탐색·모달·비활성 창·OS 모션 감소 시 자동 움직임을 쉰다.

## 개선
- Universe 상단의 ‘주간 보드로’ 버튼을 제거하고 좌측 주간 보드 메뉴로 이동하는 UI로 통일한다.
- 업무 노트 PDF의 빈 페이지/일부 글자 누락을 정적 TTF 글꼴 전체 포함으로 수정한다. 최신 에디터 내용을 내보내고 실제 PDF 제목·본문 렌더링을 검사한다.
- 업무 메모보드 내보내기를 버튼 아래 팝업 메뉴로 통일하고 Markdown/PNG·방향키·Esc·바깥 클릭·중복 실행 방지를 제공한다.

## 주의
- DB 구조 v18 유지. 모션 설정은 PC 설정이며 원본 업무·메모 데이터는 변경하지 않는다.
- PDF에는 한글 글꼴이 포함되어 파일 크기가 증가할 수 있다. 글꼴은 로컬 번들이며 실행 중 외부 다운로드/전송은 없다.
- 사용자 승인으로 improve-v19를 정식 main에 반영한다. 기존 main 1.22.1은 `release/v1.22.1`로 보존했다. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드한다.
- 로컬 검증: 단위 525개·기능 회귀 10개·CSP 7개 및 실제 PDF 렌더링. 설치 파일·정식 릴리스 성공 여부는 Actions에서 별도로 확인한다.
