# Open Beta — 칸반 섹션 기간·카드 순서·마감 경고, Universe 본 항목 묶기, 주간 요약 엑셀, 온라인 공간 다듬기

## 새 기능
- **칸반 섹션별 기간**: 사용자 섹션 ⋯ › [기간 설정…]에서 `전체 기간`이나 다른 기간으로 고정할 수 있습니다(TODO·DONE은 상단 기간 그대로). 고정한 섹션에는 기간 칩이 붙습니다.
- **칸반 카드 직접 순서**: 같은 열 안에서 카드를 끌어 원하는 자리에 놓거나 `Alt+Shift+↑`/`↓`로 옮기면 그 열만 직접 순서가 됩니다. 열 머리 [직접 순서 ↺]로 기본 정렬로 돌아갑니다. 기간·순서는 공간별·이 기기별로 기억합니다.
- **칸반 마감 경고**: 미완료 카드에 `마감 D-2`·`마감 D-1`(황색), `오늘 마감`(주황), `마감 초과 N일`(적색).
- **Universe 본 항목 묶기**: 같은 공간·같은 업무에서 이름이 같은 본 항목은 날짜가 달라도 지도에 노드 하나로 보입니다. 상세 [기록]에서 날짜별 원본·세부를 펼치고 원래 기록으로 이동합니다. 지도는 본 항목부터, 세부는 [세부 펼치기]로.
- **주간 요약 엑셀 시트**: 주간·데일리 [내보내기] 창에 `주간 요약 시트`를 따로 고를 수 있습니다(처음엔 꺼짐). 주차마다 수정본 → AI본 → 자동 집계 순으로 한 행.

## 개선
- **온라인 공간 외형**: 빈 온라인 공간을 만들 때 고른 아이콘·색이 게시 직후부터 목록·레일·다른 기기에 같은 값으로 보입니다(`chartUp`처럼 대문자가 섞인 아이콘도). 서버 목록 함수도 함께 고쳤습니다.
- **공간 전환 안내**: 온라인 공간 첫 동기화 동안 화면 가운데 카드에 `서버와 동기화 중…`. 공간 열기·이 PC로 돌아가기·로그아웃·앱 종료 때 같은 전체 화면 안내를 쓰고, 그동안 입력을 막습니다.
- **Cabinet 온라인 폴더**: 온라인 공간에서도 이 기기에 지정한 폴더를 [탐색기에서 열기](맥 [Finder에서 보기])로 엽니다. 아직 지정하지 않은 줄은 [이 기기에서 경로 지정…].
- **계정·관리자 사용량**: 그림·공간·기록 사용량을 항목별 행과 게이지로, 관리자 설정 화면 정리.
- 릴리스 본문 끝 안내를 온라인 기능에 맞게 고쳤습니다.

## 설치 후 확인
- 칸반에서 사용자 섹션 기간을 `전체 기간`으로 고정 → 이전 주 미완료 카드가 보이는지, 같은 열 안 카드 순서를 끌어 바꾼 뒤 다시 켜도 그대로인지.
- 온라인 공간을 만들 때 고른 아이콘·색이 다른 기기 목록에도 같은지, 이 기기에서 지정한 Cabinet 폴더가 탐색기/Finder로 열리는지.
- [내보내기]에서 `주간 요약 시트`만 골라 저장한 엑셀이 열리는지.
