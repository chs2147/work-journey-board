# 호환되지 않는 일지 차단 · 칸반 보드 다듬기 · 업무 타임라인 정렬 (검증용)

## 새 기능
- **앱 업데이트가 필요합니다**: 지금 앱이 지원하는 것보다 새 구조로 저장된 일지(예: 다른 PC의 최신 판이 연 일지)는 열지 않습니다. 화면에 일지 데이터 버전과 앱 버전을 보여 주고 [N 버전으로 업데이트]·[다른 워크스페이스]만 둡니다 — 이 화면에서는 일지에 아무것도 쓰지 않습니다. 업데이트 전 백업은 일지를 열지 않고 파일 사본(`_pre-update`)으로 만듭니다.
  - 앱이 열려 있는 동안 다른 PC가 일지를 새 구조로 올렸으면, 창을 다시 볼 때(활성화)·주기 백업 직전에 알아채고 쓰기를 멈춘 뒤 같은 화면으로 바뀝니다.
  - 호환되지 않는 워크스페이스로 바꾸려 하면 바꾸지 않고 알림([업데이트 확인]) — 지금 공간은 그대로입니다.
- **칸반 배치 모드**: 오른쪽 위 ⊞ 균등 분할(기본) / ▦ 자유 배치. 자유 배치에서는 섹션 머리를 끌어 위치, 오른쪽 아래 모서리를 끌어 크기(8px 격자), [배치 초기화]. 사용자 섹션 순서는 왼쪽 위부터 읽는 순서로 맞춰지고, 공간마다 기억합니다. 창이 900px보다 좁으면 균등으로 보입니다.
- **섹션 머리 끌어 순서 바꾸기**: 사용자 섹션 머리를 끌어 놓을 자리(세로 표시선)에 놓거나, 머리에 초점을 두고 `Alt+Shift+←`/`→`. 알림 [되돌리기]. TODO 맨 앞·DONE 맨 끝은 고정.
- **완료 축하 모션**: 카드를 DONE에 놓으면 초록 체크와 색종이가 잠깐 터집니다. 일괄 완료는 알림만, OS "동작 줄이기"면 체크만. 설정 › 화면 › [완료 축하 모션]에서 끕니다(이 PC 설정).
- **업무 거르기 전체 / 1개 / 여러 개**: [전체 업무], 줄에 마우스를 올려 [이것만], 여러 업무 체크 — 단추에 "업무: 전체" / 업무 이름 / "업무: N개 선택".

## 고친 점
- 칸반 상단을 주간 보드와 같은 한 줄로: "칸반 보드" 제목 글자 없이 왼쪽 업무 거르기·기간 아이콘, 오른쪽 검색·태그 거르기·**[업무 추가]**(주간 보드와 같은 새 업무 만들기 — 카드 추가는 각 열의 [+ 카드 추가]·`N`)·배치 모드·[섹션 추가].
- 카드 추가 창: 제목에 섹션 이름("카드 추가 — TODO"), 맨 위 **업무 띠**(업무 색 띠·큰 글자)로 어느 업무인지 먼저 보이게, **시작 시간**과 **마감일**을 따로 줄에서 정하기(마감일 = ★ 함께, [이번 주 금]·[다음 주 금]), [취소] → **[닫기]**, 하단 단축키 안내 글 없앰.
- 업무 타임라인: 이번 주 강조 상자 때문에 어긋나던 가로 정렬을 맞춤(모든 주 같은 안쪽 여백, 이번 주는 바탕색·왼쪽 띠만) · 요일 칸을 `수 10/21` 한 줄로(요일 굵게) · 항목과 간격 넓힘 · 다른 날 완료한 항목의 완료일을 항목 글 뒤 같은 열에 세로 정렬 · [기간] 드롭다운을 카드 바탕으로 구분.

## 주의
- 데이터 형식 변경 없음(구조 v20 유지). 칸반 배치는 일지 설정에, 완료 축하 모션 켜기/끄기는 이 PC 설정(`config.json`)에 저장합니다.
- 외부 통신·새 의존성 변화 없음.
- 검증용 판입니다(정식 릴리스 전 실기 확인). Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.
