# 메모보드 보기 도구·링크 팝업 수정

## 개선
- 주간·데일리·업무 메모보드의 관계선 보기/숨김 버튼을 왼쪽 생성 팔레트에서 상단 오른쪽 보기·확대 툴바로 이동한다.
- 링크 넣기 팝업이 창 전체 위에 표시되며 배경을 흐리게 하고 업무·툴바·메모의 클릭과 키보드 포커스 이동을 차단한다.
- Esc·취소·바깥 클릭으로 닫고 호출 버튼으로 복귀한다. 팝업 안에서는 보드 단축키를 실행하지 않는다.

## 주의
- DB 구조 v18 유지. 기존 업무·메모·관계선 데이터 변경 없음.
- Windows 기본 설치판과 macOS 유니버설 DMG를 함께 제공하며 오프라인 설치판은 별도 요청 때만 제공한다.

## 가이드
- 장면05·11의 보기 도구 위치·링크 모달 안내와 화면을 갱신한다.
