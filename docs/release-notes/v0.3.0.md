# 디자인 리뉴얼 v1 — 시그니처 테마

## 새 기능
- 설정 › 화면 › 테마에 **시그니처**가 생겼습니다. 따뜻한 베이지 바탕과 고운돋움 글꼴로 바뀌고, 고르면 바로 적용됩니다. 시스템 설정 / 라이트 / 다크는 지금 모습 그대로입니다.
- 시그니처에서 주간 보드의 요일 상태를 색으로 나눠 보여 줍니다: 오늘 = 브라운 머리 + 꿀색 칸, 선택한 요일 = 세이지 회색 + 밑줄, 연차 = 로즈, 토·일 = 흐린 회베이지.
- 시그니처의 단추는 테두리 없는 옅은 면, 주요 단추는 샌드색, 중요 항목은 구리색 왼쪽 선으로 보입니다.
- 앱 아이콘·워드마크·타이틀은 모든 테마에서 바뀌지 않습니다.

## 주의
- 데이터 형식: 변경 없음(일지 파일 그대로, 이 PC 설정의 테마 값에 `signature` 추가)
- 되돌려 설치: 안전(0.2.20으로 되돌리면 시그니처를 고른 경우 테마가 시스템 설정으로 돌아감)
- 외부 통신: 변화 없음(고운돋움은 앱 안에 함께 설치, SIL OFL 1.1)
