# 메모 끌기·연결점·중요 업무 띠 다듬기

## 새 기능
- 메모 상자를 위 막대로 끌어 메모 판 밖(보드)으로 가져가면 상자는 제자리(점선)에 남고, 작은 꼬리표 `⛓ 메모 이름`만 따라옵니다. 업무 항목에 놓으면 연결되고, `Esc`를 누르면 취소됩니다.
- 보드 행(⋮⋮)을 메모 상자 바로 바깥에 놓아도 그 상자에 연결됩니다. 빈 곳에 놓을 때 새 메모 자리가 다른 상자와 겹치면 아래로 비켜 놓입니다.
- 관계선 연결점이 상자의 위·오른쪽·아래·왼쪽 4곳에 생겼습니다. 글 상자 폭 조절 손잡이는 오른쪽 아래 모서리로 옮겼습니다.
- 중요 업무 패널의 날짜 묶음이 색 띠로 구분됩니다 — 지난 날짜(빨강)·오늘(파랑, 날짜)·이번 주(초록, 주 끝 날짜)·다음 주 이후(회색).

## 고친 점
- 메모 상자 ⋯ 메뉴의 배경색 칩이 모두 흰색으로 보이던 문제

## 주의
- 데이터 형식: 변경 없음
- 되돌려 설치: 안전(0.2.15로 되돌려도 기록·메모 그대로)
- 외부 통신: 없음(변화 없음)
