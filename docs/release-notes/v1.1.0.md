# 릴리스 후 개선 — 데일리 뷰·패널 폭·오픈소스 라이선스

## 새 기능
- **데일리 뷰**("오늘 뷰"의 새 이름): 카드 위 날짜 띠(월~일)에서 날짜를 누르거나 ‹ ›로 하루씩 이동합니다. 기록이 있는 날은 점, 연차·반차는 글자로 보입니다. 메모 머리의 [크게 보기]로 메모를 데일리 뷰 전체로 펼칠 수 있습니다(Esc로 돌아옴).
- **패널 폭 조절**: 중요 업무·주간 요약 패널의 안쪽 가장자리를 끌어 폭을 바꿉니다. 두 번 누르면 기본 폭, 다음에 켜도 그 폭입니다.
- **메모 글 속 링크 ↗**: 링크 끝 ↗를 누르면 기본 브라우저에서 엽니다. 링크 글자는 지금처럼 편집됩니다.
- **설정 › 업데이트·정보**: 정보 카드를 새로 꾸미고(소개 사이트·이 판의 릴리스 노트), 오픈소스 라이선스 카드에 글꼴 저작권자·라이선스 전문과 주요 라이브러리를 담았습니다.

## 고친 점
- 새 판 안내 띠가 진한 강조색으로 바뀌어 업무 화면과 확실히 구분됩니다.
- 가져오기 › 미리보기에서 "가져올 항목·지금 기록" 숫자가 동그라미로 깨져 보이던 문제
- 설정 › 진단 정보 표의 왼쪽·아래 여백

## 주의
- 데이터 형식: 변경 없음(패널 폭은 일지 설정 안의 값)
- 외부 통신: 변화 없음(링크·소개 사이트·릴리스 노트는 OS 브라우저에 주소만 넘김)
