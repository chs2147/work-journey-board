# Open Beta — 기능 둘러보기 소개 카드가 매번 뜨던 문제 수정

## 수정
- **처음 1회 카드가 앱을 켤 때마다 뜨던 문제**: 기존 사용자에게 업데이트 뒤 한 번만 보여야 할 ? 단추 소개 카드(새 사용자는 환영 카드)가 앱을 켤 때마다 다시 떴습니다. 설정 파일을 읽을 때 코칭 기록을 빼고 읽었기 때문입니다. 이제 코칭 기록을 그대로 읽어, 카드는 한 번만 뜨고 투어를 끝까지 본 기록·보다 멈춘 위치도 다시 켜도 남습니다.
- 카드를 직접 닫지 않고 투어를 시작하거나 ? 메뉴를 열어도 카드를 본 것으로 기록합니다.

## 주의
- **1.53.3도 Open Beta입니다.** 일지 구조 **v20 유지**, 새 의존성 없음, 외부 통신·운영 서버 변경 없음.
- 지난번에 카드를 닫지 않고 두셨다면 업데이트 뒤 한 번만 더 뜨고, 그 뒤로는 뜨지 않습니다.
- 이전 main 1.53.2는 `release/v1.53.2` 브랜치에 보존했습니다. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 가이드
- 변경 없음(장면 글·스크린샷에 영향 없음). 대응표 기준 판만 1.53.3으로 갱신.

## 코칭
- 투어 콘텐츠 변경 없음. 처음 1회 카드·진행 기록이 다시 켜도 남도록 저장 읽기를 고침.

## 설치 후 확인
- 앱을 두세 번 껐다 켜도 ? 단추 소개 카드가 다시 뜨지 않는지.
- 투어를 하나 끝까지 본 뒤 다시 켜도 ? 메뉴에 완료 표시가 남는지.
