# 업무노트 이끌이 위치·데일리 뷰 기록 있는 업무만 보기

## 수정
- **업무노트 블록 이끌이 위치**: 들여쓴 목록(불렛) 문장에서 이끌이가 함께 안쪽으로 들어가 불렛을 덮어 끌기·메뉴를 쓸 수 없던 문제를 고쳤습니다. 이제 일반 문장·불렛·여러 단계로 들여쓴 불렛 모두 같은 자리(문장 맨 앞 고정 위치)에 이끌이가 나옵니다. 블록 메뉴 위치도 같은 기준입니다.
- **"완료 묶음 N개 제외" 표기 제거**: 데일리 뷰 직전 기록 줄의 [가져오기] 옆과 주간·데일리 뷰의 가져오기 알림에서 뺐습니다. 완료된 묶음을 가져오지 않는 동작은 그대로입니다.

## 새 기능
- **데일리 뷰 [기록 있는 업무만] 스위치**: 날짜 줄 오른쪽의 깔때기 아이콘 스위치(툴팁으로 이름·상태 안내). 켜면 보고 있는 날에 기록이 0건인 업무 카드를 숨기고, 카드 아래에 "기록 없는 업무 N개를 숨겼습니다 [전체 보기]"를 보여 줍니다. 그 날 기록이 하나도 없으면 안내와 [전체 보기]가 나옵니다.
  - 켠 채 기록하던 카드는 마지막 항목을 지워도 그 날을 떠나거나 스위치를 누를 때까지 남습니다.
  - 켬·끔은 일지 설정(`ui.todayHideEmpty`)에 저장돼 다시 켜도 유지됩니다. 태그 필터와 함께 쓸 수 있고, [전체 가져오기]는 숨김과 관계없이 그대로입니다. 주간 뷰는 바뀌지 않습니다.

## 주의
- 사용자 요청 main 직접 패치(1.24.0 이후 긴급 수정). 데이터 형식 **구조 v19 유지**(설정 항목 하나 추가, 마이그레이션 없음).
- 외부 통신·새 의존성 변화 없음. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 설치 후 확인
- 업무노트에서 불렛을 2·3단 들여쓰고 각 줄에 마우스를 올려 이끌이가 같은 세로 자리(불렛 왼쪽)에 나오는지, 끌기·메뉴가 되는지.
- 데일리 뷰에서 깔때기 스위치를 켜고 끄며 기록 0건 업무가 숨고 보이는지, 앱을 다시 켜도 상태가 남는지.
