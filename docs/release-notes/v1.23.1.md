# 업무 이름에서 업무 메모보드 바로 열기

## 개선
- 주간·데일리 뷰의 업무 이름 옆에 업무 메모보드 바로가기 모노그램 아이콘을 제공한다.
- 해당 업무의 보드가 있는 경우에만 표시한다. 기존 폴더/링크 바로가기와 독립적으로 제공하며, 노트만 있는 경우에는 표시하지 않는다.
- 보드 생성·삭제 시 표시를 갱신하고 기존 모달리스 보드 창 열기 경로를 재사용한다.

## 주의
- 사용자 요청으로 main에 직접 반영한 패치다. DB 구조 v18 유지, 기존 업무·메모 자료의 이관은 없다.
- 외부 통신 범위 변경 없음. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드한다.
- 로컬 검증: 단위525개·주간/데일리 바로가기 및 기존 캐비넷 E2E7개 통과, lint·typecheck·프로덕션 빌드·가이드/Feature List 검사 완료. 설치 파일 성공 여부는 Actions에서 별도 확인한다.
- V2 설계/PoC는 v2-design에 보존하며 이번 패치에 포함하지 않는다.
