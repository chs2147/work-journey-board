# Open Beta — 라이브러리·빌드 도구 판올림, 배포 안정화

## 수정
- **라이브러리 판올림**: 편집기(Tiptap 3.35), 3D 지도(Three.js 0.187), 일지 엔진(sql.js 1.17), 화면 상태(Zustand 5.1) 등 22개 패키지를 고친 판으로 올렸습니다. 기능·화면 변화는 없습니다. 설정 › 업데이트·정보 › 오픈소스 라이선스 표의 판 번호도 맞췄습니다.
- **브라우저 모드 가짜 파일**: 새 sql.js는 깨진 일지 파일을 열 때는 받아 주고 닫을 때 실패해, 브라우저 모드(개발·시험용)에서 "깨진 일지 → 백업에서 복원" 시험이 막혔습니다. 닫을 때 내보내기가 실패하면 열었던 바이트를 그대로 두도록 고쳤습니다. 설치판(Tauri SQLite)과는 무관합니다.
- **빌드 도구 판올림**: GitHub Actions 액션 8종을 새 판으로 올려 "Node.js 20 지원 종료" 경고를 없앴습니다.
- **소개 사이트 배포 안정화**: 사이트 묶음을 올린 직후 배포하다가 묶음을 찾지 못해 실패하던 문제를, 만들기·배포 작업을 나눠 고쳤습니다(1.53.0 때 이미 main에 반영).
- **시험 안정화**: 기능 둘러보기 E2E가 말풍선을 다시 그리는 순간에 위치를 재다 간헐적으로 실패하던 문제를 고쳤습니다(1.53.0 뒤 main에 반영).

## 주의
- **1.53.1도 Open Beta입니다.** 일지 구조 **v20 유지**, 새 의존성 없음(기존 판올림만), 외부 통신·운영 서버 변경 없음.
- 이전 main 1.53.0은 `release/v1.53.0` 브랜치에 보존했습니다. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.
