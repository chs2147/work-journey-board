# 설정 전체 화면·테마·저장 표시·가져오기 화면

## 새 기능
- 설정(⚙)이 왼쪽 메뉴 줄 맨 아래로 옮겨졌습니다. 누르면(`Ctrl+,`) 보드 자리에 설정 화면이 열리고, 왼쪽 분류(화면 · 데이터·백업 · 가져오기 · 업무 관리 · 업데이트·정보)를 골라 봅니다. `↑`/`↓`로 분류 이동, `Esc`로 보던 화면으로 돌아갑니다. 새 판 알림 파란 점도 이 ⚙에 붙습니다.
- 설정 › 화면 › 테마: 시스템 설정 / 라이트 / 다크를 고르면 바로 바뀌고, 창 제목 표시줄과 시작 창도 같은 테마가 됩니다. 테마는 이 PC에 저장됩니다(일지 파일과 따로).
- 상단 오른쪽 "저장됨"이 초록 테두리 알약으로 눈에 띄게 보입니다. 저장이 오래 걸릴 때만 "저장 중…", 실패하면 빨간 [저장하지 못함 · 다시 시도]가 뜹니다. 마우스를 올리면 마지막 저장 시각이 보입니다.
- 기존 일지 가져오기: 위쪽에 단계 표시(지난 단계 ✓를 누르면 그 단계로), 진행 순서 1~8을 A·B·C 묶음 상자로 정리, 1·2단계 줄에 [양식 엑셀 받기]·[AI 지시문 복사], AI 지시문은 펼치면 코드 블록 + [복사](빈칸 노란 강조)로 보입니다.

## 고친 점
- 다크 테마에서 가져오기 창의 파란 단추 글자가 흐리게 보이던 문제

## 주의
- 데이터 형식: 변경 없음(일지 파일 그대로, 이 PC 설정 파일에 테마 값 하나 추가)
- 되돌려 설치: 안전(0.2.19로 되돌리면 설정이 예전 오른쪽 창으로 돌아가고 테마는 윈도우 설정을 따름)
- 외부 통신: 변화 없음
