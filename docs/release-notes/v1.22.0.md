# 접이식 세로 팔레트·노트와 보드 편집 개선

## 새 기능
- 왼쪽 세로 팔레트에 생성·클립보드·라이브 위젯을 1열 아이콘으로 묶고 미니멀 손잡이로 접기/펼치기를 제공한다. 확대/축소·화면 맞춤·스크린샷·최대화 등 보기 도구는 기존 상단 오른쪽에 유지한다.
- 업무 노트 표에서 행·열 추가/삭제·머리글 전환 메뉴를 제공한다. 순서 목록은 중첩 계층 번호를 표시한다.
- 모든 메모 객체의 너비·높이 프레임을 조절하고 저장·실행 취소한다.

## 개선
- 노트/주간 메모의 불필요한 고정 설명을 제거하고 이미지·가져오기·목차·복사/붙여넣기 아이콘을 명확히 한다.
- 허브의 보드 미리보기 보기 단추를 제거하고 업무 보드 창 명칭을 정리한다.
- Universe 은하/초점에 우주 성운·별빛 배경을 제공하고 정적/모션 감소 선택을 유지한다.
