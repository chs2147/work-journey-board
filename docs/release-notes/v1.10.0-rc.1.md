# Universe — 지도 보기 + 직접 연결 (검증용)

## 새 기능
- **Universe**(레일 연결망 아이콘 · `Alt+5`, 맥 `⌥5`): 업무·업무 항목·태그·메모 상자·Cabinet을 하나의 연결망으로 보고, 원래 자리로 돌아가는 화면입니다(초점·은하·목록 보기, 시간 막대, [원본 열기], 다른 워크스페이스 읽기 전용 함께 보기).
- **직접 연결**(이번에 새로): 상세의 [연결하기]로 주를 넘어 다른 기록·메모·업무와 직접 잇습니다.
  - 종류 5개: **관련**(방향 없음) · **후속** · **근거** · **반대 근거** · **대체**(원문은 그대로).
  - 대상은 같은 업무·최근 기록이 먼저 보이고, 두 글자 이상 치면 검색합니다. 설명은 한 줄(200자)까지 선택.
  - 지도에 굵은 선·화살표로, "왜 이어졌나" 맨 위에 "A 다음에 B가 이어짐" 같은 문구로 보입니다. [고치기]로 종류·방향·설명, [끊기]로 연결만 지웁니다.
  - Universe 안 `Ctrl+Z`/`Ctrl+Y`(맥 `⌘Z`/`⌘Y`) = 직접 연결 작업 되돌리기·다시 하기.

## 고친 점
- v1.8.1 워크스페이스 전환 무결성 수정을 포함합니다. Universe도 같은 규칙을 따릅니다 — 직접 연결은 지금 공간 일지에만 쓰고, 공간을 바꾸면 Universe의 지도·실행 취소 기록을 비웁니다.
