# 휴일·공휴일, 마크다운 내보내기, Cabinet, 이용 가이드

## 새 기능
- **휴일 설정**: 요일 머리 ⋯·데일리 뷰 [근무 ▾]에서 연차·반차에 더해 **공휴일(이름)**과 **기타 휴가(사유: 공가·야유회·경조사·교육·대체휴무·직접 입력)**를 고릅니다. 주간 요약 끝 줄·엑셀 날짜 머리에 이름이 들어갑니다.
- **대한민국 공휴일 자동 표시**: 2026~2030년 공휴일(설·추석 연휴, 대체공휴일, 선거일)을 앱 안 표로 보여 줍니다(외부 접속 없음). 설정 › **달력·휴일**에서 켜고 끄기·날짜별 끄기·회사 휴일·기타 휴가 사유를 관리합니다.
- **메모 보드 마크다운 내보내기**: 메모 머리 카메라 메뉴 › [마크다운으로 내보내기…] — 범위·포함 항목을 고르고 미리본 뒤 `.md`(+ 이미지 폴더)로 저장하거나 복사합니다.
- **Cabinet**(레일 🗄 · `Alt+4`): 업무별로 자주 여는 **작업 폴더와 링크**를 등록해 두는 떠 있는 창 — [전체 · 📁 폴더 · 🔗 링크]로 보기, 탐색기 폴더·브라우저 링크 끌어 놓기 등록(링크 제목은 브라우저가 준 것, 고칠 수 있음), 폴더를 **별도 창**으로 여러 개 열어 파일을 기본 앱으로 열기. 보드 항목 옆 🗄 표시·검색 결과에도 나옵니다.
- **빠른 이용 가이드**: 소개 사이트 [이용 가이드](HTML·PDF) — 장면 12개 + 단축키·자주 묻는 질문. 설정 › 업데이트·정보 [이용 가이드 ↗].
