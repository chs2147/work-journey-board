# Open Beta — 온라인 공간을 연 채로도 새 판을 찾도록 수정

## 수정
- **온라인 공간을 열어 두면 새 판을 못 찾던 문제**: 온라인 공간을 연 상태에서는 앱을 켤 때의 자동 확인과 설정 › [업데이트 확인]이 GitHub에 묻지 않고 늘 "최신"으로 답했습니다(검증판 시절 온라인 공간 화면은 업데이트를 하지 않던 설정이 정식판에 남음). 이제 온라인 공간을 열고 있어도 이 PC 공간과 같은 경로로 새 판을 확인·내려받기·설치합니다.
- 설치 직전 온라인 공간의 보낼 변경을 먼저 서버로 보내고, 이 PC에 등록된 워크스페이스는 예전처럼 업데이트 전 백업(`_pre-update`)을 남깁니다.

## 주의
- **1.54.0 이하는 온라인 공간을 연 채로 1.54.1을 스스로 찾지 못합니다.** 이번 한 번은 이 PC 공간으로 바꾼 뒤 [업데이트 확인]을 누르거나, 릴리스 페이지에서 직접 받아 설치해 주세요. 1.54.1부터는 온라인 공간에서도 새 판 안내가 뜹니다.
- 새 판을 묻는 곳(GitHub Releases)·시점(켤 때 1번 + [업데이트 확인])은 그대로입니다. DEV 판은 지금처럼 업데이트를 확인하지 않습니다.
- **1.54.1도 Open Beta입니다.** 일지 구조 **v20 유지**, 새 의존성 없음, 운영 서버 변경 없음.
- 이전 main 1.54.0은 `release/v1.54.0` 브랜치에 보존했습니다. Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 가이드
- 변경 없음(장면 글·스크린샷에 영향 없음). 대응표 기준 판만 1.54.1로 갱신.

## 코칭
- 변경 없음.

## 설치 후 확인
- 다음 새 판이 나왔을 때 온라인 공간을 연 채로 앱을 켜면 새 판 안내 띠가 뜨는지.
- 설정 › 업데이트·정보 › [업데이트 확인]이 온라인 공간에서도 같은 결과를 보이는지.
