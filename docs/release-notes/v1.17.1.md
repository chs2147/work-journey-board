# 백업 보관 규칙 안내 정렬 수정

## 고친 점
- 데이터·백업 화면에서 보관 규칙 하단의 안내 문구가 카드 왼쪽에 붙어 보이던 문제를 수정했습니다.
- 기본 안내·자동 삭제 보류·최근 정리 이력을 기존 설정 행의 좌우 여백에 맞췄습니다.
- 카드 제목·설정 행·추가 안내에 공통 여백을 적용하고, 새 텍스트 영역은 기존 기준선과 정렬하는 설계 규칙을 기록했습니다.

## 주의
- 백업·복원·자동 정리 동작과 일지 DB 구조 v14의 변경은 없습니다. Windows 기본판·macOS 유니버설 DMG를 함께 제공합니다.

## 가이드
- 장면12의 화면과 기준 판·HTML·PDF 갱신. 사용 절차는 동일합니다.
