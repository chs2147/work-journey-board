# 온라인 워크스페이스 — 여러 기기에서 같은 공간

## 새 기능
- **온라인 워크스페이스(선택 기능)**: 초대받은 이메일로 로그인하면 회사 PC·집 맥처럼 여러 기기에서 같은 공간을 쓸 수 있습니다. 로그인하지 않으면 지금과 똑같이 이 PC 일지만 씁니다.
  - 로그인: 설정 › **계정** 또는 공간 목록 아래 **[온라인 로그인…]** → 이메일 → 메일로 온 인증번호. 처음 한 번 개인정보 안내·이용 안내에 동의합니다(설정 › 계정 맨 아래에서 다시 보기).
  - 만들기: **[온라인 워크스페이스 만들기…]** → **오프라인 기록으로 시작**(이 PC 일지 복제 — 원본은 그대로) 또는 **새로 시작하기**(빈 온라인 공간).
  - 공간 목록이 **이 PC** · **온라인** 두 묶음으로 나뉘고, 같은 방식으로 오갑니다. 앱을 다시 켜면 마지막으로 쓴 공간으로 시작합니다.
  - 동기화: 상단 알약에 상태(동기화됨·이 기기에 저장됨·오프라인·대기 N건). 인터넷이 끊겨도 이 기기 사본에 저장되고 다시 연결되면 보냅니다. 같은 내용을 두 기기에서 고치면 충돌 목록에서 고릅니다.
  - 관리: 사용량(그림 100MB · 온라인 공간 3개 · 기록 30MB), 로그아웃, [서버에서 지우기], [계정 삭제].

## 주의
- 온라인 기능에 로그인한 경우에만 서버(Supabase, 일본 도쿄)와 통신합니다. 인증번호 메일은 Resend로 보냅니다. 로그인하지 않으면 새 판 확인 외에는 지금처럼 아무것도 보내지 않습니다.
- 기존 이 PC 일지·백업·설정은 바꾸지 않습니다. 데이터 형식 **구조 v20 유지**. 온라인 자료는 설정 폴더 안 별도 폴더(`WorkJourneyBoard/production/…`)에 둡니다.
- 앱 화면 보안 정책(CSP)에 WebAssembly 실행 허용 한 줄을 더했습니다(외부 주소 없음 — 온라인 공간 이 기기 사본용).
- 이전 main 1.40.1은 `release/v1.40.1` 브랜치에 보존했습니다.
- Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 가이드
- 장면16 신규 — 온라인 워크스페이스(로그인·동의·만들기·전환·동기화·충돌·사용량·로그아웃·계정 삭제), 스크린샷 `16-online`. 장면13 공간 목록 스크린샷 다시 찍음(목록 아래 [온라인 로그인…]).

## 설치 후 확인
- 로그인하지 않은 채로 지금 일지가 그대로 열리고 기록·백업이 예전처럼 되는지.
- 설정 › 계정에서 동의 → 인증번호 받기 → 로그인 → 온라인 워크스페이스 만들기(오프라인 기록으로 시작) → 원래 이 PC 공간도 그대로 열리는지.
- 다른 기기(맥/윈도우)에서 같은 계정으로 로그인 → 같은 온라인 공간이 보이고, 한쪽에서 고친 내용이 다른 쪽에 들어오는지.
