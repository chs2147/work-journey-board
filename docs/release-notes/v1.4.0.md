# Cabinet 다듬기 — 별도 창·전체 보기·끌어 정리, 스플래시 버전 표시

## 새 기능
- **Cabinet 별도 창**: `Alt+4`(레일 🗄)로 여는 Cabinet이 폴더 창처럼 **앱 밖 별도 창**으로 열립니다. 다른 모니터로 옮길 수 있고, 위치·크기와 열림 상태는 다음에 켤 때도 그대로입니다.
- **업무별 목록**: 맨 위 **전체**(업무와 관계없이 모든 폴더·링크), 그 아래 진행 중인 업무가 모두 보입니다(연결이 없으면 0).
- **끌어서 정리**: 목록 줄을 끌어 순서를 바꾸고, 왼쪽 업무에 놓으면 그 업무에도 연결됩니다(기존 연결 유지).
- **업무 이름 옆 바로가기**: 주간 뷰·데일리 뷰 업무 이름 옆 🗄(개수) — 하나면 바로 열고, 여럿이면 Cabinet을 그 업무로 엽니다.

## 고친 점
- 크롬·엣지 주소창 아이콘을 Cabinet에 끌어 놓으면 "폴더만 등록할 수 있습니다"가 나오던 것 — 이제 링크로 등록됩니다.
- 등록 폴더의 [탐색기에서 열기]가 상위 폴더에서 선택된 채 열리던 것 — 이제 그 폴더 안이 열립니다(폴더 창에서 파일을 골라 둔 경우에만 그 파일 선택).
- 시작 스플래시 버전 표시를 타이틀 옆 `버전 1.4.0`으로(설정 › 업데이트·정보와 같은 표기).

## 주의
- 데이터 형식: 변경 없음(1.3.0과 같은 v9)
- 외부 통신: 변화 없음(Cabinet 창은 일지를 직접 열지 않고 앱 안에서 메인 창과만 주고받습니다)
