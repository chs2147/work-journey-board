# 새 판 확인·설치

## 새 기능
- 앱을 켤 때 1번, 그리고 설정 › 업데이트의 [업데이트 확인]으로 새 판이 있는지 확인합니다.
- 새 판이 있으면 보드 위에 "새 판이 있습니다" 띠가 뜨고 설정(⚙) 단추에 파란 점이 붙습니다. [나중에]를 누르면 띠만 숨겨집니다.
- [자세히·설치]를 누르면 릴리스 노트를 보고 [내려받고 설치]로 한 번에 설치할 수 있습니다 — 입력 저장 → 내려받기(진행 막대) → 무결성(SHA256) 확인 → 일지 자동 백업 → 앱을 닫고 설치한 뒤 다시 엽니다.

## 주의
- 외부 통신: **바뀜** — 새 판 확인·내려받기 때만 GitHub(이 앱의 릴리스 페이지)에 연결합니다. 기록·메모는 어디에도 보내지 않습니다. 회사망에서 GitHub가 막혀 있으면 "확인하지 못했습니다"가 뜨고, 앱 사용에는 지장이 없습니다.
- 자동 설치는 이 판을 설치한 **다음 판부터** 쓸 수 있습니다(이번 0.2.19는 지금처럼 직접 설치).
- 설치 파일에 코드 서명이 없어 백신·SmartScreen이 막을 수 있습니다 — 막히면 그 문구를 알려 주세요.
- 데이터 형식: 변경 없음
- 되돌려 설치: 안전(0.2.18로 되돌리면 업데이트 확인만 사라짐)
