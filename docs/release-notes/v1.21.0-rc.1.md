# Cabi.NET Live Widget·노트 편집 개선 검증판

## 새 기능
- 업무 보드에 경과일·업무 타임라인·미완료 중요 업무 Live Widget을 배치한다.
- 타임라인은 기록 목록·수동 마일스톤·자동 주차 요약형을 제공하고 원본 기록과 연동한다.
- 중요 업무 위젯에서 완료하면 메인 원본에도 반영되며 같은 되돌리기를 사용한다.
- 노트 블록 가까이 이끌이와 메뉴를 제공하고 드래그로 이동한다. 선택한 텍스트 가까이 서식·링크·주간 메모와 동일한 글자색을 적용한다.

## 개선
- 노트/보드 저장 표시를 메인과 통일하고 중복 설명을 제거한다. 자료 카드의 네 방향 관계선 연결점과 주간 메모 목록의 원본 열기 아이콘 정렬을 개선한다.
- 보드 내보내기를 일반 아이콘과 메뉴로 통일하고 전체 삭제에 확인 문구 입력을 추가한다. 삭제된 노트 창은 저장 확인 후 닫는다.
- 위젯의 Markdown/PNG 내보내기와 주간 보드 복제는 기준일을 포함한 정적 사본이다.

## 주의
- DB v16 → v17, 직전 자동 백업 후 전진 마이그레이션. 이전 앱으로 열 수 없으므로 원복에는 직전 백업을 사용한다.
- 작업 브랜치 검증판이다. Windows/macOS 네이티브 설치 확인과 정식 배포는 별도이다.
