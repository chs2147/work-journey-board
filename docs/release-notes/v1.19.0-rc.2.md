# 날짜 복제·인사이트 개선 검증판 2

## 개선
- 연결이 없는 메모에 빈 업무 연결 띠가 표시되지 않도록 수정했습니다.
- 항목 삭제 전에 대기 중인 메모 연결 저장을 완료하여 삭제를 되돌릴 때 원래 연결을 복원합니다. 메모 본문과 다른 연결은 보존합니다.
- 첫 실행·저장 위치 이동·종료 백업의 회귀 검증이 현재 DB 구조 번호를 사용하도록 수정했습니다.
- 날짜 지정 복제·메모/Cabinet 공유 연결·이전 내역 연결 가져오기·인사이트 열 조절·기록 일수 표시 제거는 RC1과 동일합니다.

## 주의
- RC1과 구분한 작업 브랜치 검증판입니다. Windows 기본 설치판과 macOS 유니버설 DMG를 함께 빌드합니다.
- 일지 구조 v15를 사용합니다. 구형 일지는 이전 직전 자동 백업 후 전진 마이그레이션하며 예전 앱은 새 구조를 열 수 없습니다.
- RC1에서 RC2로는 추가 DB 마이그레이션이 없습니다.

## 가이드
- 장면05·12와 기준 판·실제 화면·HTML·PDF를 갱신했습니다.
