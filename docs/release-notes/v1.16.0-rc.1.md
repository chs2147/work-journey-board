# 항목 완료·가져오기·직각 띠 검증판

## 새 기능
- 일반·중요 항목마다 모노그램 아이콘으로 완료/완료 취소, 본문 취소선을 제공합니다. 중요 업무에서 완료한 상태도 같은 항목에 표시합니다.
- 완료를 취소하면 완료 전 별표 상태를 복원합니다. 일반 항목에는 별표가 새로 생기지 않습니다.

## 고친 점
- 완료 항목은 이전 기록 가져오기에서 제외합니다. 완료된 상위 항목의 하위 항목도 전부 제외하고, 미완료 상위 항목의 완료 자식만 있으면 그 자식만 제외합니다.
- 직전 기록이 모두 완료면 가져올 항목이 없음을 안내합니다. 더 오래된 날로 자동으로 거슬러 가지 않습니다.
- 강조 띠·별표·아이콘 여백을 확보하고 모든 띠를 직각으로 정리했습니다.
- 글자색 버튼은 A+사각 색상칩으로, 팔레트는 기본색 복원과 직각 색상칩으로 정리했습니다.

## 주의
- RC 검증판입니다. Windows 기본 설치판·macOS 유니버설 DMG를 함께 제공하며 Windows 오프라인판은 제외합니다.
- **일지 구조 v14**: 일반 항목의 완료 전 중요 여부를 보존합니다. 기존 마이그레이션 직전 자동 백업 후 트랜잭션으로 적용합니다.
- v14로 올린 일지는 이전 v13 앱으로 직접 열 수 없습니다. 되돌려 설치할 경우 마이그레이션 전 백업 사본을 사용하세요.
- 기존 본문은 변경하지 않습니다. 신규 외부 통신·의존성 추가 없음.

## 가이드
- 장면 02·03·04·05와 대응표, 실제 화면·HTML·PDF를 갱신했습니다.

## 확인할 동작
- 일반·중요 항목 완료/취소의 원래 별표 복원, 중요 업무와 보드·데일리 상태 동기화.
- 완료 부모/자식의 가져오기 제외와 완료 취소 후 복원, 0건 안내.
- 세 테마·좁은 칸·시작 시각/마감일 칩, 직각 글자색 팔레트와 기존 메모 서식.
