# 항목 도구 정리 · 시작 시각 00~23시 · 오늘 묶음

## 바뀐 점
- **항목 도구를 왼쪽 ⋮⋮ 손잡이 하나로**: 마우스를 올리면 글 오른쪽 위에 겹쳐 뜨던 [메모]·↻·⋯·휴지통을 없앴습니다. 항목 왼쪽 ⋮⋮를 **끌면 옮기기, 누르면 항목 메뉴** — 연결된 메모 만들기·매주 반복·시작 시각·다른 날로 옮기기·삭제. 항목 오른쪽 클릭도 같은 메뉴, 단축키(`Alt+R`·`Alt+O`·`Alt+D`·`Alt+Delete`, 맥 `⌥`)는 그대로입니다.
- ⋮⋮ 손잡이를 더 크고 또렷하게(마우스를 올린 항목에서 흰 단추 모양, 올리면 강조색) — 옆 칸 글을 덮지 않도록 칸 왼쪽에 자리를 두었습니다.
- 연결된 메모 배지(📝)·Cabinet(🗄)는 전처럼 바로 누릅니다. ↻는 매주 반복 중인 항목에만 보이고 누르면 끕니다.
- 시작 시각: 시 단추를 00~23시 24칸으로 한 번에 보입니다([더 보기] 없음).
- 중요 업무 패널: **오늘** 묶음을 다른 바탕색으로 구분합니다.
