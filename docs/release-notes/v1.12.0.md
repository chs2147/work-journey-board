# Universe — 기록과 지식의 연결 지도

## 새 기능
- **Universe**(레일 연결망 아이콘 · `Alt+5`, 맥 `⌥5`): 업무·업무 항목·태그·메모 상자·Cabinet·지식 카드를 하나의 연결망으로 보고 원래 자리로 돌아가는 화면(초점·은하·목록 보기, 시간 막대, [원본 열기], 다른 워크스페이스 읽기 전용).
- **직접 연결**: 상세의 [연결하기]로 주를 넘어 잇기(관련·후속·근거·반대 근거·대체), 굵은 선·화살표·문구, 고치기·끊기, Universe 안 `Ctrl+Z`/`Ctrl+Y`.
- **지식 카드**(이번에 새로): [지식 카드로 정리]로 해결법·의사결정·배운 점·업무 길잡이를 카드로 남깁니다.
  - 제목·요약·적용 조건·본문, 출처 1~50개(기록·메모·Cabinet·업무·태그), 관련 업무.
  - 상태 초안 → 검토함 → 보관("검토함"은 확인했다는 표시이지 사실 보증이 아님).
  - 원문이 바뀌면 카드를 저절로 고치지 않고 출처마다 **내용 변경**·**위치 변경**·**원문 없음** 배지 — [비교]로 당시 발췌와 지금 원문, [다시 확인].
  - 작성 중 임시본은 일지에 보관돼 창을 닫아도 [이어 쓰기].
  - 보드의 출처 항목에 **◆**(누르면 그 카드), 통합 검색 결과에 카드 묶음.
- **근거 묶음**(이번에 새로): [근거에 담기](Universe 상세·카드·보드 항목 메뉴)로 모아 [근거 묶음 n] 서랍에서 질문을 적으면, 사내 AI에 붙여 넣을 글(지시문 + 원문 + 근거 번호 S1·K1 + 주의)을 미리 보고 [사내 AI용 복사]·[Markdown으로 저장…].
  - 원문 12,000자·원본 20개까지 — 넘치면 원본을 통째로 빼고 무엇을 뺐는지 보여 줍니다.
  - Cabinet 경로·링크 주소는 기본으로 빼고, 그림은 설명만 담습니다.
  - 복사 직전에 원문을 다시 읽어, 바뀌었으면 미리보기를 새로 만들고 다시 확인받습니다.
  - 앱은 사내 AI에 접속하거나 보내지 않습니다(복사·파일 저장까지).
