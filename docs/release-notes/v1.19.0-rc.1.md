# 날짜 복제·인사이트 개선 검증판

## 새 기능
- 주간/데일리 항목 ⋯ › 날짜로 복제…에서 대상일과 복제 범위를 확인합니다. 본 항목은 하위도 함께, 하위 하나는 독립 본 항목으로 복제합니다.
- 메모·Cabinet 원본은 그대로 공유하고 새 항목의 연결만 추가합니다. 다른 주의 메모 배지는 원본 주차를 안내하며 원본 객체를 엽니다.
- 업무 타임라인 목록과 활동 업무 이름 열의 경계를 끌어 너비를 조절하고 공간별로 기억합니다. 방향키·Shift·Home·더블클릭으로도 조절/초기화합니다.

## 개선
- 이전 내역 가져오기도 메모·Cabinet 연결을 함께 가져옵니다. 완료 묶음 제외·중복 생략을 유지하고 실제 생성한 항목에만 연결합니다.
- 활동 이름 열 조절에 따라 날짜 격자가 유연하게 늘고 줄어 가로 스크롤을 만들지 않습니다. 기록 일수 제목과 표시 열을 제거하여 날짜 격자가 남은 폭을 사용합니다.
- 메모 글 저장·되돌리기에서 새 공유 연결과 원문 편집을 보존합니다. 연결 한도 초과 시 전체 복제를 취소합니다.

## 주의
- 일지 DB 구조 v15입니다. 기존 구조를 올리기 직전 자동 백업하며 예전 앱으로 새 구조를 열 수 없습니다. 되돌아가려면 이전 백업 사본을 사용하세요.
- 복제는 미완료·일회성 항목으로 생성하며 시작 시각/원래 마감일을 보존합니다. 대상 주가 업무 비활성 기간이면 실행을 막고 재활성을 안내합니다.
- 작업 브랜치 검토용 RC 번호입니다. 설치 파일 생성·main 반영·정식 릴리스는 이 변경만으로 실행하지 않습니다.
