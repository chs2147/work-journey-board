# 날짜 복제·공유 연결·인사이트 개선

## 새 기능
- 주간/데일리 항목 ⋯ › **날짜로 복제…**에서 대상일과 범위를 확인해 복제합니다. 본 항목은 하위까지 함께, 하위 하나는 독립 본 항목으로 추가합니다.
- 메모·Cabinet은 같은 원본 객체를 공유하고 새 항목의 연결만 추가합니다. 다른 주의 메모 배지에서 원본 주차를 확인하고 원본 객체를 엽니다.
- 업무 타임라인 목록과 활동 업무 이름 열의 경계를 드래그·키보드로 조절하고 공간별로 기억합니다.

## 개선
- 이전 내역 가져오기도 실제로 추가한 항목의 메모·Cabinet 연결을 함께 가져옵니다. 완료 묶음 제외·중복 생략을 유지하며 한 번에 되돌릴 수 있습니다.
- 활동의 기록 일수 제목·표시 열을 제거했습니다. 이름 열을 조절하면 날짜 격자가 남은 폭에 맞춰 유연하게 늘고 줄며 가로 스크롤을 만들지 않습니다.
- 연결 없는 메모에는 빈 띠를 표시하지 않습니다. 항목 삭제 시 관계만 정리하고 메모 본문을 유지하며, 삭제 취소에서 원래 연결을 복원합니다.
- 관계 저장·연결 한도·실패 롤백과 공유 원문 편집 보존, 백업의 현재 DB 구조 검증을 보완했습니다. RC2 검증 결과를 정식 반영합니다.

## 주의
- 일지 구조 v15입니다. 기존 일지는 이전 직전 자동 백업 후 전진 마이그레이션하며 예전 앱으로 새 구조를 열 수 없습니다. 이전 앱을 사용하려면 이전 구조 백업 사본을 선택하세요.
- 복제 항목은 미완료·일회성으로 생성하고 시작 시각과 원래 마감일을 유지합니다. 대상 주에 업무가 표시될 수 없거나 메모 연결 20개 한도를 넘으면 전체 복제를 차단합니다.
- Windows 기본 설치판과 macOS 유니버설 DMG를 함께 제공합니다. Windows 오프라인 설치판은 별도 요청 시 제공합니다.
