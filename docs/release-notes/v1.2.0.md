# 검색

## 새 기능
- **검색**(`Ctrl+Shift+F` 또는 상단 검색 칸): 요일별 업무 기록과 메모 보드(글 상자·이미지 설명·링크 카드·관계선 이름표)를 한 번에 찾습니다. 결과마다 어디서 찾았는지 꼬리표가 붙고, 주별로 묶여 찾은 글자가 형광으로 보입니다.
- 결과를 누르면 그 주의 그 칸 항목, 또는 그 메모 상자로 바로 갑니다. `F3`·`Shift+F3`와 보드 위 노란 띠의 ▲▼로 결과를 차례로 확인하고, [검색 초기화]를 누를 때까지 결과 기준 보기가 유지됩니다.
- 거르기(전체·업무 기록·메모 보드)와 기간(전체·올해·최근 12주)을 고를 수 있습니다.

## 고친 점
- 항목에 마우스를 올릴 때 매주 반복(↻) 단추가 휴지통 자리에서 옮겨 가며 겹치던 것
