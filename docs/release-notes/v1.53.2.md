# Open Beta — 보안 점검 확정 2건 수정

## 수정
- **Markdown 내보내기가 고른 폴더 밖에 쓰지 않게**: 업무 보드·주간 메모를 Markdown으로 내보낼 때 이미지 파일 이름을 일지에 저장된 ID로 만들었습니다. ID에 `..` 같은 경로 조각이 들어 있는 일지(공유·동기화 폴더에서 받은 파일 등)는 고른 폴더 밖의 그림 파일을 덮어쓸 수 있었습니다. 이제 경로 중간의 `..`·`.`을 화면과 Rust 두 곳에서 모두 거부합니다. 이미지 확장자는 정해진 목록(png·webp·jpg·gif)에서만 정하고, 글자·숫자·`_`·`-`가 아닌 문자가 섞인 ID에는 `image-1.png`처럼 번호 이름을 붙입니다. 이미지마다 저장 전에 경로를 다시 검사합니다. 보통 일지의 파일 이름은 그대로입니다.
- **동기화로 받은 기록이 이 기기 설정을 덮지 않게**: 온라인 공간에서 다른 기기가 보낸 기록을 받을 때 보내기 쪽 규칙을 확인하지 않아, 변조된 기기가 이 기기의 Cabinet 폴더 경로나 백업 보관 설정을 바꿀 수 있었습니다. 이제 Cabinet 폴더 항목의 경로는 서버에서 받지 않고 이 기기에서 지정한 경로를 유지합니다. 설정은 백업·AI를 받지 않고, 화면 설정은 칸반 열 순서만 받습니다. 공간이 함께 쓰는 설정은 그대로 동기화됩니다.
- **보안 점검 요약 문서**: `docs/security-audit-1126.md`(확정 2건·실기 확인 3건·보강 권고)를 더했습니다.
