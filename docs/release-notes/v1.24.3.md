# 메모 보드 크게 보기 도구 막대 위치 수정

## 수정
- **메모 보드 크게 보기의 왼쪽 도구 막대 위치**: 주간·데일리 뷰에서 메모 보드를 [크게 보기]로 바꾸면 왼쪽 도구 막대(텍스트·링크·이미지 넣기 등)가 메모 보드 왼쪽이 아니라 화면 맨 왼쪽 대메뉴(레일) 자리로 붙던 문제를 고쳤습니다. 중요 업무 목록이 열려 있으면 목록 위로, 닫혀 있어도 레일 위로 겹쳐 있었습니다.
  - 크게 보기에서도 도구 막대의 기준을 메모 보드로 고정해, 중요 업무 목록 열림/닫힘과 주간/데일리 뷰에 상관없이 메모 보드 왼쪽에 붙습니다.

## 주의
- 사용자 요청 main 직접 패치. 데이터 형식 **구조 v19 유지**, 외부 통신·새 의존성 변화 없음.
- Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 가이드
- 변경 없음(장면 글·스크린샷은 크게 보기 도구 막대 위치를 다루지 않음). 대응표 기준 판만 1.24.3으로 갱신.

## 설치 후 확인
- 중요 업무 목록을 연 채 주간 뷰·데일리 뷰에서 메모 보드 [크게 보기] → 도구 막대가 메모 보드 왼쪽에 있고 레일·중요 업무 목록을 가리지 않는지.
