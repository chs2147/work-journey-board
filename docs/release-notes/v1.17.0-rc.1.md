# 백업 버전·복원·보관 정책 검증판

## 새 기능
- 백업 파일명·이력에 생성 앱과 실제 DB 구조를 표시합니다. 구형 이름도 지원하며 과거 앱 버전은 추정하지 않습니다.
- 백업 이력·복원에서 현재 지원 구조와 실제 백업 구조를 비교하고 새 구조·정보 불일치·손상을 차단합니다.
- 일일 기간/개수·월간 개수·선택적 용량 목표와 정리 미리보기를 제공합니다. 보호 사본·최신 정상 일일 사본은 유지합니다.

## 주의
- 일지 DB 구조는 v14이며 추가 구조 변경은 없습니다. 기존 사용자의 보관 정책은 유지합니다. 용량 목표는 보호 사본 때문에 초과할 수 있습니다.
- 정책 적용 시 표시된 자동 백업이 실제 삭제되며 되돌릴 수 없습니다. 목록 변경 시 다시 확인합니다.
- 정상 복원에서 현재 보관 정책을 유지하고, 파손 복원은 정책 검토 전까지 자동 삭제를 보류합니다.
- RC 검증판입니다. Windows 기본 설치판과 macOS 유니버설 DMG를 함께 제공합니다.

## 가이드
- 장면12·대응표·실제 설정 화면·HTML·PDF 갱신.

## 호환성
- 이전 앱은 새 파일명 백업을 복원 목록에서 인식하지 못합니다. 새 백업의 목록/버전 검사는 v13 지원 앱에서 사용하세요. 새 형식도 SQLite DB 한 파일이며 별도 동반 파일은 없습니다.
