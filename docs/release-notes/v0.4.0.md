# 최적화·백업 보강·앱 안 복원

## 새 기능
- **백업에서 복원**: 설정 › 데이터·백업 [백업에서 복원…], 또는 "데이터 파일에 문제가 있습니다" 화면에서 백업을 고르면 먼저 검사해 요약(업무 수·기록 줄 수·마지막 기록일)을 보여 주고 복원합니다. 지금 파일은 지우지 않고 backups 폴더에 `…_before-restore.db`로 보관하며, 복원 직후 [되돌리기]로 돌아갈 수 있습니다.
- **자동 백업 보강**: 앱을 켜 둔 동안 바뀐 게 있으면 2시간마다 그날 사본을 새로 씁니다. 켤 때는 보드가 먼저 뜨고 백업은 입력이 쉬는 틈에 뒤에서 합니다(상태 줄 "백업 중…"). 아무것도 고치지 않았으면 닫을 때 백업을 건너뛰어 빨리 닫힙니다.
- **보조 백업 위치(선택)**: 설정 › 데이터·백업에서 다른 드라이브·폴더를 고르면 그날 사본을 거기에도 하나 더(최근 3일치) 남깁니다. 기본은 꺼져 있습니다.
- **진단 정보**: 설정 › 업데이트·정보에서 화면 메모리·일지 크기·이미지·백업 폴더 용량을 보고 [복사]할 수 있습니다(기록 내용은 들어가지 않음).
- 설정 › 데이터·백업에 백업 폴더 개수·용량이 보입니다.

## 고친 점
- 1년치 일지에서 주를 오가며 보고 고칠수록 메모리가 계속 늘던 문제 — 메모 이미지를 표시용 작은 사본으로, 보이는 크기만큼만 그리고 주를 옮기면 바로 해제합니다.
- 주를 넘길 때 다시 읽던 업무·설정·태그·반복 규칙을 다시 읽지 않습니다(조회 약 절반).
- `Alt+←`/`Alt+→`를 빠르게 여러 번 눌러도 누른 만큼 정확히 이동합니다.
- 쓰는 도중 파일이 깨지면(디스크 오류 등) 더 쓰지 않고 복원 화면으로 안내합니다.

## 주의
- 데이터 형식: 변경 있음(구조 v7 — 메모 이미지 표시용 사본 칸 추가). 처음 켤 때 `backups\…_pre-migration-v7.db`가 자동으로 생깁니다. 기존 이미지는 그대로 두고, 표시용 사본은 그 이미지를 처음 볼 때 만들어 채웁니다.
- 되돌려 설치: 0.3.0 이하는 v7 일지를 열지 않습니다("앱을 업데이트하세요") — 되돌리려면 `_pre-migration-v7` 백업으로 복원하세요.
- 외부 통신: 변화 없음
