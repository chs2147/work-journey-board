# 데일리 뷰 전체 가져오기 단추 제거·메모 사진 크게 보기 레이어 수정

## 수정
- **메모 사진 크게 보기 레이어**: 주간 뷰 메모 보드의 사진을 크게 볼 때 크게 보기 화면이 메모 도크 안에 갇혀, 위쪽 보드·상단 막대·왼쪽 레일 등 일부 기능이 흐림 없이 그대로 보이고 누를 수도 있던 문제를 고쳤습니다.
  - 크게 보기를 브라우저의 **최상위 레이어**(네이티브 모달 창)로 띄웁니다. 앱 화면 전체가 흐려지고, 뒤 화면은 누르기·초점 이동·화면 읽기가 막힙니다. 크게 보기 안에서 누른 단축키(주 이동·뷰 전환 등)도 뒤 화면에 전달되지 않습니다.
  - 앞으로 더해지는 기능이 z-index를 얼마나 크게 잡든 크게 보기 위로 올라오지 않습니다. `Esc`·[닫기]·바깥(어두운 곳) 누르기로 닫고, 닫으면 원래 초점으로 돌아갑니다.

## 고친 점
- **데일리 뷰 [전체 가져오기] 단추 제거**: 날짜 줄 오른쪽의 "직전일 전체 가져오기" 단추를 뺐습니다. 카드별 [가져오기], 단축키 `Alt+Shift+P`, 주간 뷰 요일 머리 ⋯ 메뉴의 전체 가져오기는 그대로입니다.

## 주의
- 사용자 요청 main 직접 패치. 데이터 형식 **구조 v19 유지**, 외부 통신·새 의존성 변화 없음.
- Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 가이드
- 변경 없음(장면 글에 데일리 뷰 [전체 가져오기] 단추·크게 보기 레이어 설명이 없음). 대응표 기준 판만 1.24.2로 갱신.

## 설치 후 확인
- 주간 뷰 메모 보드에서 사진을 크게 보기 → 앱 화면 전체가 흐려지고 위쪽 막대·보드·레일이 눌리지 않는지, `Esc`로 닫히는지.
- 데일리 뷰 날짜 줄에 [전체 가져오기] 단추가 없고, `Alt+Shift+P`는 그대로 되는지.
