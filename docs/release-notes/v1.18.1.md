# Feature List 문서 체계·시그니처 타임라인 구분선 대비

## 개선
- 시그니처 테마의 업무 타임라인에서 월 아래·주차 사이 구분선을 진한 갈색으로 표시해 배경과 명확히 구분합니다.
- 현재 기능을 고정 Feature ID, 최초 제공·RC·개선·제거 버전, 출처·구현 위치로 관리하는 문서 체계를 추가했습니다.
- 검토용 Excel에 현재 기능, 버전별 포함, 배포 프로필 비교, 변경 이력, 근거, 미제공 항목, 검토 의견 입력을 정리했습니다.

## 주의
- Feature List는 저장소 문서·Excel 산출물이며 앱에 새 기능 화면이나 기능 토글을 추가하지 않습니다.
- 독립 파생 제품과 Windows/macOS/오프라인 패키징을 구분합니다. 현재 제품은 하나이며 오프라인판은 요청 때만 빌드합니다.
- 일지 DB 구조 v14 유지. Windows 기본 설치판과 macOS 유니버설 DMG를 함께 제공합니다.

- 장면06의 외부 AI 활용 문구를 현재 수정본·복사 동작에 맞췄습니다.
