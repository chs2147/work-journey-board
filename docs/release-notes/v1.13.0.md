# 업무 항목 마감일 — 중요 업무 "마감일이 있는 업무"

## 새 기능
- **마감일**: 항목에서 `Alt+U`(맥 `⌥U`) 또는 ⋮⋮ 항목 메뉴(오른쪽 클릭) › **⏳ 마감일…** — 빠른 단추(오늘·내일·이번 주 금·다음 주 월·다음 주 금·+2주), 달력(`←→↑↓`), 숫자 바로(`1026`·`20261026`), `Enter` 저장 · `Delete` 지우기 · `Esc` 취소.
  - 항목 오른쪽 아래 꼬리표 `⏳ 10/26(월) D-4` — 지나면 빨강 `⏳ 10/20 · 2일 지남`, 당일 `⏳ 오늘 마감`, 7일 안 주황, 그 뒤 회색(색만으로 구분하지 않고 글이 함께). 꼬리표를 누르면 바꾸기·지우기.
  - 본 항목·세부 항목 모두, 데일리 뷰도 같은 꼬리표.
- **정하면 ★ 중요 표시도 함께** 켜집니다. 마감일을 지워도 ★는 남고, ★를 꺼도 마감일은 남습니다(패널에서만 빠짐).
- **중요 업무 패널 맨 위 "⏳ 마감일이 있는 업무"**: 마감 임박순(지난 것 맨 위 → 같은 마감이면 시작 시각 → 기록 날짜), 줄 오른쪽 `D-4`·`오늘 마감`·`2일 지남`, 아래 줄 `업무 · 마감 · 기록`. 이 묶음에 든 항목은 아래 날짜 묶음에 다시 나오지 않습니다. 처리 완료하면 "이 주 완료"로.
- 마감이 지난 항목이 있으면 레일 ★에 빨간 점.
- 엑셀 원장에 `마감일` 열(J), 통합 검색 결과 줄에 `⏳ 10/26`, Universe 항목 상세에 "마감 10/26 (월)".

## 주의
- 데이터 형식: **구조 v12 → v13**(업무 항목 `due_date` 열) — 처음 켤 때 일지마다 `_pre-migration-v13` 백업을 만든 뒤 올립니다. 올린 일지는 1.12 이하 판에서 열 수 없습니다(새 판 안내, 데이터는 그대로).
- 마감일은 주간 요약(자동 집계)에 넣지 않고, 직전 기록 가져오기·매주 반복으로 복사하지 않습니다. 다른 날로 옮겨도 마감일은 그대로입니다.
- 알림·소리는 없습니다(패널·꼬리표·레일 점으로만).
- 외부 통신: 변화 없음
- 검증용 `1.13.0-rc.1`로 확인한 뒤 정식 판으로 반영했습니다(2026-11-04).
