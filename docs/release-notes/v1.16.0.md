# 항목 완료·가져오기·직각 띠 개선

## 새 기능
- 일반·중요 업무 항목마다 모노그램 아이콘으로 완료/완료 취소할 수 있습니다. 행에 마우스를 올리거나 키보드로 접근하면 아이콘이 표시됩니다.
- 완료된 본문에는 취소선을 표시하고, 중요 업무에서 완료한 상태도 같은 항목에 반영합니다. 완료 상태 배지는 항상 표시됩니다.
- 완료를 취소하면 완료 전 별표 상태를 복원합니다. 일반 항목에는 별표가 새로 생기지 않습니다.

## 고친 점
- 완료 항목은 이전 기록 가져오기에서 제외합니다. 완료된 상위 항목의 하위 항목도 전부 제외하고, 미완료 상위 항목의 완료 자식만 있으면 그 자식만 제외합니다.
- 직전 기록이 모두 완료면 가져올 항목이 없음을 안내합니다. 더 오래된 날로 자동으로 거슬러 가지 않습니다.
- 강조 띠·별표·본문 사이 여백을 확보하고 모든 강조 띠를 직각으로 정리했습니다.
- 글자색 버튼은 A+사각 색상칩으로, 팔레트는 기본색 복원과 직각 색상칩으로 정리했습니다.
- 좁은 주간 칸의 과도한 줄바꿈·행 높이를 줄이고, 완료 아이콘 표시 전후 행 크기를 유지합니다.

## 주의
- **일지 구조 v14**: 일반 항목의 완료 전 중요 여부를 보존합니다. 구조 변경 직전 자동 백업 후 트랜잭션으로 적용합니다. RC1·RC2에서 이미 v14로 변경했다면 추가 구조 변경은 없습니다.
- v14로 올린 일지는 이전 v13 앱으로 직접 열 수 없습니다. 이전 앱으로 되돌릴 때는 마이그레이션 전 백업 사본을 사용하세요.
- 기존 본문은 변경하지 않습니다. Windows 기본 설치판·macOS 유니버설 DMG를 함께 제공합니다.

## 가이드
- 장면 02·03·04·05의 완료·가져오기·직각 팔레트 설명과 화면은 RC2와 동일합니다. 기준 판과 HTML·PDF를 정식 1.16.0으로 갱신했습니다.
