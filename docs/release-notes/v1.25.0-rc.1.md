# 칸반 보드 · 업무 타임라인 요일별 묶음·실제 완료일 (검증용)

## 새 기능
- **칸반 보드**: 왼쪽 레일 주간 보드와 인사이트 사이(`Alt+6`). 본 항목이 카드가 되어 **TODO**에서 시작하고, 카드를 통째로 끌어 다른 열에 놓으면 상태가 바뀝니다(`Alt+Shift+←`/`→`도 가능).
  - **DONE**에 놓으면 완료 — 끝나지 않은 세부 항목도 함께 완료됩니다. 알림의 [되돌리기]로 되돌리면 그때 함께 끝난 세부만 되살아납니다. DONE은 끝낸 날로 묶여 한 줄씩 접혀 있습니다.
  - **사용자 섹션**: TODO와 DONE 사이에 "검토 중"·"보류" 같은 단계(최대 8개, 이름·5색·순서). TODO·DONE은 고정. 섹션을 지우면 그 카드는 TODO로 돌아갑니다. 사용자 섹션에 둔 ★ 카드는 중요 업무 목록에서 빠지고(★는 유지) 칸반에서만 보입니다.
  - **상태 이력**: 카드 ⋯ › [상태 이력] — 칸반·주간 보드·중요 업무 목록·일괄 완료 어디서 바꿨든 시각과 함께 모두 남습니다.
  - **업무 항목 추가 창**(`N`): 업무·날짜(기본 오늘)·섹션을 고르고 주간 보드와 같은 키(`Enter`·`Tab`·`Alt+I`·`Alt+U`·`Alt+O`·`Ctrl+Enter`)로 적으면 주간 보드 그 날 칸에 들어갑니다.
  - **일괄 완료**: TODO ⋯ › [일괄 완료…] — 날짜 이전 카드를 미리 보고 빼고 싶은 것을 끈 뒤 한 번에 완료(완료일 = 각 기록일 또는 오늘). ⋯ › [최근 일괄 처리]에서 묶음째 되돌립니다.
  - 거르기: 업무 · 기간(오늘 · **이번 주**(기본) · 최근 2주 · 4주 · 12주 · 전체 · 지정일), 정렬(최신·오래된·마감).
  - 왼쪽 중요 업무 목록은 그대로 — ✓ = DONE, 항목을 누르면 칸반 카드가 강조됩니다.
  - Cabi.NET 폴더·링크 줄을 카드 위에 끌어 놓으면 그 항목에 연결됩니다.
- **설정 › 화면 › 시작 화면**: 주간 보드(기본) / 칸반 보드 — 공간마다 따로.

## 고친 점
- **업무 타임라인 요일별 묶음**: 주 안에서 날짜마다 `요일 + 월/일`을 한 번만 쓰고 그날 항목을 그 아래에 묶습니다. 경과 복사 글도 같은 묶음 형식(`(월) 10/12` 줄 아래 `- 항목`).
- **실제 완료일 표시**: 기록한 날이 아닌 날에 끝낸 항목은 ✓ 옆에 `완료 2026-10-27 (화)`. 같은 날 끝냈으면 지금처럼 ✓만(일괄 완료를 기록일로 처리한 항목도 ✓만).
- 주간 보드·중요 업무 목록에서 본 항목을 완료해도 끝나지 않은 세부 항목이 함께 완료됩니다(칸반과 같은 규칙).

## 주의
- 데이터 형식: **구조 v19 → v20**(칸반 섹션·항목 섹션 열·상태 이력·일괄 완료 되돌리기 자료) — 처음 켤 때 일지마다 `_pre-migration-v20` 백업을 만든 뒤 올립니다. 이미 완료한 항목에는 완료 시각으로 TODO → DONE 이력 한 줄을 채웁니다. 올린 일지는 1.24 이하 판에서 열 수 없습니다(새 판 안내, 데이터는 그대로).
- 이번 판은 Cabi.NET 줄 → 카드 연결만 지원합니다. 카드를 메모 보드·Cabi.NET 창으로 끌어 놓는 연결은 들어 있지 않습니다(설계 14절, 후속 검토).
- 외부 통신·새 의존성 변화 없음.
- 검증용 판입니다(정식 릴리스 전 실기 확인). Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.
