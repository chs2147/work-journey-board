# Open Beta — 메모보드 노트 바로가기, 업무노트 블록 메뉴 다듬기, 보안 알림 정리

## 개선
- **노트 바로가기**: 주간 메모보드와 Cabi.NET 업무 메모보드에 붙인 업무노트가 노트 내용(본문·첫 그림) 없이 **제목만 보이는 바로가기**로 바뀝니다. 노트 아이콘 · 제목 · `업무노트 · 업무 이름` · ↗로 보이고, 더블클릭·Enter·↗로 노트 창을 엽니다. 선택하면 왼쪽 위에 [항목 연결]·[카드만 삭제]가 나타납니다. 원본 노트가 지워졌으면 제목 취소선과 `원본 없음`으로 표시합니다.
  - 높이는 내용에 맞춰 고정하고 너비만 조절합니다. 이미 붙여 둔 노트 카드도 바로가기 모양으로 보이며, 저장 형식은 바뀌지 않습니다.
  - 주간 메모를 원본 연결한 카드는 지금처럼 글 미리보기로 보입니다.
- **업무노트 블록 메뉴**: 표 칸에서 글을 고치는 중에 블록 메뉴가 뜻하지 않게 열려 표를 가리던 문제를 고쳤습니다.
  - `/` 블록 메뉴는 **빈 줄 맨 앞**에서만 열립니다. 표 칸·코드·문장 중간의 `/`는 글자 그대로 들어갑니다.
  - 이끌이나 `/`로 연 메뉴는 **메뉴 밖을 누르면 닫힙니다**. `/` 뒤에 글자를 이어 쓰거나 `/`를 지워도 닫힙니다.
  - 메뉴는 창 안에 다 들어오게 놓이고(아래 자리가 모자라면 블록 위로), [닫기]는 스크롤해도 늘 맨 아래에 보입니다.
- **보안 알림 정리**: GitHub 보안 탭의 알림을 정리했습니다.
  - 엑셀 라이브러리 안의 `uuid`와 개발 도구의 `minimatch`, Rust `url`을 고친 판으로 올렸습니다.
  - 노트 HTML을 글자로 바꿀 때 겹친 태그를 끝까지 지우고, 노트를 Markdown으로 내보낼 때 코드 조각이 깨지지 않게 했습니다.

## 주의
- **1.52.0도 Open Beta입니다**(2.0.0에서 정식). 일지 구조 **v20 유지**, 새 의존성 없음(기존 의존성 판올림만), 운영 서버 변경 없음.
- 이전 main 1.51.0은 `release/v1.51.0` 브랜치에 보존했습니다.
- Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 가이드
- 장면11 — 원본 연결 카드 문단에 노트 바로가기, 블록 이끌이 문단에 빈 줄 맨 앞 `/` 메뉴·메뉴 밖 클릭으로 닫기(스크린샷 변경 없음).

## 설치 후 확인
- 자료함에서 업무노트를 업무 보드로 끌어 놓으면 제목만 보이는 바로가기가 생기고, ↗·더블클릭으로 노트가 열리는지. 예전에 붙여 둔 노트 카드도 같은 모양인지.
- 업무노트 표 칸에서 `A/B`를 입력해도 메뉴가 열리지 않는지, 이끌이 메뉴를 연 뒤 메뉴 밖을 누르면 닫히는지.
