# Open Beta — 보안 점검 알림 2건 정리

## 수정
- **Markdown 가져오기의 HTML 정리**: 업무노트에 Markdown을 가져올 때 들어 있는 HTML 덩어리를 글자로 바꾸는 방식을 정규식 지우기에서 **한 글자씩 읽기**로 바꿨습니다. 꺾쇠 안과 `<script>`·`<style>` 안의 글은 버리고, 결과에는 `<`·`>`가 남지 않습니다. 가져온 글은 예전처럼 글자로만 들어갑니다(GitHub 코드 점검 알림 #11).
- **V2 설계 시안 파일**: 저장소의 설계 시안(`docs/v2-design/mockups/step6`)이 주소의 장면 이름을 허용 목록에서 꺼낸 값으로만 그리게 했습니다. 앱과 소개 사이트에는 들어가지 않는 파일입니다(알림 #4).

## 주의
- 1.52.0 배포 뒤 GitHub 코드 점검(CodeQL)이 알린 2건을 고친 main 패치입니다. **1.52.1도 Open Beta**, 일지 구조 **v20 유지**, 새 의존성·외부 통신·운영 서버 변경 없음.
- 이전 main 1.52.0은 `release/v1.52.0` 브랜치에 보존했습니다.
- Windows 기본판과 macOS 유니버설 DMG를 함께 빌드합니다.

## 가이드
