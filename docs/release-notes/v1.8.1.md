# 워크스페이스 전환 무결성 긴급 수정

## 고친 점
- **워크스페이스를 바꾸면 메모 이미지가 지워지던 결함**(1.8.0): 공간을 바꾼 직후 메모 정리가 "이전 공간의 메모"를 기준으로 "새 공간의 이번 주 이미지"를 지워, 메모 판에 "그림을 찾을 수 없습니다"가 뜨던 문제를 고쳤습니다. 이제 메모 저장·이미지 정리는 늘 그 메모를 읽어 온 공간의 일지에만 합니다.
- 공간을 바꾸는 동안 친 글·메모·요약 수정본은 떠나는 공간에 저장한 뒤 닫고, 남은 예약 저장·실행 취소 기록·그림 캐시는 다음 공간으로 넘기지 않습니다.
- 같은 결함이 있던 **설정 › 저장 위치(다른 폴더의 일지로 바꾸기·옮기기)**, **백업에서 복원**, **데이터 파일 문제 화면으로 넘어갈 때**도 같은 방식으로 고쳤습니다.

## 주의
- 데이터 형식: 변경 없음(구조 v10 그대로)
- 외부 통신: 변화 없음
- 1.8.0에서 이미 지워진 이미지는 이 판으로 되살아나지 않습니다. 이미지를 붙인 날보다 앞선 백업(`backups` 폴더)에는 남아 있을 수 있습니다.

- 변경 없음
