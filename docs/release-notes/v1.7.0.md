# 시작 시각 · 다른 날로 옮기기

## 새 기능
- **시작 시각**: 회의처럼 그날 몇 시에 시작하는 항목에 `Alt+O`(맥 `⌥O`)로 시각을 붙입니다 — 15분 단위, 항목 앞에 `⏰ 10:00`. 숫자로 바로(`1430`), `↑`/`↓` 15분씩, 꼬리표를 누르면 바꾸거나 지웁니다. 중요 업무 패널에도 시각이 보이고 같은 날 안에서 시각 순, 엑셀 원장 시트 맨 끝에 `시작 시각` 열.
- **다른 날로 옮기기**: `Alt+D`(맥 `⌥D`) — 다음 주·이전 주 같은 요일·내일, 또는 달력에서 고른 날의 같은 업무 칸 맨 아래로. 본 항목이면 세부 항목까지 함께, ★·⏰·↻·Cabinet·메모 연결은 그대로 따라갑니다(★는 중요 업무 패널 날짜도 바뀜). 알림의 [그 날로 가기]·[되돌리기], `Ctrl+Z` 한 번으로 원래대로.
- 두 기능은 항목에 커서를 두면 나오는 **⋯** 또는 항목 **오른쪽 클릭** 메뉴에도 있습니다.

## 고친 점
- 첫 실행에서 업무 이름을 쓰고 `Enter` 없이 [보드 열기]를 누르면 업무가 생기지 않던 것.
- 맥에서 한글로 업무 이름을 쓰고 `Enter`를 한 번 누르면 들어가지 않던 것(첫 실행·[+ 업무 추가]).
- 메모 보드 상자의 ⋯ 단추가 그림 위에서 거의 보이지 않던 것 — 흰 바탕·테두리로 또렷하게, 상자를 고른 채 `Shift+F10`으로도 메뉴.
- 메모 상자에 연결된 항목을 다른 주로 옮겨도 연결 띠에 새 날짜로 보입니다.

## 주의
- 데이터 형식: **구조 v10**(항목 시작 시각 칸 추가) — 업데이트 직후 자동 백업(`_pre-migration-v10`) 뒤 바뀝니다. 1.6.0 이하로 되돌려 설치해도 일지는 열리지만 시작 시각은 보이지 않고, 그 판에서 칸을 고치면 그 칸의 시작 시각이 지워질 수 있습니다.
- 외부 통신: 변화 없음
