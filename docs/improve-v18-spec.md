## 1. 추천 조합

최초 추천은 A였으며 사용자는 **C 왼쪽 세로 팔레트 + 접기/펼치기**를 선택했다. 접힌 상태에도 다시 여는 손잡이를 항상 남긴다. 접힘 상태는 PC UI 설정으로 저장하고 편집 중인 내용을 지우거나 포커스를 강제로 옮기지 않는다. 노트의 문서 작업은 상단의 짧은 아이콘+텍스트, 보드의 생성/클립보드/위젯은 하단의 묶음으로 구분한다. 보드 이름·저장 상태·자료함/주간 메모 패널·내보내기/창 작업은 상단에 남긴다. 업무 보드와 주간 보드의 공통 도구는 같은 순서와 아이콘을 쓴다. 주간 보드에는 업무 전용 Live Widget 묶음을 표시하지 않는다.

| 안 | 배치 | 특징 |
|---|---|---|
| A 추천 | 캔버스 하단 중앙 플로팅 | 시선 이동이 짧고 가로 공간 활용. 툴바 높이+여백만큼 마지막 객체에 접근 가능한 스크롤 여유 제공 |
| B | 캔버스 상단 고정 도구줄 | 기존 구조와 가장 가까움. 캔버스 높이를 차지하지만 객체를 가리지 않음 |
| C | 왼쪽 세로 도구 팔레트 | 도구가 늘어도 세로 확장. 좁은 창에서 보드 가로 공간 감소 |

공통: 생성(텍스트/이미지/링크), 클립보드(겹친 문서=선택 객체 복사 / 클립보드+문서=객체 붙여넣기), Live Widget(경과일/타임라인/중요 업무), 보기(맞춤/관계선/확대·축소)를 구분선으로 그룹화한다. 아이콘은 단색 선형 SVG, 선택 상태는 면/테두리/aria-pressed로 표시한다. 강조 띠는 모두 직각. 실제 객체 드래그용 복제 핸들과 도구줄의 복사 명령은 구분한다.

확장 시 type/id/icon/label/description/context/group를 가진 도구 등록 목록을 사용한다. 그룹마다 최대 3~4개를 우선 노출하고 나머지는 ‘더 보기’에 배치한다. 가로폭 부족 시 기능을 삭제하거나 페이지 전체를 가로 스크롤시키지 않고 그룹별 메뉴로 접는다. 툴팁은 기능명+한 줄 설명+실제 단축키, hover와 키보드 focus에 모두 제공하고 Esc로 닫는다. 아이콘 버튼에 접근 가능한 이름을 유지한다.

**단축키 주의:** Ctrl+C/V를 연상하는 아이콘으로 바꾸되 기존 객체 명령 Ctrl+Alt+C/V(맥 표기는 기존 변환)를 유지한다. Ctrl+C/V를 전역으로 가로채면 텍스트/표 편집과 충돌한다. 향후 변경은 편집/선택/이미지 붙여넣기 우선순위를 별도 설계한다.

## 2. 업무 노트

- 제목 위 `CABI.noteOwner` 고정 설명을 제거한다. 제목·본문 기준선과 여백은 유지하고 빈 설명 행은 남기지 않는다.
- 현재 + 단독 버튼은 이미지 입력을 연다. **이미지**(그림 아이콘), +가져오기는 **가져오기**(문서+안쪽 화살표)로 구분한다. 후자는 Markdown 구조 가져오기이며 툴팁으로 지원 형식을 설명한다. 내보내기는 기존 기능 유지.
- 목차의 IconTune은 짧은 제목줄과 들여쓰기된 목록줄로 구성된 **목차 아이콘**으로 교체한다. 시각적 토글 상태/aria-expanded와 ‘목차 열기/닫기’ 이름 제공.
- 테이블은 이미 TableKit과 열 경계 resize를 사용하지만 행/열 명령 UI가 없다. 표 안 hover/focus 시 행 왼쪽과 열 위쪽에 이끌이를 노출한다. **행 위/아래 추가·행 삭제**, **열 왼쪽/오른쪽 추가·열 삭제**, 표 메뉴 **머리글 행 전환·표 삭제**를 제공한다. 마지막 행/열 삭제는 표 삭제 영향 안내를 거친다. 삭제와 이동을 혼동하지 않게 이번 범위의 표 이끌이는 메뉴용으로만 사용한다.
- 표 메뉴를 열 때 셀의 ProseMirror 위치를 기억한다. 다른 셀에 커서를 옮겨도 엉뚱한 행/열에 적용되지 않게 selection을 복원하며 문서가 바뀌면 위치를 다시 검증한다. Tab은 셀 이동 유지, 마지막 셀 Tab은 기존 새 행 동작 유지. 키보드는 셀 메뉴 단추 또는 Shift+F10에서 표 명령 접근.
- 일반 문서의 순서 목록은 `1. → 1-1. → 1-1-1.` 계층 번호를 표시한다. 형제는 마지막 번호 증가, Shift+Tab 승격 시 재계산. 기존 listItem의 sink/lift 명령을 재사용하고 Tab/Shift+Tab은 순서 목록 안에서만 처리한다. 표의 Tab은 가로채지 않는다.
- 번호는 원문에 문자열로 삽입하지 않고 중첩 구조에서 계산한다. 시작 번호(start)/목록 분리·병합/부모 이동/Undo/붙여넣기를 검증한다. Markdown은 표준 중첩 순서 목록으로 내보내고, 편집 화면/PDF에서 계층 번호를 일치시키도록 번호 생성 규칙을 공용화한다. 표준 Markdown 뷰어는 자체 번호 표현을 사용할 수 있다.

## 3. 보드와 허브

- 허브의 **보드 미리보기 보기 버튼**을 제거한다. 업무 보드 열기/목록·카드 보기는 유지한다. 저장된 hub view=board는 목록으로 안전하게 전환한다. 노트 우측 미리보기 패널의 별도 토글과 혼동하지 않는다.
- 업무 보드 창 제목을 `<업무명> — Cabi.NET · 업무 메모보드`로 변경한다. 보드당 하나라는 도메인 제약은 그대로다.
- 주간 보드의 ‘이번 주 메모’ 보이는 제목만 제거하고, 영역의 aria-label/검색·메뉴 명칭은 유지한다. 위치 확보용 빈 heading은 남기지 않는다.
- 업무 보드의 텍스트·이미지·링크·자료 참조·주간 메모 참조·라이브 위젯 모두 네 모서리/변 손잡이로 너비·높이 조절한다. 주간 보드에도 공유 객체 손잡이 체계를 적용한다. 이미지 resize는 프레임 조절이며 원본 비율은 보존하고 contain으로 표시(잘라내기/왜곡 없음). 텍스트·카드는 고정 높이에 내용이 넘치면 내부 스크롤, 편집/표 선택 중에는 드래그를 시작하지 않는다.
- 기존 h는 일부 객체에서 측정값이다. 명시적 사용자 높이를 auto 측정값과 분리하고, ResizeObserver가 사용자의 크기를 덮어쓰지 않게 한다. 최소 크기/최대 내보내기 해상도 제한, 좌표 확대율 반영, Shift 비율 잠금, Esc 취소, 한 gesture당 Undo 1회, 다중 선택/관계선 앵커/미니맵/PNG 내보내기까지 함께 검증한다.
- 기존 문서는 기본 auto 높이로 무손실 표시한다. 새 사용자 크기 메타데이터가 필요하면 기존 마이그레이션을 수정하지 않고 신규 버전 게이트를 추가한다. 설계 단계에서 DB 버전/정식 앱 버전을 먼저 올리지 않는다.

## 4. Universe

레퍼런스는 실제 티저의 `site/features.js` canvas/`features.css` Universe 씬이다. 짙은 남색 바탕, 별 레이어, 청록/보라 성운, 중심 광원과 부드러운 궤도·원근감을 앱의 은하/초점 모두에 적용한다. 마케팅 샘플의 가짜 노드를 실제 기록 노드로 이식하지 않는다.

- 3D는 별/성운을 실제 데이터 노드와 분리한 배경 레이어로 구성한다. 카메라 회전·줌·은하↔초점 전환과 연속성을 유지한다. hover/선택 노드와 라벨은 배경보다 명확한 대비를 갖는다.
- 2D/정적 모드에도 동일한 우주 색과 성운 정지 프레임을 사용한다. 다이나믹 모드에서는 약한 별빛 변화/느린 배경 이동만 더하며 기록이 임의로 위치를 바꾸거나 선택 노드가 떠다니지 않는다.
- prefers-reduced-motion·사용자 정적 선택·백그라운드 탭에서는 지속 애니메이션을 멈춘다. WebGL 비가용 fallback도 같은 배경 계열을 사용한다. 해상도/DPR·입자 수 상한·dispose 및 탭 복귀 시 과도한 delta 방지로 GPU 부하를 제어한다.
- 아래 시안의 Universe는 연출 검토용 가상 SVG다. 실제 티저 씬/실제 앱 화면과 구분하며 앱 카메라·원본 데이터·성능 검증을 대신하지 않는다.

## 5. 구현 및 검증 순서

1. 툴바 A/B/C 선택 및 세로 크기 정책 확인 후 공통 도구 등록/아이콘/문구 정리.
2. 표 명령·중첩 번호·Markdown/PDF 경로 구현 및 실제 표/목록 편집 회귀.
3. 모든 객체 resize·실행 취소·영속 저장·관계선·내보내기 구현. 이미지 자산은 복제/재압축하지 않음.
4. Universe 배경/모션과 reduced-motion·정적/비활성 탭·WebGL fallback 확인.
5. 노트·이미지·보드 크기를 넣고 공간 3회 왕복, 열린 창 종료/삭제·다른 공간 응답 방지. DB 변경 시 직전 백업/복원/구 앱 차단.
6. 가이드·Feature List/Excel·릴리스 문서를 동반 갱신하고 브라우저/CSP·Windows 기본판/macOS를 검증한다. 이 단계의 설계 시안은 앱 구현 완료로 기재하지 않는다.

선택할 핵심 결정은 **툴바 A/B/C**다. 나머지는 위 추천 정책을 기본으로 구현할 수 있도록 정리했다. 이번 문서·시안은 커밋/푸시/배포 전이며 구현은 시안 검토 뒤 진행한다.


## 6. C안 구현 기록

- `improve-v18`, 검증판 1.22.0-rc.1 / DB18. C안에 별도 접기/펼치기를 적용하고 PC UI 설정에 상태를 보관한다. 보드 접기와는 별개이며 닫힌 팔레트에도 펼치기 손잡이를 남긴다. 도구는 생성→클립보드→Live Widget(업무 보드 전용)→보기 순서다.
- 이미지/가져오기와 목차 아이콘·문구 정리, 표 행/열 이끌이와 명령, 계층 번호 decoration/Tab/Shift+Tab 및 PDF 번호, 허브 보드 미리보기 버튼 제거를 구현했다. 표 이끌이는 셀 선택/focus 시 제공하며 임의의 행/열 이동까지 지원한다고 표시하지 않는다.
- 모든 객체는 공통 8방향 손잡이를 사용한다. 별도 `frameH`를 파서·복제·저장에 보존하고 자동 측정 높이와 구분한다. 이미지 원본을 재가공하지 않으며 프레임 안에 비율을 유지한다. 실제 지원 범위는 기존 객체별 너비 제한(텍스트160~960px·이미지80~1600px·링크200~640px), 높이 80~1200px(위젯 최소160px)다. 한 gesture당 실행 취소, Esc 취소, 방향키 크기 변경을 지원하고 기존 공간 전환 gesture 취소/epoch 가드에 연결했다.
- 신규 migration0018은 업무 보드 갱신일 인덱스와 구 앱 재저장 방지 버전 게이트다. 기존 migration은 바꾸지 않으며 DB17→18 직전 자동 백업과 구 앱 차단을 검증한다.
- Universe의 실제 3D 캔버스를 투명 렌더링해 은하/초점/정적 2D에 공통 성운·별빛 배경을 적용했다. 동적 별빛·성운 연출은 CSS 로컬 레이어이고 reduced-motion/숨긴 탭/정적 선택을 따른다. 노드의 실제 위치·원본 데이터·선택 상태는 변경하지 않는다.
- 구현 중 팔레트의 containing block 문제로 메인 레일을 가리는 것을 발견해 보드 영역 안으로 한정했다. 크기 조절 후 포커스를 가진 객체가 Alt+방향키 주차 이동까지 소비하는 문제도 modifier 가드로 보완했다.
- 전체 단위 520개, Cabi.NET/새 v18/공간 왕복 브라우저 22개 통과. 추가 주간 메모/Universe/CSP 회귀 검사를 수행하고 가이드 실제 화면·Feature List/Excel을 동반 갱신한다. OS 설치·WebKit·네이티브 빌드는 별도이며 이 작업에서는 커밋/푸시/배포를 실행하지 않는다.


최종 확인: 전체 단위520개와 추가 객체별 폭 보존 회귀 검사, 새 v18/기존 Cabi.NET/공간 전환22개, 주간 메모/새 v18/CSP20개가 통과했다. Universe·스냅샷 회귀도 확인했다. 타입/린트/포맷·웹 빌드·Feature List/릴리스 노트/가이드 일치 검사를 통과했다. 실제 C안 [펼침](mockups/v18/implemented-open.png) / [접힘](mockups/v18/implemented-folded.png), 가이드 장면05/11/14 화면과 HTML/PDF를 갱신했다. 이미지 폭은 기존 제한을 보존하며 드래그 정리 콜백은 종료 때 해제한다.


## 7. 툴바 배치 후속 수정안 — 승인 및 구현

사용자 후속 피드백에 따라 [수정 시안](mockups/v18/toolbar-refinement/index.html)을 별도로 작성했다. 확대/축소·화면 맞춤·최대화/최소화·스크린샷은 기존 상단 오른쪽 위치로 복귀한다. 객체 연결 도구는 생성 그룹에 둔다. 팔레트의 상자 개수/카테고리 명칭은 보이는 화면에서 제거하고 생성/클립보드/라이브 위젯 논리 그룹과 접근 가능한 이름은 유지한다. 아이콘을 각 그룹 내 한 줄당 하나씩 1열로 배치하고 그룹 사이 직선 구분선만 남긴다. 접기/펼치기는 외곽선 없는 작은 꺾쇠와 얇은 손잡이, 충분한 비가시적 입력 영역으로 정리한다. 접혀도 펼치기 손잡이는 남긴다.

**사용자가 이번 수정 시안으로 구현을 승인했다. 상단 보기 도구를 복귀시키고, 팔레트는 카테고리명/개수 표시 없이 1열 정렬·구분선·미니멀 손잡이로 반영했다. 보기 도구는 팔레트를 접어도 유지된다. 위의 최초 C안 캡처는 이전 구현이며 최신 가이드/실제 캡처로 대체한다.**

후속 툴바 수정 검증: 640px 창의 상단 도구/팔레트 비겹침, 펼침/접힘 시 보기 도구 유지, 명칭/개수 숨김과 1열 정렬을 확인했다. 메모·이미지·스크린샷 및 계층 번호/표 회귀를 통과했고 타입·린트·웹 빌드·포맷과 가이드/Feature List 일치 검사를 확인했다. 실제 펼침/접힘 캡처와 가이드 HTML/PDF도 갱신했다. 커밋/푸시/배포는 실행하지 않았다.
