## 1. 진단 정보 여백
- 원인: `<details>`가 카드 안에서 여백 없이 붙어 있음(다른 카드는 행마다 좌우 20px).
- 수정: 진단 정보 영역 = 위 구분선 + 좌우 20px·아래 20px(카드의 설정 행과 같은 여백). 내용·동작은 그대로.

## 2. 패널 가로 폭 자유 조절
- 대상: **중요 업무 패널(왼쪽, 기본 264px)**, **주간 요약 패널(오른쪽, 기본 360px)**. 데일리 뷰의 메모|카드 경계는 이미 끌어서 조절됨(그대로).
- 조작: 패널 안쪽 가장자리(8px)에 올리면 `↔` 커서 + 강조선 → 끌어서 폭 조절, **두 번 누르면 기본 폭**, 손잡이에 포커스 후 `←/→` = 10px씩.
- 범위(추천): 중요 업무 220~520px, 주간 요약 300~720px. 보드가 너무 좁아지면(900px 미만) 지금 규칙대로 주간 요약은 겹쳐 뜬다.
- 기억: 일지 설정 `ui.importantPanelW`·`ui.summaryPanelW`(구조 변경 없음 — settings JSON 안의 값). 다음에 켜도 그 폭.

## 3. 데일리 뷰 메모 [크게 보기]
- 데일리 뷰 메모 머리에도 주간 뷰와 같은 [크게 보기] 아이콘. 누르면 메모가 데일리 뷰 전체(날짜 띠·카드 자리까지)를 덮고, `Esc`·[작게 보기]로 돌아간다. 카드의 입력 상태(커서·되돌리기)는 숨긴 채 그대로.
- 메모 폭이 좁아 머리 단추가 두 줄이 되는 경우(시안에서 보임)는 구현 때 배율 표시를 줄여 한 줄로 맞춘다.

## 4. 데일리 뷰(이름·날짜 이동)
- 이름: 화면·툴팁·도움말·문서의 "오늘 뷰" → **"데일리 뷰"**(단축키 `Alt+V` 그대로, 툴팁 `데일리 뷰 · 10/22(목) (Alt+V)`). 설정 값 이름(`viewMode: "today"`)은 내부 값이라 그대로.
- **날짜 이동 띠**(카드 위): `‹  월 10/19 · 화 10/20 · … · 일 10/25  ›  [오늘]`
  - 보고 있는 날 = 강조색 칸, 오늘 = 테두리, 기록이 있는 날 = 작은 점, 연차·반차는 점 대신 글자(`연차`·`오전 반차`).
  - 날짜를 누르면 그 날로, `‹ ›` = 하루씩(주를 넘으면 그 주를 불러옴 — 지금의 `Alt+←/→`와 같은 동작), [오늘]은 오늘이 아닐 때만.
  - 상단 `◀ ▶`·`Alt+←/→`도 그대로 둔다(추천).

## 5. 가져오기 미리보기 값 표시
- 원인: 표의 숫자 칸 CSS 이름(`.num`)이 위쪽 단계 표시의 동그라미 번호(`.num`)와 같아 숫자가 동그라미로 그려짐.
- 수정: 숫자 칸 이름을 따로 두어 표 숫자로(가져올 항목·지금 기록 `10 +메모`). 회귀 E2E에서 숫자 칸 모양을 확인한다.

## 6. 메모 글 속 링크 ↗
- 링크 글자 끝에 작은 ↗ 아이콘(편집되지 않는 장식 — 메모 내용·자동 집계·엑셀에는 들어가지 않음).
- **↗를 누르면 OS 기본 브라우저**로 연다(링크 열기 규칙 그대로 — 앱은 접속하지 않음). 올리면 `기본 브라우저에서 열기 — 주소` 툴팁.
- 링크 글자 자체를 누르면 지금처럼 **편집**(커서 이동), `Ctrl+클릭`은 지금처럼 바로 열기.
  - 다른 안: 글자를 그냥 누르면 바로 열기 — 링크 글자를 고치기 어려워져서 추천하지 않음.

## 8. 새 판 안내 띠
- 바탕 = 테마 강조색(시그니처 갈색 · 라이트 파랑 · 다크 밝은 파랑), 글자 = 반전색, 앞에 ↑ 아이콘.
- 문구: `새 판 1.1.0이(가) 있습니다 · 지금 판 1.0.0 · 설치 전에 일지를 자동으로 백업합니다`
- 단추: [자세히·설치] = 반전(밝은 바탕·강조색 글자), [나중에] = 테두리만.
