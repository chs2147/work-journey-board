## 1. 업무일지 내보내기

### 1-1. 이름

- 창 제목·주간 보드 [내보내기] 단추 툴팁: "업무일지 내보내기 (Alt+E)". 단추 글자 "내보내기"와 `Alt+E`는 그대로.
- 저장 대화상자 제목: 엑셀 = "엑셀 파일로 저장"(그대로), 마크다운 = "마크다운 파일로 저장".
- 함께 고칠 곳: 코칭 T0 "엑셀로" 단계·T2 "내보내기" 단계 문구, 이용 가이드 장면07·부록 단축키 표.

### 1-2. 창 구성(시안 A 추천)

```
┌ 업무일지 내보내기                      [엑셀|마크다운] ┐  ← 타이틀(형식 토글은 오른쪽)
├──────────────────────────────────────────────────────┤
│ 범위  ○ 이번 주 / ○ 최근 4주 / ○ 기간 지정 /           │
│       ○ 연도 [2026년 ▾] / ○ 전체                       │
│ - - - - - - - - - - - - - - - - - - - - - - - - - - - │
│ 업무  [전체 ▾]                                          │
├──────────────────────────────────────────────────────┤
│ 포함  (형식에 따라 바뀜)                                │
├──────────────────────────────────────────────────────┤
│ 미리 계산  N주 · 업무 N개 · 항목 N개                    │
│ (안내 글)                         [취소] [저장 위치 선택…] │
└──────────────────────────────────────────────────────┘
```

- 구분선은 `--line` 1px 가로선(구역 사이). 구역 안 여백·글자 기준선은 지금 창과 같다. 키보드만으로 끝까지 되는 것은 그대로(토글·업무 목록 모두 Tab·방향키·Space/Enter).
- B안(형식을 맨 위 별도 구역)은 더 눈에 띄지만 창이 길어진다 → A안 추천.

### 1-3. 범위 — 연도

- 범위 선택지 다섯: 이번 주 · 최근 4주 · 기간 지정 · **연도 [YYYY년 ▾]** · 전체.
- 연도 목록 = 첫 기록 연도 ~ 이번 연도(최신 위). 기록이 없으면 이번 연도 하나.
- 범위 = 그 해의 ISO 주(W01~마지막 주) 중 **첫 기록 주 ~ (이번 연도면 이번 주)**로 잘라 빈 주가 수십 개 생기지 않게 한다(결정 D3). 옆에 실제 주 범위를 보인다.
- 파일 이름: 그 해 전체 `업무일지_2026년.xlsx`, 이번 연도처럼 일부면 `업무일지_2026년_W38~W43.xlsx`(공간 이름 규칙은 지금과 같음).

### 1-4. 범위 — 업무

- [업무 ▾] 단추 → 칸반 보드 업무 거르기와 같은 목록(전체 업무 · 체크해서 여러 개 · 행 끝 [이것만]). 단추 글자: 전체 / 업무 이름 하나 / "업무 N개".
- 목록 = 범위 안에 보이는 업무 + 범위 안 기록이 있는 종료 업무, 보드 순서.
- 고른 업무만: 주간보고 시트 행 · 원장 행 · 마크다운 업무 절 · 미리 계산.
- **주간 요약**: 저장된 수정본·AI본은 전체 업무 기준이라, 업무를 고르면 **고른 업무만으로 자동 집계**를 쓴다(창에 안내 한 줄, 결정 D5). 전체면 지금처럼 수정본 > AI본 > 자동 집계.
- 주간 메모(글)·메모 보드 스냅샷은 업무와 상관없는 주 단위 자료라 업무를 골라도 그대로 넣는다(D5).
- 고른 업무는 다음에 열 때 기억하지 않는다(늘 "전체"로 시작 — 고른 채 잊고 내보내는 실수 방지, D4).
- 파일 이름: 1개면 `_업무이름`, 여러 개면 `_업무N개`를 범위 앞에 붙인다(예: `업무일지_협력사 보안 점검_2026-W40~W43.md`).

### 1-5. 파일 형식

| | 엑셀(.xlsx) | 마크다운(.md) |
|---|---|---|
| 포함 | 주간보고 시트 · 원장 시트 · 주간 요약 시트 · 메모 보드 스냅샷(지금 그대로) | **업무 기록** · **주간 요약** · **주간 메모**(글만, 그림 제외) |
| 기본 | 주간보고·원장 켬 | 업무 기록·주간 요약 켬, 주간 메모 끔 |
| 저장 | `.xlsx`(지금 길) | `.md` 하나 — 그림 폴더 없음 |

- 마지막에 고른 형식은 기억한다(설정 `ui.exportFormat`, 구조 변경 없음 — 설정 JSON 안 값).
- 마크다운 쓰기는 기존 `Platform.writeExport` + `exportPathProblem(…, "markdown")` + Rust `export_write`(`.md` 이미 허용) — **새 Rust 명령·새 권한 없음**.

### 1-6. 마크다운 모양(`src/export/journalMarkdown.ts`, 순수 함수 + 골든 시험)

```
# 업무일지 2026-W40~W43
업무: 전체 · 내보낸 날 2026-10-22

## 2026-W43 (10/19 ~ 10/25)

### 차세대 정산 시스템 구축
- 10/20 (화)
  - 야간 배치 02~04시 확정
    - 운영팀 공유 완료
- 10/21 (수) · 연차(오후)
  - 배치 재시도 정책 정리 ✓

### 주간 요약
(수정본·AI본·자동 집계 중 최종 — 업무를 고르면 고른 업무 자동 집계)

### 주간 메모
(메모 상자 글만)
```

- 업무 → 날짜 → 항목, 세부 항목은 한 단계 더 들여쓴다. 항목 안 줄바꿈은 같은 들여쓰기로 이어 쓴다.
- 처리 완료(`flagDoneAt`) 항목은 끝에 ` ✓`. 연차·휴일 표시는 날짜 옆(`· 연차(오후)`).
- 기록이 없는 업무·주는 쓰지 않는다(그 주에 아무 기록이 없으면 `## 주` 아래 "기록 없음" 한 줄).
- 글 안 `#`·`*` 등 마크다운 기호는 그대로 둔다(사용자가 쓴 글 보존 — 노트 마크다운 내보내기와 같은 원칙).

### 1-7. 미리 계산

- "N주 · 업무 N개 · 항목 N개" — 고른 업무로 센다(`exportStats(from, to, categoryIds?)`).
- 안내 글(요약 행 안내·스냅샷 크기 안내·업무 고름 안내)은 이 구역에, 단추는 맨 아래 오른쪽.

## 2. 메모보드 텍스트 객체 아래 여백

### 2-1. 원인(재현함)

- 상자 테두리 손잡이(v18 자유 프레임)를 잡으면 **너비만 바꾸는 옆면 손잡이(◀▶)라도** 그때 높이를 `frameH`로 고정한다. 최소 80px이라 한 줄 상자(높이 약 64px)는 바로 아래가 16px 넘게 빈다.
- 고정된 뒤에는 글을 줄여도 높이가 그대로라 빈칸이 커진다(브라우저 모드 재현: 64px → 80px, 글 아래 9px → 25px).
- 연결 띠(업무 항목 연결)가 있는 상자도 같은 규칙이라 "단추 있는 객체든 없는 객체든" 생긴다. 주간 메모보드·업무 메모보드가 같은 상자 코드를 쓴다.

### 2-2. 고침(A안 추천)

- **텍스트 상자 높이는 늘 글에 맞춘다.** 텍스트 상자의 테두리 손잡이는 옆면(◀▶)만 남겨 너비만 바꾼다(노트 바로가기와 같은 `widthOnly`). 위·아래·모서리 손잡이는 텍스트 상자에서 뺀다.
- 이미 저장된 텍스트 상자의 `frameH`는 화면·PNG 스냅샷에서 쓰지 않는다(값은 문서에 그대로 남김 — 되돌리기·예전 판 호환).
- 이미지·링크 상자와 Live Widget(정해진 높이)은 지금 그대로.
- 위 여백(8px)과 아래 여백(8px)을 같게 유지 — 글 마지막 줄 아래 여백 = 위 여백.

B안(높이 조절 유지 + 옆면 손잡이는 높이를 건드리지 않음 + 글보다 크게 늘린 높이만 허용)은 이미 생긴 빈칸이 남고 "높이 맞춤" 단추가 따로 필요해 추천하지 않는다.
