## 1. 들어가기 · 화면 틀

### 1-1. 들어가는 길 (시안 ③ A)
| 길 | 동작 |
|---|---|
| 왼쪽 레일 [인사이트] | 레일 위쪽 "보기" 묶음, 주간 보드 아래. 아이콘 = 세로 시간축 + 점 + 줄(흐름). 툴팁 `인사이트 (Alt+3)`. 열면 **마지막에 보던 업무**(처음이면 보드 첫 업무) |
| `Alt+3` | 보드 칸에 커서가 있으면 **그 칸의 업무**를 골라 연다. 인사이트에서 다시 누르면 보드로(토글) |
| 업무 머리 ⋯ 메뉴 | 맨 위에 **[경과 타임라인 보기]**(오른쪽에 `Alt+3`) — 그 업무로 연다 |
| 오늘 뷰 | 같은 레일·`Alt+3`. 인사이트에서 보드로 돌아오면 오늘 뷰 그대로 |

- 레일의 "만들지 않은 기능은 넣지 않는다" 규칙(Rail.tsx) 그대로 — S1에서 처음 아이콘이 생긴다.

### 1-2. 보드 상태 보존
- 인사이트는 보드를 **숨기기만** 한다(메모 [크게 보기]와 같은 방식, i-m3-plan 2절). 보던 주·뷰(주간/오늘)·편집 중 칸·스크롤·메모 도크가 그대로 남는다.
- 들어가기 전에 대기 중인 칸·메모 저장을 먼저 끝낸다(`flushAll`·`flushNote`) — 타임라인이 방금 친 글까지 보여 주게.
- `Alt+1`·레일 [주간 보드]·`Alt+3`(다시)·항목 클릭(6절)으로 보드에 돌아온다.
- 인사이트 상태(고른 업무·기간·종료 포함·펼친 달·검색어·스크롤)는 **앱 실행 중 유지**, 재시작하면 기본값(viz-spec 5-2). 고른 업무만 설정 `ui.insightCategory`에 기억(다음 실행 때 "마지막에 보던 업무").

### 1-3. 상단 바 (시안 ③ B)
- 1줄(워드마크)은 그대로.
- 2줄을 **인사이트 모드**로: `인사이트` 제목 + `기록이 어떻게 흘러왔나` … `[태그: 전체 ▾]` `저장됨 ✓` `[⚙]`.
- 감추는 것: 주 이동(◀ ▶·제목), [오늘], [연간 보기], 보기 아이콘, [주간 요약], [내보내기] — 모두 "보고 있는 주" 기능이라 인사이트에서는 뜻이 없다.
- 태그 필터는 남긴다 — 같은 필터가 인사이트 업무 목록에도 걸린다(3-2).

### 1-4. 탭
- viz-spec 5-1의 탭 2개(경과 타임라인 / 활동 개요) 중 **S1은 타임라인만** 만든다. 탭 줄은 개요 탭이 생기는 S2에서 함께 그린다(13절 #1). S1의 필터 줄 왼쪽에는 화면 이름 `경과 타임라인`만 보인다.

## 2. 필터 (S1 범위)

| 필터 | 값 | 기본 | 비고 |
|---|---|---|---|
| 기간 | 최근 4주 / 최근 12주 / 올해 / 전체 / 직접 지정(주 선택기: 시작 주 ~ 끝 주) | **최근 12주** | viz-spec 5-2 그대로. 탭 공통 상태(S2 개요도 같은 값) |
| 종료 업무 포함 | 토글 | 끔 | 켜면 업무 목록 아래 "종료된 업무" 묶음 |
| 업무 다중 선택 | — | — | **S2(개요 탭)에서**. 타임라인은 왼쪽 목록이 업무 선택(13절 #3) |

- 필터 줄 오른쪽에 지금 범위를 글로: `2026-W32 ~ W43 · 이번 주 2026-W43`.
- 기간 끝은 **이번 주**까지(직접 지정 제외). 단, 그 업무에 이번 주 뒤의 기록(미리 적어 둔 일정)이 있으면 그 주까지 늘린다 — 미래 기록이 잘리지 않게.
- 기간 밖에 기록이 더 있으면 타임라인 맨 위에 안내(8-3).

## 3. 업무 목록 (시안 ①)

### 3-1. 한 줄
`● 업무명` / 아랫줄 `마지막 10/22 · 항목 142`
- 마지막 기록일 = 그 업무의 가장 늦은 기록 날짜(기간 무관), 항목 수 = **지금 기간 안**의 항목 수(세부 포함). 기록이 없으면 `기록 없음`.
- 순서 = 보드 순서(진행 중), 그 아래 `종료된 업무` 구분선 + 종료된 업무(종료일 늦은 순). 종료된 업무 점은 속 빈 원.
- 고른 업무 = 옅은 파랑 바탕(`aria-current`). `↑↓` 고르기 → 타임라인이 바로 바뀜, `Enter`/`→` = 타임라인으로 포커스.

### 3-2. 태그 필터
- 상단 태그 필터(improve-1026-spec 4절)가 **업무 목록에도 걸린다**(보드·오늘 뷰와 같은 `matchesTagFilter`). 걸러져 목록에 없는 업무를 보고 있었다면 타임라인은 그대로 두고 목록 맨 위에 `필터에 가려진 업무를 보는 중 · [필터 해제]`.
- 업무 머리 줄에 그 업무의 태그 칩(최대 3개, 보드와 같은 `chipsToShow`).

## 4. 타임라인 본문

### 4-1. 머리 (시안 ①)
- `● 업무명 #태그` / `2026-07-06 시작 · 진행 중 · 기록한 주 14 / 16 · 항목 142`
  - 시작 = 첫 활성 구간 시작일. 상태 = `진행 중` / `종료 (05/29)`. 재활성 이력이 있으면 `· 재개 1회`.
  - `기록한 주 a / b` = 지금 기간에서 활성 주 b개 중 기록이 있는 주 a개.
- 오른쪽: [이 업무에서 찾기] 입력칸(5절), [경과 복사](7절).
- 종료된 업무면 머리 오른쪽에 **[다시 시작]**(overview 251행 — 기존 `reactivateCategory`, 실행 취소 가능).

### 4-2. 세로 시간축
- 위 = 과거 → 아래 = 최근. 처음 열 때·업무를 바꿀 때 **맨 아래(이번 주)로 스크롤**(viz-spec 1-3).
- 월 머리: `─ 2026년 10월 ─` (주는 **목요일이 속한 달** — 연간 보기와 같은 규칙, week.ts).

### 4-3. 주 행
- 왼쪽 고정 폭 열(118px): `W42` 굵게 / `10/12~18`. 이번 주는 `이번 주` 배지 + 옅은 파랑 바탕.
- 오른쪽: 그 주 항목을 날짜 → 칸 안 순서로. 본 항목 `(월) 내용`, 세부 항목은 들여쓰기 `· 내용`(자동 집계와 같은 표기, output-spec 2-2). 같은 날의 두 번째 본 항목부터도 `(월)`을 다시 쓴다(복사·검색 결과가 줄마다 홀로 읽히게).
- 그 주에 연차·반차가 있으면 항목 위에 작은 칩 `연차 10/21(수)` `오후 반차 10/23(금)`(13절 #6) — 기록이 없는 날의 이유가 보이게. 연차만 있고 그 업무 기록이 없는 주는 무기록 주로 접힌다(칩도 접힘 줄에 `연차 1일`로).

### 4-4. 항목 표시 — 보드에서 생긴 표시를 그대로
| 표시 | 타임라인 |
|---|---|
| ★ 중요(important-repeat-spec 2절) | 항목 앞 `★`(별 색) + 옅은 형광 바탕. 처리 완료(`flag_done_at`)된 것은 표시 없음 |
| ↻ 매주 반복으로 들어온 항목 | 항목 끝 흐린 `↻` |
| 기록 속 링크(improve-1026-spec 9절) | 보드와 같은 `LinkedText` — 밑줄 + ↗, `Ctrl+클릭`·↗ = 기본 브라우저(앱은 접속 안 함) |
| 연결된 메모(improve-1026v2-spec 4~7절) | 항목 끝 `메모 N ▾` 칩 → 누르면 항목 아래에 그 메모 글(읽기 전용, 이미지 상자는 `(이미지) 설명`, 링크 카드는 `(링크) 제목`)을 펼침(13절 #5) |
| 가져온 기록(M3-S0) | 구분하지 않음(i-m3-plan 6절 #9) |

### 4-5. 무기록 주 접기
- 그 업무의 **활성 구간 안**에서 기록 없는 주가 이어지면 한 줄 `· · · N주 기록 없음 (W37~W38) · · ·`. 1주도 접는다(`1주 기록 없음 (W40)`).
- 활성 구간 밖(종료 ~ 재개 사이)은 4-7의 `쉬는 구간`으로.

### 4-6. 오래된 달 접기
- **최근 3개월(오늘이 든 달 포함 3개 달)** 은 펼치고, 그 이전 달은 월 머리 한 줄로 접는다: `▸ 2026년 7월 · 4주 · 항목 23`(13절 #4). 누르거나 `Enter`로 펼침, 펼친 달은 `▾`로 다시 접기.
- "최근 12주"·"최근 4주" 기간에서는 대개 접을 달이 없다. "올해"·"전체"에서 의미가 있다.

### 4-7. 구간 구분선 (시안 ② B)
| 지점 | 표시 |
|---|---|
| 첫 활성 시작 | `▶ 시작 2026-03-02 (월)` (기간 안일 때만) |
| 종료 | `■ 종료 2026-05-29 (금)` |
| 종료 ~ 재개 사이 | 점선 상자 `쉬는 구간 18주 (W23~W40) — 업무가 종료된 동안` |
| 재개 | `▶ 재개 2026-10-05 (월)` |
- 활성 구간 밖의 기록(드물게 종료 뒤 같은 주에 적은 것)도 빼지 않고 그 주 행에 그린다.

## 5. 검색 (시안 ② A)
- 머리의 입력칸(`Ctrl+F`). 고른 업무의 지금 기간 안 항목 글(+ 펼친 연결 메모 글은 제외 — 항목만)에서 찾는다. 대소문자·전각 구분 없이 부분 일치.
- 일치 글자 노란 강조, **일치 없는 주는 흐리게**(숨기지 않음 — 흐름 유지, viz-spec 1-3). 무기록 접힘 줄·구분선은 그대로.
- 일치가 든 접힌 달은 **자동으로 펼침**(머리에 `일치 2`). 검색어를 지우면 원래대로 접힘(사용자가 직접 펼친 달은 펼친 채).
- 입력칸 옆 `2 / 5 일치`. `Enter`/`Shift+Enter` = 다음/이전(그 항목으로 스크롤 + 파란 테두리), `Esc` = 지우기(한 번 더 = 업무 목록으로).
- 검색은 화면 안 계산(저장소 조회 추가 없음).

## 6. 항목 → 보드 이동
- 항목을 누르거나(`Enter`) → **보드의 그 주·그 칸, 그 항목에 커서 + 잠깐 강조**(중요 업무 목록의 이동과 같은 `revealItem`). 인사이트는 닫히고 보드가 보인다(13절 #7).
- 보드에서 `Alt+3`·레일로 돌아오면 같은 업무·같은 스크롤·같은 검색어.
- 마우스를 올린 항목 줄 끝에 흐린 `보드에서 열기 ↗`. 링크 글자 위 클릭은 링크 규칙(`Ctrl+클릭`만 열기, 그냥 클릭은 이동)을 따른다.

## 7. [경과 복사] (시안 ② C)
- **지금 기간 전체**(접힌 달도 펼친 것처럼, 검색과 무관)를 평문으로 클립보드에(`Ctrl+Shift+C`). 토스트 `경과를 복사했습니다(14주 · 항목 142)`.
- 형식(자동 집계의 항목 표기를 주 단위로 이어 붙임 — 같은 함수 재사용, CLAUDE.md 4-4):
```
[업무 경과] 차세대 정산 시스템 구축
기간 2026-W32 ~ 2026-W43 (기록한 주 9 · 항목 61) · 2026-07-06 시작 · 진행 중

■ 2026-W35 (8/24~8/30)
- (화) 정산 배치 현행 분석 착수
- (목) 현행 배치 목록 30개 확인

(2026-W37~W38 기록 없음)

■ 2026-W42 (10/12~10/18)
- (월) 정산 배치 요구사항 2차 리뷰
  · 수수료 재계산 조건 3건 추가 확정
- (화) 배치 스케줄러 설계안 작성
  [메모] 야간 배치 시간대 후보: 02~04시 / 03~05시

── 종료 2026-05-29 ──
(쉬는 구간 18주: 2026-W23~W40)
── 재개 2026-10-05 ──
```
- ★·↻는 넣지 않는다(보고서용 평문). 연결된 메모는 그 항목 아래 `[메모] 첫 줄…`(여러 줄이면 같은 들여쓰기로 이어 씀, 13절 #10). 연차 칩은 넣지 않는다.
- 클립보드는 기존 `Platform.writeClipboard`(네트워크 없음).

## 8. 빈·적은 데이터 (시안 ② D)
1. 업무 미선택(업무가 하나도 없을 때만 — 그 밖에는 늘 하나가 골라져 있다): `업무를 고르면 기록이 시간순으로 펼쳐집니다`.
2. 기록 0건(그 업무 전체): `아직 이 업무의 기록이 없습니다` + [보드에서 기록하기 (Alt+1)].
3. 기간 밖 이전 기록: 타임라인 맨 위 `이 기간(최근 12주) 앞에도 기록이 8주 더 있습니다 — 2026-07-06 시작 · [기간: 전체로 보기]`(13절 #2).
4. 앱 전체 기록이 4주 미만: 필터 줄 아래 `기록이 4주보다 적어 흐름이 짧습니다 — 기존 일지를 가져오면 처음부터 이어서 볼 수 있습니다`(viz-spec 5-3 + M3-S0 연결, 설정 › 기존 일지 가져오기).
5. 기간 안에 기록 0건(전에는 있음): 무기록 접힘 한 줄 + 3번 안내.

## 11. 데이터 · 코드 배치

### 11-1. 저장소 (읽기 전용 조회 3개 — 스키마·쓰기 변경 없음)
| 메서드 | 쿼리 | 쓰는 곳 |
|---|---|---|
| `getCategoryEntries(categoryId, from, to): EntryItem[]` | `SELECT … FROM entry_item WHERE category_id = ? AND date BETWEEN ? AND ? ORDER BY date, seq` (색인 `ix_item_category(category_id, date)` 그대로 탐) | 타임라인 본문 |
| `getCategoryStats(from, to): { categoryId, first, last, inRange }[]` | `GROUP BY category_id` 한 번 — 처음·마지막 기록일(전체), 기간 안 항목 수 | 업무 목록 · 기간 밖 안내 · 4주 미만 안내 |
| `getWeekNotesBetween(fromWeek, toWeek): Record<WeekId, NoteDoc>` | `week_note` 범위 조회 + `parseNoteDoc` | 연결된 메모(`ref.item`) |
- 활성 구간은 기존 `listCategories().periods`, 연차는 기존 `getDayMarks(from, to)`, 태그는 기존 `getCategoryTags`.
- 1년치 한 업무 ≈ 항목 1,000개 수준 — 한 번에 읽어 화면에서 접는다(가상 스크롤 불필요). 접힌 달은 항목 줄을 그리지 않는다.

### 11-2. 도메인 `src/domain/insights.ts` (순수 함수, CLAUDE.md 3절)
| 함수 | 하는 일 |
|---|---|
| `periodRange(filter, today, lastRecordAfterToday?)` | 기간 필터 → `{ from, to }`(주 경계, 2절 규칙) |
| `buildTimeline({ items, periods, range, today, dayMarks, notes })` | 주 행·무기록 접힘·월 머리(접힘 여부·주 수·항목 수)·구간 구분선·쉬는 구간·이번 주·연차 칩·연결 메모를 **줄 목록**(`TimelineRow[]`)으로 |
| `monthOf(weekId)` | 목요일 기준 달(week.ts 위임) |
| `foldedMonths(rows, today)` | 4-6 접기 기본값 |
| `searchTimeline(rows, query)` | 일치 항목 id 목록 · 주별 일치 여부 · 펼칠 달 |
| `timelineText(rows, meta)` | 7절 평문 — 항목 줄은 `aggregate.ts`의 표기 함수 재사용 |
- 주차는 `week.ts`만(53주 연도·연말 걸친 주 포함), 활성 판정은 `categories.ts`와 같은 규칙.

### 11-3. 화면
- `src/ui/insights/InsightsView.tsx`(틀·필터 줄) · `CategoryList.tsx` · `Timeline.tsx`(줄 목록 렌더·키보드) · `insightsStore.ts`(고른 업무·기간·펼친 달·검색·스크롤 — 실행 중 유지).
