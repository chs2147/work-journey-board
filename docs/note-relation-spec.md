## 0. 요약

메모 판의 상자(텍스트·이미지·링크 카드)끼리 **관계선**(화살표)을 잇고, 고치고, 해제한다. 선은 상자 뒤로 지나가며 상자를 옮기면 따라온다.

| # | 항목 | 설계 요점 | 시안 |
|---|---|---|---|
| 1 | 보기 | 상자 가장자리에서 가장자리로 **둥근 모서리 꺾은선**(직각, 가로-세로-가로 / 세로-가로-세로), 기본 화살표 하나(→). 선 색 = 보조 글자색, 업무 색은 쓰지 않음 | ① |
| 2 | 잇기(마우스) | 상자에 마우스를 올리거나 선택하면 **연결점 2개**(왼쪽 가운데·아래 가운데) → 끌어서 다른 상자에 놓기 | ① |
| 3 | 잇기(키보드·메뉴) | 선택한 상자에서 `L` 또는 ⋯ [관계선 잇기…] → 후보 상자 번호·`Tab` → `Enter` | ② C |
| 4 | 고치기 | 선을 누르면 선택 + **선 도구 막대**: 방향(→ ↔ —) · 실선/점선 · 이름표(20자) · 방향 바꾸기 · 해제 | ② A |
| 5 | 해제 | 선 도구 [해제]·`Delete`, 상자 ⋯ 메뉴의 **관계선 목록 ✕**·[관계선 모두 해제]. 모두 토스트 [되돌리기]·`Ctrl+Z` | ② A·B |
| 6 | 따라 움직임 | 선은 저장하지 않고 늘 지금 상자 자리에서 계산 — 옮기기·폭·높이가 바뀌면 바로 맞음 | ③ B |
| 7 | 함께 지우기 | 상자를 지우면 그 상자의 선도(되돌리기 한 번에 둘 다) | ③ C |
| 8 | 보기 끄기 | 메모 머리의 **[관계선 보기]** 켜고 끄기(데이터는 그대로) | ①, ③ D |
| 9 | 미니맵·다크 | 미니맵에 가는 회색 선, 다크 테마 토큰 | ③ D |

- 데이터 변경: 메모 문서 JSON에 `edges` 배열(선택 필드)을 더한다 — **스키마·마이그레이션 없음**(5절).
- 외부 통신: 없음. 선은 판 안의 인라인 SVG(속성만, `style` 문자열 없음 — CSP 그대로).

## 1. 보기 (시안 ①)

### 1-1. 모양
- **경로 = 둥근 모서리 꺾은선**(10절 #5, 2026-10-27 사용자 결정):
  - 두 상자가 **가로로 더 떨어져 있으면** 마주 보는 옆면 가운데에서 나와 가로 → 세로 → 가로(가운데 x에서 꺾음), **세로로 더 떨어져 있으면** 아랫면/윗면 가운데에서 세로 → 가로 → 세로.
  - 마주 보는 면이 12px 이상 겹치면(같은 줄·같은 열) 꺾지 않고 겹친 구간 가운데로 **곧게**.
  - 꺾이는 곳은 반지름 **10px**로 둥글게(짧은 선분이면 그 절반까지). 끝은 테두리에서 **4px** 띄운다(화살촉이 상자 밑으로 들어가지 않게, 틈이 좁으면 줄임).
  - 두 상자가 겹치면(나갈 틈이 없음) 그리지 않는다. 계산은 `src/domain/noteEdge.ts` `routeEdge` 한 곳.
- **방향**: `→`(기본, 처음 잇는 쪽 = 출발) · `↔`(양쪽) · `—`(화살표 없음).
- **모양**: 실선(기본) · 점선(약한 관계·참고용). 굵기 1.5px, 선택 시 2.5px + 옅은 강조 띠.
- **이름표**(선택): 선 가운데의 둥근 알약, 최대 20자(예: `원인`·`후속`·`참고`·`서로 영향`). 비어 있으면 그리지 않는다.
- **색**: 선·화살촉·이름표 글자 = `--text-2`(라이트 `#5f5e5a` · 다크 `#c3c2b7`), 선택·잇는 중 = `--accent`. 업무 색·사용자 색은 쓰지 않는다(상자 배경색과 섞여 시끄러워짐).
- **겹침**: 선은 **모든 상자 뒤**(판 바로 위 층). 두 상자가 겹쳐 테두리 밖으로 나오는 선분이 없으면 그리지 않는다(상자 ⋯ 목록에는 남음).

### 1-2. [관계선 보기] (시안 ① 머리 오른쪽)
- 메모 머리 도구 줄 끝의 켜고 끄는 단추. 기본 켜짐. 끄면 판·미니맵에서 선과 연결점을 숨긴다(상자 ⋯ 목록·데이터는 그대로). 앱 실행 중 유지, 다시 켜면 켜짐(10절 #13).
- 관계선이 하나도 없는 주에는 흐리게(누르면 "상자의 연결점을 끌어 관계선을 이을 수 있습니다" 안내).

## 2. 잇기

### 2-1. 마우스 — 연결점 끌기 (시안 ①)
- 상자에 마우스를 올리거나 상자를 선택하면 **연결점**(흰 원 + 파란 테두리, 12px) 2개: **왼쪽 가운데**, **아래 가운데**. 위는 옮기기 막대, 오른쪽 가운데는 폭 손잡이라 피한다(10절 #3). 편집 중(글자 치는 중)에는 숨긴다.
- 연결점을 누르고 끌면 출발 상자 가장자리에서 커서까지 **파란 점선 + 화살촉**이 따라오고, 커서 아래 상자는 **파란 2px 테두리 + 옅은 파랑 바탕**(놓을 곳).
- 놓으면: 다른 상자 위 = 선 생성(→, 실선, 이름표 없음) + 그 선 선택(도구 막대가 바로 떠 이름표를 붙이기 쉽게) / **빈 곳·같은 상자 = 취소**(10절 #4) / `Esc` = 취소.
- 배율(줌)이 있어도 좌표는 문서 px(지금 상자 끌기와 같은 계산). 판 밖 상자로 잇고 싶으면 [화면에 맞춤]·축소 후 끈다(상자 옮기기처럼 가장자리 자동 스크롤은 없음).
- 대기 상자(글자를 아직 안 친 새 상자)는 연결점이 없고 놓을 곳도 될 수 없다.

### 2-2. 메뉴·키보드 (시안 ② B·C)
- 상자 ⋯ 메뉴 **[관계선 잇기…]**(단축키 표시 `L`) 또는 상자 선택 중 `L` → **잇는 중** 상태:
  - 다른 상자들에 가까운 순 번호(1~9) 표시, 이미 이어진 상자는 "이어짐".
  - 판 아래 안내 띠: `잇는 중: 남은 질문 → (고른 상자)` · `Tab` 다음 상자 · `1`~`9` 번호로 · `Enter` 잇기 · `Esc` 취소.
  - 마우스로 상대 상자를 눌러도 된다. "이어짐" 상자를 고르면 새로 만들지 않고 그 선을 선택.
- 상자 편집 중(글자를 치는 중)에는 `L`이 글자 그대로다 — 잇기 단축키는 **선택 상태**(Esc로 편집을 끝낸 상태)에서만.

### 2-3. 같은 쌍·자기 자신
- 같은 두 상자 사이에는 선 **1개만**(방향이 반대여도). 이미 있으면 새로 만들지 않고 그 선을 선택 + 토스트 `이미 이어져 있습니다`(10절 #9). 양쪽 화살표가 필요하면 그 선의 방향을 ↔로.
- 자기 자신에게는 잇지 않는다.

## 3. 고치기 (시안 ② A)
- 선(눈에 보이는 선 ±5px, 이름표 포함)을 누르면 **선 선택**: 선이 파랗고 굵어지며 양끝에 작은 점. 상자 선택은 풀린다(선과 상자는 한 번에 하나만 선택).
- **선 도구 막대**(선 가운데 아래, 배율과 상관없이 100% 크기 — 서식 막대와 같은 방식):
  | 단추 | 동작 |
  |---|---|
  | `→` `↔` `—` | 방향(누른 것이 눌림 상태) |
  | 실선 · 점선 | 모양 |
  | 이름표 | 막대 아래 입력 칸(20자, `Enter` 저장 · `Esc` 취소). 선을 **두 번 누르기**·선 선택 중 `Enter`도 같음 |
  | `⇄` | 방향 바꾸기(출발·도착 맞바꿈, → 일 때만 의미) |
  | 해제 | 선 삭제 |
- 키: 선 선택 중 `Delete`/`Backspace` = 해제, `Enter` = 이름표, `Esc` = 선 선택 풀고 출발 상자 선택으로, `Ctrl+Z`/`Ctrl+Y` = 메모 실행 취소·다시 실행(지금 메모 기록과 하나).
- 모든 변경(잇기·방향·모양·이름표·해제)은 **메모 실행 취소 1단계**씩.

## 4. 해제 (시안 ② A·B)
- **선 하나**: 선 도구 [해제] · 선 선택 중 `Delete`.
- **상자 ⋯ 메뉴 › 관계선 N개** 목록: 줄마다 `방향 기호 · 상대 상자 이름 · 이름표` + **✕**(그 선 해제). 줄에 마우스를 올리면 판의 그 선이 강조, 줄을 누르면 그 선 선택. 상대 상자 이름 = 텍스트 상자 첫 줄 / 이미지 설명(없으면 `(이미지)`) / 링크 카드 제목, 30자.
- **[관계선 모두 해제]**: 그 상자의 선 전부(한 번의 되돌리기로 복구).
- 키보드로 선 고르기: 상자 선택 중 `Shift+L` = 그 상자의 선을 차례로 선택(다시 누르면 다음 선).
- 해제·삭제는 확인 대화상자 없이 하고 토스트 `관계선을 해제했습니다 [되돌리기]`(여러 개면 `관계선 3개를 해제했습니다`).

## 5. 데이터

### 5-1. 메모 문서 JSON (week_note.doc — 스키마 변경 없음)
```json
{
  "v": 1,
  "boxes": [ … 지금 그대로 … ],
  "edges": [
    { "id": "019a…", "from": "<상자 id>", "to": "<상자 id>", "dir": "one", "dash": false, "label": "원인" }
  ]
}
```
| 필드 | 값 | 비고 |
|---|---|---|
| `id` | uuidv7 | |
| `from` · `to` | 같은 문서의 상자 id | `dir = "one"`이면 from → to |
| `dir` | `"one"` · `"both"` · `"none"` | 기본 `"one"` |
| `dash` | boolean | 기본 false(실선) |
| `label` | 0~20자, 줄바꿈·연속 공백은 한 칸 | 빈 글이면 이름표 없음 |

- **선택 필드**: `edges`가 없는 지금 문서는 그대로 읽힌다(관계선 0개). `v`는 1 그대로.
- **읽을 때 정리**(`parseNoteDoc`): 없는 상자를 가리키는 선, from = to, 같은 쌍의 두 번째 선, 알 수 없는 `dir`은 버리거나 기본값으로. 선 개수 상한 500(넘는 것은 버림 — 한 주 메모로는 충분).
- 좌표·높이는 저장하지 않는다 — 선은 늘 상자 자리(`x`·`y`·`w`·잰 `h`)에서 계산(1-1, 시안 ③ B).
- 상자 삭제·실행 취소·다시 실행은 문서 전체를 바꾸므로 선도 함께 따라간다(메모 기록 한 줄에 상자와 선이 같이 들어 있음).
- **이전 판과의 관계**: `0.2.13` 이하가 `edges`가 든 메모를 저장하면 `edges`가 빠진다(모르는 필드를 버림). 회사 PC는 한 판만 쓰므로 판올림 후에는 문제없음 — 되돌려 설치하면 관계선이 지워질 수 있다고 릴리스 노트에 적는다.

### 5-2. 다른 기능과의 관계
| 기능 | 처리 |
|---|---|
| 상자 복제 | 선은 따라오지 않는다 |
| 상자 ↔ 보드 항목 연결(타이틀 띠, v2 #4~#7) | 별개 — 관계선은 메모 상자끼리, 항목 연결은 상자와 보드 항목. 서로 영향 없음 |
| 다른 주 | 관계선은 그 주 메모 안에서만 |
| 주간 요약·엑셀·경과 타임라인 | **넣지 않는다**(화면에서 보는 관계, 10절 #12). 연결 메모의 글은 지금처럼 |
| [화면에 맞춤]·미니맵 범위 | 상자 기준 그대로(선은 상자 사이라 늘 안에 들어옴) |
| 이미지 정리(prune) | 관계 없음(선은 그림을 가리키지 않음) |
| 기존 일지 가져오기 | 가져온 메모 상자에는 선이 없다 |

## 6. 화면 읽기·키보드 요약
- 선마다 화면 읽기 글: `관계선: 배치 지연 원인 → 스케줄러 재설계 안, 이름 원인`(↔는 `↔`, 없음은 `—`). 선 SVG는 `role="img"`가 아닌 **선택 가능한 항목**(초점을 받는 `<g tabindex="-1">`)으로 두고, 상자 글(`aria-label`)에 `관계선 N개`를 덧붙인다.
- 단축키(모두 메모 판 안, 글자를 치는 중이 아닐 때): `L` 잇기 시작 · `Shift+L` 이 상자의 선 차례로 · `Tab`/`1`~`9`/`Enter`/`Esc`(잇는 중) · 선 선택 중 `Delete`/`Enter`/`Esc`. overview.md 10-3 단축키 표와 메모 판 안내에 함께 적는다.
- 보드 쪽 키보드 흐름(매일 기록 2분, CLAUDE.md 4-6)은 바뀌지 않는다 — 모두 메모 판 안의 선택 상태에서만 동작.

### 11-1. 설계와 달라진 점·구현에서 정한 것
- **선 경로 = 둥근 모서리 꺾은선**(10절 #5 사용자 결정). 시안 ①·③ A도 꺾은선으로 바꿨다.
- **선 도구 막대 모양**은 시안의 흰 막대 대신 **글 서식 막대와 같은 어두운 막대**(메모 판 안 도구를 한 모양으로). 이름표 칸만 흰 바탕.
- **상자 ⋯ 메뉴가 열린 동안 그 상자를 맨 위로** 올린다(메뉴 항목이 늘어 아래 상자에 가려지던 문제 — 텍스트·이미지·링크 카드 상자 모두, 관계선 전부터 있던 메뉴에도 같이 적용).
- **판(`.canvas`)을 쌓임 맥락으로**(`isolation: isolate`): 맨 뒤로 보낸 상자·선 층의 z가 0 아래여도 판 바탕 밑으로 숨지 않게.
- **키보드로 잇기는 가장 가까운 상자를 미리 골라 둔다** — `L` → `Enter`만으로 가장 가까운 상자와 이어진다(`Tab`·번호로 바꿈).
- **⋯ 목록에서 해제한 뒤 포커스를 그 상자로** 되돌린다(이어서 `Ctrl+Z`·`Shift+L`이 듣게).
- **이름표 칸**은 바깥을 누르면 저장(Enter와 같음), `Esc`만 취소.
- 가장자리 자동 스크롤은 넣지 않았다(상자 옮기기에도 없음 — 2-1절 문구 고침).
- 선의 눌림 영역(±6px)은 상자 밖에서만 잡힌다(선이 상자 뒤 층이므로).
