# 개선 v10 — 업무 항목 마감일 · 중요 업무 "마감일이 있는 업무" 묶음

> 상태: **승인**(2026-11-04, D1~D9 추천안) · 작업 브랜치 `improve-v10` 구현 → 검증판 `1.13.0-rc.1`(9절 기록) → **`v1.13.0` main 반영(2026-11-04)** · 보존 브랜치 `release/v1.13.0`
> 시안: `docs/mockups/1104v10/due-board.png`(①②③) · `due-panel.png`(④)

## 0. 요청(2026-11-04, 사용자)
- 업무 항목에 **마감일**을 정할 수 있어야 한다.
- 마감일을 정한 항목은 **중요 업무로 표시**되고, 중요 업무 목록에 **별도 "마감일이 있는 업무" 묶음**으로 마감일이 잡힌 업무만 모아 보여 준다.
- 나열 순서는 **마감 임박순**.

시작 시각(v8, `⏰ 10:00` — 그날 언제 시작하는지)과는 다른 것이다. 마감일은 **날짜 하나**(그날까지 끝내야 함)이고, 항목이 기록된 날과 달라도 된다.

## 1. 뜻과 규칙
- 항목 하나에 마감일(날짜) 하나. 본 항목·세부 항목 모두 가능(시작 시각과 같은 규칙).
- **마감일을 정하면 ★ 중요 표시가 함께 켜진다**(D1). 마감일을 지워도 ★는 그대로 둔다 — 중요 표시만 끄고 싶으면 ★를 누른다.
- ★를 끄면 마감일도 함께 지울지 묻지 않고 **마감일은 남긴다**(D2 추천 — 중요 업무 목록에서만 빠지고 보드 꼬리표는 그대로). 다시 ★를 켜면 마감일 묶음으로 돌아온다.
- 마감일은 기록한 날보다 앞이어도 된다(늦게 적은 기록) — 꼬리표가 "지남"으로 보일 뿐 막지 않는다.
- 완료(✓ 완료 뱃지, improve-1027v4-spec)한 항목은 마감일 묶음에서 빠져 "이 주 완료"로 간다 — 지금 중요 업무와 같다.

## 2. 화면

### 2-1. 보드 꼬리표 (시안 ①)
- 항목 글 **끝**에 `⏳ 10/26(월) D-4`(시작 시각 `⏰`는 글 앞 — 둘 다 있으면 앞·뒤에 하나씩).
- 남은 날·색은 **오늘 기준**:
  | 상태 | 글 | 색 |
  |---|---|---|
  | 지남 | `⏳ 10/20 · 2일 지남` | 빨강 |
  | 오늘 | `⏳ 오늘 마감` | 진한 주황 |
  | 7일 안 | `⏳ 10/26(월) D-4` | 연한 주황 |
  | 그 뒤 | `⏳ 11/14(금) D-23` | 회색 |
- 색만으로 구분하지 않는다 — 글("지남"·"오늘"·"D-n")이 늘 함께.
- 꼬리표를 누르면 마감일 고르기(2-3). 데일리 뷰도 같은 꼬리표.

### 2-2. 여는 길 (시안 ②)
- 항목 ⋮⋮ 손잡이 메뉴(오른쪽 클릭 같음) › **⏳ 마감일…** — "시작 시각…" 바로 아래.
- 단축키 **`Alt+U`**(맥 `⌥U`, D3 — 지금 비어 있는 글쇠 중 "마감(due)"에 가까운 것). 단축키 표(overview 10-3)·부록 함께 갱신.
- 꼬리표 누르기.

### 2-3. 마감일 고르기 창 (시안 ③)
- 제목: `마감일 — <항목 글>`.
- 빠른 단추: **오늘 · 내일 · 이번 주 금 · 다음 주 월 · 다음 주 금 · +2주**(이번 주 금이 지났으면 숨김).
- 달력(월요일 시작, 오늘 = 주황 테두리, 고른 날 = 파랑, ◀▶ 달 이동) — "다른 날로 옮기기" 달력과 같은 모양을 재사용.
- [지우기] · [취소] · [**10/26(월) 저장**](확인 단추에 고른 날).
- 키보드: `←→↑↓` 하루·한 주 이동 · `Enter` 저장 · `Delete` 지우기 · `Esc` 취소 · 숫자 바로(`1026` → 10/26, `20261026`도) — 시작 시각 창과 같은 감각.
- 새로 열 때 기본 선택: 이미 있으면 그 날, 없으면 **이번 주 금요일**(지났으면 다음 주 금요일).

### 2-4. 중요 업무 패널 (시안 ④)
- 맨 위에 새 묶음 **"⏳ 마감일이 있는 업무"**(D4 — 이름은 요청 그대로). 마감일이 있고 ★ 켜졌고 완료하지 않은 항목만.
- **정렬: 마감일 오름차순**(가장 임박한 것 위 — 지난 것이 맨 위) → 같은 마감일이면 시작 시각 → 기록 날짜.
- 줄 오른쪽에 남은 날 배지(`2일 지남`·`오늘 마감`·`D-4`), 아래 줄에 `업무 · 마감 10/26(월) · 기록 10/22(목)`(기록 날과 마감일이 같으면 "기록" 생략).
- 이 묶음에 든 항목은 **아래 날짜 묶음(지난 날짜·오늘·이번 주·다음 주 이후)에 다시 나오지 않는다**(D5 — 겹침 없음).
- 묶음 배경: 연한 살구 + 왼쪽 주황 띠(v9 "오늘" 묶음과 비슷하되 색으로 구분).
- 줄을 누르면 지금처럼 그 기록이 있는 날 칸으로 이동.
- **레일 ★ 배지**: 마감이 지난 항목이 있으면 빨간 점(지금 "지난 날짜" 표시와 같은 규칙에 마감 지남을 더함, D6).

## 3. 다른 기능과의 관계(추천안)
| 기능 | 마감일 | 이유 |
|---|---|---|
| 주간 요약(자동 집계) | **넣지 않음** | 보고 글 형식 그대로(골든 테스트 유지) |
| 엑셀 상세 기록 시트 | **`마감일` 열 추가** | 기록 보관용 |
| 직전 기록 가져오기·매주 반복 | **복사하지 않음** | 마감은 그 일만의 약속 |
| 다른 날로 옮기기 | **마감일 그대로**(날짜 고정) | 옮겨도 마감은 바뀌지 않음 |
| 통합 검색 | 결과 줄에 `⏳ 10/26` 작게 | 참고 |
| Universe | 항목 상세에 "마감 10/26(월)" 한 줄 | 참고(지도 모양은 그대로) |
| 알림·소리 | **하지 않음** | 외부 통신·방해 없이 패널·배지로만 |

## 4. 데이터 — 구조 v13
```sql
-- 0013_due_date.sql (전진 전용, 직전 자동 백업 _pre-migration-v13)
ALTER TABLE entry_item ADD COLUMN due_date TEXT
  CHECK (due_date IS NULL OR due_date GLOB '[0-9][0-9][0-9][0-9]-[0-1][0-9]-[0-3][0-9]');
CREATE INDEX ix_entry_item_due ON entry_item (due_date) WHERE due_date IS NOT NULL;
```
- 도메인 `src/domain/dueDate.ts`(순수): `dueState(today, due)`(지남·오늘·임박·나중 + 남은 날 수) · `dueLabel` · `parseDueInput` · `quickDues(today)` · `compareDue` + 단위 테스트.
- 중요 업무 묶음 `domain/important.ts` `groupImportant`에 `due` 묶음(맨 앞) 추가 + 레일 배지 규칙.
- 저장은 지금 칸 저장(`saveCells`)에 `dueDate` 추가(시작 시각과 같은 길) — 항목 id 그대로라 실행 취소 한 단계. 마감일을 정할 때 ★도 같은 저장에서 켠다.
- 가져오기(기존 일지 가져오기)·되돌리기 자료(`import_batch.undo_json`)는 마감일을 지우지 않게 보존(v10 `start_time`과 같은 처리).
- **되돌려 설치(1.12 이하)**: v13 일지는 옛 판에서 열리지 않는다(새 판 안내, 데이터 그대로) — 릴리스 노트 `## 주의`.

## 5. 무결성·안전
- 쓰기는 지금 칸 저장 한 길(`boardStore` → `JournalRepository.saveCells`) — 새 저장소 상태 없음. 마감일 고르기 창 열린 채 공간을 바꾸면 창을 닫는다(`detachBoard`가 도구 상태를 비움, CLAUDE.md 4-7).

## 10. 개선 v10-b — "마감일이 있는 업무" 보기 다듬기 (2026-11-04 요청, 검토 대기)
- 요청: 마감 묶음에서 본 항목 글·업무 분류가 먼저 보여 항목명을 읽기 어렵다 → **항목명만** 보이고 **마감일로 묶어** 보여 달라.
- 시안: `docs/mockups/1104v10b/due-group.png`(지금 ↔ 개선).
  - 마감일마다 머리줄(남은 날 배지 + `10/26 (월)` + 개수), 임박순(지난 것 맨 위).
  - 줄에는 항목명만(길면 두 줄까지) — 본 항목 글(›)·업무 이름·기록 날짜는 빼고, 업무는 앞 색 점만(마우스를 올리면 업무 이름·기록 날짜).
  - 같은 마감일 안 순서는 지금 그대로(시작 시각 → 기록 날짜), 누르면 그 칸으로 · ✓ 처리 완료 그대로.
