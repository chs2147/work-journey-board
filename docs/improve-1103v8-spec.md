## T1. 항목 시작 시각

### 1-1. 뜻과 규칙
- 항목 하나에 **"그날 몇 시 몇 분에 시작"** 을 하나 붙인다(예: 오전 10시 회의 — 언제 시작해야 하는지 알아보기 위함, 마감 아님). 날짜는 항목이 있는 날이다.
- 시각은 `00:00`~`23:45`, 분은 `:00`·`:15`·`:30`·`:45`만 고를 수 있다.
- 세부 항목에도 붙일 수 있다(본 항목·세부 항목 같은 규칙).
- 시각이 지났는지 표시·추적하지 않는다(2026-11-03 사용자 결정).

### 1-2. 화면 (시안 `t1-due-time.png`)
- **꼬리표**: 항목 글 **앞**에 `⏰ 10:00`(파랑, 시작 시각이라 앞에 둔다). 꼬리표를 누르면 시각 고르기가 열린다.
- **여는 길**: ① 항목에 마우스를 올리면 나오는 도구의 새 **⋯** 단추 › **시작 시각…** ② `Alt+O`(맥 `⌥O`) ③ 꼬리표 누르기.
- **시각 고르기 창**:
  - 시 단추 `08`~`19`(자주 쓰는 시간) + [더 보기]로 `00`~`23` 전체.
  - 분 단추 `:00` `:15` `:30` `:45`.
  - [지우기] · [취소] · [**10:00**](확인 단추에 고른 시각).
  - 키보드: `↑`/`↓` 15분씩 · 숫자 바로(`1430`·`930` → 14:30·09:30, 15분이 아니면 가까운 15분으로 내림) · `Enter` 확인 · `Delete` 지우기 · `Esc` 취소.
  - 새로 열 때 기본값: 오늘 칸이면 지금 시각 다음 15분, 다른 날은 `09:00`.
- **데일리 뷰**: 같은 꼬리표·같은 창. **중요 업무 패널**: 날짜 옆에 `10:00`, 같은 날 안에서 시각 순으로 정렬(시각 없는 것은 뒤).
- 맥 표기: 단축키 안내는 `⌥O`로 자동 변환(platformText).

### 1-3. 데이터 — 구조 v10
```sql
-- 0010_start_time.sql (전진 전용, 직전 자동 백업 _pre-migration-v10)
ALTER TABLE entry_item ADD COLUMN start_time TEXT
  CHECK (start_time IS NULL OR (start_time GLOB '[0-2][0-9]:[0-5][0-9]' AND substr(start_time, 4, 2) IN ('00','15','30','45') AND substr(start_time, 1, 2) <= '23'));
```
- 도메인 `src/domain/startTime.ts`(순수 함수): `parseTimeInput`·`snap15`·`stepTime`·`compareByTime` + 단위 테스트.
- 저장 경로는 지금 칸 저장(`saveCells`)에 `startTime`을 더한다 — 항목 id 그대로라 실행 취소·되돌리기 한 단계.
- **되돌려 설치(1.6.0 이하)**: 열 하나가 더해질 뿐이라 옛 판에서도 일지는 열리고 시각만 보이지 않는다(옛 판이 칸을 저장하면 그 칸 시각이 지워질 수 있음 — 릴리스 노트 `## 주의`).

### 1-4. 다른 기능과의 관계(추천안)
| 기능 | 시작 시각 | 이유 |
|---|---|---|
| 주간 요약(자동 집계) | **넣지 않음** | 주간 보고 글에 하루 안 시각은 소음 — 골든 테스트 그대로 |
| 엑셀 상세 기록 시트 | **`시작 시각` 열 추가** | 기록 보관용 표에는 남겨 둔다 |
| 직전 기록 가져오기·매주 반복 | **복사하지 않음** | 시각은 그날만의 약속 |
| 다른 날로 옮기기(T4) | **그대로 따라감** | 같은 항목이 날만 바뀜 |
| 검색·인사이트 타임라인 | 타임라인 항목 옆에 작게 `14:30` | 경과를 볼 때 참고 |
| 지남 표시·알림 | **하지 않음** | 2026-11-03 사용자 결정(시작 시각을 알아보는 용도) |

## T2. 첫 실행 — 업무가 추가되지 않음 (버그)

### 2-1. 원인 (재현 확인)
- 첫 실행 3단계 "지금 하고 있는 업무를 적어 보세요"에서 이름을 입력하고 **`Enter` 없이 [보드 열기 →]** 를 누르면, 입력란에 남은 이름은 목록에 들어가지 않은 채 버려진다 → 보드에 업무 0개.
  - 브라우저 모드에서 재현: 이름 입력 → [보드 열기] → 업무 행 0개.
- 맥에서는 한 번 더 겹친다. 한글 입력 중 `Enter`는 마지막 글자를 확정하는 데 쓰이고, WebKit이 그 `Enter`를 조합 중 키(`keyCode 229`)로 보내서 앱이 "추가"로 받지 않는다. 그래서 `Enter`를 한 번 더 눌러야 들어가고, 그걸 모르면 이름이 칩으로 들어가지 않는다.
- 보드 아래 [+ 업무 추가] 입력란에도 맥 한글 `Enter` 문제가 같은 방식으로 있다.

### 2-2. 고치기
- [보드 열기]를 누르면 **입력란에 남은 이름도 함께 추가**한다(칩 목록 + 남은 글).
- 한 줄 이름 입력란(첫 실행 업무 이름 · 보드 [+ 업무 추가])은 공용 도우미 `onEnterCommit`을 쓴다. 한글 조합을 확정한 `Enter`도 "추가"로 처리한다.
  - 조합 중 `Enter`가 오면 확정 직후 한 번 추가한다.
  - 윈도우처럼 확정 뒤 `Enter`가 한 번 더 오면, 이미 추가해 입력란이 비어 있어 두 번 들어가지 않는다.
- 칸 편집기(개조식 입력)는 바꾸지 않는다(매일 기록 동작 그대로, 4-6).
- E2E: `Enter` 없이 [보드 열기] → 업무 1개 / 조합 확정 `Enter`(229) 한 번 → 칩 1개.

## T4. 다른 날로 옮기기 (시안 `t4-move-date.png`)

### 4-1. 동작
- 고른 항목을 **같은 업무의 다른 날 칸 맨 아래**로 옮긴다.
  - 본 항목이면 **세부 항목이 함께** 간다(지금 끌어 옮기기와 같은 규칙).
  - 세부 항목 하나만 옮기면 옮긴 날에서 본 항목이 된다.
- **여는 길**: 항목 도구 ⋯ › **다른 날로 옮기기**, `Alt+D`(맥 `⌥D`).
- **창**:
  - 빠른 단추 [다음 주 같은 요일 · 10/29(목)] [이전 주 같은 요일 · 10/15(목)] [내일 · 10/23(금)].
  - 그 아래 **달력**(월 넘기기, 오늘 테두리, 주말·공휴일 빨간 글자), [옮기기].
  - 키보드: `←→↑↓` 날짜 이동 · `PageUp/PageDown` 달 이동 · `Enter` 옮기기 · `Esc`.
- 옮긴 뒤 알림 "★ 1개·세부 2개를 11/4(수)로 옮겼습니다 [그 날로 가기] [되돌리기]".
  - 실행 취소(`Ctrl+Z`) 한 단계로 원래 칸·원래 자리로 돌아온다.
- 같은 날을 고르면 아무것도 하지 않는다.

### 4-2. 따라가는 것
| 항목에 붙은 것 | 옮긴 뒤 |
|---|---|
| ★ 중요 표시·처리 완료 | 그대로(항목 id 같음) → **중요 업무 패널이 새 날짜 묶음으로**(지난 날짜 ↔ 이번 주 ↔ 다음 주 이후) |
| ⏰ 시작 시각(T1) | 그대로 |
| ↻ 매주 반복 연결 | 그대로(그 주는 이미 만든 주로 기록돼 원래 자리에 다시 생기지 않음) |
| 🗄 Cabinet 연결 | 그대로 |
| 연결된 메모 상자 | 상자는 **원래 주 메모 보드에 그대로**, 연결도 유지 — 다른 주로 갔으면 타이틀 띠에 "11/4(수) · 항목 글"로 보이고 누르면 그 날로(8절 D5) |
| 가져오기 묶음 | 그대로 |

### 4-3. 저장
- 다른 주의 칸은 지금 화면에 없으므로 저장소에서 그 칸을 읽어 끝에 붙인다.
- 두 칸을 한 batch로 쓴다(`saveCells`, 받는 칸 먼저 — 지금 `moveRowsTo`와 같은 길).
- 옮긴 날이 업무의 활성 구간 밖이어도 그 주에 기록이 생기므로 보드에 보인다(data-spec 4절 규칙 그대로).
- 휴일·연차인 날도 옮길 수 있다(창에서 그 날짜를 빨간 글자로 보여 준다).

## 5. 항목 도구 ⋯ (T1·T4 공통) — 구현에서 바꾼 점
> 구현 중 확인(2026-11-03): 좁은 칸에서는 마우스를 올렸을 때 보이는 ⋯가 글 가운데를 덮어, 글을 누르면 ⋯가 눌렸다(기존 E2E가 잡음). 그래서 **⋯는 항목에 커서가 있을 때만** 보이고, 마우스로는 **항목 오른쪽 클릭**으로 같은 메뉴를 연다(글을 고른 채 오른쪽 클릭하면 기본 메뉴 — 복사 등).

- 항목에 마우스를 올리면 나오는 도구(☆ · ↻ · 📝 · 🗄 · 🗑) 끝에 **⋯** 하나를 더한다. 메뉴는 두 줄이다: ⏰ 시작 시각… `Alt+O` / 📅 다른 날로 옮기기 `Alt+D`.
- 아이콘을 더 늘리지 않아 칸이 붐비지 않는다. 앞으로 항목 동작은 이 메뉴에 모은다.
- 단축키 표(overview 10-3)·이용 가이드 02(매일 기록)·04(중요 업무)·부록을 함께 고친다.
