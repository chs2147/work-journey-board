## 2. 현재 구현 분석

### Universe

- `UniverseScene.tsx`: Three.js + OrbitControls의 damping과 requestAnimationFrame, 은하↔포커스 카메라 이동을 이미 제공한다. 사용자가 조작하지 않을 때의 카메라 자동 움직임은 없다.
- `UniverseView.tsx`: 다이나믹3D/정적2D 선택은 PC 설정 `universeMotion`에 저장한다. 모션 감소 설정·비활성 창 처리와 기존 v18 성운/별빛 배경을 갖고 있다.
- 티저 `site/features.js`: 비조작 시 각도를 시간에 비례해 증가시키고, 드래그와 휠로 사용자가 조작할 수 있다. 이를 단순 복제하면 업무 노드를 읽는 위치가 지속 변하므로 앱에서는 더 작은 연출을 추천한다.
- 상단 ‘주간 보드로’는 UniverseView가 아닌 `src/ui/common/TopBar.tsx`의 `universe-back` 버튼이다. 다른 메뉴와 동일하게 좌측 주간 보드 메뉴로 이동하도록 해당 버튼을 제거한다. 제목/부제와 좌측 메뉴는 유지한다.

### 업무 노트 PDF

- `TaskNoteWindow.exportDoc` → `writeCabiDocument` → `cabiPdf` → 플랫폼 파일 저장 순서이다.
- `cabiPdf.ts`는 번들된 GowunDodum WOFF2를 fontkit/pdf-lib로 부분 포함하고 제목·본문·표·이미지를 직접 그린다.
- 동일 폰트·옵션으로 제목 ‘Cabi.NET 한글 제목’과 본문 ‘업무노트 PDF 본문 123 ABC’를 그린 최소 재현 PDF에서 텍스트 추출은 성공하지만 Poppler 실제 렌더링 결과는 빈 페이지였다. 전체 폰트를 그대로 포함한 비교 PDF도 폰트 오류를 출력했다. **글꼴 포함/인코딩 경로가 유력한 원인**이며, 실제 앱에서 내려받은 파일의 렌더링과 비교해 원인을 확정한다. 단순 `subset: false` 전환만으로 해결된다고 판단하지 않는다.
- 기존 CSP PDF 검사는 `%PDF` 헤더와 페이지 개수만 확인해, 글자가 보이지 않는 결함을 검출하지 못했다.

### 업무 메모보드 내보내기

- `TaskBoardWindow.tsx`: 헤더 버튼을 누르면 전체 너비의 두 번째 `.toolbar` 줄에 Markdown / PNG 버튼을 표시한다.
- 업무 노트·메모 스냅샷은 버튼에 연결된 팝업 메뉴를 사용한다. 보드도 같은 표현·입력 규칙으로 정리한다.

## 3. Universe 자동 움직임 비교안

| 안 | 움직임 | 용도·장단점 |
|---|---|---|
| **A · 미세 궤도 / 추천** | 기준 카메라 주위 좌우 약 ±2.5°, 상하 약 ±0.6°를 120~150초 주기로 왕복 | 공간감을 살리고 위치 변화가 작아 읽기 편함. 선택 노드를 고정 중심으로 유지 |
| B · 부유하는 공간 | 회전 없이 화면상 약 ±5px의 느린 부유 | 가장 잔잔하고 라벨 읽기가 쉬움. 3D 회전의 인상은 약함 |
| C · 느린 순환 | 약 180초에 한 바퀴 수평 순환 | 티저와 가장 가까운 전시 효과. 노드 위치가 계속 달라 읽기 부담이 큼 |

수치는 초기 튜닝 기준이며 구현 중 실제 데이터 밀도와 프레임 성능을 확인한다. 시안에서는 세 안을 비교하지만 **최종 앱에는 선택한 한 안과 ON/OFF만 제공**하는 것을 추천한다. 사용자가 원하면 여러 유형 선택으로 확장할 수 있다.

### 공통 UI와 기본값

- 지도 상단 오른쪽에 기존 버튼과 동일한 모노그램 `⏸ / ▶` 아이콘 버튼을 배치한다. 보이는 긴 설명·별도 패널 없이 title/툴팁과 접근 가능한 이름으로 ‘자동 움직임 일시정지/재생’을 제공한다.
- 다이나믹3D의 은하·포커스에서 기본 ON. 끄더라도 3D 드래그·휠·직접 탐색은 계속 사용할 수 있다. 2D 선택과 자동 움직임 OFF는 서로 다른 상태다.
- PC 설정에 선택을 저장하며 DB 마이그레이션은 하지 않는다. 기존 설정 파일과 Rust/브라우저 설정 보존·정규화 경로를 확인하고 새 선택값이 유실되지 않도록 양쪽을 맞춘다.
- 정적2D·목록 모드에서는 자동 움직임 버튼을 비활성화하고 툴팁으로 이유를 안내한다. 3D 지도로 돌아오면 저장한 ON/OFF를 적용한다.
- OS 모션 감소를 우선하고, 해당 상태에서 자동 재생을 억제한다. 기존 사용자 선택값을 지우지 않는다. 비활성/가려진 창에서 자동 움직임을 멈추고 복귀 때 지나간 시간을 몰아서 재생하지 않는다.
- 자동 움직임 OFF는 카메라뿐 아니라 자동 배경 부유/별빛 연출도 정지시킨다. 수동 3D 탐색과 은하↔포커스 전환은 유지하며 모션 감소 시 전환 애니메이션도 기존 규칙을 따른다.

### 조작과 카메라 안정성

- 포인터 드래그·휠·터치·키보드 탐색 중 자동 움직임 정지. 조작이 끝난 3초 뒤 현재 시점에서 부드럽게 재개한다. 노드/라벨 위 탐색과 편집/모달 중에도 자동 움직임을 쉰다.
- 마지막 수동 조작 카메라를 새 기준으로 삼아, 자동 재개·ON/OFF 시 원래 시점으로 튀지 않는다. OFF는 현재 위치를 유지한다.
- 포커스는 대상 노드를 중심에 유지하고 카메라 거리/줌을 바꾸지 않는다. 자동 움직임은 기존 모드 전환의 `zoomIntent`로 취급하지 않아 자동으로 은하↔포커스를 오가지 않게 한다.
- 카메라 전환 flight 중 자동 움직임을 멈추고 완료 후 재개한다. 상태 토글이 Three.js 장면 재생성이나 선택/카메라 초기화를 일으키지 않도록 기존 render loop와 ref에 연결한다.
- delta time 기준으로 프레임 속도에 독립적으로 적용하고, 기존 WebGL 실패 시 2D 대체와 자원 정리를 유지한다.

## 4. PDF 수정 방향

1. 실제 에디터에서 작성/가져오기한 노트를 내보내 빈 페이지를 재현한다. 클릭 시 최신 제목·본문 JSON과 문서/공간 식별자를 확보하고, 저장 대기·창 간 변경 때문에 오래된 내용이 사용되는지도 별도로 확인한다.
2. PDF에 적합한 정적 TTF/OTF 폰트와 CID/GID 매핑을 검증한다. 우선 같은 GowunDodum의 공식 글꼴을 사용하고, 필요하면 라이선스를 확인한 한글 글꼴을 로컬 번들한다. 런타임 글꼴 다운로드/외부 전송은 하지 않는다.
3. 제목·한글/영문/숫자·긴 문단·계층 목록·체크리스트·표·이미지를 포함한 대표 PDF를 생성한다. 이미지가 없는 한글 본문 영역도 실제로 렌더링되는지 확인한다.
4. 회귀 검사는 PDF 파일 생성/페이지 수뿐 아니라 **페이지를 이미지로 렌더링한 결과의 제목/본문 영역에 글자가 있는지**와 추출 텍스트를 함께 검사한다. 다중 페이지·이미지 누락·빈 노트·지원하지 않는 문자도 확인한다.
5. Windows/macOS에서 내려받은 같은 문서를 기본 PDF 뷰어로 확인하는 실기 체크 항목을 남긴다. 원본 노트/이미지를 수정하지 않으며 기존 내보내기 경로 가드를 유지한다.

## 5. 내보내기 메뉴 통일안

**추천: 기존 내보내기 버튼에 연결된 팝오버 메뉴.**

- 업무 메모보드: Markdown으로 저장… / PNG로 저장… 두 항목. 기존 지원 형식을 유지한다.
- 업무 노트: Markdown / PDF 항목과 동일한 아이콘+텍스트·간격·정렬·호버·포커스 문법으로 맞춘다. 동작과 관련 없는 새 설명줄/카테고리명은 추가하지 않는다.
- 버튼 바로 아래 오른쪽 정렬, 창 가장자리에서 넘치지 않게 배치. 새 가로 툴바 줄이 생겨 보드 높이가 바뀌는 현상 제거.
- `aria-haspopup=menu`, `aria-expanded`, 메뉴/메뉴항목 역할, 방향키·Enter/Space·Esc, 바깥 클릭과 항목 선택 시 닫기, 버튼 포커스 복귀를 제공한다.
- 문서 내보내기 메뉴는 공통 스타일/동작을 재사용하되, 주간 보드의 전체 내보내기 설정 화면까지 불필요하게 바꾸지 않는다.
- 보드의 스냅샷 메뉴에서 접근하는 동일 내보내기 경로도 유지한다. 중복 클릭 중 생성/저장 동작이 겹치지 않도록 한다.

## 7. 최종 승인·구현 (초기 비교안에 우선)

사용자는 A안과 C안을 각각 모노그램 아이콘으로 전환하도록 승인했다. B안은 비교 시안에만 남는다. 기본 A/자동 ON, 독립 재생/정지 아이콘과 PC 설정(`universeAutoMotion`, `universeAutoStyle`)을 제공한다. 시점/선택/줌을 유지하고 3초 대기·모션 감소/팝업/비활성 창 제어를 기존 render loop에 통합했다. 상단 복귀 버튼은 제거했다.

PDF는 기존 WOFF2의 빈 렌더링, 공식 TTF 부분 포함의 글자 누락, 공식 TTF 전체 포함의 정상 한글/영문/숫자 렌더링을 비교 확인했다. 동일 GowunDodum TTF를 기존 OFL 라이선스로 로컬 번들하고 전체 포함한다. 최신 에디터 JSON을 내보낸다. CI에 Poppler를 설치해 실제 PDF 제목/본문의 렌더링을 별도로 검사하며 파일 헤더/페이지 수·추출 텍스트만으로 통과시키지 않는다.

업무 보드는 기존 노트 메뉴와 같은 Cabi.NET 메뉴 스타일의 버튼 연결 팝오버로 변경했다. 보드 높이를 바꾸지 않으며 Markdown/PNG·방향키·Esc/바깥 클릭·포커스 복귀·중복 실행 방지를 지원한다. 기존 업무 노트의 관리/삭제 기능은 그대로 제공한다.

커밋/푸시·설치판 빌드·main 반영은 실행하지 않았다.
